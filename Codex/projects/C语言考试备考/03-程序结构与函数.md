# 03-程序结构与函数
> 使用约定见 [[README]]。只提供题目，不含答案或解题步骤。

## 3.01 程序结构、声明与ANSI C函数定义
**简讲：**程序从main进入；函数先声明后调用，原型明确返回类型和参数类型。使用int main(void)，使用相应头文件声明库函数；不使用旧式隐含int。

**练习**
- [ ] **3.01-1** 写含main和int max2(int a,int b)的完整程序，由main读入两数并调用max2。
- [ ] **3.01-2** 把旧式定义int add(a,b) int a; int b; {return a+b;}改为ANSI原型格式。
- [ ] **3.01-3** 改正主调函数在前、被调函数在后但缺少原型的程序，并说明声明和定义的区别。
- [ ] **3.01-4** 写程序包含两个自定义函数：计算平方和立方，main输出输入整数的两种结果；输入限制-100至100。

## 3.02 形参、实参与值传递
**简讲：**C参数按值传递；修改普通形参不会改变调用者变量，形参变量在不同调用间独立。

**练习**
- [ ] **3.02-1** 对void f(int x){x+=5;}在main中令a=2并调用f(a)，写出a并解释传递过程。
- [ ] **3.02-2** 写函数int sum(int a,int b)，分别用变量、常量和表达式作为实参调用。
- [ ] **3.02-3** 分析void swap(int a,int b){int t=a;a=b;b=t;}为何不能交换调用者的两个变量，并画出值的变化。

## 3.03 指针参数、数组参数与输出参数
**简讲：**指针也是按值传递，但通过它可修改调用者对象；数组形参会调整为指针，长度应另行传入。二维数组参数需明确行宽或采用相容接口。

**练习**
- [ ] **3.03-1** 写void swap(int *a,int *b)，在main中调用并验证变量交换。
- [ ] **3.03-2** 写int sum_array(const int *a,int n)，求数组和；n=0时返回0。
- [ ] **3.03-3** 写函数通过两个输出参数返回非空整数数组的最大值和最小值。
- [ ] **3.03-4** 写函数计算3列矩阵各行之和，行数由参数传入，并写调用程序。
- [ ] **3.03-5** 写函数把调用者的int *置为空，说明为什么仅传int *不够。

## 3.04 返回值与指针返回值
**简讲：**返回表达式转换为函数返回类型；返回指针必须指向返回后仍有效的对象。可返回调用者数组中的元素指针，不能返回局部自动对象地址。

**练习**
- [ ] **3.04-1** 写函数在数组中查找第一个等于x的元素，返回其地址；未找到返回NULL。
- [ ] **3.04-2** 改正int *f(void){int x=10; return &x;}，分别用调用者提供存储和静态存储两种方案。
- [ ] **3.04-3** 写函数返回两个有效int指针中所指值较大者的地址，同值返回第一个。
- [ ] **3.04-4** 比较return 3.8;出现在int返回函数与double返回函数中的返回值。

## 3.05 函数调用、嵌套调用与函数指针
**简讲：**调用由函数名和实参列表组成；函数指针必须与目标函数类型相容，可用它选择运算。嵌套调用不同于在函数体中嵌套定义函数，后者不属于标准C。

**练习**
- [ ] **3.05-1** 写add和sub函数，定义合适函数指针，根据用户输入选择调用。
- [ ] **3.05-2** 对int f(int x){return x+1;} int g(int x){return 2*x;}求f(g(3))与g(f(3))。
- [ ] **3.05-3** 定义接收二元整数函数指针的apply函数，分别传入加法和较大值函数。
- [ ] **3.05-4** 判断标准C是否允许在main函数内部定义另一个函数，并改写为合法结构。

## 3.06 递归
**简讲：**递归必须有可达终止条件，并使规模逐步缩小；每层调用的自动局部变量独立。注意递归深度和重复计算。

**练习**
- [ ] **3.06-1** 递归计算0—12范围整数的阶乘，列出计算4!的调用及返回顺序，不给结果。
- [ ] **3.06-2** 递归求两个非负整数的最大公约数；两数不同时为0。
- [ ] **3.06-3** 递归逆序输出一个正整数的十进制数字，不用数组或字符串。
- [ ] **3.06-4** 递归计算斐波那契数F(0)=0、F(1)=1，并比较其与迭代法的重复计算情况。
- [ ] **3.06-5** 写递归函数计算整数数组前n项之和，n=0为终止条件。

## 3.07 数学库函数
**简讲：**math.h声明cos、sqrt、pow、exp、fabs、log、log10；cos参数为弧度，log是自然对数。计算前注意定义域；链接方式依编译环境确定。

**练习**
- [ ] **3.07-1** 输入非负double数x，输出sqrt(x)、pow(x,3)、fabs(x-2)。
- [ ] **3.07-2** 输入角度，转换为弧度后用cos计算余弦；自行定义足够精度的PI。
- [ ] **3.07-3** 输入正数x，输出log(x)、log10(x)、exp(log(x))，比较最后一项与x的误差。
- [ ] **3.07-4** 利用sqrt求一元二次方程的实根，要求a不为0，判别式为负时报告无实根。

## 3.08 字符库函数
**简讲：**ctype.h提供isalnum、isalpha、isdigit、islower、toupper等；分类结果为零或非零，不应假定真必为1。参数须为EOF或可表示为unsigned char的值。

**练习**
- [ ] **3.08-1** 读取一行ASCII文本，分别统计字母、数字、字母或数字、其他字符的数量；换行不计入。
- [ ] **3.08-2** 用islower和toupper把字符串中的小写字母转为大写。
- [ ] **3.08-3** 用getchar读取到EOF，统计数字字符数量；明确接收变量的类型。
- [ ] **3.08-4** 对char c来源于任意字节的情况，写出安全调用isalpha的形式，并说明原因。

## 3.09 字符串库函数
**简讲：**string.h提供strlen、strcpy、strcat、strcmp；目标数组须有足够容量，参数须满足字符串终止等要求。strcmp只保证结果的符号，不保证具体差值。

**练习**
- [ ] **3.09-1** 对char s[20]="abc";比较strlen(s)与sizeof(s)，说明各自测量什么。
- [ ] **3.09-2** 将"hello"复制到数组，再连接" C"，写出容量充足的代码。
- [ ] **3.09-3** 用strcmp判断输入的两个单词是否相同，或谁的字典序在前。
- [ ] **3.09-4** 找出char s[5]="abc"; strcat(s,"de");的问题并修复。
- [ ] **3.09-5** 不用strcmp实现字符串比较，只要求返回负数、0或正数，不要求具体数值。
