# 06-常用算法
> 使用约定见 [[README]]。只提供题目，不含答案或解题步骤。

## 6.01 冒泡排序
**简讲：**反复比较相邻元素并交换，每轮使一个极值就位；用是否发生交换的标志可提前结束。相等元素不交换可保持稳定性。

**练习**
- [ ] **6.01-1** 对{5,1,4,2,8}按升序冒泡，每轮从左至右扫描，写出每轮后的数组。
- [ ] **6.01-2** 编写带提前结束标志的升序冒泡排序函数，支持n=0或1。
- [ ] **6.01-3** 把冒泡改为降序排序，说明需修改哪个比较条件。
- [ ] **6.01-4** 对学生结构数组按成绩升序冒泡，同分保持输入顺序；同时移动所有字段。
- [ ] **6.01-5** 比较已升序与逆序的n元素数组在优化冒泡下的比较次数数量级。

## 6.02 选择排序
**简讲：**每轮从未排序区间找最小值，与该区间首元素交换；普通交换式选择排序通常不稳定。

**练习**
- [ ] **6.02-1** 对{4,2,5,1,3}做升序选择排序，写出每轮结果。
- [ ] **6.02-2** 编写升序选择排序函数，支持空数组和重复值。
- [ ] **6.02-3** 给出一个含相等键及身份标签的记录数组，演示普通选择排序可能改变同键顺序。
- [ ] **6.02-4** 用选择排序把字符串数组按strcmp定义的字典序排列。

## 6.03 直接插入排序
**简讲：**把待插元素插入已有序前缀；先保存待插值，再向后移动较大元素。只移动严格更大的元素可保持稳定性。

**练习**
- [ ] **6.03-1** 对{5,2,4,6,1,3}做升序直接插入排序，写出每次插入后的数组。
- [ ] **6.03-2** 编写插入排序函数，特别检查待插值小于所有已排序元素的情况。
- [ ] **6.03-3** 将插入排序用于学生结构数组，成绩降序且同分保持原顺序。
- [ ] **6.03-4** 比较冒泡、选择、插入排序的基本操作、通常稳定性及最坏时间复杂度。

## 6.04 顺序查找与无序数据遍历
**简讲：**从头检查每个元素，适用于无序数据；需约定返回下标、地址或未找到标志。多个匹配项须明确返回第一项还是全部。

**练习**
- [ ] **6.04-1** 写函数返回无序数组中目标值首次出现的下标，未找到返回-1。
- [ ] **6.04-2** 输出目标值出现的全部下标及次数。
- [ ] **6.04-3** 在学生结构数组中按学号查找，输出完整记录，未找到时报告。
- [ ] **6.04-4** 遍历数组找第二大的不同数值；不足两个不同值时报告不存在。

## 6.05 二分查找
**简讲：**二分要求序列按比较规则有序；每轮缩小区间，统一闭区间或半开区间写法。中点可用low+(high-low)/2，注意重复值及边界。

**练习**
- [ ] **6.05-1** 对升序{1,3,5,7,9,11,13}查找9，按闭区间记录每轮low、high、mid。
- [ ] **6.05-2** 编写升序数组二分查找，支持空数组及未找到情况。
- [ ] **6.05-3** 把算法改为降序数组查找，说明左右区间更新规则。
- [ ] **6.05-4** 在有重复值的升序数组中查找目标值首次出现的下标。
- [ ] **6.05-5** 构造并测试目标在首位、末位、小于最小值、大于最大值、位于两值之间的输入，只写预期行为不写答案表。

## 6.06 一维数组遍历与统计
**简讲：**一次遍历可累计和、极值、计数；极值初始化应来自有效数据，不能随意设为0。空数组须另作约定。

**练习**
- [ ] **6.06-1** 求非空整数数组的最大值、最小值和平均值；数据范围-1000至1000，长度最多100。
- [ ] **6.06-2** 原地逆置数组，不能使用第二个等长数组。
- [ ] **6.06-3** 删除数组中的全部0并保持其他元素的相对顺序，返回新长度。
- [ ] **6.06-4** 合并两个已升序数组为新的升序数组，保留重复元素。

## 6.07 二维数组遍历与矩阵算法
**简讲：**矩阵可按行、列或指定区域遍历；对角线与边界条件应由行列下标明确表达，避免角点重复累计。

**练习**
- [ ] **6.07-1** 计算n×n矩阵主对角线和副对角线之和，中心交点只计一次，1<=n<=10。
- [ ] **6.07-2** 计算m×n矩阵的边界元素和，正确处理单行、单列，1<=m,n<=10。
- [ ] **6.07-3** 输出3×4矩阵中的鞍点：该元素在所在行最大且所在列最小，允许并列且输出全部。
- [ ] **6.07-4** 计算两个2×2整数矩阵的乘积；输入绝对值不超过100。

## 6.08 链表遍历与综合算法
**简讲：**链表不支持数组式随机访问；通过游走指针保存当前位置。修改链接时先保存后续节点，区分只读遍历与结构变更。

**练习**
- [ ] **6.08-1** 遍历非空链表，返回最大值节点地址；同值返回第一个，空表返回NULL。
- [ ] **6.08-2** 原地逆置单链表，只调整next，不额外创建节点。
- [ ] **6.08-3** 合并两条升序链表，复用原节点；原表无共享节点，明确合并后节点归结果表所有。
- [ ] **6.08-4** 删除升序链表的重复值节点，每个不同值仅保留一个，并释放被删节点。

## 6.09 文件遍历综合算法
**简讲：**遍历文件可累计统计或逐条筛选；读取返回值控制循环，文件结束、格式错误与读错误须分别处理。

**练习**

- [ ] **6.09-3** 按输入文件顺序筛选及格学生写入新文件，同时输出人数与平均成绩；没有及格者单独报告。
- [ ] **6.09-4** 统计文本中各数字字符0—9的出现次数，并按数字顺序输出到结果文件。

## 6.10 多项式与简单数值计算
**简讲：**多项式可逐项算幂，也可用霍纳法按系数从高次到低次反复乘加；浮点结果可能有舍入误差，计算需明确误差或次数条件。

**练习**
- [ ] **6.10-1** 用循环计算P(x)=3x^4-2x^3+5x-7，禁止调用pow。
- [ ] **6.10-2** 写霍纳法函数计算n次多项式，系数数组从最高次到常数项存放，0<=n<=20。
- [ ] **6.10-3** 用循环求1+1/2+…+1/n，1<=n<=10000，注意整数除法。
- [ ] **6.10-4** 利用exp(x)的级数从常数项起累加，|x|<=1，当下一项绝对值小于1e-8时停止；与exp比较误差。

## 6.11 进制转换
**简讲：**十进制整数转其他进制可反复除基取余再逆序；其他进制转十进制可从左到右乘基加当前位值。需验证数字合法性及范围。

**练习**

- [ ] **6.11-2** 编写函数把合法八进制字符串转为十进制；最多7位。
- [ ] **6.11-3** 将非负十进制整数转换为2—16中的指定进制，用A—F表示10—15。
- [ ] **6.11-4** 把最多6位十六进制字符串转为十进制，允许大小写字母，遇非法字符报告错误。
