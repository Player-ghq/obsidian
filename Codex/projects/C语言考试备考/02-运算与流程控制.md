# 02-运算与流程控制

## 2.01 算术、自增与自减
**简讲：**整数除法向零截断；余数运算用于整数。前置自增先更新再取值，后置先取旧值；同一表达式中对对象的无序修改可能造成未定义行为。

**练习**
- [ ] **2.01-1** 计算17/5、17%5、-17/5、-17%5。
- [ ] **2.01-2** 分别独立执行int i=3; int a=++i;和int i=3; int a=i++;列出a、i。
- [ ] **2.01-3** 写程序将非负三位整数拆成百、十、个位，并输出各位和。
- [ ] **2.01-4** 判断i=i++ + 1;能否得到标准C保证的结果，说明原因。
- [ ] **2.01-5** 读入非负秒数，换算为小时、分钟和秒，余数均取规范范围。

## 2.02 关系与逻辑运算
**简讲：**关系、逻辑运算结果为int型0或1；非零视为真。&&、||有短路求值，不能把数学连写不等式直接照搬为C表达式。

**练习**
- [ ] **2.02-1** 计算3<2、3!=2、!5、!!(-2)、2&&7、0||4。
- [ ] **2.02-2** 把“x在闭区间[10,20]内”写为C表达式，指出10<=x<=20的问题。
- [ ] **2.02-3** 对int x=0,y=3;分别独立分析x && ++y和!x || ++y求值后y的值。
- [ ] **2.02-4** 编写闰年判断程序，输入公历年份，输出是否闰年。

## 2.03 位运算
**简讲：**&、|、^、~、<<、>>操作整数的位；本册优先使用unsigned。移位数须小于类型位宽，避免对负有符号数移位的可移植性问题。

**练习**
- [ ] **2.03-1** 计算无符号数12u & 10u、12u | 10u、12u ^ 10u。
- [ ] **2.03-2** 用位运算判断非负整数的奇偶性。
- [ ] **2.03-3** 对unsigned x，写表达式将从最低位起编号为3的位设1、清0及翻转。
- [ ] **2.03-4** 假定unsigned为32位，计算1u<<5与32u>>2，并判断1u<<32是否有效。
- [ ] **2.03-5** 写函数统计unsigned整数二进制表示中的1的个数。

## 2.04 赋值、条件与逗号运算
**简讲：**赋值表达式具有值，复合赋值更新左操作数；?:只求值被选分支。逗号运算按顺序求值并取最后一项的值，函数实参分隔逗号不是逗号运算符。

**练习**
- [ ] **2.04-1** 对int a=2,b=3;执行a+=b*2;后写出a、b。
- [ ] **2.04-2** 用条件运算符求两个整数的较大值，再扩展为三个整数的最大值。
- [ ] **2.04-3** 对int x=2,y=0;求int z=x>0 ? ++x : ++y;之后各变量值。
- [ ] **2.04-4** 对int a=1,b=2;求int c=(a+=2,b*=3,a+b);后的a、b、c。

## 2.05 优先级、结合方向与表达式
**简讲：**优先级决定分组，结合方向解决同优先级的分组；两者不能普遍决定操作数的执行先后。复杂表达式应先补括号再分析。

**练习**
- [ ] **2.05-1** 给a+b*c、a>b&&c!=0、x&1u==0加上体现默认分组的括号。
- [ ] **2.05-2** 对int a,b,c;分析a=b=c=5的分组及最终值。
- [ ] **2.05-3** 对int a=3,b=4,c=2;计算a+b*c>10 && b-c==2。
- [ ] **2.05-4** 比较(*p)++、*p++、++*p的作用，假定p指向数组中有足够后续元素的位置。
- [ ] **2.05-5** 说明f()+g()能否仅依据加法结合方向断言f先调用。

## 2.06 隐式与强制类型转换
**简讲：**运算和赋值可能发生类型转换；强制转换用(类型)表达式。整数除法完成后再转double无法恢复小数；有符号与无符号混合需注意转换规则。

**练习**
- [ ] **2.06-1** 比较(double)(5/2)、(double)5/2、5/(double)2的结果。
- [ ] **2.06-2** 对double x=3.9; int n=(int)x;求n，再分析x=-3.9的情况。
- [ ] **2.06-3** 输入三个整数，计算保留两位小数的平均值，避免整数除法。
- [ ] **2.06-4** 判断-1 < 1u的结果并从通常算术转换解释；不依赖具体int位宽。

## 2.07 表达式语句、空语句与复合语句
**简讲：**分号结束表达式语句；单独分号是空语句；花括号把多条语句组成一个块，也会形成局部作用域。

**练习**
- [ ] **2.07-1** 分析int i; for(i=0;i<3;i++); printf("%d",i);的输出。
- [ ] **2.07-2** 改正if(x>0); printf("positive");使输出仅在x>0时执行。
- [ ] **2.07-3** 用复合语句实现：若a大于b，则交换二者并累计交换次数。

## 2.08 if与嵌套选择
**简讲：**if条件按零或非零判断；else匹配最近尚未匹配的if。用花括号明确层次，注意条件边界。

## 2.09 switch选择
**简讲：**switch使用整数类型控制表达式，case为互异的整型常量表达式；未遇break会继续执行后续分支。

## 2.10 for、while与do-while
**简讲：**for适合次数明确的循环，while先判断，do-while先执行；循环应明确初值、条件与推进，防止边界错误和死循环。

**练习**

- [ ] **2.10-3** 输入非负整数n，计算n!；限制0<=n<=12，并正确处理0。

## 2.11 break、continue与return
**简讲：**break退出最近一层循环或switch；continue进入最近一层循环的下一轮，在for中会先执行更新表达式；return结束当前函数。

**练习**

- [ ] **2.11-3** 分析for(i=0;i<5;i++){if(i==2) continue; if(i==4) break; printf("%d ",i);}的输出。
