## 统一题目条件

- 以标准C及ANSI函数原型语法为基础；除题目明确讨论外，不使用编译器扩展。使用标准头文件，变量先声明后使用；不依赖旧式隐含声明。
- 题目短片段默认置于合适函数体内，并包含所需头文件；题中给出初值的语句按顺序执行。写完整程序时自行补全声明、函数及输入检查。
- 整数运算仅在结果可表示范围内讨论；若题目要求判断越界、溢出、未定义行为，则需指出问题，不能编造固定输出。输入规模未限定的编程题应自行明确合理上限并检查。
- 不默认int为32位、long为64位，也不默认指针长度；涉及ASCII或特定位宽的题目会另行说明。
- 浮点结果按要求精度输出；若未指定，允许合理精度。读取失败、空输入、未找到等情况按题目处理，不使用未初始化值。
- 文件题默认文本文件；姓名、单词无空格的限制以题面为准。文件名可写为相对路径；须检查打开失败，编程综合题也应检查读写错误并关闭文件。
- `gets`按考纲保留辨析题，实际编程改用`fgets`；不要求在现代编译器上运行`gets`。`NULL`与`EOF`的具体表示不作无依据假定。
- 数学函数均使用`math.h`，字符函数使用`ctype.h`，字符串函数使用`string.h`，动态分配使用`stdlib.h`。字符分类参数需满足函数要求。
- 宏题若要求“展开”，应先按记号替换写表达式；展开过程不等于合法运行结果。未定义行为题只作识别和改正。

## 考纲映射说明

第一章覆盖基本类型及常量、变量、数组、结构、指针及混合定义、链表、void、存储类别/作用域/生存期。第二章覆盖所有所列运算及转换、表达式、语句和流程控制。第三章覆盖程序结构、ANSI函数定义、值/指针参数和返回值、函数指针、嵌套/递归调用及全部所列库函数。第四章覆盖标准输入输出、文本文件打开关闭、字符/行/格式化读写、状态和查找。第五章覆盖预处理、宏、包含与argc/argv。第六章覆盖三种排序、顺序/二分查找、数组/链表/文件遍历、多项式与进制转换。

动态存储、数组指针、条件编译和少量综合算法作为完成上述题目所需的辅助或迁移练习；不据此推定新增考试范围。题量反映知识点拆分，并不代表试卷分值分布。
