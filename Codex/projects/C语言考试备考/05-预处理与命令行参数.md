# 05-预处理与命令行参数
> 使用约定见 [[README]]。只提供题目，不含答案或解题步骤。

## 5.01 预处理基本概念与对象式宏
**简讲：**预处理在正式编译前处理#指令；#define做记号替换，不按变量作用域或类型规则工作，通常不写末尾分号。

**练习**
- [ ] **5.01-1** 用#define定义数组容量100，读取n个整数并求和，检查0<=n<=100。
- [ ] **5.01-2** 写出#define A 2+3下表达式A*4展开后的形式，再修正宏定义。
- [ ] **5.01-3** 比较#define N 10与const int n=10在替换、类型及作用域方面的区别。

## 5.02 带参数宏与副作用
**简讲：**宏参数及整个结果应加括号，但括号不能消除重复求值；含自增、函数调用的实参可能产生副作用或未定义行为。

**练习**
- [ ] **5.02-1** 修正#define SQR(x) x*x，并分析原宏SQR(2+3)的展开形式。
- [ ] **5.02-2** 对#define MAX(a,b) ((a)>(b)?(a):(b))分析MAX(i++,j++)为什么不适合作为安全调用，不要求猜测一个固定结果。
- [ ] **5.02-3** 写求两数较小值的宏；另写一个等效函数，比较参数求值次数。
- [ ] **5.02-4** 展开#define TWICE(x) ((x)+(x))用于TWICE(i++)的结果，判断是否存在未定义行为。

## 5.03 文件包含与条件编译
**简讲：**#include引入头文件声明等内容；尖括号与双引号的搜索规则由实现规定，双引号通常优先查找本地。头文件保护避免重复包含；条件编译按预处理条件选择内容。

**练习**
- [ ] **5.03-1** 为自定义max2函数创建头文件声明，写出调用源文件中的包含语句。
- [ ] **5.03-2** 为util.h写出#ifndef、#define、#endif头文件保护结构。
- [ ] **5.03-3** 用#ifdef DEBUG控制是否输出调试信息，正常结果始终输出。
- [ ] **5.03-4** 列出使用printf、sqrt、isdigit、strlen、malloc各自需包含的标准头文件。

## 5.04 argc与argv
**简讲：**int main(int argc,char *argv[])接收命令行；argc计入程序名，argv[argc]为NULL。argv元素是字符串，使用前先检查参数数量，再解析并验证内容。

**练习**
- [ ] **5.04-1** 程序名为calc，以calc 12 34启动，列出argc及各argv字符串。
- [ ] **5.04-2** 编写程序输出所有用户参数，每行一个，并标注从1起的参数序号。
- [ ] **5.04-3** 编写程序接收两个十进制整数参数并求和；用strtol检查完整转换及int范围，错误时输出用法。
- [ ] **5.04-4** 编写程序接收源文件路径和目标文件路径，逐字符复制文件，缺少参数时报告用法。
- [ ] **5.04-5** 说明argv[1][0]、argv[argc]、argc==1分别表示什么，哪些访问需要先检查argc。
