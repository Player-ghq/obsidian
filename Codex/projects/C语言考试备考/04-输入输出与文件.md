# 04-输入输出与文件
> 使用约定见 [[README]]。只提供题目，不含答案或解题步骤。

## 4.01 printf格式化输出
**简讲：**格式说明需与提升后的实参类型匹配；%d、%u、%ld、%f、%c、%s常用，浮点参数传入printf时使用double。宽度和精度控制显示。

**练习**
- [ ] **4.01-1** 定义int、unsigned、long、double、char和字符串各一个，用匹配格式分别输出。
- [ ] **4.01-2** 对double x=12.3456;写出printf("[%8.2f]",x);的输出，明确空格数量。
- [ ] **4.01-3** 把整数7输出为宽度4左补零的形式，把字符串"C"输出为宽度5左对齐的形式。
- [ ] **4.01-4** 改正printf("%d",3.5);与printf("%f",10);的类型不匹配，不能猜测其输出。

## 4.02 scanf格式、地址与返回值
**简讲：**scanf通常接收目标地址，%f对应float *、%lf对应double *；返回成功赋值项数。%c不跳过空白，格式中的前导空白可跳过空白字符。

**练习**
- [ ] **4.02-1** 读取int、float、double、char各一个，写正确格式和实参。
- [ ] **4.02-2** 给定输入12 x，分析scanf("%d%d",&a,&b)的返回值及哪些变量被成功赋值；假定a、b先初始化为0。
- [ ] **4.02-3** 解释scanf("%d",&n);后立即scanf("%c",&c);可能读到什么，给出跳过空白的写法。
- [ ] **4.02-4** 向char s[10]读取一个单词，限制宽度并检查返回值。
- [ ] **4.02-5** 读取逗号分隔的两个整数，输入格式如12,34；不满足格式时报告错误。

## 4.03 getchar、putchar、puts与gets考纲遗留项
**简讲：**getchar返回int以区分所有unsigned char值与EOF；putchar输出一个字符，puts输出字符串并附换行。gets无法限制长度，C11已删除；只辨析旧题，实际读行使用fgets。

**练习**
- [ ] **4.03-1** 用getchar和putchar复制输入到输出，直到EOF。
- [ ] **4.03-2** 比较puts("abc")与printf("%s","abc")在换行上的区别。
- [ ] **4.03-3** 解释char c; while((c=getchar())!=EOF)的问题，并改正。
- [ ] **4.03-4** 把旧题gets(s);改为容量已知的fgets读取，并去掉末尾可能存在的换行。
- [ ] **4.03-5** 读取一行文本，统计空格数；正确处理文件末尾先于换行到达的情况。

## 4.04 文件概念、FILE指针、文本与二进制
**简讲：**stdio.h中的FILE描述流，FILE *保存流指针；stdin、stdout、stderr为标准流。文本模式可能转换换行等表示，二进制模式按字节保存，二者不能简单等同于可读与不可读。

**练习**
- [ ] **4.04-1** 说明FILE *fp;与磁盘文件之间的关系，列出标准输入、输出、错误流名称。
- [ ] **4.04-2** 比较将整数123用fprintf写成文本与用fwrite写对象表示的区别；只需说明，不要求实现二进制读写。
- [ ] **4.04-3** 说明在一种系统写出的二进制int文件为什么不一定能在另一系统直接读取为相同整数。

## 4.05 fopen、fclose与打开模式
**简讲：**fopen成功返回流指针，失败返回NULL；r要求文件存在，w可能截断，a追加，+允许读写。关闭及写出时也应检查失败。

**练习**
- [ ] **4.05-1** 写程序以只读方式打开data.txt，失败时报告并返回非零状态。
- [ ] **4.05-2** 分别选择模式：读取旧文件、覆盖写报告、追加日志、打开已存在文件用于读写。
- [ ] **4.05-3** 分析以w打开已有成绩文件的后果，并改成追加写方式。
- [ ] **4.05-4** 编写创建文本文件并写入一行后关闭的程序，检查打开、写入和关闭结果。

## 4.06 fscanf与fprintf
**简讲：**格式化文件读写与标准格式化读写类似，但需指定流；读取循环依据成功转换数量，不能先用feof预测下一次读取。

**练习**

- [ ] **4.06-2** 将5名学生的学号、无空格姓名和成绩用fprintf写入文件，每行一条。
- [ ] **4.06-3** 给定文件内容为10 20 x 30，分析while(fscanf(fp,"%d",&x)==1)能读入哪些数据以及为何停止。
- [ ] **4.06-4** 读取每行两个整数的文件，区分正常结束与格式不匹配，不陷入重复读取同一错误字符的循环。

## 4.07 fgetc、fputc与逐字符读写
**简讲：**fgetc以int返回字符或EOF，fputc写字符并可报告失败；逐字符循环适合复制、计数和转换。

**练习**

- [ ] **4.07-2** 统计文件中字符、空格及换行符数量；字符数按成功读到的字节计数。
- [ ] **4.07-3** 把文本文件中的ASCII小写字母改为大写并写入另一个文件。
- [ ] **4.07-4** 统计文本的行数：每个换行结束一行，末尾非空且无换行的一段也算一行，空文件为0行。

## 4.08 fgets、fputs与逐行读写
**简讲：**fgets最多读容量减1个字符，保留读到的换行，成功后补\0；长行可分多次读取。fputs不自动补换行。

**练习**

## 4.09 EOF、feof、ferror与状态检测
**简讲：**EOF是读取返回标志，feof查询已发生的结束状态，ferror查询错误；读取失败后再判断原因。读取成功之前不能用未设置的结束标志预测结束。

**练习**

- [ ] **4.09-2** 写读取循环，结束后用feof、ferror分别识别正常文件结束与读错误。
- [ ] **4.09-3** 解释为什么fscanf转换失败时可能既不是feof也不是ferror，并给出处理策略。
- [ ] **4.09-4** 说明clearerr的作用，并写出清除流状态的调用；此项为帮助理解状态的补充题。
