# 鼠标控制训练

## 目标

鼠标控制要服务于 Valorant 的击杀方式：头线预瞄、首发命中、微调稳定、短时间内处理多个目标。

## 不建议一开始追求

- 夸张大 flick。
- 只刷反应榜单。
- 长时间无脑 deathmatch。
- 每天改灵敏度。

## 灵敏度原则

先固定一个灵敏度至少 2 周。除非明显无法转身或微调过度，否则不要频繁改。

记录：

- DPI
- 游戏内灵敏度
- eDPI
- 鼠标垫空间
- 是否手腕流 / 手臂流 / 混合

## 每日训练

### 1. 头线定位，5 分钟

在靶场或自定义中移动准星：

- 准星始终保持头部高度。
- 经过墙角时，准星提前放到可能出人的位置。
- 不看地面，不看墙中间。

### 2. 慢速首发命中，8 分钟

普通 Bot：

1. 准星移动到头。
2. 确认停稳。
3. 单点。
4. 打不中也不要立刻乱补，先重新定位。

目标：第一发质量高于速度。

### 3. 微调训练，8 分钟

准星故意放在目标头部旁边一点点，然后用小幅度移动修正到头。

用途：解决“拉到了附近但最后一厘米不稳”的问题。

### 4. 多目标转移，5-8 分钟

打掉一个 Bot 后，立刻找下一个头线目标。

要求：准星走直线，停稳再打。

## Aim Trainer 选择

如果使用 Aim Lab / KovaaK，优先选：

- small target precision
- microshot
- sixshot
- static dots
- smooth tracking

每次只练 2-3 个任务，不要刷到疲劳变形。

## 训练记录指标

- 困难 Bot 击杀数。
- 死斗爆头率。
- 首发命中主观评分。
- 是否频繁过拉。
- 是否频繁差一点点没修到头。

## 常见错误

- 一紧张就扫射。
- 准星长期低于头线。
- flick 到身体后直接开枪。
- 看到人先开枪再修准星。
- 连续训练太久，动作质量下降仍硬刷。
