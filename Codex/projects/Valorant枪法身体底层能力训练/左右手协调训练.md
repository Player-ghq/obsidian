# 左右手协调训练

## 目标

Valorant 枪法的关键不是右手甩得多快，而是左手移动和右手瞄准能否同步。很多枪软问题，本质是移动没停稳、peek 节奏乱、准星修正和身体暴露时间不匹配。

## 核心能力

- A/D 急停。
- peek 后准星仍在头线。
- 反拉时不丢准星。
- 移动中观察，停稳后开枪。
- 左手位移服务于右手瞄准，而不是打乱右手。

## 每日训练

### 1. A/D 急停单点，8 分钟

靶场中左右移动：

1. 按 A 移动。
2. 松 A 或轻点 D 停稳。
3. 准星确认在头。
4. 单点。
5. 换方向重复。

要求：宁可慢，也不要移动中开枪。

自检：如果子弹明显发散，说明停得不干净。

### 2. 预瞄出墙，8 分钟

找墙边或箱体：

1. 躲在掩体后。
2. 准星先放在敌人可能头线。
3. A/D 横拉出掩体。
4. 看到目标后只做微调。
5. 停稳单点。

重点：不要出墙后才大幅度找人。

### 3. 肩骗 + 回拉，5 分钟

练短暂露身获取信息：

1. 小身位露出。
2. 立刻回掩体。
3. 不开枪。
4. 记住敌人可能位置。

用途：训练左手控制暴露时间，减少无意义干拉。

### 4. 死斗主题练习，1 局

只关注一个指标：每次死亡前，我是不是在移动中开枪？

如果是，把原因记为“左手问题”，不是枪法问题。

## 常见错误

- 右手已经瞄到，但左手还在移动。
- peek 太宽，暴露给多个角度。
- 出墙后准星低，需要大幅上拉。
- 被打后慌蹲扫，丢掉头线。
- 反拉时鼠标也乱甩，导致准星飞走。

## 每周目标

- 移动中开枪死亡次数下降。
- 预瞄出墙后需要大幅修正的次数下降。
- 死斗中“没停稳就开枪”的自觉次数下降。
