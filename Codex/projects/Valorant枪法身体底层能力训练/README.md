# Valorant 枪法身体底层能力训练

## 项目定位

目标不是单纯堆排位时间，而是训练支撑 Valorant 枪法的身体底层能力：眼睛、左右手协调、鼠标控制、姿势、手腕肩颈耐受和恢复。

2026 考研结束前，本项目默认作为低负担专项训练。每日训练控制在 45-60 分钟，避免挤压学习和睡眠。

## 核心原则

- 先稳定，再变快。
- 先头线预瞄，再追求夸张 flick。
- 先降低死亡错误，再追求击杀集锦。
- 身体疼痛不是训练刺激，是停止信号。
- 每天必须记录，不记录就无法判断是否真的进步。

## 能力模块

1. 眼睛训练：动态视觉、扫点、周边视觉、小地图感知、眼疲劳管理。
2. 左右手协调：键盘移动和鼠标瞄准同步，重点是急停、peek、反拉。
3. 鼠标控制：定位、微调、跟枪、首发命中率、不同距离头线控制。
4. 身体维护：坐姿、肩颈、前臂、手腕、手指耐受和恢复。

## 每日最小训练

如果当天学习压力大，只做最小版本：

1. 眼睛放松 3 分钟。
2. 手腕肩颈激活 5 分钟。
3. Valorant 靶场 10 分钟。
4. 死斗 1 局。
5. 记录 3 个死亡原因。

## 每周复盘指标

- 死斗平均爆头率。
- 靶场困难 Bot 击杀数。
- 排位首死次数。
- 因移动中开枪、准星低、没清点导致的死亡次数。
- 手腕、肩颈、眼睛疲劳评分。
