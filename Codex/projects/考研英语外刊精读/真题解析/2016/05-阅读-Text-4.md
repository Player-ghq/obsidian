# 2016 阅读 Text 4：纸质报纸转型

返回：[[00-索引]]

## 主旨

《纽约时报》最终可能停止印刷，但不应仓促退出；应把纸质版提价并转成服务忠实读者的高端传统产品，以资助品质并完成渐进转型。

## 逐题解析

| 题 | 答案 | 证据与排错 |
| ---: | :---: | --- |
| 36 | A | 印刷设备、配送车辆等基础设施成本高且过度。 |
| 37 | B | Peretti 主张加速但不骤停、提价并重塑定位，即战略调整。 |
| 38 | B | legacy product 面向最忠实、愿意高价支持的读者。 |
| 39 | C | 末段明确说市场变化时更积极比不积极更好。 |
| 40 | B | 标题应抓“把纸报做成奢侈/高端传统产品”；其他项主张骤停、永存或抒情怀旧。 |

## 重点表达

`ditch print` 放弃纸媒；`financial constraints` 财务约束；`dwarf online sales` 远高于线上销售；`go about doing` 着手处理；`turn out to be foresighted` 结果证明有远见；`legacy product` 传统高端产品。
