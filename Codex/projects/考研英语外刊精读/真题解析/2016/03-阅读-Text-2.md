# 2016 阅读 Text 2：英国乡村开发

返回：[[00-索引]]

## 主旨

英国公众珍视乡村，但主流政党偏向开发；作者认为住房危机不等于侵占绿地，应优先城市更新并坚持城乡规划。

## 逐题解析

| 题 | 答案 | 证据与排错 |
| ---: | :---: | --- |
| 26 | A | 民调高度珍视乡村，但政治支持有限，公众情感未被政策反映。 |
| 27 | D | 绿地持续被混凝土吞噬，National Trust 的保护成果正逐渐受损。 |
| 28 | C | Ukip 支持乡村保护并令地方保守党恐慌，可从该立场获益。 |
| 29 | A | Osborne 偏爱乡村新建、反对城市更新，忽视乡村特征；B/C 与文意相反，D 偷换为反城市偏见。 |
| 30 | C | 末段明确赞赏半世纪城乡规划保留了乡村整体性。 |

## 重点表达

`city dwellers` 城市居民；`green belt` 绿化隔离带；`constant guardianship` 持续保护；`side with` 支持；`intrusion on` 侵占；`let development rip` 放任开发；`rural coherence` 乡村整体性。
