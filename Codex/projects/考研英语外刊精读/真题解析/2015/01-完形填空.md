# 2015 完形：朋友的基因相似性

返回：[[00-索引]]

## 主旨与结构

研究发现朋友之间约有 1% 的基因相似性，程度近似四代表亲；这种相似不是族裔背景造成的，可能与嗅觉、环境选择和人类进化有关。

结构：研究结论 → 样本设计 → 1% 的意义 → 可能机制 → 排除族裔混淆因素。

## 逐空解析

## 复现链与易错点

`related → genes → resemble → genetic`；`study → analysis → samples → findings`。第 6、10 空由语气决定；第 11、18、20 空依靠固定结构。不要根据常识质疑研究结论，完形只恢复原文逻辑。

## 必会表达

`be biologically related` 有血缘关系；`genome-wide analysis` 全基因组分析；`resemble one's kin` 像亲属；`there is more to it` 事情不止如此；`rather than` 而不是；`contributory factor` 促成因素；`take care to see that` 确保。
