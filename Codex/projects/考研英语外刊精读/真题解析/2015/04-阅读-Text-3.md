# 2015 阅读 Text 3：论文统计审查

返回：[[00-索引]]

## 主旨与结构

《科学》杂志增设统计审查委员会，以减少数据分析错误和研究不可重复问题；专家总体肯定，但指出如何准确筛出需要统计复核的论文仍是薄弱环节。

## 重点表达

`peer-review process` 同行评审流程；`irreproducibility` 不可重复性；`flag up` 标出；`additional scrutiny` 额外审查；`play an advisory role` 发挥咨询作用；`long overdue` 早该实施；`take a tougher line` 采取更严格立场。
