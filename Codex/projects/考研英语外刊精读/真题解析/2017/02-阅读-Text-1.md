# 2017 阅读 Text 1：机场安检与 PreCheck

返回：[[00-索引]]

## 主旨

旅客愿以时间换安全，但美国机场安检排队过长且安全提升不明；应降低 PreCheck 加入成本、扩大使用，让安检资源集中于高风险旅客。

## 重点表达

`in return for` 作为……的交换；`a drag on` 对……的拖累；`sneak weapons past security` 偷带武器通过安检；`expedited screening` 快速安检；`sticker shock` 标价震惊；`fatal flaw` 致命缺陷。
