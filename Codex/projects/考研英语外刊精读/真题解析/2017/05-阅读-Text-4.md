# 2017 阅读 Text 4：腐败与政治偏袒

返回：[[00-索引]]

## 主旨

最高法院撤销前州长腐败定罪在法律上合理：一般性牵线不等同受贿；但政治偏袒仍会破坏平等接触政府的原则，应靠透明制度和公众监督约束。

## 逐题解析

| 题 | 答案 | 证据与排错 |
| ---: | :---: | --- | --- |
| 36 | C | `holding its nose` 表示法院虽撤销定罪，却厌恶其行为。 |
| 37 | C | 腐败需礼物换取合同批准、监管等 concrete returns；仅安排会面不足。 |
| 38 | A | 代议政府假定官员会听取并回应选民关切，因此正常协助具有正当性。 |
| 39 | B | 透明法用于防止因捐款或礼物获得不同接触机会，保障公平。 |
| 40 | D | 作者称裁决 legally sound、a step forward，态度支持，同时补充制度约束。 |

## 重点表达

`overturn a conviction` 推翻定罪；`hold one's nose at` 对……表示厌恶；`in return for` 作为交换；`open doors` 牵线搭桥；`play favorites` 偏袒；`equality of access` 平等接触机会；`rest on` 建立在……基础上。
