# 2014—2017 完形与阅读跨年规律

## 阅读正确项的形成方式

1. 同义压缩：把定位句多个动作压缩为一个上位概念，如 active engagement、strategic adjustments。
2. 转折定调：`but / however / yet / yet / even so` 后常出现作者最终判断。
3. 例子回指观点：先问例子为何出现，再向前寻找其证明的抽象观点。
4. 全文双覆盖：最佳标题必须同时覆盖“问题＋方案”或“肯定＋批评”，只覆盖一半通常是干扰项。
5. 语气守恒：原文是 may/tend，选项若改成 must/always/never，通常错误。

## 高频干扰项

| 类型 | 表现 | 应对 |
| --- | --- | --- |
| 原词复现 | 选项复用原文名词，但改变因果、主体或评价。 | 比较关系，不凭眼熟选。 |
| 主体偷换 | non-lawyers 换成 lawyers；机构意见换成作者意见。 | 在定位句旁标出“谁说/谁做”。 |
| 局部冒充主旨 | 只概括一个原因、例子或方案。 | 检查能否覆盖首段问题与末段结论。 |
| 程度扩大 | limited concern 改成 severe criticism；可能改成必然。 | 对照情态词和态度强度。 |
| 方向颠倒 | 作者引用反方后反驳，选项却当成作者结论。 | 追踪引用后的 but/however。 |
| 概念邻近 | privacy、security、technology 都出现，但题问的是其中的关系。 | 用一句中文写出完整因果链。 |

## 完形稳定得分点

- 固定搭配优先：`keep track of`、`look into`、`attribute A to B`。
- 复现链优先于孤立词义：同一概念会换同义词贯穿全文。
- 先判断逻辑再看词：让步、递进、因果、时间顺序是连接词题的核心。
- 说明文尤其重视研究结构：研究结论、样本、机制、限制和排除混淆因素。

## 后续累计字段

每完成一年，追加：题型数量、正确项同义改写方式、错误项类型、最难定位题、最值得复盘的长难句。
