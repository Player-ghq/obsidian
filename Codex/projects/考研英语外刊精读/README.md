# 考研英语外刊精读

本项目用于把英文杂志、报刊、社论、长文和整期 PDF 转化为考研英语能力训练材料。默认使用本地 skill `english-magazine-close-reading`，先按主题筛选文章，再进入泛读与精读。

## 项目目标

- 提升考研英语阅读的信息提取、主旨判断、态度判断和推理能力。
- 积累高价值主题语料，用于作文、翻译和长难句训练。
- 建立整期杂志的筛选机制，避免把时间浪费在低考试价值文章上。

## 日常入口

```text
这期杂志先帮我分类
按外刊精读项目处理这个 PDF
从推荐第一篇开始精读
把这篇文章做泛读和精读
我不知道怎么精读这篇文章
更新外刊阅读记录
```

## 训练闭环

```text
整期 PDF/单篇文章输入
→ 目录与文章边界识别
→ 重点主题匹配
→ 考研价值排序
→ 选 1 篇泛读
→ 提取并清理文章全文，保存到知识库 source text
→ 生成全文中文翻译
→ 选重点段落精读
→ 词汇/长难句/翻译/写作迁移沉淀
→ reading-log.md 记录进度
```

## 输出约定

- 有用的外刊精读笔记默认写入本知识库，聊天窗口只给简短摘要和文件位置。
- 单篇文章默认使用一个独立文件夹，文件夹名称直接使用文章题目，例如 `articles/Rules for supermodels/`。
- 进入单篇精读前，默认先把文章全文从 PDF/网页/用户文本中提取出来，清理版保存为 `articles/[Article Title]/source-text.md`，再基于该文本做泛读、精读、翻译和制卡。
- 单篇精读必须生成全文中文翻译，保存为 `articles/[Article Title]/full-translation.md`，供对照精读使用。
- 单篇文章产生的词汇、短语、语法和作文表达，默认用 `anki-excel-card-maker` 生成 Anki 可导入 `.tsv`，同时保留 `.xlsx` 编辑版和 `.json` 源数据，统一放入 `articles/[Article Title]/anki/`。
- 默认按用户主动词汇量约 4000 处理。选词要更宽：考研核心词、阅读卡壳词、外刊高频短语、熟词辟义、抽象名词、态度词、政策/经济/科技搭配、可作文迁移表达都要提取。短社论通常 30-50 张卡，长特写通常 50-90 张卡。
- 单篇文章制卡默认分三类：`单词`、`词组/句块`、`作文复用`。单词和词组由用户词表与 Codex 主动补充共同决定；Codex 发现明显值得背诵的表达时直接加入。作文复用卡全部由 Codex 负责筛选和制作，按 [[anki-writing-transfer-card-template]] 执行。

## 外刊精读 Anki 制卡规范

### 准入标准

不为了制卡而制卡。每张 Anki 卡必须能对应考研英语一能力点：

- 阅读：主旨、细节、推理、态度、词义猜测、篇章逻辑。
- 翻译：熟词僻义、一词多义、抽象名词、长难句。
- 完形：固定搭配、语义辨析、逻辑关系。
- 新题型：段落衔接、篇章结构。
- 写作：可迁移表达、话题论证、句型模板。

文章八卦、低频专名、过窄技术细节、装饰性细节、无法迁移的表达，不进 Anki，只放笔记或跳过。

### 正面规范

- 正面优先使用词组或句子块，不优先使用孤立单词。
- 制卡前必须做归一化去重：动词还原原形，复数/分词/时态变体合并，代词替换成文章中的具体宾语。
- 一般短语和文章具体短语重复时，只保留更有背诵价值的一张，其他变体写进 `Extra` 的 `<b>归一化合并</b>：...`。

### 字段内容

单词/词组卡使用“精简记忆模板”，目标是容易背、容易复习，不做词典式堆料。

```text
Front：
目标词 / 目标词组

Back：
<b>核心意思</b>：一句话说清楚中文含义。
<b>原文句</b>：放完整原文句 + 中文翻译。
<b>怎么记</b>：词根 / 搭配 / 熟词僻义 / 易混点，只保留最有用的一点。
<b>怎么考</b>：考研阅读、翻译或完形里最可能怎么考。
<b>真实例句</b>：2 个完整英文句 + 中文翻译。

Extra：
<b>作文可用</b>：能自然写进考研作文才写；不能就写“不建议作文使用，语境较窄。”
<b>合并说明</b>：只有合并变体时才写。
```

执行规则：

- 每张卡只解决一个表达，不把所有词根、多义、语气、政治意味和作文模板都塞进去。
- `怎么记` 必须具体、短、能帮助背诵；没有帮助的词根词缀不写。
- 多义项只讲常见、易混、可能考的含义。
- `作文可用` 不是必填项；不要为了作文而硬套。
- `<b>原文句</b>` 必须放包含目标表达的完整英文句，并附中文翻译，不能只放单一词组。
- `<b>真实例句</b>` 必须是真实使用场景，不准用 “In an exam passage...” 或 “When writing about...” 这类讲考试/讲写作方法的元句子当例句。

### 格式和导出

- 字段里的冒号前标签要加粗，只加粗标签，不加粗整段解释。
- Anki 标签只能使用 `外刊精读` 一个标签；不要追加文章名、词性、主题、卡片类型或其他标签。
- 导出时保留 `cards.json`、`anki.tsv`、`anki.xlsx`。
