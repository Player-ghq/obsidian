# 完整外刊精读输出需求

当用户要求“完整精读”“按我的外刊精读需求处理”“全文翻译+长难句+Anki”时，使用本需求。

## 宏观全文需求

先回答：

1. 这篇文章大概讲什么？
2. 作者可能想证明什么？
3. 这篇文章和哪个重点主题有关？
4. 读完后，将单词和词组制成 Anki 卡片，标签统一为 `外刊精读`。

## 微观段落分片需求

每个段落或逻辑分片都要覆盖：

1. 全文精准翻译。
2. 长难句语法拆解，常见从句都拆出来。
3. 考研作文热门话题。
4. 核心短语注解，包括熟词辟义、一词多义、搭配、学术词、动词短语。
5. 考研英语作文可直接套用金句、适配话题、改写模板。
6. 这段在全文中起什么作用：背景、问题、对比、原因、例子、转折、结论。

## 长难句拆解格式

```markdown
### 1. 结构名称

> 原句

- 核心结构：**...**
- 主干：...
- 从句/修饰成分：...
- 短语：...
- 翻译：...
- 写作仿写：...
```

优先识别：

- 主语从句
- 宾语从句
- 表语从句
- 同位语从句
- 定语从句
- 状语从句
- 分词后置定语
- 插入语
- 同位语
- 并列结构
- 让步、转折、因果、比较、省略
- 代词指代

## 作文金句格式

```markdown
原句：**XX is steeped in innovation.**

直译：某地 / 某领域饱含创新精神。

适用话题：科技创新、城市发展、传统文化创新、科技强国。

作文套用改写：The contemporary society is steeped in technological innovation.
当代社会处处充满科技创新的氛围。

替换高级词：innovation → pioneering spirit
```

## Anki 卡片格式

```text
Front | Back | Extra | Tags
```

制卡范围：

- 核心单词
- 核心短语
- 熟词辟义
- 一词多义
- 长难句结构
- 作文金句模板
- 文章主题观点

制卡正面优先用词组或句子块，例如 `cracking down on distillation`、`slapped with export controls`、`a gulf between A and B`；只有没有自然搭配时才用单词。例句也要尽量词组化，方便背诵搭配和语境。

制卡前先归一化去重：把 `formalising` 归为 `formalise...`，把 `tinker with them` 改成 `tinker with + 具体宾语`，把 `crack down on` 与 `cracking down on distillation` 合并为更具体的词组卡。不要为同一个知识点重复出卡。

高价值表达必须使用“考研深度词卡模板”：

```text
Back:
字面含义：...
考研核心考点：...
词汇拆解：...
熟词辟义/一词多义：...
语气色彩：...

Extra:
文章语境：...
暗示意思/政治意味/诙谐意味：...
特殊考查方式：...
答题技巧：...
同义替换/错误选项信号：...
多场景例句：...
其他可用地方：...
```

标签统一为：

```text
外刊精读
```

如用户要求导出文件，使用 `anki-excel-card-maker` 生成 Excel/TSV。
