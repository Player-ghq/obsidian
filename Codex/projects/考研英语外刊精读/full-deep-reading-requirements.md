# 完整外刊精读输出需求

当用户要求“完整精读”“按我的外刊精读需求处理”“全文翻译+长难句+Anki”时，使用本需求。

## 宏观全文需求

先回答：

1. 这篇文章大概讲什么？
2. 作者可能想证明什么？
3. 这篇文章和哪个重点主题有关？
4. 读完后，将单词和词组制成 Anki 卡片，标签统一为 `外刊精读`。

## 微观段落分片需求

每个段落或逻辑分片都要覆盖：

1. 全文精准翻译。
2. 长难句语法拆解，常见从句都拆出来。
3. 考研作文热门话题。
4. 核心短语注解，包括熟词辟义、一词多义、搭配、学术词、动词短语。
5. 考研英语作文可直接套用金句、适配话题、改写模板。
6. 这段在全文中起什么作用：背景、问题、对比、原因、例子、转折、结论。

## 长难句拆解格式

```markdown
### 1. 结构名称

> 原句

- 核心结构：**...**
- 主干：...
- 从句/修饰成分：...
- 短语：...
- 翻译：...
- 写作仿写：...
```

优先识别：

- 主语从句
- 宾语从句
- 表语从句
- 同位语从句
- 定语从句
- 状语从句
- 分词后置定语
- 插入语
- 同位语
- 并列结构
- 让步、转折、因果、比较、省略
- 代词指代

## 作文金句格式

```markdown
原句：**XX is steeped in innovation.**

直译：某地 / 某领域饱含创新精神。

适用话题：科技创新、城市发展、传统文化创新、科技强国。

作文套用改写：The contemporary society is steeped in technological innovation.
当代社会处处充满科技创新的氛围。

替换高级词：innovation → pioneering spirit
```

## Anki 卡片格式

```text
Front | Back | Extra | Tags
```

制卡范围：

- 核心单词
- 核心短语
- 熟词辟义
- 一词多义
- 长难句结构
- 作文金句模板
- 文章主题观点

制卡按以下契约执行：

1. 不为了制卡而制卡。进入 Anki 的表达必须服务于考研英语一：阅读理解、词义猜测、推理态度、篇章逻辑、翻译、完形搭配/逻辑、新题型衔接或作文迁移。
2. 正面优先用词组或句子块。先做原型化和去重：`formalising` -> `formalise safety rules`，`tinker with them` -> `tinker with safety protections`，`crack down on` 与 `cracking down on distillation` 合并为更具体的词组卡。
3. 字段标签要加粗，只加粗冒号前标签，例如 `<b>字面含义</b>：...`。
4. 模板不是死模板。根据表达本身决定详略。
5. 高价值卡应尽量包含原文/拓展表达、双语词汇拆解、多义项详解、完整英文句子例句+中文翻译、作文应用。
6. 无法对应考研英语一能力点的低频专名、文章趣闻和过窄技术细节，只写入笔记，不制卡。
7. 词汇拆解和作文应用必须逐卡特异，不能所有卡套同一句。作文套用句必须实际使用该卡表达或其合理变形。
8. 原文/拓展表达必须是包含目标表达的完整英文句子，并附中文翻译，不能只放单一词组。
9. 多场景例句必须是真实场景句，不准用 “In an exam passage...” 或 “When writing about...” 这类元说明当例句。

高价值表达必须使用“考研深度词卡模板”：

```text
Back:
<b>原文/拓展表达</b>：...
<b>字面含义</b>：...
<b>考研核心考点</b>：...
<b>词汇拆解</b>：中文+English 双语解释构词、搭配、介词逻辑、词根词缀
<b>熟词辟义/一词多义</b>：...
<b>多义项详解</b>：...
<b>语气色彩</b>：...

Extra:
<b>文章语境</b>：...
<b>暗示意思/政治意味/诙谐意味</b>：...
<b>特殊考查方式</b>：...
<b>答题技巧</b>：...
<b>同义替换/错误选项信号</b>：...
<b>多场景例句</b>：完整英文句子 + 中文翻译
<b>作文应用</b>：适配话题、套用句、可替换表达
<b>其他可用地方</b>：...
```

标签统一为：

```text
外刊精读
```

如用户要求导出文件，使用 `anki-excel-card-maker` 生成 Excel/TSV。
