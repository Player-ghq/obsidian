# 完整外刊精读输出需求

当用户要求“完整精读”“按我的外刊精读需求处理”“全文翻译+长难句+Anki”时，使用本需求。

## 宏观全文需求

先回答：

1. 这篇文章大概讲什么？
2. 作者可能想证明什么？
3. 这篇文章和哪个重点主题有关？
4. 读完后，将单词、词组/句块、作文复用表达分别筛选，并统一制成 Anki 卡片，标签统一为 `外刊精读`。

## 微观段落分片需求

每个段落或逻辑分片都要覆盖：

1. 全文精准翻译。
2. 长难句语法拆解，常见从句都拆出来。
3. 考研作文热门话题。
4. 核心短语注解，包括熟词辟义、一词多义、搭配、学术词、动词短语。
5. 考研英语作文可直接套用金句、适配话题、改写模板。
6. 这段在全文中起什么作用：背景、问题、对比、原因、例子、转折、结论。

## 长难句拆解格式

```markdown
### 1. 结构名称

> 原句

- 核心结构：**...**
- 主干：...
- 从句/修饰成分：...
- 短语：...
- 翻译：...
- 写作仿写：...
```

优先识别：

- 主语从句
- 宾语从句
- 表语从句
- 同位语从句
- 定语从句
- 状语从句
- 分词后置定语
- 插入语
- 同位语
- 并列结构
- 让步、转折、因果、比较、省略
- 代词指代

## 作文金句格式

```markdown
原句：**XX is steeped in innovation.**

直译：某地 / 某领域饱含创新精神。

适用话题：科技创新、城市发展、传统文化创新、科技强国。

作文套用改写：The contemporary society is steeped in technological innovation.
当代社会处处充满科技创新的氛围。

替换高级词：innovation → pioneering spirit
```

## Anki 卡片格式

```text
Front | Back | Extra | Tags
```

制卡范围：

- 核心单词
- 核心短语
- 熟词辟义
- 一词多义
- 长难句结构
- 作文金句模板
- 文章主题观点

制卡按以下契约执行：

1. 不为了制卡而制卡。进入 Anki 的表达必须服务于考研英语一：阅读理解、词义猜测、推理态度、篇章逻辑、翻译、完形搭配/逻辑、新题型衔接或作文迁移。
2. 正面优先用词组或句子块。先做原型化和去重：`formalising` -> `formalise safety rules`，`tinker with them` -> `tinker with safety protections`，`crack down on` 与 `cracking down on distillation` 合并为更具体的词组卡。
3. 字段标签要加粗，只加粗冒号前标签，例如 `<b>核心意思</b>：...`。
4. 模板不是死模板。根据表达本身决定详略。
5. 单词和词组/句块由用户词表与 Codex 主动补充共同决定。Codex 发现明显有考研价值的表达时，不需要再次征求用户同意，直接加入最终制卡清单。
6. 作文复用卡全部由 Codex 负责筛选和制作，重点训练“能写出来”，不按普通词汇卡模板处理。
7. 单词/词组卡使用精简记忆模板，不做词典式堆料；重点是核心意思、原文句、怎么记、怎么考、真实例句。
8. 无法对应考研英语一能力点的低频专名、文章趣闻和过窄技术细节，只写入笔记，不制卡。
9. `怎么记` 和 `作文可用` 必须逐卡特异，不能所有卡套同一句。作文套用句必须实际使用该卡表达或其合理变形。
10. 原文/拓展表达必须是包含目标表达的完整英文句子，并附中文翻译，不能只放单一词组。
11. 多场景例句必须是真实场景句，不准用 “In an exam passage...” 或 “When writing about...” 这类元说明当例句。

单词/词组卡使用“精简记忆模板”：

```text
Back:
<b>核心意思</b>：...
<b>原文句</b>：完整英文原句
译：...
<b>怎么记</b>：词根 / 搭配 / 熟词僻义 / 易混点，只保留最有用的一点
<b>怎么考</b>：阅读、翻译或完形中最可能考的点
<b>真实例句</b>：
1. 完整英文句。译：...
2. 完整英文句。译：...

Extra:
<b>作文可用</b>：能自然写进考研作文才写；不能就写“不建议作文使用，语境较窄。”
<b>合并说明</b>：只有合并变体时才写
```

标签统一为：

```text
外刊精读
```

如用户要求导出文件，使用 `anki-excel-card-maker` 生成 Excel/TSV。

## 作文复用卡单独模板

作文复用卡使用 [[anki-writing-transfer-card-template]]，核心字段为：

```text
Front:
用 "[target expression]" 写一句[topic]作文句：如何表达“[Chinese idea]”？

Back:
<b>原文句</b>：...
译：...
<b>表达功能</b>：...
<b>可复用句型</b>：...
<b>考研作文成句</b>：...
译：...

Extra:
<b>适配话题</b>：...
<b>替换槽位</b>：...
<b>多场景改写</b>：完整英文句子 + 中文翻译
<b>常见错误</b>：...
<b>记忆抓手</b>：...
```

作文复用卡不负责“认词”，而负责“产出句子和论证”。只有能自然写进考研作文的表达才做作文卡。
