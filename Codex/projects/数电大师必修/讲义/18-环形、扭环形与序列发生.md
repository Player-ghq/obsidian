# 环形、扭环形与序列发生

## 知识点介绍

移位寄存器反馈形成有限状态机。反馈方式决定状态转移，初态决定进入哪一个循环；正常循环长度与全部状态能否自动进入该循环是两个不同问题。

## 原理讲解与图示

### 环形计数器

将移出的末位直接反馈到串行输入，得到循环移位。采用上一讲的右移定义：

$$Q_3^+=Q_0,\quad Q_2^+=Q_3,\quad Q_1^+=Q_2,\quad Q_0^+=Q_1.$$

n 位独热码初态具有一个 1，经过 n 次移位回到原态，构成模 n 环形计数器。全 0 会锁死，全 1 也不变化；其他多 1 状态可能进入其他周期，不能从“有 n 位”推出“任意初态都模 n”。

### 扭环形（Johnson）计数器

把末位反相后反馈：$Q_{n-1}^+=\overline{Q_0}$，其余位右移。从全 0 开始，先逐步填入 1，再逐步填入 0，正常循环有 2n 个状态。

```mermaid
flowchart LR
 A[最高位] --> B[中间移位级]
 B --> C[最低位]
 C --> N[反相]
 N --> A
```

n 位共有 $2^n$ 个编码，当 $2^n>2n$ 时存在未用编码。这些编码的去向要逐一分析；“正常循环模 2n”不等于“整个电路自启动”。加入恢复逻辑后，还要确认正常循环的所有转移仍被保留。

### 反馈移位寄存器

异或反馈把若干旧状态位组合成新的串行输入，产生线性反馈移位序列。n 位异或型 LFSR 的全 0 状态通常锁死；最长非零周期为 $2^n-1$，达到该长度需要合适的反馈多项式及连接约定，并非任意抽头组合均可。

判断给定电路的周期，直接从规定初态反复计算次态，直到首次重复；不要仅凭抽头数量或寄存器位数判断。

### 计数器与选择器产生指定序列

若目标序列为 $a_0,a_1,\ldots,a_{M-1}$，可用模 M 计数器表示当前位置，再以计数值选择常量 $a_i$：

$$Z=g(Q),\qquad g(i)=a_i.$$

计数器状态周期为 M，但输出序列可能具有更短的基本周期。例如某段图样在 M 位中重复出现时，输出先于状态返回相同图样。

### 暂停、复位与异常恢复

暂停必须冻结决定序列位置的全部状态；只冻结输出会使恢复后跳位。同步复位在下一有效沿改变位置，异步复位立即改变；对输出是否需要寄存，也会影响复位后的第一位及序列起点。

## 配套例题

### 例题 18-01｜反馈周期

3 位右移寄存器满足 $Q_2^+=Q_1\oplus Q_0$、$Q_1^+=Q_2$、$Q_0^+=Q_1$。初态 001，输出为每拍更新前 Q0。求状态周期、输出串及其最小周期，并检查全部 8 个编码的去向。

### 例题 18-02｜自恢复Johnson计数器

用 4 只公共上升沿 D 触发器实现以下八状态循环，状态按 Q3Q2Q1Q0 书写：0000→1000→1100→1110→1111→0111→0011→0001→0000。其余 8 种编码必须在下一拍进入 0000，不允许依赖外部复位才能脱离异常环。

1. 求全部 D 输入函数，给出满足规格的门电路实现。
2. 与直接反相反馈的 4 位右移 Johnson 结构比较，明确为自恢复增加的逻辑。
3. 生成八路高有效相位输出 P0—P7，分别对应上列八个正常状态；非法状态时八路全为 0。尽量共享译码项。
4. 说明正常稳定状态下的输出互斥能否保证实际转换期间绝不同时有效，并给出使用条件。

### 例题 18-03｜暂停与异常恢复的周期序列发生

用一片 74LS161、一只理想同相 16 选 1 MUX 和必要门电路，生成循环位串 1100101011010。状态地址固定采用 0—12，复位后地址为 0；Y 为当前地址的组合输出，在每拍计数更新前读取。

E=1 时推进一个位置，E=0 时地址和输出保持。地址 13—15 为非法，规定其组合输出为 0；E=1 时下一拍回 0，E=0 时保持。74LS161 的 CLR 低有效异步清零、LOAD 低有效同步装载且优先于使能；两计数使能高有效。

1. 给出 MUX 全部数据端和两片模块的所有控制接线。
2. 验证串长度、输出最小周期及复位相位。
3. 初始地址 11，E 依次为 1、0、1、1、1，列沿前地址、Y 和沿后地址。
4. 说明如果系统把 Y 当作另一个模块的时钟，为什么原功能规格不足以证明这种接法可靠。
