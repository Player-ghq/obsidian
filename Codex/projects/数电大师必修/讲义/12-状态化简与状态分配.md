# 状态化简与状态分配

## 知识点介绍

状态化简合并行为等价的状态；状态分配为剩余状态选择二进制编码。前者改变抽象状态数量，后者影响触发器数量、组合逻辑复杂度和异常状态行为。

## 原理讲解与图示

### 等价的含义涉及全部未来输入

两个状态等价，要求对任意允许的后续输入序列产生相同输出序列。当前输出相同只是必要条件；若某个输入会让它们进入可区分的状态，原状态也可区分。

对于完全指定状态机，可递归表述为：对应输入下输出相同，且对应次态仍属于同一等价类。

### 划分法为什么需要迭代

Moore 机先按当前输出分组，Mealy 机先按全部输入下的输出向量分组。随后将“每个输入指向的次态所属组”作为新标签，在旧组内继续拆分，直到不再变化。

设两状态 p、q 的输出相同，但某输入使 p 指向组 A、q 指向组 B，且 A 与 B 已被区分，则从 p、q 开始也能通过该输入与后续区分序列区分。每轮拆分都把更长时间后的行为差异向前传播，所以只检查一次不够。

```mermaid
flowchart LR
 P0[按输出分组] --> P1[比较各输入下的次态组]
 P1 --> P2[拆分行为不同的状态]
 P2 --> P1
 P2 --> F[分组稳定后得到等价类]
```

### 可达性与兼容性

固定初态下不可达的抽象状态可不参与该运行行为，但硬件未用编码仍可能因上电或扰动出现。删除不可达节点不能代替异常恢复设计。

不完全指定状态机的 X 项没有规定行为，需要兼容关系与后继约束；兼容不一定传递，不能直接把若干两两看似不冲突的状态任意合并成一组。此时与完全指定机的等价划分不同。

### 编码与实现成本

M 个状态至少需要 $n=\lceil\log_2M\rceil$ 个状态位。二进制编码节省触发器；独热编码用更多触发器表达一个有效状态，常能减少输出或转移译码；格雷式赋码使指定邻接转换只改变一位，但任意状态图不一定能让所有边都满足该条件。

编码改变各次态位的真值分布，因而改变激励式。最少状态数不保证最少门数；如果要求未用编码下一拍回初态，它们对应的次态值是确定值，不能再任意设为无关项。

## 配套例题

### 例题 12-01｜Mealy 化简

对下表完全指定 Mealy 机进行状态化简，表格单元为“次态/输出”。

| 现态 | X=0 | X=1 |
|---|---|---|
| A | B/0 | C/1 |
| B | B/0 | D/1 |
| C | A/1 | C/0 |
| D | A/1 | D/0 |

### 例题 12-02｜不能直接合并

判断状态 A、B 是否等价，给出判别依据或能区分它们的输入序列。Moore 机如下。

| 现态 | X=0 次态 | X=1 次态 | Z |
|---|---|---|---|
| A | A | C | 0 |
| B | B | D | 0 |
| C | A | C | 1 |
| D | B | D | 0 |

### 例题 12-03｜状态最小化与实现代价

同步 Moore 机初态 A，输入 X，完整表如下。

| 现态 | X=0 次态 | X=1 次态 | Z |
|---|---|---|---|
| A | B | C | 0 |
| B | C | A | 0 |
| C | A | D | 1 |
| D | C | D | 1 |
| E | F | G | 0 |
| F | G | E | 0 |
| G | E | H | 1 |
| H | G | H | 1 |

1. 先在“八个状态都可能成为初态”的条件下化简，给出每一轮划分；再说明固定复位到 A 时可达性与等价化简的关系。
2. 对最小状态机选择两种不同二进制编码，分别求 D 触发器驱动式和输出式。
3. 按驱动与输出最简与或式的总文字数比较编码，允许共享项时再讨论比较标准是否改变。
4. 为一种编码给出 JK 实现，比较其激励逻辑与 D 实现，不以触发器种类直接判断优劣。
