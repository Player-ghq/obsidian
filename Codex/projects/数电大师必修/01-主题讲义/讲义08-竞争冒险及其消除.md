# 08 竞争冒险及其消除

> 学习对象：学过但遗忘；按《42天学习计划》分配学习。配套题：[[例题08-竞争冒险及其消除]]。


## 逻辑正确为何还会出现毛刺

同一个输入通过不同路径到达输出，传播时间不一致，称为竞争；竞争可能使输出产生预期之外的短暂跳变，形成冒险。不是每次竞争都会造成错误输出。

| 类型 | 理想输出 | 实际异常 |
|---|---|---|
| 静态 1 冒险 | 保持 1 | 短暂掉到 0 |
| 静态 0 冒险 | 保持 0 | 短暂升到 1 |
| 动态冒险 | 只跳变一次 | 多次来回跳变 |

必须根据具体电路结构讨论，两个稳态等价表达式实现的电路不一定有相同冒险。

## 两级与或电路的静态 1 冒险

在一次只有一个输入变化的假设下，检查卡诺图相邻的两个 1 是否有共同的乘积项覆盖。若只由不同项分别覆盖，在路径延迟不同时可能出现两项同时失效。加入跨越该相邻对的冗余项，可以在交接期间维持输出。

代数上，$XY+\overline XZ$ 在 $Y=Z=1$、X 变化时存在这种可能；其共识项 YZ 可构成不依赖 X 的维持路径。这是一般消冒险规则，并非“任何电路加一个项就安全”。

两级或与电路的静态 0 冒险采用对偶方法：检查相邻 0 是否由共同和项覆盖。多级电路与多输入同时变化需要进一步分析，不能直接套用两级单变量判据。

## 常见处理方法的适用范围

增加冗余覆盖用于消除指定静态冒险；重新组织逻辑减少危险路径；延后采样可避免在暂态期间读取输出。输出寄存器只能在满足建立、保持时间且输入已稳定时正确采样，不能神奇消除所有毛刺。

滤波或脉冲选通可能出现在教材方法中，但其有效性取决于脉冲宽度、延迟和后级阈值，考试需按给定电路分析。普通组合逻辑直接生成时钟或异步复位尤其需要留意短脉冲。

## 分析步骤

先确定哪些输入变化、理想输出应否保持，再画每条相关路径的时间线，最后检查短暂错误窗口。若题目只给功能而无延迟，说明“可能发生”的条件，不虚构精确毛刺宽度。
