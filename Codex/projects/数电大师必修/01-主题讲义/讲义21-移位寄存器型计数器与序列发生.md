# 21 移位寄存器型计数器与序列发生

> 高阶题卡点参考：按《42天学习计划》需要查阅，不要求从基础章节顺读。配套题：[[例题21-移位寄存器型计数器与序列发生]]。


## 环形计数器

把移出的位直接送回串入端，构成循环移位。n 位独热初态（恰好一位为 1）形成 n 个状态的环，因此常称模 n 环形计数器。这个结论依赖初态：全 0、全 1 会自锁，其他多 1 代码可能形成不同长度的环。

优点是单独状态常可直接由一位输出译码，缺点是触发器利用率低，且通常需初始化。不要仅凭 n 个触发器就认定正常计数会自动开始。

## 扭环形（Johnson）计数器

把移出位取反后送回。对 n 位、从全 0 开始的标准连接，正常循环包含 2n 个状态。与普通环形一样，2n 不是说所有 $2^n$ 编码都会自动进入该环，仍需分析异常状态环。

本项目右移模型：$Q_{n-1}^+=\overline Q_0$，其余各位接前一高位旧值。具体题目改变方向时，应重新从方程推序列。

## 移位反馈生成任意循环序列

给出目标串行序列后，先确定输出位与读出时刻，按滑动窗口列寄存器状态，再确定反馈位。若同一个寄存器状态需要两种不同反馈，说明当前状态信息不足，需要增加状态位或改结构。

线性反馈移位寄存器常用异或反馈，但并非任意抽头都能得到最大长度。只在给定反馈多项式或实际验证后才能声称周期为 $2^n-1$；全 0 状态在常见纯异或结构中会锁定。

## 计数器加选择器生成序列

用模 M 计数器产生位置编号，再通过 MUX 数据端的 0、1 或组合译码输出目标序列。若目标串长度不是 $2^n$，必须限制地址循环长度，不能让其自动走过额外地址。初态与输出在沿前／沿后读取共同决定序列相位。

## 两类结构怎样选择

环形／扭环形适合规则相位信号；计数器加选择器适合任意固定周期序列；移位反馈适合硬件紧凑但需严谨验证的状态循环。比较时考虑存储位、组合门、初始化和异常恢复，而不只数门数。

## 自检

画正常环后再画所有异常环；确认实际序列的最小周期，而不只是题目给出的串长度。重复的短串可能使实际输出周期小于状态周期。
