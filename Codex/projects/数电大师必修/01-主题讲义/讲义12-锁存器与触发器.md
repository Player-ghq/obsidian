# 12 锁存器与触发器

> 学习对象：学过但遗忘；按《42天学习计划》分配学习。配套题：[[例题12-锁存器与触发器]]。


## 结构回答“何时变”，逻辑类型回答“变成什么”

存储单元可保持 1 位状态。锁存器对电平敏感，在使能有效期间可透明传递输入；边沿触发器只在有效边沿采样。主从结构由两级交替开放的锁存环节组成，脉冲触发的内部动作不能无条件等同于理想边沿采样。做波形题必须先识别结构或题目模型。

SR、D、JK、T 是逻辑功能分类，不直接决定上升沿还是下降沿触发。时钟端三角形表示边沿，配反相小圆圈常表示下降沿。异步置位／清零端通常具有比时钟数据端更高的优先级。

## 基本 SR 锁存器

交叉耦合 NOR 门构成高有效 SR 锁存器：S=1、R=0 置 1；S=0、R=1 清 0；S=R=0 保持；S=R=1 为禁用组合。交叉耦合 NAND 门构成低有效输入版本，保持与禁用组合相反。禁用组合释放后的状态可能不确定，不能当普通保持状态。

## 特性方程与功能

用 Q 表示现态，$Q^+$ 表示下一有效动作后的次态：

| 类型 | 特性方程 | 功能重点 |
|---|---|---|
| 高有效 SR | $Q^+=S+\overline RQ$，约束 SR=0 | 置位、复位、保持 |
| D | $Q^+=D$ | 在有效动作时复制输入 |
| JK | $Q^+=J\overline Q+\overline KQ$ | 00 保持，01 清零，10 置位，11 翻转 |
| T | $Q^+=T\oplus Q$ | T=0 保持，T=1 翻转 |
| T′ | $Q^+=\overline Q$ | 每次有效动作均翻转 |

方程只描述适用动作时刻和正常工作条件；异步控制生效时，应先按异步控制更新状态。

## 激励表是设计工具

特性表从“输入＋现态”求次态；激励表从“现态→次态”反求允许输入。X 表示任选，不表示实际未知电平。

| Q→Q⁺ | D | T | J K | S R（高有效） |
|---|---|---|---|---|
| 0→0 | 0 | 0 | 0 X | 0 X |
| 0→1 | 1 | 1 | 1 X | 1 0 |
| 1→0 | 0 | 1 | X 1 | 0 1 |
| 1→1 | 1 | 0 | X 0 | X 0 |

SR 输入选择仍须避免同时为 1。设计 JK 激励时可以利用表中 X 化简，但检查次态时必须代回完整特性方程。

## 易混点

异步清零不等于下降沿触发；时钟为高也不等于出现上升沿；D 触发器的 Q 不会在两个采样沿之间连续跟随 D。
