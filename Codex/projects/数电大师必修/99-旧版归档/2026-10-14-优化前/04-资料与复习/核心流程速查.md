# 核心流程速查

本页用于闭卷回忆后的核对，只列通用方法，不包含配套题答案。

| 任务 | 检查顺序 |
|---|---|
| 函数表达转换 | 变量顺序 → 全输入表 → 1 集／0 集 → 标准形式 |
| 卡诺图化简 | 格雷码定位 → 填 1／0／X → 必要覆盖 → 补剩余 → 检查有效输入 |
| 组合分析 | 节点连接 → 中间式 → 输出式 → 真值表 → 功能 |
| 组合设计 | 需求与极性 → 编码 → 真值表 → 化简 → 门型／模块 → 反向验证 |
| MUX 实现 | 定地址 → 固定地址逐组求子函数 → 接数据端 → 查使能与输出极性 |
| 触发器转换 | 目标次态 → 现有激励表 → 驱动式 → 代回验证 |
| 同步分析 | 识别时钟 → 驱动式 → 次态式 → 表／图 → 波形 → 未用状态 |
| 同步设计 | 状态含义 → 原始图 → 化简 → 编码 → 激励 → 连接 → 完整验证 |
| 异步计数 | 外部有效沿 → 第一级变化 → 后级是否见到有效沿 → 逐级稳定 |
| 基本模式异步 | 输入约束 → 流表稳定项 → 状态分配 → 反馈式 → 竞争／冒险 |
| 任意模计数 | 目标环长度 → 同步／异步控制 → 检测状态 → 装载值 → 全状态验证 |
| 移位 | 位序 → 方向 → 串入与串出端 → 沿前／沿后读出 → 初态逐拍推演 |
| DAC | 代码类型 → 极性与增益 → D 数值 → 传输式 → 单位与满码检查 |
| ADC | 范围 → 量化方式 → 步长 → 代码限幅 → 误差与时序 |

## 最容易混淆的成对概念

| 概念对 | 区别 |
|---|---|
| 反函数／对偶式 | 是否把全部变量也取反 |
| 最小项／最大项 | 指定组合上分别为 1／0 |
| 无关项／未知结果 | 前者来自规格，后者只是尚未计算 |
| 使能／时钟 | 允许某功能／规定状态动作时刻 |
| 现态／次态 | 同一节点不同时刻的值 |
| 特性表／激励表 | 已知输入求次态／已知转移求输入 |
| 同步装载／异步清零 | 等有效沿／立即生效 |
| 复位／自启动 | 外部强制初始化／异常编码自行恢复 |
| 高阻 Z／逻辑 0 | 不驱动／主动低电平 |
| 状态周期／输出周期 | 状态完整重复／可见输出最小重复 |
| 分辨率／准确度 | 码步细度／与真实理想值的偏差 |
| 参考跨度／满码输出 | 量化覆盖幅度／最大代码对应输出 |

核心公式与限定条件分别见各讲义；避免把本页变成脱离条件的公式背诵表。
