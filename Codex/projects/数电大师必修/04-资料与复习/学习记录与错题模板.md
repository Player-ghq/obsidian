| | | 待核对／错误／续做 | | | | |

建议标签：概念遗忘、题意建模、变量位序、低有效、公式反号、卡诺图邻接、时钟边沿、旧值更新、未用状态、异步过渡、量程分母、计算失误。先记录自己如何出错，再决定回看哪一节。

只写下一步，不抄整页讲义。例如“重列驱动表并检查各位是否都用了旧值”。隔日、3 天后、7 天后挑选典型题重做。答案与解析不自动写入本项目；后续如用户明确要求讲解某题，再按其新要求处理。
