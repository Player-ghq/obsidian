# 数电大师必修｜维护约定

先读 README.md 与数电大师必修-学习导航.md，沿用每天约 2 小时、42 天的高阶路线。用户明确不需要入门内容，直接上难度；不得重新安排入门诊断、数制预习或基础扫盲课程。以综合设计题驱动，讲义按卡点查阅。

讲义允许解释概念与通用推导；配套例题、高阶题和测验默认只包含题目与必要图表条件，不附答案、解析或题目专属提示。用户以后明确要求某题讲解时，以新请求为准。

不把练习题冒充真题。新题必须标清有效电平、时钟沿、初始状态、位序、非法状态要求和 ADC／DAC 量程约定中与题目有关的条件。器件功能以题给表与厂家说明为准。

优先维护已有讲义与题号。新进度、疑点和复习安排写入本项目记录，不覆盖用户手工作答。修改内容后检查讲义、例题、日程之间的链接与编号；不要未经用户要求把原 PDF 中的答案复制进项目。
