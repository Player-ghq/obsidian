# H11｜带使能的模60模块设计

> 原创综合设计题；仅题目，无答案、解析或提示。按《42天学习计划》安排 1—2 次课；不能把未做完自动记作不会。


用两片 74LS161 构成以两位 BCD 表示的 00—59 同步循环计数器，共用上升沿时钟。低有效异步 CLR 仅用于外部初始化。正常计数使用同步装载，装载端低有效且优先于计数使能；ENP、ENT 都为 1 时才加 1。

输入 E 高有效；E=0 时必须保持，含 09、59 等边界状态。E=1 时加 1。正常状态以外的任意两片编码，在 E=1 的下一拍必须恢复到 00；E=0 时仍保持。输出 C 在当前为 59 且 E=1 时为 1。

1. 给出两片的装载数据、LOAD、ENP、ENT 及 CLR 连接式，所有状态检测须写明。
2. 验证 08→09→10、58→59→00，以及在 09、59 暂停和恢复的情况。
3. 枚举或按类别证明全部非法编码满足恢复规格。
4. 给出 C 的逻辑和重复频率；说明存在暂停时能否继续按固定 60 分频解释。
