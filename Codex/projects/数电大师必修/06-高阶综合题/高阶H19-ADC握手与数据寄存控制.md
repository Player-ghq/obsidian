# H19｜ADC握手与数据寄存控制

> 原创综合设计题；仅题目，无答案、解析或提示。按《42天学习计划》安排 1—2 次课；不能把未做完自动记作不会。


设计公共上升沿同步控制器。输入 req、busy_adc、done_adc 已同步到该时钟域，ADC 的 12 位 data 在 done_adc=1 的采样沿前后满足建立保持要求。req 是单拍请求，空闲时到达才接受，忙碌期间请求忽略。

控制器接受请求后输出 start=1 恰好一个完整周期；ADC 保证在 start 周期之后进入 busy_adc=1，且在 busy_adc 首次被采到为 1 的那个沿，done_adc 必为 0。此后完成转换才令 done_adc=1，同时 busy_adc=0；done_adc 可保持到下次转换启动时清除。控制器只有见过 busy_adc=1 后才允许接受 done_adc=1，防止旧完成标志被误认。完成时把 data 捕获进输出寄存器，下一状态区间 valid=1 恰好一个周期，然后回空闲。复位 R 高有效同步且最高优先，清除 valid 与数据寄存器。完成后的 valid 周期不接受新请求。

1. 给出 Moore 状态图、状态编码和所有输出条件，明确数据捕获发生在哪个边沿。
2. 求 D 触发器状态驱动函数及数据寄存器装载使能，确保 start、valid 不多持续一拍。
3. 列“done_adc 先为 1、再出现 busy_adc、随后完成”场景的合法输入时序，并证明不会提前输出 valid。
4. 如果 done_adc 不再同步，说明现有逻辑证明遗漏了什么，不要求设计跨时钟域传输方案。
