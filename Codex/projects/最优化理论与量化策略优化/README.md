# 最优化理论与量化策略优化

## 目标

系统掌握线性规划、二次规划、凸优化，并用于资产配置、权重优化、约束条件下的策略参数寻优。

## 用户背景与难度

- 本科智能科学与技术专业。
- 学过高等数学和线性代数。
- 当前题目应偏入门：从直觉、二维几何、小规模手算、基础建模开始，暂缓复杂证明、KKT 和大规模矩阵推导。

## 日常训练规则

状态：2026-07-10 起暂停。用户决定停止最优化每日题计划，当前专注 2026 年上海体育大学运动康复专业考研相关内容。

- 每天 3 题。
- 每题标记知识点。
- 默认结构：1 题概念辨析，1 题小规模计算/画图，1 题简化资产配置或策略优化应用。
- 先不给答案；用户做完后逐题讨论、纠错和扩展。
- 每日题目和解析后的知识点归档到 `每日归档/`，并同步维护知识体系、月度路线图和薄弱点。
