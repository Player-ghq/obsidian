# 二次型

返回：[[../README|项目首页]] · 前置：[[特征值与特征向量]]

## 核心关系

实二次型写作 f(x)=xᵀAx，其中 A 取实对称矩阵。平方项系数填入对角线，交叉项系数的一半填入两个对称位置。

非退化线性替换 x=Cy 给出 f=yᵀ(CᵀAC)y，对应合同变换。若 C=Q 为正交矩阵，则 QᵀAQ=Q⁻¹AQ，同时是合同与相似变换。

## 必会题型

- [ ] 从二次型写出对称矩阵，并从矩阵还原二次型。
- [ ] 用配方法化标准形，写出变量替换。
- [ ] 用正交变换化标准形，写出 Q 与 x=Qy。
- [ ] 求秩、正负惯性指数与规范形。
- [ ] 判断正定、负定、半正定、半负定或不定。
- [ ] 求含参数二次型正定的参数范围。

## 标准形与规范形

- 标准形只含平方项，系数可为任意实数。
- 规范形的非零系数为 +1 或 −1，一般需在标准形基础上缩放变量；这种缩放通常不是正交变换。
- 惯性定律：实对称矩阵在非退化合同变换下，正、负惯性指数不变；秩等于两者之和。

## 正定判别

对实对称矩阵 A，下列条件等价：

- 任意非零 x 都有 xᵀAx>0。
- 所有特征值均大于 0。
- 各阶顺序主子式均大于 0。

半正定可由全部特征值非负判别，也可由所有主子式非负判别；仅检验顺序主子式非负不足以保证半正定。

## 易错检查

- 交叉项系数忘记除以 2。
- 将合同与相似混淆：一般合同不保持特征值。
- 正交变换的 Q 未单位化，或列向量顺序不对应特征值。
- 只写标准形，漏写题目要求的变量替换。
- 正定参数讨论遗漏严格不等号或边界检验。
