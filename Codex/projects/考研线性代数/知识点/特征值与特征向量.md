# 特征值与特征向量

返回：[[../README|项目首页]] · 衔接：[[二次型]]

## 核心关系

对 n 阶矩阵 A，若非零向量 x 满足 Ax=λx，则 λ 为特征值，x 为对应特征向量。求解流程：

1. 解 det(λI−A)=0。
2. 对每个 λ 解 (A−λI)x=0，写出特征子空间的基；非零解才是特征向量。
3. 用 Ax=λx 检验，必要时用特征值之和 tr(A)、之积 det(A) 交叉检查（按代数重数计）。

## 必会题型

- [ ] 求特征值、特征向量及特征子空间维数。
- [ ] 由已知特征值、特征向量求参数或矩阵。
- [ ] 求 p(A) 的特征值；A 可逆时求 A⁻¹ 的特征值。
- [ ] 判断相似、判断可对角化并构造 P。
- [ ] 讨论含参数矩阵可对角化的条件。
- [ ] 对实对称矩阵作正交对角化。

## 判断条件

- 不同特征值对应的特征向量线性无关。
- 在所讨论数域内，A 可对角化当且仅当有 n 个线性无关的特征向量；等价地，特征多项式在该数域分裂且每个特征值的几何重数等于代数重数。
- n 个互异特征值是可对角化的充分条件；重根不代表一定不能对角化。
- P 的列向量是特征向量，Λ 的对角元素须与列向量顺序一致，满足 P⁻¹AP=Λ。
- 实对称矩阵的特征值均为实数，不同特征值的特征向量正交；同一特征子空间内可正交化，再单位化，组成 Q，得到 QᵀAQ=Λ。

## 易错检查

- 求向量时忘记排除零向量。
- 只计算特征值，没有求重根对应的特征子空间维数。
- 特征向量排列与对角矩阵顺序不一致。
- 将一般相似变换中的 P⁻¹ 错写为 Pᵀ；后者要求 P 正交。
