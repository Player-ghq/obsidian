## 第01—03章 逐点解析

#### T01-01-S

答案：**C**。预处理不是运行；函数只有被调用才执行；return向调用者/环境返回结果。

<!-- example: A-T01-01-F -->
```c
#include <stdio.h>
int main(void)
{
    int a = 4, b = 6;
    printf("%d\n", a * b); /* 输出乘积 */
    return 0;
}
```

<a id="T01-01-P"></a>

完整参考程序：

<!-- example: A-T01-01-P -->

```c
#include <stdio.h>
int main(void)
{

```

**核验：**

<a id="T01-04-S"></a>

#### T01-04-S

答案：**C**。静态存储期与块作用域可以同时存在；定义不会自动扩大可见范围。

<a id="T01-04-F"></a>

#### T01-04-F

依空顺序：`static`。两次调用分别得到1、2，自动局部变量则每次初始化后只得到1。

补全后的完整程序：

<!-- example: A-T01-04-F -->
```c
#include <stdio.h>
int next(void)
{
    static int n = 0;
    n++;
    return n;
}
int main(void)
{
    printf("%d\n", next());
    printf("%d\n", next());
    return 0;
}
```

<a id="T01-04-P"></a>

#### T01-04-P

**解题步骤：**static对象只初始化一次，100→101→102→103。分三条语句调用明确顺序；不把多次修改同一静态对象的调用放进一个printf中猜左右次序。仅练习三次，未设计无限号码范围。

完整参考程序：

<!-- example: A-T01-04-P -->
```c
#include <stdio.h>
int next_ticket(void)
{
    static int ticket = 100;
    ticket++;
    return ticket;
}
int main(void)
{
    printf("%d\n", next_ticket());
    printf("%d\n", next_ticket());
    printf("%d\n", next_ticket());
    return 0;
}
```

**核验：**

- 输入`无` → 输出`101 / 102 / 103`；退出状态0。


**自评（本题训练建议10分）：**输入/已知数据与范围2分，核心步骤4分，输出与格式2分，边界解释2分；不作为官方评分标准。

#### T02-01-S

<a id="T02-01-F"></a>

#### T02-01-F

<!-- example: A-T02-01-F -->
```c
#include <stdio.h>
int main(void)

```

<a id="T02-01-P"></a>

#### T02-01-P

**解题步骤：**先检查scanf返回项数，短路使读取失败后不访问未赋值变量；再检查范围与除数。−7/3向零截断为−2，余数−1。范围防止本例算术溢出。

完整参考程序：

<!-- example: A-T02-01-P -->
```c
#include <stdio.h>
int main(void)
{
    int a, b;
    if (scanf("%d%d", &a, &b) != 2 ||
        a < -1000 || a > 1000 || b < -1000 || b > 1000 || b == 0) {
        puts("invalid");
        return 1;
    }
    printf("%d %d %.2f\n", a / b, a % b, (double)a / b);
    return 0;
}
```

**核验：**

- 输入`7 3` → 输出`2 1 2.33`；退出状态0。

- 输入`-7 3` → 输出`-2 -1 -2.33`；退出状态0。

- 输入`1 0` → 输出`invalid`；退出状态1。

- 输入`x` → 输出`invalid`；退出状态1。


**自评（本题训练建议10分）：**输入/已知数据与范围2分，核心步骤4分，输出与格式2分，边界解释2分；不作为官方评分标准。


<a id="T02-02-P"></a>

#### T02-02-P

<a id="T02-03-S"></a>

#### T02-03-S

答案：**C**。掩码4U仅第2位为1，取反后该位0，其余1；与运算清此位，保留其他位。

<a id="T02-03-F"></a>

#### T02-03-F

依空顺序：`<<`。将1移到第3位得到8U，位编号从0开始。

补全后的完整程序：

<!-- example: A-T02-03-F -->
```c
#include <stdio.h>
int main(void)
{
    unsigned int flags = 0U;
    flags |= (1U << 3);
    printf("%u\n", flags);
    return 0;
}
```

<a id="T02-03-P"></a>

#### T02-03-P

**解题步骤：**1010→1011=11；1011异或1000得到0011=3；0011清第1位为0001=1。

完整参考程序：

<!-- example: A-T02-03-P -->
```c
#include <stdio.h>
int main(void)
{
    unsigned int flags = 10U;
    flags |= 1U;
    printf("%u\n", flags);
    flags ^= 8U;
    printf("%u\n", flags);
    flags &= ~2U;
    printf("%u\n", flags);
    return 0;
}
```

**核验：**

- 输入`无` → 输出`11 / 3 / 1`；退出状态0。


**自评（本题训练建议10分）：**输入/已知数据与范围2分，核心步骤4分，输出与格式2分，边界解释2分；不作为官方评分标准。

<a id="T02-04-P"></a>

<a id="T03-01-P"></a>

```c
    if (month <= 3) {
        quarter = 1;
    } else if (month <= 6) {
```

#### T03-02-S

答案：**C**。do-while的检查在循环体之后。

<a id="T03-02-F"></a>

#### T03-02-F

依空顺序：`i <= 5（或i < 6）`。边界包含5，迭代加1，退出时i为6。

补全后的完整程序：

<!-- example: A-T03-02-F -->
```c
#include <stdio.h>
int main(void)
{
    int sum = 0;

```

<a id="T03-02-P"></a>

#### T03-02-P

**解题步骤：**累加器用long以容纳338350；在乘法前转换为long，避免先按可能较窄的int计算乘积。n=0时初次条件假，sum保持0。

完整参考程序：

<!-- example: A-T03-02-P -->
```c
#include <stdio.h>
int main(void)
{
    int n;
    if (scanf("%d", &n) != 1 || n < 0 || n > 100) {
        puts("invalid");
        return 1;
    }
    long sum = 0;
    for (int i = 1; i <= n; i++) {
        sum += (long)i * i;
    }
    printf("%ld\n", sum);
    return 0;
}
```

**核验：**

- 输入`3` → 输出`14`；退出状态0。

- 输入`0` → 输出`0`；退出状态0。

- 输入`100` → 输出`338350`；退出状态0。

- 输入`-1` → 输出`invalid`；退出状态1。

<a id="T03-04-F"></a>

#### T03-04-F

```c
#include <stdio.h>
int main(void)

    for (int row = 1; row <= 2; row++) {

            putchar('#');
        }
        putchar('\n');
    }

}
```

<a id="T03-04-P"></a>

#### T03-04-P

**解题步骤：**外层确定行，内层输出1到row；每行从col=1重新开始。将n限为9保证每个输出数只占一个数字位。

```c
#include <stdio.h>
int main(void)

        puts("invalid");
        return 1;
    }
    for (int row = 1; row <= n; row++) {
        for (int col = 1; col <= row; col++) {
            printf("%d", col);
        }
        putchar('\n');
    }
    return 0;
}
```

**核验：**

- 输入`3` → 输出`1 / 12 / 123`；退出状态0。

- 输入`1` → 输出`1`；退出状态0。

- 输入`0` → 输出`invalid`；退出状态1。

#### T05-03-P 答案与解析

**解题步骤：**对3个指针元素做选择式交换：比较*refs[i]与*refs[j]；需要交换时用int *临时变量交换地址，不能交换解引用值。结果指针顺序指向b、c、a，原整数值不变。

**完整参考程序：**

<!-- example: A-T05-03-P -->
```c
#include <stdio.h>
int main(void)
{
    int a = 7, b = 2, c = 5;
    int *refs[3] = {&a, &b, &c};
    for (size_t i = 0; i < 3; ++i) {
        for (size_t j = i + 1; j < 3; ++j) {
            if (*refs[j] < *refs[i]) {
                int *temp = refs[i];
                refs[i] = refs[j];
                refs[j] = temp;
            }
        }
    }
    printf("sorted=%d %d %d\n", *refs[0], *refs[1], *refs[2]);
    printf("original=%d %d %d\n", a, b, c);
    return 0;
}
```


**边界与验证说明：**第二行是关键验证：若变成2 5 7，说明错误地交换了目标整数。相等目标无需交换，仍能形成非递减序列。

## 第08章 单向链表

### K08-01 单向链表的节点与尾插建立

<a id="T08-01-S"></a>

**T08-01-S：B**

第一个节点既是首节点也是尾节点；它的 next 必须为 NULL。只更新 tail 会使 head 无法找到已有节点。

<a id="T08-01-F"></a>

**T08-01-F：填空与步骤**

空①：`*head = node`；空②：`(*tail)->next = node`。

①空链没有旧尾，先把外部head指向新节点。②非空链把旧尾的next改为新节点。③两条分支汇合后再更新tail；node->next已置NULL，尾部结束标记有效。

完整参考程序：

<!-- example: A-T08-01-F -->
```c
#include <stdio.h>
#include <stdlib.h>
struct Node { int value; struct Node *next; };
static void destroy(struct Node *head) {
    while (head != NULL) {
        struct Node *next = head->next;
        free(head);
        head = next;
    }
}
static int append(struct Node **head, struct Node **tail, int value) {
    struct Node *node = malloc(sizeof *node);
    if (node == NULL) return 0;
    node->value = value;
    node->next = NULL;
    if (*tail == NULL) *head = node;
    else (*tail)->next = node;
    *tail = node;
    return 1;
}
static void print_list(const struct Node *head) {
    if (head == NULL) { puts("EMPTY"); return; }
    for (const struct Node *p = head; p != NULL; p = p->next) {
        printf("%d%s", p->value, p->next == NULL ? "\n" : " ");
    }
}
int main(void) {
    struct Node *head = NULL, *tail = NULL;
    if (!append(&head, &tail, 4) || !append(&head, &tail, 9)) {
        puts("ALLOC_FAIL"); destroy(head); return 1;
    }
    print_list(head);
    destroy(head);
    return 0;
}
```

默认测试：输入 `""`，输出 `"4 9\n"`。

<a id="T08-01-P"></a>

**T08-01-P：解题步骤**

①head、tail 均置 NULL。②read_list 检查数量与每个值；返回 1 成功、0 输入错误、−1 申请失败。③不论失败发生在第几个节点，调用者都 destroy(head) 释放已建部分。④成功才输出完整链表，避免半成品输出。⑤空链 destroy 不进入循环，安全结束。

完整参考程序：

<!-- example: A-T08-01-P -->
```c

#include <stdlib.h>

static void destroy(struct Node *head) {
    while (head != NULL) {
        struct Node *next = head->next;
        free(head);
        head = next;
    }
}
static int append(struct Node **head, struct Node **tail, int value) {
    struct Node *node = malloc(sizeof *node);
    if (node == NULL) return 0;
    node->value = value;
    node->next = NULL;
    if (*tail == NULL) *head = node;
    else (*tail)->next = node;
    *tail = node;

}

    for (const struct Node *p = head; p != NULL; p = p->next) {
        printf("%d%s", p->value, p->next == NULL ? "\n" : " ");
    }

    int n;
    if (scanf("%d", &n) != 1 || n < 0 || n > 10) return 0;
    for (int i = 0; i < n; ++i) {
        int value;

    }
    return 1;
```

### K08-02 单向链表遍历与统计

<a id="T08-02-S"></a>

**T08-02-S：B**

### K10-02 整行与字符分类

<a id="T10-02-S"></a>

<a id="T10-02-F"></a>

#### T10-02-F 答案与解析

#### T10-02-P 算法与参考实现

先读后判断EOF和换行；用isalpha/isdigit分类，普通空格单独比较；其余包括制表符和标点。ctype调用前转成unsigned char，符合函数参数规则；getchar结果保存在int中，EOF不会丢失。正常EOF也可以结束一条无换行的末行。

<!-- example: A-T10-02-P -->

### K10-03 文本文件生命周期

<a id="T10-03-S"></a>

#### T10-03-S 答案

<a id="T10-03-F"></a>

#### T10-03-F 答案与解析

<!-- example: A-T10-03-P -->

### K10-04 EOF、行数与查找

<a id="T10-04-S"></a>

#### T10-04-S 答案

C。读取动作实际触发EOF或错误，先检查返回值才知道是否拿到新数据。A把状态查询当预测；B可能使EOF与字符值混淆；D是puts的行为，fputs只输出字符串自身的内容。

<a id="T10-04-F"></a>

#### T10-04-F 答案与解析

①`EOF`；②`'\n'`。遍历时每见一个换行计一行，结束后只为无换行末行补计一次。last初值为换行，使空文件循环0次后也不补计；若初始化成普通字符，会把空文件误计1行。

<!-- example: A-T10-04-F -->
```c
#include <stdio.h>
int main(void) {
    FILE *fp = fopen("input.txt", "r");
    if (fp == NULL) return 1;
    size_t lines = 0;
    int ch, last = '\n';
    while ((ch = fgetc(fp)) != EOF) {
        if (ch == '\n') ++lines;
        last = ch;
    }
    int bad = ferror(fp);
    if (last != '\n') ++lines;
    if (fclose(fp) == EOF) bad = 1;
    if (bad) return 1;
    printf("lines=%zu\n", lines);
    return 0;
}
```

**F题测试**：

- 输入`""`；输入文件`{"input.txt": "a\nb"}`；预期输出`"lines=2\n"`；退出状态0。
- 输入`""`；输入文件`{"input.txt": ""}`；预期输出`"lines=0\n"`；退出状态0。
- 输入`""`；输入文件`{"input.txt": "\n\n"}`；预期输出`"lines=2\n"`；退出状态0。
- 输入`""`；输入文件`{"input.txt": "a\n"}`；预期输出`"lines=1\n"`；退出状态0。

<a id="T10-04-P"></a>

#### T10-04-P 算法与参考实现

用80字节缓冲区保证本题的一整行装得下；每次fgets后只判断一次strstr；匹配则fputs到输出文件并累加一次。fputs保留原文换行状态；这与讲义为终端显示补换行的目标不同。两文件都关闭，写失败/读取错误/关闭失败均退出1。

<!-- example: A-T10-04-P -->
```c

    if (in == NULL) return 1;

    char line[80];

    int bad = 0;
    while (fgets(line, sizeof line, in) != NULL) {
        if (strstr(line, "error") != NULL) {
            if (fputs(line, out) == EOF) { bad = 1; break; }
            ++hits;
        }
    }
    if (ferror(in)) bad = 1;
    if (fclose(in) == EOF) bad = 1;
    if (fclose(out) == EOF) bad = 1;
    if (bad) return 1;
    printf("hits=%zu\n", hits);
    return 0;
}
```

**P题测试（精确输出，空stdout表示无输出）**：

### K11-02 宏展开与副作用

<a id="T11-02-S"></a>

#### T11-02-S 答案

D。先展开成`((i++)*(i++))`；乘法两操作数求值没有规定先后且未定序，两处修改同一i，触发未定义行为。A/B是在假定不存在的固定顺序；C把优先级保护误认为求值次数保护。不可用某次机器输出证明该写法可靠。

### K12-01 冒泡与选择

<a id="T12-01-S"></a>

#### T12-01-S 答案

B。先比较3与1，交换成[1,3,2]；再比较3与2，交换成[1,2,3]，第一轮最大值3到末尾。A只完成第一对比较；C、D都不符合规定的相邻比较过程。该数据恰好一轮全有序，并不说明所有数组都如此。

<a id="T12-01-F"></a>

#### T12-01-F 答案与解析

①`j + 1 < end`；②`>`；③`!changed`。比较涉及j和j+1，两者都不能越过区间；相等不交换以维护稳定性；整轮无交换才表示可提前结束，不能在某一对无需交换时立刻退出。

<!-- example: A-T12-01-F -->
```c
#include <stdio.h>
static void bubble_sort(int a[], size_t n) {
    for (size_t end = n; end > 1; --end) {
        int changed = 0;
        for (size_t j = 0; j + 1 < end; ++j) {
            if (a[j] > a[j + 1]) {
                int t = a[j]; a[j] = a[j + 1]; a[j + 1] = t;
                changed = 1;
            }
        }
        if (!changed) break;
    }
}
int main(void) {
    int a[] = {6, 2, 5, 2};
    size_t n = sizeof a / sizeof a[0];
    bubble_sort(a, n);
    for (size_t i = 0; i < n; ++i) printf("%s%d", i ? " " : "", a[i]);
    putchar('\n');
    bubble_sort(a, 0);
    return 0;
}
```

**F题测试**：

- 输入`""`；预期输出`"2 2 5 6\n"`；退出状态0。

#### T12-01-P 算法与参考实现

把升序选择的“最小值”改为“最大值”，每轮maximum从i开始，再扫描i+1到n-1。内层仅更新下标，外层末尾交换。输出时第一个数前不加空格。n=0时输入数组和排序循环均不执行，只输出换行。

### K12-02 插入排序与容量

<a id="T12-02-S"></a>

#### T12-02-S 答案

B。保存key=2乙，5大于2而右移；2甲与key相等，不满足>，停止，把2乙放在2甲后。严格大于的条件保留相等项的原先顺序，故本实现稳定；若写>=才可能让新相等项越过旧项。

<a id="T12-02-F"></a>

#### T12-02-F 答案与解析

①`a[i]`；②`a[j - 1]`；③`j`。从右侧开始移动较大元素，a[i]可能被覆盖，因此必须先保存待插值。while结束时j就是应插入的空位，而不是固定的i；n=0或1时无须执行外层循环。

<!-- example: A-T12-02-F -->
```c
#include <stdio.h>
static void insertion_sort(int a[], size_t n) {
    for (size_t i = 1; i < n; ++i) {
        int key = a[i];
        size_t j = i;
        while (j > 0 && a[j - 1] > key) {
            a[j] = a[j - 1];
            --j;
        }
        a[j] = key;
    }
}
int main(void) {
    int a[] = {7, 3, 5, 3};
    size_t n = sizeof a / sizeof a[0];
    insertion_sort(a, n);
    for (size_t i = 0; i < n; ++i) printf("%s%d", i ? " " : "", a[i]);
    putchar('\n');
    insertion_sort(a, 0);
    return 0;
}
```

- 输入`""`；预期输出`"3 3 5 7\n"`；退出状态0。

### K12-03 二分边界与首个匹配

<a id="T12-03-S"></a>

#### T12-03-S 答案

B。下标0—2的元素均小于5，下标3的9是首个不小于5的值，所以返回3；a[3]!=5，因此不存在目标。lower_bound给插入位置，不直接给布尔存在性；返回n也不是最后元素下标。

<a id="T12-03-F"></a>

#### T12-03-F 答案与解析

①`i`；②`n`。扫描顺序从左到右，首次相等立即返回；n不属于合法下标，可作未找到标志。0本身是合法首元素位置，若无匹配也返回0将无法区分两种情况。

<!-- example: A-T12-03-F -->

```c
    for (size_t i = 0; i < n; ++i) if (a[i] == target) return i;
    return n;
}
int main(void) {
    const int a[] = {8, 2, 8};
    size_t n = sizeof a / sizeof a[0];
    printf("%zu %zu\n", find(a, n, 8), find(a, n, 5));
    return 0;
}
```

**F题测试**：

- 输入`""`；预期输出`"0 3\n"`；退出状态0。

<a id="T12-03-P"></a>

#### T12-03-P 算法与参考实现

输入时验证顺序；二分求lower_bound，相等时high=mid继续向左；结束后先判断low<n，再判断a[low]==target。区间每轮严格缩小；使用int索引且n≤20避免端点算术溢出，公式仍采用low+(high-low)/2。

```c
    int n, a[20], target;
    if (scanf("%d", &n) != 1 || n < 0 || n > 20) return 1;
    for (int i = 0; i < n; ++i) {
        if (scanf("%d", &a[i]) != 1 || (i > 0 && a[i] < a[i - 1])) return 1;
    }
    if (scanf("%d", &target) != 1) return 1;
    int low = 0, high = n;
    while (low < high) {
        int mid = low + (high - low) / 2;
        if (a[mid] < target) low = mid + 1;
        else high = mid;

    return 0;
}
```

<a id="T12-04-P"></a>

#### T12-04-P 算法与参考实现

逐字符映射为数码，先检查字符合法及digit<base；累加前判断value>(ULLONG_MAX-digit)/base，成立则乘加会越界；否则value=value*base+digit。宽度64为结尾空字符保留一位，题设保证无更长数码串，避免把截断前缀误当完整输入。全零与前导零均可正确得到0。

<!-- example: A-T12-04-P -->
```c
#include <stdio.h>
#include <limits.h>
int main(void) {
    unsigned int base;
    char text[65];
    if (scanf("%u %64s", &base, text) != 2 || base < 2 || base > 16) return 1;
    unsigned long long value = 0;
    for (size_t i = 0; text[i] != '\0'; ++i) {
        unsigned int digit;
        if (text[i] >= '0' && text[i] <= '9') digit = (unsigned)(text[i] - '0');
        else if (text[i] >= 'A' && text[i] <= 'F') digit = (unsigned)(text[i] - 'A') + 10;
        else { puts("Invalid digit"); return 1; }
        if (digit >= base) { puts("Invalid digit"); return 1; }
        if (value > (ULLONG_MAX - digit) / base) { puts("Overflow"); return 1; }
        value = value * base + digit;
    }
    printf("decimal=%llu\n", value);
    return 0;
}
```

### M01-F03 链表遍历（5分）

(1)`p != NULL`，2分；(2)`p->next`，3分。先检查再访问，循环沿a→b→c→NULL；next存下一节点地址，不能写成`p++`，三个局部结构不保证按链表逻辑相邻。

<!-- example: A-M01-F03 -->

```c
    int value;
    struct Node *next;
};

```

### M01-F04 文件读取（5分）

(1)`fgetc(fp)`，2分；(2)`ferror(fp)`，2分；(3)`fclose(fp)`，1分。fgetc失败既可能是正常结束，也可能是I/O错误；循环后检查ferror，随后不论是否出错都关闭。fflush检查尚留在stdout缓冲中的写入是否成功。

<!-- example: A-M01-F04 -->
```c
#include <stdio.h>
int main(void)
{
    FILE *fp = fopen("input.txt", "r");
    if (fp == NULL) {
        return 1;
    }
    int ch;
    int failed = 0;
    while ((ch = fgetc(fp)) != EOF) {
        if (putchar(ch) == EOF) {
            failed = 1;
            break;
        }
    }

        failed = 1;
    }

        failed = 1;

        failed = 1;

}
```

### M01-P01 插入排序与首下标查找（15分）

**分析。** 先验证n，使数组访问始终在0—19；读取每项及key时检查返回值和范围。插入排序保持前缀有序，每次取出当前元素，再把大于它的元素右移，最后放入空位。题目要求第一个重复值位置，使用从左到右找到即停的顺序查找最直接。

<!-- example: A-M01-P01 -->
```c
#include <stdio.h>
int main(void)
{
    int n, a[20], key;
    if (scanf("%d", &n) != 1 || n < 0 || n > 20) {
        puts("invalid");
        return 1;
    }
    for (int i = 0; i < n; i++) {
        if (scanf("%d", &a[i]) != 1 || a[i] < -1000 || a[i] > 1000) {
            puts("invalid");
            return 1;
        }
    }
    if (scanf("%d", &key) != 1 || key < -1000 || key > 1000) {
        puts("invalid");
        return 1;
    }
    for (int i = 1; i < n; i++) {
        int value = a[i];
        int j = i;
        while (j > 0 && a[j - 1] > value) {
            a[j] = a[j - 1];
            j--;
        }
        a[j] = value;
    }
    for (int i = 0; i < n; i++) {
        if (i > 0) {
            putchar(' ');
        }
        printf("%d", a[i]);
    }
    putchar('\n');
    int found = -1;
    for (int i = 0; i < n; i++) {
        if (a[i] == key) {
            found = i;
            break;
        }
    }
    printf("%d\n", found);
    return 0;
}
```

### M01-P02 文件最高分记录（20分）

**分析。** 不知道是否有第一条记录，所以用`found`区分“还没有最佳值”与“已有最佳值”，而不是编一个不存在的学号。`fscanf`返回2才得到完整记录；返回1为半条记录，返回0为格式不匹配，返回EOF后还需用ferror区分读取错误。所有已打开路径最终都调用fclose。

<!-- example: A-M01-P02 -->
```c
#include <stdio.h>
struct Record {
    int id;
    int score;
};
int main(int argc, char *argv[])
{
    if (argc != 2) {
        puts("usage");
        return 1;
    }
    FILE *fp = fopen(argv[1], "r");
    if (fp == NULL) {
        puts("invalid");
        return 1;
    }
    struct Record current;
    struct Record best = {0, 0};
    int count = 0, found = 0, failed = 0;
    int status;
    while ((status = fscanf(fp, "%d%d", &current.id, &current.score)) == 2) {
        count++;
        if (count > 100 || current.id < 1 || current.id > 9999 ||
            current.score < 0 || current.score > 100) {
            failed = 1;
            break;
        }
        if (!found || current.score > best.score ||
            (current.score == best.score && current.id < best.id)) {
            best = current;
            found = 1;
        }
    }
    if (status != EOF || ferror(fp)) {
        failed = 1;
    }
    if (fclose(fp) != 0) {
        failed = 1;
    }
    if (failed) {
        puts("invalid");
        return 1;
    }
    if (!found) {
        puts("empty");
    } else {
        printf("%d %d\n", best.id, best.score);
    }
    return 0;
}
```

|---|---|---|
| 1003 88 | 从无记录变为1003 88 | 第一条合法记录 |

| 1002 95 | 保持1001 95 | 同分且新学号更大 |

#### H01-F01

**按空填写：** 1：`a > INT_MAX - b`；2：`a < INT_MIN - b`。

<!-- example: A-H01-F01 -->
```c
#include <stdio.h>
#include <limits.h>

static int add_checked(int a, int b, int *result)
{
    if ((b > 0 && a > INT_MAX - b) || (b < 0 && a < INT_MIN - b)) return 0;
    *result = a + b;
    return 1;
}

int main(void)
{
    int result = 9;
    int ok = add_checked(INT_MAX, 1, &result);
    printf("%d %d\n", ok, result);
    ok = add_checked(INT_MAX, -1, &result);
    printf("%d\n", ok && result == INT_MAX - 1);
    return 0;
}
```

#### H01-P01 有边界的整数计算器

**分步思路与关键不变量：** 先同时验证三项输入；用switch分派操作；除法和余数共享非零检查；乘法前转long，避免先发生窄int溢出再转换；最终统一打印。

<!-- example: A-H01-P01 -->
```c
#include <stdio.h>


int main(void)
{
    int a, b;
    char op;
    if (scanf("%d %c %d", &a, &op, &b) != 3 || a < -1000 || a > 1000 || b < -1000 || b > 1000) {
        puts("INVALID"); return 1;
    }

    switch (op) {
        case '+': result = (long)a + b; break;
```

#### H01-P03 替换整数中的连续位域

**分步思路与关键不变量：** 先验证width再移位，使1U<<width至多移8位；mask产生width个低位1；右移并与mask提取旧位域；先用反掩码清位，再或入新值。unsigned至少16位，lo最高15，符合移位界限。

```c
#include <stdio.h>


int main(void)
{

    if (scanf("%u%u%u%u", &x, &lo, &width, &value) != 4 || x > 65535U || lo > 15U || width < 1U || width > 8U || lo + width > 16U) {
        puts("INVALID"); return 1;

    unsigned int mask = (1U << width) - 1U;
    if (value > mask) { puts("INVALID"); return 1; }
    unsigned int old = (x >> lo) & mask;
    unsigned int changed = (x & ~(mask << lo)) | (value << lo);
    printf("%u %u\n", old, changed);
    return 0;
}
```

#### H02-P01 无序数组稳定去重

**分步思路与关键不变量：** 已处理前缀的唯一元素放在[0,used)。每读到a[i]，只在已保留前缀中查重；没找到才向写位置放入。每轮开始used≤i，故不会覆盖尚未读取的后缀。最坏O(n²)，额外空间O(1)。

**手工跟踪：** [3,1,3,2,1]：读3写入→[3]；读1→[3,1]；读3跳过；读2→[3,1,2]；末1跳过。

```c
#include <stdio.h>

{
    int n, a[30];
    if (scanf("%d", &n) != 1 || n < 0 || n > 30) { puts("INVALID"); return 1; }
    for (int i = 0; i < n; ++i) if (scanf("%d", &a[i]) != 1) { puts("INVALID"); return 1; }

    for (int i = 0; i < n; ++i) {

        while (j < used && a[j] != a[i]) ++j;
        if (j == used) a[used++] = a[i];
```

```c
{
```

```c
    for (size_t i = 0; i < n; ++i) if (text[i] < 'a' || text[i] > 'z') { puts("INVALID"); return 1; }
```

**分步思路与关键不变量：** 区间使用[first,last)，先确认非空才--last；整体逆序，再逆转前k段和余段。所有指针都属于同一数组，尾后指针仅用于界限。k=0时整体逆序会被余段逆序抵消；空数组必须先分流。

```c
#include <stdio.h>

static void reverse(int *first, int *last)
{
    while (first < last) {
        --last;
        if (first >= last) break;
        int t = *first;
        *first++ = *last;
        *last = t;
    }
}

{

        reverse(a, a + n);
        reverse(a, a + k);
        reverse(a + k, a + n);
    }
```

**分步思路与关键不变量：** 实际对象每行5个int，n只描述有效区域，不能把参数改成int **或行长n。只遍历c>r的上三角；与下三角交换，对角线保持。遍历全矩阵会交换两次恢复原状。

```c
#include <stdio.h>

static void transpose(int (*a)[5], int n)
{
    for (int r = 0; r < n; ++r) {
        for (int c = r + 1; c < n; ++c) {
            int temp = a[r][c];
            a[r][c] = a[c][r];
            a[c][r] = temp;
        }
    }
}
```

#### H03-P03 函数指针驱动的稳定筛选

**分步思路与关键不变量：** 三个判断函数具有同一签名int(int)，指针数组保存地址；mode−1选择规则；filter只依赖返回值真假，因此不需要复制三份遍历代码。写位置不会越过读位置，保留原相对次序。

```c
static int filter(int a[], int n, int (*keep)(int))
{
    int used = 0;
    for (int i = 0; i < n; ++i) if (keep(a[i])) a[used++] = a[i];
    return used;
}

int main(void)
{

    printf("%d\n", used);
    for (int i = 0; i < used; ++i) printf("%s%d", i ? " " : "", a[i]);
    putchar('\n');
    return 0;
}
```

#### H04-P01 递归二分寻找第一个重复值

**分步思路与关键不变量：** 未匹配时只递归一半；相等时仍搜索左半，左半找不到才保留mid。不同时递归左右，最坏仍O(log n)。空数组调用(0,−1)直接命中基线，不读取a[0]。

<!-- example: A-H04-P01 -->
```c
#include <stdio.h>

static int first(const int a[], int lo, int hi, int key)
{
    if (lo > hi) return -1;
    int mid = lo + (hi - lo) / 2;
    if (a[mid] < key) return first(a, mid + 1, hi, key);
    if (a[mid] > key) return first(a, lo, mid - 1, key);
    int earlier = first(a, lo, mid - 1, key);
    return earlier == -1 ? mid : earlier;
}

int main(void)
{
    int n, a[30], key;
    if (scanf("%d", &n) != 1 || n < 0 || n > 30) { puts("INVALID"); return 1; }
    for (int i = 0; i < n; ++i) {
        if (scanf("%d", &a[i]) != 1 || (i > 0 && a[i] < a[i-1])) { puts("INVALID"); return 1; }
    }
    if (scanf("%d", &key) != 1) { puts("INVALID"); return 1; }
    printf("%d\n", first(a, 0, n - 1, key));
    return 0;
}
```

#### H04-P03 一次Horner同时求多项式与导数

**分步思路与关键不变量：** 若下一步多项式为Q_new=Q_old*x+a，则导数为D_new=D_old*x+Q_old。因此必须先更新d，再更新p，或提前保存旧p。常数多项式无迭代，导数自然为0。结果写回调用者提供的两个对象。

**手工跟踪：** P=2x³−3x²+5，x=2：初p=2,d=0；读−3→d=2,p=1；读0→d=5,p=2；读5→d=12,p=9。

<!-- example: A-H04-P03 -->
```c
#include <stdio.h>

static void evaluate(const double a[], int degree, double x,
                     double *value, double *derivative)
{
    double p = a[0], d = 0;
    for (int i = 1; i <= degree; ++i) {
        d = d * x + p;
        p = p * x + a[i];
    }
    *value = p;
    *derivative = d;
}

int main(void)
{
    int degree;
    double x, a[7];
    if (scanf("%d%lf", &degree, &x) != 2 || degree < 0 || degree > 6 || x < -3 || x > 3) { puts("INVALID"); return 1; }
    for (int i = 0; i <= degree; ++i) if (scanf("%lf", &a[i]) != 1 || a[i] < -10 || a[i] > 10) { puts("INVALID"); return 1; }
    double value, derivative;
    evaluate(a, degree, x, &value, &derivative);
    printf("%.2f %.2f\n", value, derivative);
    return 0;
}
```

#### H05-P01 结构数组的多关键字稳定排序

**分步思路与关键不变量：** 排序规则是两级判断，不靠分数相减拼接。整条结构移动，不能只移动score；条件严格优于才右移，完全相同的key不会跨过旧记录，因此稳定。order是可观测的稳定性证据。

**手工跟踪：** [(3,90,0),(1,90,1),(3,90,2),(2,80,3)]最终(1,90,1),(3,90,0),(3,90,2),(2,80,3)，两条3/90仍保持0在2前。

```c
{
    return x.score > y.score || (x.score == y.score && x.id < y.id);
}

{
```

#### H06-F01

**按空填写：** 1：`*head = node`；2：`(*tail)->next = node`；3：`*tail = node`。

第一次插入要同时建立head、tail；后续先用旧tail连接新节点再移动tail。节点为自动对象，在main结束前有效，不可free；若节点已属于其他链，不能不检查就复用此函数。

<!-- example: A-H06-F01 -->
```c
#include <stdio.h>

struct Node { int value; struct Node *next; };
static void append_node(struct Node **head, struct Node **tail, struct Node *node)
{
    node->next = NULL;
    if (*tail == NULL) *head = node;
    else (*tail)->next = node;
    *tail = node;
}

int main(void)
{
    struct Node a = {4,NULL}, b = {6,NULL};
    struct Node *head = NULL, *tail = NULL;
    append_node(&head,&tail,&a);
    append_node(&head,&tail,&b);
    printf("%d %d %d\n", head->value, head->next->value, tail->value);
    return 0;
}
```

- 核对：输入`""` → 输出`"4 6 6\n"`，退出状态0。

#### H06-F02

**按空填写：** 1：`&(*link)->next`；2：`*link = (*link)->next`。

link保存的是指针对象的地址，推进时取next成员的地址，不是把next值当成二级指针。改*link同时兼容头部与中部摘除；如果是动态节点，还需先保存victim并在改线后free一次。

<!-- example: A-H06-F02 -->
```c

int main(void)
{
    struct Node c={3,NULL}, b={2,&c}, a={1,&b};
    struct Node *head=&a;
    struct Node **link=&head;
    while (*link != NULL && (*link)->value != 2) link = &(*link)->next;
    if (*link != NULL) *link = (*link)->next;
    for (struct Node *p=head; p!=NULL; p=p->next) printf("%d%s",p->value,p->next?" ":"\n");
    return 0;
}
```

#### H06-F03

**按空填写：** 1：`p->next`；2：`*ot = p`；3：`ot = &p->next`。

必须在p->next=NULL前保存后继，否则丢失未处理链。ot始终指奇链末尾的NULL槽，写*ot=p后再移至新节点next槽。每条链采用尾接，故稳定；不需要奇链首次插入的特别分支。

<!-- example: A-H06-F03 -->
```c
#include <stdio.h>

struct Node { int value; struct Node *next; };

int main(void)
{
    struct Node d={4,NULL}, c={3,&d}, b={2,&c}, a={1,&b};
    struct Node *odd=NULL,*even=NULL;
    struct Node **ot=&odd, **et=&even;
    struct Node *p=&a;
    while (p != NULL) {
        struct Node *next=p->next;
        p->next=NULL;
        if (p->value % 2 != 0) { *ot = p; ot = &p->next; }
        else { *et=p; et=&p->next; }
        p=next;
    }
    for (struct Node *q=odd;q!=NULL;q=q->next) printf("%d%s",q->value,q->next?" ":"\n");
    for (struct Node *q=even;q!=NULL;q=q->next) printf("%d%s",q->value,q->next?" ":"\n");
    return 0;
}
```

- 核对：输入`""` → 输出`"1 3\n2 4\n"`，退出状态0。

#### H06-P01 三指针原地反转单链表

**分步思路与关键不变量：** previous是已反转前缀的入口，current是未处理后缀入口；先保留next，再反向改线。每轮恰好把一个节点从未处理移到已处理。结束head=previous；旧tail不再使用，若后续要尾插必须重新维护tail。

**手工跟踪：** 1→2→3：prev=NULL；处理1后1→NULL,current2；处理2后2→1,current3；处理3后3→2→1,currentNULL。

<!-- example: A-H06-P01 -->
```c
#include <stdio.h>
#include <stdlib.h>

struct Node { int value; struct Node *next; };
static void destroy(struct Node *head)
{
    while (head != NULL) {
        struct Node *next = head->next;
        free(head);
        head = next;
    }
}
static int append(struct Node **head, struct Node **tail, int value)
{
    struct Node *p = malloc(sizeof *p);
    if (p == NULL) return 0;
    p->value = value; p->next = NULL;
    if (*tail != NULL) (*tail)->next = p;
    else *head = p;
    *tail = p;
    return 1;
}
static void print_list(const struct Node *head)
{
    if (head == NULL) { puts("EMPTY"); return; }
    for (const struct Node *p = head; p != NULL; p = p->next)
        printf("%d%s", p->value, p->next == NULL ? "\n" : " ");
}

int main(void)
{
    int n;
    struct Node *head = NULL, *tail = NULL;
    if (scanf("%d", &n) != 1 || n < 0 || n > 20) { puts("INVALID"); return 1; }
    for (int i = 0; i < n; ++i) {
        int value;
        if (scanf("%d", &value) != 1) { puts("INVALID"); destroy(head); return 1; }
        if (!append(&head, &tail, value)) { puts("ALLOC_FAIL"); destroy(head); return 1; }
    }
    struct Node *previous = NULL, *current = head;
    while (current != NULL) {
        struct Node *next = current->next;
        current->next = previous;
        previous = current;
        current = next;
    }
    head = previous;
    print_list(head);
    destroy(head);
    return 0;
}
```

#### H06-P02 重接节点合并两条有序链表

**分步思路与关键不变量：** 局部dummy只提供统一入口槽位，不被纳入返回链；返回dummy.next所指的动态节点合法，返回&dummy则非法。每次取较小首节点，相等取a保证来源内次序；一条耗尽就接另一条剩余链。合并后所有权转移到merged，只destroy它，不能再分别destroy(a)和destroy(b)。

**手工跟踪：** a=1→3→5，b=1→2→6：依次取a1、b1、b2、a3、a5，再接b6；一共6个原节点，无新增动态分配。

<!-- example: A-H06-P02 -->
```c
#include <stdio.h>
#include <stdlib.h>

struct Node { int value; struct Node *next; };
static void destroy(struct Node *head)
{
    while (head != NULL) {
        struct Node *next = head->next;
        free(head);
        head = next;
    }
}
static int append(struct Node **head, struct Node **tail, int value)
{
    struct Node *p = malloc(sizeof *p);
    if (p == NULL) return 0;
    p->value = value; p->next = NULL;
    if (*tail != NULL) (*tail)->next = p;
    else *head = p;
    *tail = p;
    return 1;
}
static void print_list(const struct Node *head)
{
    if (head == NULL) { puts("EMPTY"); return; }
    for (const struct Node *p = head; p != NULL; p = p->next)
        printf("%d%s", p->value, p->next == NULL ? "\n" : " ");
}
static struct Node *merge(struct Node *a, struct Node *b)
{
    struct Node dummy = {0, NULL};
    struct Node *tail = &dummy;
    while (a != NULL && b != NULL) {
        if (a->value <= b->value) { tail->next = a; a = a->next; }
        else { tail->next = b; b = b->next; }
        tail = tail->next;
    }
    tail->next = a != NULL ? a : b;
    return dummy.next;
}

int main(void)
{
    int n, m;
    struct Node *a = NULL, *at = NULL, *b = NULL, *bt = NULL;
    if (scanf("%d%d", &n, &m) != 2 || n < 0 || n > 20 || m < 0 || m > 20) { puts("INVALID"); return 1; }
    for (int which = 0; which < 2; ++which) {
        int length = which == 0 ? n : m;
        struct Node **head = which == 0 ? &a : &b;
        struct Node **tail = which == 0 ? &at : &bt;
        for (int i = 0; i < length; ++i) {
            int value;
            if (scanf("%d", &value) != 1 || (*tail != NULL && value < (*tail)->value)) {
                puts("INVALID"); destroy(a); destroy(b); return 1;
            }
            if (!append(head, tail, value)) { puts("ALLOC_FAIL"); destroy(a); destroy(b); return 1; }
        }
    }
    struct Node *merged = merge(a, b);
    print_list(merged);
    destroy(merged);
    return 0;
}
```

#### H06-P03 二级指针删除所有匹配节点

**分步思路与关键不变量：** link指向“通往当前节点的指针槽位”，可以是外部head或某节点next。删除后槽位已指向下一节点，因此留在原槽位继续检查；没删除才前进。若删除后仍前进，会跳过连续相等节点。

**手工跟踪：** 2→2→1→2删2：head槽连续删除前两个2；在1时移动到1.next槽；删除尾2后该槽为NULL；返回3，余链1。

<!-- example: A-H06-P03 -->
```c
#include <stdio.h>
#include <stdlib.h>

struct Node { int value; struct Node *next; };
static void destroy(struct Node *head)
{
    while (head != NULL) {
        struct Node *next = head->next;
        free(head);
        head = next;
    }
}
static int append(struct Node **head, struct Node **tail, int value)
{
    struct Node *p = malloc(sizeof *p);
    if (p == NULL) return 0;
    p->value = value; p->next = NULL;
    if (*tail != NULL) (*tail)->next = p;
    else *head = p;
    *tail = p;
    return 1;
}
static void print_list(const struct Node *head)
{
    if (head == NULL) { puts("EMPTY"); return; }
    for (const struct Node *p = head; p != NULL; p = p->next)
        printf("%d%s", p->value, p->next == NULL ? "\n" : " ");
}
static int remove_all(struct Node **head, int target)
{
    struct Node **link = head;
    int count = 0;
    while (*link != NULL) {
        if ((*link)->value == target) {
            struct Node *victim = *link;
            *link = victim->next;
            free(victim);
            ++count;
        } else {
            link = &(*link)->next;
        }
    }
    return count;
}

int main(void)
{

        int value;
        if (scanf("%d", &value) != 1) { puts("INVALID"); destroy(head); return 1; }
        if (!append(&head, &tail, value)) { puts("ALLOC_FAIL"); destroy(head); return 1; }
    }
    int target;
    if (scanf("%d", &target) != 1) { puts("INVALID"); destroy(head); return 1; }
    int deleted = remove_all(&head, target);
    printf("%d\n", deleted);
    print_list(head);
    destroy(head);
    return 0;
}
```

#### H07-S01

**答案：B。** 先成功给a赋值7，之后遇EOF；返回已成功赋值项数1，不是EOF。即使feof已置位，也不能把半条记录当合法完整数据。

<a id="H07-S02"></a>

#### H07-S02

**答案：B。** 正常读完最后一项后，通常尚未因下一次失败读取设置EOF指示；再次进入循环可能重复累加旧值。空文件还可能读取未初始化x。必须以读操作返回值为循环条件。

#### H07-S03

**答案：B。** ||会短路，A在关闭a失败时跳过关闭b。关闭成功或失败后都不能继续把原FILE *当成可用流进行查询。分别执行能覆盖两次清理。

<a id="H07-F01"></a>

#### H07-F01

**按空填写：** 1：`isspace((unsigned char)ch)`；2：`!inside`。

读取成功后ch已经不是EOF，转换为unsigned char交给isspace。只在“之前在空白区、当前非空白”的边沿加1；不能每个非空白字符都加1。换行、制表也属于空白。

<!-- example: A-H07-F01 -->
```c
#include <stdio.h>
#include <ctype.h>


int main(void)
{
    FILE *fp=fopen("word.txt","r");
    if (fp==NULL) return 1;
    int ch, inside=0;
    size_t words=0;
    while ((ch=fgetc(fp))!=EOF) {
        if (isspace((unsigned char)ch)) inside=0;
        else if (!inside) { ++words; inside=1; }
    }
    int bad=ferror(fp)!=0;
    if (fclose(fp)!=0) bad=1;
    if (bad) return 1;
    printf("%zu\n",words);
    return 0;
}
```

- 核对：输入`""`；输入文件`{"word.txt": "one\t two\nthree"}` → 输出`"3\n"`，退出状态0。

- 核对：输入`""`；输入文件`{"word.txt": " \n\t"}` → 输出`"0\n"`，退出状态0。

- 核对：输入`""`；输入文件`{"word.txt": ""}` → 输出`"0\n"`，退出状态0。

- 核对：输入`""` → 输出`""`，退出状态1。

#### H07-F02

**按空填写：** 1：`fgets(line, sizeof line, fp) != NULL`；2：`fputs(line, stdout) == EOF`。

成功读取一整行才加行号；本题有行长前提，所以每次fgets对应一行。fputs不自行加换行，故末行无换行时需补。不存在的输入文件返回1；空文件不打印任何编号。

<!-- example: A-H07-F02 -->
```c
#include <stdio.h>
#include <string.h>


int main(void)
{
    FILE *fp=fopen("input.txt","r");
    if (fp==NULL) return 1;
    char line[64];
    size_t number=0;
    int bad=0;
    while (fgets(line, sizeof line, fp) != NULL) {
        if (printf("%zu:",++number)<0 || fputs(line, stdout) == EOF) { bad=1; break; }
        if (strchr(line,'\n')==NULL && putchar('\n')==EOF) { bad=1; break; }
    }

    if (fclose(fp)!=0) bad=1;
```

#### H07-F03

**按空填写：** 1：`if (fclose(a) != 0) bad = 1`；2：`if (fclose(b) != 0) bad = 1`。

先前写入失败也必须清理两个流。分别调用保证第一次关闭失败不会阻止第二次关闭。每条if都独立执行一个完整检查，不能把关闭失败作为跳过另一项清理的理由。

#### H07-P01 文件逻辑行与数字频次统计

**分步思路与关键不变量：** 每遇换行结束当前行并比较最大长度；循环结束时根据是否非空且末字符非换行补计末行。读取变量为int，EOF不入统计。计数全部用size_t，文件上限限制增长；读错误与正常结束必须区分，最后检查关闭。标准输出失败只保证返回1，无法保证故障输出设备仍能显示INVALID。

**手工跟踪：** 内容a12

9：两次换行已计2行，末尾9再补1行；长度为3、0、1，最长3；数字1、2、9各1。

<!-- example: A-H07-P01 -->
```c
#include <stdio.h>
int main(int argc, char *argv[])
{
    if (argc != 2) { puts("INVALID"); return 1; }
    FILE *fp = fopen(argv[1], "r");
    if (fp == NULL) { puts("INVALID"); return 1; }
    size_t counts[10] = {0}, lines = 0, longest = 0, current = 0, bytes = 0;
    int ch, last = '\n', bad = 0;
    while ((ch = fgetc(fp)) != EOF) {
        if (++bytes > 10000) { bad = 1; break; }
        if (ch >= '0' && ch <= '9') ++counts[ch - '0'];
        if (ch == '\n') {
            ++lines;
            if (current > longest) longest = current;
            current = 0;
        } else ++current;
        last = ch;
    }
    if (bytes > 0 && last != '\n') {
        ++lines;
        if (current > longest) longest = current;
    }
    if (ferror(fp)) bad = 1;
    if (fclose(fp) != 0) bad = 1;
    if (bad) { puts("INVALID"); return 1; }
    printf("lines=%zu longest=%zu\n", lines, longest);
    for (int i = 0; i < 10; ++i) printf("%s%zu", i ? " " : "", counts[i]);
    putchar('\n');
    if (fflush(stdout) == EOF) return 1;
    return 0;
}
```

#### H07-P02 两个有序文件的流式归并

**分步思路与关键不变量：** next将“合法记录/正常EOF/错误”分成1/0/−1，并在读入时验证非递减。主循环只输出两个当前值中较小者，然后仅推进其来源文件；缺失的一侧视为耗尽。写入、读取、三个关闭结果都收集，不能短路跳过某个fclose。空间O(1)，遍历O(n+m)。

**手工跟踪：** left=1,4；right=2,4：输出1推进left→4；输出2推进right→4；相等先取left4使其耗尽；最后输出right4。

<!-- example: A-H07-P02 -->
```c
#include <stdio.h>

struct Input { FILE *fp; int previous, count; };
static int next(struct Input *in, int *value)
{
    int status = fscanf(in->fp, "%d", value);
    if (status == EOF) return ferror(in->fp) ? -1 : 0;
    if (status != 1 || *value < -1000 || *value > 1000 || in->count == 30 ||
        (in->count > 0 && *value < in->previous)) return -1;
    in->previous = *value;
    ++in->count;
    return 1;
}

int main(void)
{
    struct Input a = {NULL, 0, 0}, b = {NULL, 0, 0};
    a.fp = fopen("left.txt", "r");
    b.fp = fopen("right.txt", "r");
    if (a.fp == NULL || b.fp == NULL) {
        if (a.fp != NULL) fclose(a.fp);
        if (b.fp != NULL) fclose(b.fp);
        puts("INVALID"); return 1;
    }
    FILE *out = fopen("merged.txt", "w");
    if (out == NULL) { fclose(a.fp); fclose(b.fp); puts("INVALID"); return 1; }
    int x = 0, y = 0, sa = next(&a, &x), sb = next(&b, &y);
    int bad = 0, first = 1;
    while (sa > 0 || sb > 0) {
        if (sa < 0 || sb < 0) { bad = 1; break; }
        int take_a = sb == 0 || (sa > 0 && x <= y);
        if (fprintf(out, "%s%d", first ? "" : " ", take_a ? x : y) < 0) { bad = 1; break; }
        first = 0;
        if (take_a) sa = next(&a, &x);
        else sb = next(&b, &y);
    }
    if (sa < 0 || sb < 0) bad = 1;
    if (!bad && fputc('\n', out) == EOF) bad = 1;
    if (fclose(a.fp) != 0) bad = 1;
    if (fclose(b.fp) != 0) bad = 1;
    if (fclose(out) != 0) bad = 1;
    puts(bad ? "INVALID" : "OK");
    return bad;
}
```

**正常与边界核验：**

- 输入文件`{"left.txt": "1 4", "right.txt": "2 4"}`；输入`""` → 输出`"OK\n"`；退出状态0。

- 输入文件`{"left.txt": "", "right.txt": ""}`；输入`""` → 输出`"OK\n"`；退出状态0。

- 输入文件`{"left.txt": "", "right.txt": "-1 3"}`；输入`""` → 输出`"OK\n"`；退出状态0。

- 输入文件`{"left.txt": "2 1", "right.txt": "3"}`；输入`""` → 输出`"INVALID\n"`；退出状态1。

- 输入文件`{"left.txt": "1 x", "right.txt": ""}`；输入`""` → 输出`"INVALID\n"`；退出状态1。

- 输入`""` → 输出`"INVALID\n"`；退出状态1。

#### H07-P03 按文件中的学号累计统计

**分步思路与关键不变量：** 按完整记录fscanf==2推进，匹配失败0或半条1都判错；退出后即使出现EOF也看ferror。每个id首次出现建立四字段记录，之后更新次数、和、最大值；总分≤10000，int足够。读取完全成功后才排序并输出，避免把部分统计当正确结果。结构复合字面量是C99及以后语法，可改为逐成员赋值理解。

**手工跟踪：** 2/80、1/90、2/100：表先2:(1,80,80)，再1:(1,90,90)，再2:(2,180,100)；按id输出1后2。

<!-- example: A-H07-P03 -->
```c
#include <stdio.h>
struct Summary { int id, count, sum, maximum; };
int main(int argc, char *argv[])
{
    if (argc != 2) { puts("INVALID"); return 1; }
    FILE *fp = fopen(argv[1], "r");
    if (fp == NULL) { puts("INVALID"); return 1; }
    struct Summary a[20];
    int used = 0, records = 0, id, score, status, bad = 0;
    while ((status = fscanf(fp, "%d%d", &id, &score)) == 2) {
        if (++records > 100 || id < 1 || id > 9999 || score < 0 || score > 100) { bad = 1; break; }
        int j = 0;
        while (j < used && a[j].id != id) ++j;
        if (j == used) {
            if (used == 20) { bad = 1; break; }
            a[used] = (struct Summary){id, 0, 0, score};
            ++used;
        }
        ++a[j].count; a[j].sum += score;
        if (score > a[j].maximum) a[j].maximum = score;
    }
    if (status != EOF || ferror(fp)) bad = 1;
    if (fclose(fp) != 0) bad = 1;
    if (bad) { puts("INVALID"); return 1; }
    for (int i = 1; i < used; ++i) {
        struct Summary key = a[i]; int j = i;
        while (j > 0 && a[j-1].id > key.id) { a[j] = a[j-1]; --j; }
        a[j] = key;
    }
    if (used == 0) puts("EMPTY");
    for (int i = 0; i < used; ++i) printf("%d %d %d %d\n", a[i].id, a[i].count, a[i].sum, a[i].maximum);
    if (fflush(stdout) == EOF) return 1;
    return 0;
}
```

#### H08-F01

**按空填写：** 1：`last = i`；2：`end = last`。

最后交换发生在i−1与i，i及其后缀已无需再次比较，下一轮处理长度i的前缀，即end=i。若全轮无交换last=0，直接终止；错填i−1可能跳过尚未有序的一对。

<!-- example: A-H08-F01 -->
```c
#include <stdio.h>


int main(void)
{
    int a[]={4,1,3,2};
    int end=4;
    while (end>1) {
        int last=0;
        for (int i=1;i<end;++i) if (a[i-1]>a[i]) {
            int t=a[i-1]; a[i-1]=a[i]; a[i]=t;
            last = i;
        }
        end = last;
    }
    for (int i=0;i<4;++i) printf("%s%d",i?" ":"",a[i]);
    putchar('\n');
    return 0;
}
```

- 核对：输入`""` → 输出`"1 2 3 4\n"`，退出状态0。

#### H08-F03

**按空填写：** 1：`value > (ULONG_MAX - digit) / 10UL`；2：`value * 10UL + digit`。

要判断value×10+digit是否超过上限，移项得到value>(ULONG_MAX−digit)/10。先检查再运算，不能等无符号绕回后才凭变小猜溢出。失败不改*out。本机unsigned long为64位，给定38位9超其范围；移植时按ULONG_MAX验证该具体长串。

<!-- example: A-H08-F03 -->
```c
#include <stdio.h>
#include <limits.h>

static int parse(const char *text, unsigned long *out)
{
    unsigned long value=0;
    for (size_t i=0;text[i]!='\0';++i) {
        unsigned long digit=(unsigned long)(text[i]-'0');
        if (value > (ULONG_MAX - digit) / 10UL) return 0;
        value=value * 10UL + digit;
    }
    *out=value;
    return 1;
}

int main(void)
{
    unsigned long value=0;
    if (parse("123",&value)) printf("%lu\n",value);
    printf("%d\n",parse("9999999999999999999999999999999999999999",&value));
    return 0;
}
```

#### H08-P01 排序后找出全部众数

**分步思路与关键不变量：** 排序使同值相邻；第一遍扫描段求最大长度，第二遍只输出达到最大长度的段首。先求最大再输出，避免先前候选被更长段推翻。n=0两遍都跳过，maximum=0。

**手工跟踪：** [3,1,3,2,2,1]排序[1,1,2,2,3,3]，三个段长都2，输出全部1、2、3。

<!-- example: A-H08-P01 -->
```c
#include <stdio.h>


int main(void)
{
    int n, a[30];
    if (scanf("%d", &n) != 1 || n < 0 || n > 30) { puts("INVALID"); return 1; }
    for (int i = 0; i < n; ++i) if (scanf("%d", &a[i]) != 1) { puts("INVALID"); return 1; }
    for (int i = 1; i < n; ++i) {
        int key = a[i], j = i;
        while (j > 0 && a[j-1] > key) { a[j] = a[j-1]; --j; }
        a[j] = key;
    }
    int maximum = 0;
    for (int i = 0; i < n;) {
        int j = i + 1;
        while (j < n && a[j] == a[i]) ++j;
        if (j - i > maximum) maximum = j - i;
        i = j;
    }
    printf("frequency=%d\n", maximum);
    int first = 1;
    for (int i = 0; i < n;) {
        int j = i + 1;
        while (j < n && a[j] == a[i]) ++j;
        if (j - i == maximum) { printf("%s%d", first ? "" : " ", a[i]); first = 0; }
        i = j;
    }
    putchar('\n');
    return 0;
}
```

#### H08-P02 两次二分定位重复值区间

**分步思路与关键不变量：** lower求首个≥key位置，upper求首个>key位置。出现区间是[lower,upper)，长度为差，末次位置upper−1。不存在时两端相同；空数组返回0、0，不解引用尾后位置。

**手工跟踪：** [1,2,2,2,4]找2：lower=1,upper=4→1 3 3；找3：两者都4→−1 −1 0。

<!-- example: A-H08-P02 -->
```c
#include <stdio.h>

static int bound(const int a[], int n, int key, int upper)
{
    int low = 0, high = n;
    while (low < high) {
        int mid = low + (high - low) / 2;
        if (a[mid] < key || (upper && a[mid] == key)) low = mid + 1;
        else high = mid;
    }
    return low;
}

int main(void)
{
    int n, q, a[30], queries[10];
    if (scanf("%d", &n) != 1 || n < 0 || n > 30) { puts("INVALID"); return 1; }
    for (int i = 0; i < n; ++i) if (scanf("%d", &a[i]) != 1 || (i > 0 && a[i] < a[i-1])) { puts("INVALID"); return 1; }
    if (scanf("%d", &q) != 1 || q < 0 || q > 10) { puts("INVALID"); return 1; }
    for (int i = 0; i < q; ++i) if (scanf("%d", &queries[i]) != 1) { puts("INVALID"); return 1; }
    for (int i = 0; i < q; ++i) {
        int low = bound(a, n, queries[i], 0);
        int high = bound(a, n, queries[i], 1);
        if (low == high) puts("-1 -1 0");
        else printf("%d %d %d\n", low, high - 1, high - low);
    }
    return 0;
}
```

#### H08-P03 通过插入排序计数逆序对

**分步思路与关键不变量：** 插入key时，前缀已排序，但其元素均来自key之前的原位置。每个大于key的旧元素右移一次，恰对应以key为右端的一个逆序对。所有右端各处理一次，无遗漏重复；必须用>，使用>=会把相等元素计入。

**手工跟踪：** [3,1,2,1]：插1移3一次；插2移3一次；末1移3和2各一次，共4；两次1不形成逆序对。

<!-- example: A-H08-P03 -->
```c
#include <stdio.h>


int main(void)
{
    int n, a[30];
    if (scanf("%d", &n) != 1 || n < 0 || n > 30) { puts("INVALID"); return 1; }
    for (int i = 0; i < n; ++i) if (scanf("%d", &a[i]) != 1) { puts("INVALID"); return 1; }
    long inversions = 0;
    for (int i = 1; i < n; ++i) {
        int key = a[i], j = i;
        while (j > 0 && a[j-1] > key) {
            a[j] = a[j-1]; --j; ++inversions;
        }
        a[j] = key;
    }
    printf("%ld\n", inversions);
    for (int i = 0; i < n; ++i) printf("%s%d", i ? " " : "", a[i]);
    putchar('\n');
    return 0;
}
```

**正常与边界核验：**

- 输入`"4 3 1 2 1"` → 输出`"4\n1 1 2 3\n"`；退出状态0。

- 输入`"0"` → 输出`"0\n\n"`；退出状态0。

- 输入`"3 2 2 2"` → 输出`"0\n2 2 2\n"`；退出状态0。

- 输入`"5 5 4 3 2 1"` → 输出`"10\n1 2 3 4 5\n"`；退出状态0。

- 输入`"3 -1 0 1"` → 输出`"0\n-1 0 1\n"`；退出状态0。
