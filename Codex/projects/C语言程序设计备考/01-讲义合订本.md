## 使用约定与先修顺序

**★基础**要求说清概念、手算短程序；**★★应用**要求独立组合知识、处理边界；**★★★提高**选做，不作为开始下一章的门槛。考纲要求的知识点正文均应学习；只有明确标出的提高拓展或题目可选做。知识点按K编号，完整例题按E编号；每点配T编号的选择S、程序完善F、独立编程P三题。看到`T05-02-P`就能定位“第5章第2点的编程题”，题目与解析同号。

本讲义统一使用**标准C17**，使用`int main(void)`，需要命令行参数时使用`int main(int argc, char *argv[])`。考纲中的“ANSI C格式”以明确参数类型的函数原型和定义来讲，区分声明、定义、调用，不采用早期K&R旧式定义。“ANSI C”常用于指C89/C90；C17在2017年完成修订并于2018年发布，不代表本考纲改考新内容。[GCC官方标准说明](https://gcc.gnu.org/onlinedocs/gcc/Standards.html#C-Language)

C99以后允许在语句间声明变量、在for初始化中声明变量，支持`//`注释、`long long`及`%zu`。若指定严格C90作答，需把块内声明移到语句之前、for变量提前声明、用`/*...*/`注释，并核对类型及格式；不能直接把本讲义所有示例宣称为C90代码。旧考点`gets`仍解释其输入行为、与fgets的区别和缺陷；C11已移除gets，可运行示例统一使用fgets。[WG14 C11制定过程草案N1516，前言变更列表](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1516.pdf)

**程序与片段。** 标有“完整程序”的代码块可单独保存为`.c`编译；不要把多个带main的程序粘贴成同一个源文件。标有“片段”“填空”“问题分析”的代码不保证能独立运行；多文件例必须按文件名分别保存后共同编译。所有代码块用`c`标记，固定输出另外用`text`标记。

**数值和文字前提。** 没有另行说明时，示例处理明确给定的小整数和单字节英文字符；字符/字符串的具体比较结果按本机ASCII兼容执行字符集及默认C区域设置核对。scanf数值题约定输入数字在接收类型可表示范围内，再检查题目的业务范围；仅检查scanf返回值不能解决超长数字的转换溢出。任意数字文本的稳健处理示例见K11-03的strtol。浮点数的最后几位受实现和舍入影响；数学例题用明确精度展示，勿把屏幕小数等同于数学上的精确值。中文UTF-8常是一字多字节，不可把char、strlen与汉字个数画等号。

## 怎样学一个知识点

1. 用自己的话说出本点解决什么问题，以及输入、输出与合法范围。
2. 遮住运行结果，按“语句→变量旧值→变量新值”手动跟踪；指针额外画对象与地址箭头，递归同时画下降与回升。
3. 编译运行完整例题，对照预测；若不一致，找第一处变量轨迹差异，不急着改最后一行输出。
4. 做对应S题和F题，再独立写P题。先构造正常、最小/空、重复、未找到、失败输入等适用用例。
5. 对照解析后只记录“错因＋正确规则＋一条反例”；同类题改一个条件再做，避免只记本题数字。

第一轮每次学习1—2个知识点即可，不要求一天学完一章。先走01—06章基础，再学07—09章数据组织，最后10—12章文件和算法；第12章排序可在数组与函数学完后提前练。学习资料完成不等于用户已经掌握，具体进度以实际答题为准。

## 怎样讲一节小课

每次只设一个可观察目标，例如“能画出p与*p分别指什么”或“能说明二分为何需要有序”。用5分钟明确生活问题和规则，10分钟画数据/流程，10分钟手动跟踪完整程序，10分钟做相应S/F题，5分钟让学生独立改一个条件。时间仅是教学参考，不强制排进既有备考日程。

板书留四栏：**题意与边界｜对象/变量表｜程序与执行箭头｜输出与核验**。学生答错时，先让其指出自己认为被修改的对象，再用最短反例区分。例如把数组容量写成最后下标，就画3个格子标0、1、2；把指针当值，就分别改p和*p；把feof当预言，就追踪“最后一次成功读完”与“下一次失败读取”两个时刻。

生活比喻只负责帮助建立最初图像，最终必须回到类型、对象、生存期和操作规则；“像盒子、像地址簿”不替代C语言语义。

## 第01章 从程序到数据定义

<a id="K01-01"></a>

### K01-01 ★ 程序结构、语句与解决问题的步骤

**先懂概念。** 程序把“输入是什么、按什么规则处理、输出什么”写成计算机能执行的指令。C程序通常包含预处理指令、声明和函数；在本讲义的普通宿主环境中，程序从`main`开始执行。源文件并非从第一行开始逐行运行：`#include`先参与预处理，函数体内的语句才在函数被调用时执行。标准库提供输入输出等现成工具，自定义函数用于拆分自己的任务。

**生活入口与学生理解。** 把程序看作一份算购物费用的操作单：数量和单价是数据，乘法是规则，账单是输出。先用纸笔算一组数据，再用变量代表可变化的数。类比边界：计算机不会从“差不多”“适量”推断规则，必须明确类型、顺序和边界。

**例题 E01-01：买3本、每本8元的练习册，输出总价。完整程序。**

<!-- example: E01-01 -->
```c
#include <stdio.h>

int main(void)
{
    int count = 3;
    int price = 8;
    int total = count * price;
    printf("total=%d\n", total);
    return 0;
}
```

**分步解答。** ①`#include <stdio.h>`提供`printf`的声明，不带分号。②`int main(void)`表示主函数返回`int`，不接收参数；一对花括号构成函数体。③三条声明依次把`count`、`price`、`total`设为3、8、24。④`printf`中的`%d`由整数24替换，`\n`换行。⑤`return 0;`向运行环境报告成功；它不是向屏幕打印0。

预期输出：
```text
total=24
```

**老师如何讲。** 板书按“输入/已知量→数学式→变量表→完整程序→手算核验”排列。先遮住代码让学生算24，再逐句对照，不要求先背头文件。追问：“把`count`改成4，哪一行还要改？”答：计算语句不必改，结果自动为32。追问：“漏写分号属于算错还是语法问题？”答：语法问题，往往编译阶段发现。

**常见错误与纠正。** `printf`拼错或漏声明不能靠猜测修复；先读编译器指出的位置及其前一行。把`×`写进C表达式应改为`*`。输出不符合预期时按变量变化检查，不能因为“能运行”就认定逻辑正确。

**方法小结。** 题意→输入输出及范围→手工算例→算法步骤→编码→正常/边界用例。对应练习：T01-01-S/F/P。

### K01-02 ★ 常量、进制、转义字符与符号常量

**概念与写法。** 常量是源代码中直接写出的固定值。`26`是十进制，`032`是八进制，`0x1A`是十六进制，都表示26；前导0不是装饰，`08`不是合法八进制整数。`26L`带`long`后缀，`26U`带`unsigned`后缀，`26UL`组合两者。整数常量的最终类型还取决于进制、后缀和值能被哪些类型表示，不能把所有无后缀常量都当成`int`。负数写法`-3`在语法上是负号运算符作用于常量3。

`3.5`、`.5`、`5.`是十进制浮点常量；`1.25e2`是125，`1e-3`是0.001；指数部分必须是整数。无后缀通常是`double`，`3.5f`为`float`，`3.5L`为`long double`。C17不把`0b1010`作为标准二进制整数写法。

普通字符常量`'A'`在C中类型是`int`，`"A"`则是包含字符A和末尾零字符的字符串字面量。`'\n'`换行、`'\t'`水平制表、`'\0'`零字符、`'\\'`反斜杠、`'\''`单引号、`'\"'`双引号；`\ooo`最多三位八进制数字，`\xhh...`连续读取十六进制数字，因此后面若紧接A—F要特别小心。中文字符通常不能按一个`char`理解。

**符号常量。** `#define DAYS 7`做预处理替换，无等号、无尾分号。`NULL`是相关标准头文件提供的空指针常量宏，用于表示不指向对象/函数的空指针，不是一个可以解引用的地址；`EOF`在`<stdio.h>`中表示输入结束或失败的负整数常量，不能假定永远等于−1。二者都不是字符串末尾的`'\0'`。

**生活入口。** 同一件商品可以用中文名、编号或条码表达，数值也能用不同进制书写；但编码规则不能混用。学生先把`032`展开为`3×8+2`，再算`0x1A=1×16+10`，认识“写法不同、值相同”。

**例题 E01-02：对照常量写法。完整程序。**

<!-- example: E01-02 -->
```c
#include <stdio.h>
#define DAYS 7

int main(void)
{
    unsigned int stock = 26U;
    long distance = 120L;
    printf("%d %d %d\n", 26, 032, 0x1A);
    printf("%u %ld %.2f %d\n", stock, distance, 1.25e2, DAYS);
    printf("%c %s\n", 'A', "A");
    printf("quote=\" slash=\\\n");
    return 0;
}
```

**分步解答。** 第一行先解释进制再输出十进制，所以三个数都是26。第二行`%u`对应无符号整数、`%ld`对应`long`，`%.2f`保留两位小数，`DAYS`在编译前被替换为7。第三行字符和字符串恰好显示一样，但类型与存储方式不同。第四行的转义组合各生成一个字符。

```text
26 26 26
26 120 125.00 7
A A
quote=" slash=\
```

**教师板书与追问。** 顺序：字面形式→对应数值→类型/后缀→输出格式→三个容易混淆的零。问“`'0'`与`'\0'`一样吗？”答：前者是数字字符，后者值为0的字符，用于字符串终止。问“`NULL`与`EOF`能互换吗？”答：用途和类型语境都不同。

**纠错。** 不能用`%d`随意打印`long`或`double`；可变参数函数不会自动替你修正格式。不要把字符串字面量当成可修改数组。对应练习：T01-02-S/F/P。

### K01-03 ★ 变量定义、初始化与基本类型

**概念与语法。** 变量是有名称、有类型、在生存期内保存值的对象。`int score = 80;`同时定义并初始化；`score = 90;`是后续赋值；`int score;`在自动局部情形下没有给出确定初值。标识符由字母、数字、下划线组成，不能以数字开头，区分大小写，不能用`int`等关键字。

整数常用`short`、`int`、`long`及对应`unsigned`，实数常用`float`、`double`，单个字节大小的字符对象用`char`。标准保证`sizeof(char)==1`，这个1是一个C字节，位数用`CHAR_BIT`查；不规定所有机器`int`都是4字节。用`<limits.h>`查看整数范围；本讲义数值例题取可表示的小数值。有符号整数溢出是未定义行为，不能按“必定绕回负数”答题；无符号运算按其取值范围的模进行。浮点数往往只能近似表示十进制小数。

`const int limit = 10;`定义不可通过该名字修改的对象；它不同于文本替换宏，在C中也不普遍等同于整数常量表达式。一次声明多个变量时，每个变量要分别初始化：`int a = 0, b = 0;`。

**生活入口。** 变量像带标签的容器，类型约束可放入的数据和运算方式；但实际内存不是各种形状的盒子，赋值也不会把原变量“搬空”。学生应在纸上为每个变量画一格，赋值时划掉旧值、写入新值。

**例题 E01-03：记录库存与单价。完整程序。**

<!-- example: E01-03 -->
```c
#include <stdio.h>

int main(void)
{
    int stock = 5;
    double price = 2.5;
    char grade = 'A';
    const int sold = 2;
    stock = stock - sold;
    double value = stock * price;
    printf("%c %d %.2f\n", grade, stock, value);
    return 0;
}
```

| 步骤 | stock | price | sold | value |
|---|---:|---:|---:|---:|
| 初始化 | 5 | 2.5 | 2 | 尚未定义 |
| 卖出后 | 3 | 2.5 | 2 | 尚未定义 |
| 计算余货价值 | 3 | 2.5 | 2 | 7.5 |

输出为`A 3 7.50`后换行。`stock = stock - sold`先用旧值5算出3，再写回；不是数学中的恒等式。`value`定义在语句后是C99及以后允许的写法，若题目要求严格C90，可把声明移到代码块开头，再赋值。

**教师板书与追问。** 先列“名称/类型/初值/后续值”，再写赋值。问“初始化`int a=3,b=a;`以后改a，b跟着变吗？”答：不会，b已经取得当时的值3。问“`double x=5/2;`等于2.5吗？”答：不是，右侧先做整数除法得到2，再转换为2.0，详见K02-01。

**纠错。** 不读取未初始化自动局部变量；不把`float`当成“能精确装所有小数”的类型；比较大小前先确认有符号/无符号混合转换。对应练习：T01-03-S/F/P。

### K01-04 ★→★★ 存储类别、作用域、生存期与链接

这四件事应分开问：**类型**决定值和操作；**作用域**决定在哪里能用名字；**生存期/存储期**决定对象何时存在；**链接**决定不同声明是否指同一个对象。以下讨论普通单线程程序，不展开考纲外的线程存储。

| 声明情形 | 名字通常在哪里可见 | 对象存在多久 | 关键区别 |
|---|---|---|---|
| 块内`int x`或`auto int x` | 从声明起到所属块结束 | 本次进入块期间 | 不显式初始化则值不确定 |
| 块内`static int x` | 仍只在该块 | 整个程序运行期 | 保留上次调用后的值，默认初始化为0 |
| 文件作用域`int g` | 当前翻译单元声明后的范围 | 整个运行期 | 通常有外部链接，别的文件可用extern声明 |
| 文件作用域`static int g` | 当前翻译单元声明后的范围 | 整个运行期 | 内部链接，别的文件不能借extern访问它 |
| `extern int g;` | 声明所在作用域 | 对应已有对象的存储期 | 常用于声明外部定义的对象，不是“复制一个变量” |

文件作用域变量没有显式初始化时也默认零初始化。块内`static`初始化只在程序开始前完成一次，不是每次进入函数重新赋值；其初始化式需满足相应常量表达式规则。`extern`声明也可能指本文件此前定义的对象；带初始化的文件作用域`extern int g=1;`是定义，勿死记“有extern就一定不是定义”。

**生活入口。** 自动局部变量像每次拿一张新草稿纸，静态局部变量像留在柜里的累计本。钥匙能否看见本子类似作用域，本子是否仍存在类似生存期；名字不可见不代表对象已经销毁。

**例题 E01-04：比较每次归零和累计计数。完整程序。**

<!-- example: E01-04 -->
```c
#include <stdio.h>

int total_calls = 0;
static int file_marker = 9;

void visit(void)
{
    auto int local = 0;
    static int saved = 0;
    local++;
    saved++;
    total_calls++;
    printf("%d %d %d\n", local, saved, total_calls);
}

int main(void)
{
    visit();
    visit();
    printf("marker=%d\n", file_marker);
    return 0;
}
```

| 调用 | local初始化后/增加后 | saved进入时/增加后 | total_calls增加后 |
|---|---|---|---:|
| 第1次 | 0 / 1 | 0 / 1 | 1 |
| 第2次 | 0 / 1 | 1 / 2 | 2 |

```text
1 1 1
1 2 2
marker=9
```

`visit`结束时本次的`local`对象结束生存；`saved`仍在，但`main`不能直接用这个局部名字。`total_calls`也保留值，具有外部链接。`file_marker`与它同样活得久，但只有内部链接。跨文件完整例见K11-04。

**教师板书与追问。** 画“main→visit→main→visit”的时间线，分别画每次新建的local和贯穿全程的saved。问“把saved改成普通局部变量会怎样？”答：两次都输出1。问“静态局部变量是否变成全局变量？”答：否，作用域没有扩大。

**纠错。** “static让变量全局可见”错误；“所有局部变量都在返回时消失”错误；“extern是另一种赋初值方法”错误。先标作用域，再标存储期，最后标链接，避免混为一谈。对应练习：T01-04-S/F/P。

## 第02章 运算、表达式和语句

<a id="K02-01"></a>

### K02-01 ★ 算术、自增自减和类型转换

`+ - * / %`分别表示加减乘除和整数余数。两个整数相除丢掉小数部分，C17规定向零截断：`-7/3==-2`，`-7%3==-1`，满足`a==(a/b)*b+a%b`，前提是商可表示且b非0。`%`不能用于浮点操作数。整数除以0、有符号整数溢出都不能要求确定输出；最小有符号整数除以−1也可能无法表示。

`++i`先增加再提供新值，`i++`先提供旧值再增加；单独作为语句时二者都让i增加1，`--`同理。初学时把修改变量的操作单独写一行，避免`i=i++`或`i++ + ++i`这类未定义行为。多个函数实参的求值次序也不能按书写顺序猜测。

**隐式与显式转换。** `int`和`double`做普通算术通常先把整数转为`double`；`char`和较窄整数常先进行整数提升。更一般的整数混合规则受等级、符号和可表示范围影响，尤其要警惕负数与`unsigned`比较。`(double)a/b`在除法前转换；`(double)(a/b)`转换得太晚。浮点转整数向零截断，且结果必须在目标类型可表示范围内。赋值转换发生在右侧计算之后。

**生活入口。** 把7个面包装进每袋3个的袋子，完整袋数是商2、剩余1个；平均分给3人则需要实数2.333…。类比用于非负整数，负数余数规则应按C标准计算。

**例题 E02-01：整数平均值和实数平均值。完整程序。**

<!-- example: E02-01 -->
```c
#include <stdio.h>

int main(void)
{
    int a = 7, b = 3;
    double wrong = a / b;
    double average = (double)a / b;
    int i = 4;
    int old = i++;
    int now = ++i;
    printf("%d %d %.2f %.2f\n", a / b, a % b, wrong, average);
    printf("%d %d %d\n", old, now, i);
    return 0;
}
```

步骤：`a/b=2`→赋给wrong变2.0；转换a后`7.0/3`约2.3333；old取4后i变5；前置增加使i变6，再把6赋给now。输出：
```text
2 1 2.00 2.33
4 6 6
```

**教师板书。** 先写操作数类型，再画“运算→转换→赋值”的箭头，最后列i的4→5→6。追问“只把wrong声明成double，能补回已经丢掉的小数吗？”答：不能。纠错：除法之前转换一个操作数；自增不与同一变量的其他读写挤在同一表达式。对应T02-01-S/F/P。

<a id="K02-02"></a>

### K02-02 ★ 关系、逻辑、短路与条件运算

关系运算`< <= > >=`和相等运算`== !=`的结果是`int`型0或1；C的条件把0视为假，非0视为真。逻辑非`!`、与`&&`、或`||`也产生0或1。`&&`左侧为假时不再算右侧；`||`左侧为真时不再算右侧，称短路。

区间判断必须写成`low <= x && x <= high`；`low <= x <= high`会先得到0/1，再拿它与high比较。`=`赋值与`==`判断相等不可混淆。`条件 ? 表达式1 : 表达式2`只求值被选中的一支；两支类型还会影响整个表达式类型。

**生活入口。** “有票并且未过期”两个条件都满足才进场；“有票或者持有效通行证”任一满足即可。短路像验票没通过就不查票上日期，但不能把它泛化为所有运算符都从左到右。

**例题 E02-02：防止除零并取较大值。完整程序。**

<!-- example: E02-02 -->
```c
#include <stdio.h>

int main(void)
{
    int total = 12, people = 0;
    int possible = people != 0 && total / people >= 3;
    int a = 8, b = 5;
    int maximum = a > b ? a : b;
    printf("%d %d %d\n", possible, maximum, !maximum);
    return 0;
}
```

`people!=0`为0，因此右侧除法根本不执行，possible为0。`a>b`为1，条件表达式取a即8；8是非零真值，`!8`为0。输出`0 8 0`后换行。若把people改为4，12/4为3，possible为1。

**教师板书与追问。** 先写真值表，再用箭头划掉未执行的右支，最后讲三目表达式。问“换成单个`&`能防除零吗？”答：不能，它是位与，不短路。问“`2 && 3`是2还是3？”答：都是非零，结果是1。纠错时让学生把连续比较改写成两个明确命题。对应T02-02-S/F/P。

### K02-03 ★→★★ 位运算与标志位

位运算处理整数的二进制位：`&`逐位与、`|`逐位或、`^`逐位异或、`~`逐位取反、`<<`左移、`>>`右移。它们不是逻辑运算符；例如`6 & 3`得到2，`6 && 3`得到1。`^`不是乘方。

本讲义位运算优先用`unsigned int`，用`1U << k`制作掩码。最低位编号0。设置位：`flags |= mask`；清除位：`flags &= ~mask`；翻转位：`flags ^= mask`；检查某位：`(flags & mask) != 0U`。移位数必须非负且小于提升后左操作数类型的位宽；不要对负的有符号数做移位推断。无符号右移补0；无符号左移按类型宽度截去高位，不能随意用移位模拟可能溢出的有符号乘法。

**生活入口。** 用几个开关表示灯、风扇、门铃的开关状态。一位只记一个是/否，组合起来保存多个独立状态；类比不意味着程序一定控制真实电器。

**例题 E02-03：修改三个位。完整程序。**

<!-- example: E02-03 -->
```c
#include <stdio.h>

int main(void)
{
    unsigned int flags = 5U;
    flags |= 2U;
    printf("%u\n", flags);
    flags &= ~1U;
    printf("%u\n", flags);
    flags ^= 4U;
    printf("%u %d\n", flags, (flags & 2U) != 0U);
    printf("%u %u\n", 3U << 1, 6U >> 1);
    return 0;
}
```

| 操作 | 低三位变化 | 十进制 | 原因 |
|---|---|---:|---|
| 初始 | 101 | 5 | 第2、0位开 |
| 或010 | 111 | 7 | 把第1位置1 |
| 与~001 | 110 | 6 | 只清第0位 |
| 异或100 | 010 | 2 | 翻转第2位 |

```text
7
6
2 1
6 3
```

**教师板书。** 写每一位的0/1表→将数对齐→逐列运算→还原十进制→解释掩码。追问“为什么清位不用减去1？”答：原位如果已经是0，减法可能借位改变别的位；与反掩码总能只清指定位置。纠错：`~1U`反转整个unsigned宽度，表中只画低三位，不代表它只有3位。对应T02-03-S/F/P。

### K02-04 ★→★★ 优先级、结合方向、表达式语句与空语句

下表从高到低；同一行内列出的运算符同级，括号用来主动表达意图。

| 级别 | 运算符 | 结合方向 |
|---|---|---|
| 1 | 后缀`()`调用、`[]`、`.`、`->`、后置`++ --` | 左到右 |
| 2 | 前置`++ --`、`+ - ! ~ * &`、`sizeof`、强制转换 | 右到左 |
| 3 | `* / %` | 左到右 |
| 4 | `+ -` | 左到右 |
| 5 | `<< >>` | 左到右 |
| 6 | `< <= > >=` | 左到右 |
| 7 | `== !=` | 左到右 |
| 8、9、10 | 依次`&`、`^`、`|`，三者不同级 | 左到右 |
| 11、12 | 依次`&&`、`||`，不同级 | 左到右 |
| 13 | `?:` | 右到左 |
| 14 | `= += -= *= /= %= <<= >>= &= ^= |=` | 右到左 |
| 15 | 逗号运算符`,` | 左到右 |

优先级回答“如何分组”，结合方向回答“同级如何分组”，**都不等于所有操作数的运行求值顺序**。`a+b*c`相当于`a+(b*c)`；`a=b=3`相当于`a=(b=3)`。实参列表里的逗号只是分隔符，不是逗号运算符；真正的`(a=2,a+1)`先完成左侧再算右侧，值为3。

表达式后加`;`成为表达式语句，如`sum += x;`。单独`;`是空语句；`{ ... }`把多个声明、语句组织为复合语句并引入块作用域。`sizeof`通常不求值其操作数，本讲义不用变长数组，避免其特殊求值规则。

**生活入口。** 数学先乘除后加减能帮助理解分组，不能据此猜测两个函数谁先调用。学生先写全括号，再算数值；有修改变量时另外记录副作用。

**例题 E02-04：把表达式拆成可追踪的步骤。完整程序。**

<!-- example: E02-04 -->
```c
#include <stdio.h>

int main(void)
{
    int a = 2, b = 3, c = 4;
    int result = a + b * c;
    a = b = 5;
    {
        int extra = 1;
        result += extra;
    }
    printf("%d %d %d\n", result, a, b);
    return 0;
}
```

步骤：乘法3×4先组成子表达式12，result初值14；右结合赋值先让b=5，再让a=5；块内extra=1，使result=15，离开后不能再使用extra这个名字。输出`15 5 5`后换行。

**教师板书与追问。** “原式→全括号式→数值→变量新状态”。问“`if (x>0);`后的分号有什么作用？”答：它就是if控制的空语句，后面的语句不会被这个if控制。纠错时不只删除分号，要让学生圈出if实际控制的语句。问“`f()+g()`一定先调用f吗？”答：不能据书写顺序保证。对应T02-04-S/F/P。

## 第03章 顺序、选择和循环控制

<a id="K03-01"></a>

### K03-01 ★ if与switch：先确定互斥规则

`if (条件) 语句`可接`else`；多个等级通常用`if / else if / else`从严格条件开始判断。`else`归最近的尚未匹配的if；统一使用花括号能减少误读。几个独立if可能执行多支，与if-else链最多执行一支不同。

`switch`控制表达式使用整数或枚举类型；`case`是不同的整数常量表达式标签，不能写运行时变量或实数范围。找到标签后会向后执行，直到break或switch结束，因此有意贯穿与忘记break要区分；default处理未匹配情况。

**生活入口。** 满90优秀，满60通过，其余未通过，需要先查90再查60；菜单编号则适合switch。类比边界：现实评价更复杂，本题规则只按给定整数分数执行。

**例题 E03-01：成绩分级并选择打印格式。完整程序。**

<!-- example: E03-01 -->
```c
#include <stdio.h>

int main(void)
{
    int score = 85;
    char level;
    if (score >= 90) {
        level = 'A';
    } else if (score >= 60) {
        level = 'B';
    } else {
        level = 'C';
    }
    switch (level) {
        case 'A': puts("excellent"); break;
        case 'B': puts("pass"); break;
        default: puts("retry"); break;
    }
    return 0;
}
```

85>=90为假，85>=60为真，所以level='B'；从`case 'B'`执行puts，然后break，输出`pass`后换行。分数输入范围在本例固定为0—100；接受用户输入时需另做范围检查。

**教师板书。** 先画互不重叠区间0—59、60—89、90—100，再写条件链；switch画一条带标签的向下通道。追问“删除B后的break会怎样？”答：继续执行default，额外打印retry。纠错：范围判断用if；case后的冒号不能误写成分号。对应T03-01-S/F/P。

<a id="K03-02"></a>

### K03-02 ★ for、while、do-while及循环跟踪

循环都要明确“初值、继续条件、每轮工作、如何接近结束”。`for (初始化; 条件; 更新)`先初始化一次，每次检查条件，通过后执行循环体，再更新。`while`先检查再执行；`do { ... } while (条件);`先执行再检查，所以至少执行一次，最后的分号不可省。

**生活入口。** 清点5个盒子可用已知次数for；有盒子就继续清点像while；必须先试一次才知道要不要重试像do-while。类比仅解释检查时机，不自动保证循环会停，停止条件必须由程序推进。

**例题 E03-02：用三种循环算1+2+3。完整程序。**

<!-- example: E03-02 -->
```c
#include <stdio.h>

int main(void)
{
    int sum_for = 0;
    for (int i = 1; i <= 3; i++) {
        sum_for += i;
    }
    int sum_while = 0, j = 1;
    while (j <= 3) {
        sum_while += j;
        j++;
    }
    int sum_do = 0, k = 1;
    do {
        sum_do += k;
        k++;
    } while (k <= 3);
    printf("%d %d %d\n", sum_for, sum_while, sum_do);
    return 0;
}
```

| 检查前i | i<=3 | 本轮加数 | sum_for变化 | 更新后i |
|---:|---|---:|---|---:|
| 1 | 真 | 1 | 0→1 | 2 |
| 2 | 真 | 2 | 1→3 | 3 |
| 3 | 真 | 3 | 3→6 | 4 |
| 4 | 假 | 无 | 仍6 | 不更新 |

另两种循环同样依次累加1、2、3，输出`6 6 6`后换行。若上界改成0，for和while执行0次，当前do写法仍执行一次，这是不等价边界，不能机械替换。

**教师板书。** 用四个框画执行次序，再逐轮填表，退出检查也要列。追问“条件写`i<3`会少哪个数？”答：少3。问“sum在循环体开头置0会怎样？”答：丢掉之前累计，末次仅保留3。纠错：表中先判条件再算，不把退出后的i当作最后一次加数。对应T03-02-S/F/P。

<a id="K03-03"></a>

### K03-03 ★→★★ break、continue、return的控制范围

`break`结束最近一层循环或switch；`continue`结束最近一层循环的本轮，继续下一轮；`return`结束整个当前函数。for中的continue会先执行更新表达式再判断，while中的continue直接回到条件，若必要更新在continue之后可能死循环。嵌套循环的break只跳出内层，不自动退出外层。

**生活入口。** 检查商品时“这件跳过”像continue，“这一箱不再查”像break，“结束本次检查工作并交结果”像return。箱子层级必须明确，不能把一次break解释成退出所有工作。

**例题 E03-03：跳过偶数，遇到7结束，累计先前奇数。完整程序。**

<!-- example: E03-03 -->
```c
#include <stdio.h>

int main(void)
{
    int sum = 0;
    for (int i = 1; i <= 9; i++) {
        if (i == 7) {
            break;
        }
        if (i % 2 == 0) {
            continue;
        }
        sum += i;
    }
    printf("%d\n", sum);
    return 0;
}
```

| i | 行为 | sum |
|---:|---|---:|
| 1 | 累加 | 1 |
| 2 | continue，仍会i++ | 1 |
| 3 | 累加 | 4 |
| 4 | continue | 4 |
| 5 | 累加 | 9 |
| 6 | continue | 9 |
| 7 | break，退出循环 | 9 |

输出`9`后换行；7没被累加，8和9根本没检查。最后return结束main。

**教师板书。** 画三支箭头：continue指向for更新处，break指向循环后的printf，return指向函数外。追问“把break换成return 0还打印9吗？”答：不会，直接退出main。纠错：switch放在循环中时，switch内break只结束switch；continue则仍针对外层循环。对应T03-03-S/F/P。

<a id="K03-04"></a>

### K03-04 ★→★★ 嵌套循环与问题分解

嵌套循环不是“一次同时增加两个变量”。外层每执行一轮，内层从其初始化开始走完整个过程。二维遍历常用“外层行、内层列”；三角形输出则让内层次数依赖外层行号。分析运行次数要把每行工作相加，不总是直接乘法。

**生活入口。** 给教室每排座位编号：先确定一排，再走完这一排所有座位；本例每排座位数随行号增加。类比边界：程序只输出符号，空格、换行也都是必须明确执行的操作。

**例题 E03-04：打印三行直角星形。完整程序。**

<!-- example: E03-04 -->
```c
#include <stdio.h>

int main(void)
{
    for (int row = 1; row <= 3; row++) {
        for (int col = 1; col <= row; col++) {
            putchar('*');
        }
        putchar('\n');
    }
    return 0;
}
```

| row | 实际进入内层的col | 星号次数 | 内层退出后做什么 |
|---:|---|---:|---|
| 1 | 1 | 1 | 换行 |
| 2 | 1、2 | 2 | 换行 |
| 3 | 1、2、3 | 3 | 换行 |

```text
*
**
***
```

分步解题：①目标拆成“重复3行”与“第row行重复row颗星”。②把行规则放外层，把星号规则放内层。③换行只需每行一次，因此放内层之后、外层之内。④总共打印1+2+3=6颗星，另有3个换行。

**教师板书与追问。** 先画最终图形，再在每行写row，逐颗标col，最后翻译为循环。问“把换行移入内层会怎样？”答：每颗星后都换行，成6行单星。問“打印矩形3行4列时改哪处？”答：内层条件改`col<=4`。纠错：每行col必须重新从1开始；不要让内外层复用同一个变量。对应T03-04-S/F/P。

## 第04章 数组与字符串 ★～★★

学习方式：每节先画数据对象或调用过程，再独立预测例题输出，最后编译核对。所有完整程序均按C17编写；代码片段若标为非完整程序，不可单独编译。

<a id="K04-01"></a>

### K04-01 一维数组：用下标管理同类数据 ★

#### 概念与语法

数组把同一类型的若干元素连续存放。`int score[5] = {72, 88, 65, 90, 85};` 定义5个`int`，合法下标为0～4。元素`score[i]`可以出现在赋值号两侧。长度是5，最后一个下标却是4；遍历通常写`i < 5`，不能写`i <= 5`。

定义时可由初始化列表推断长度，例如`int a[] = {2, 4, 6};`。指定长度但只给出部分初值时，剩余元素初始化为0；`int a[5] = {0};`会将全部元素置0。函数内部未初始化的自动数组元素没有可用的确定值，不能先读取后“看看是多少”。数组整体不能用`a = b`赋值，应逐元素复制。

在数组定义所在的作用域，`sizeof a / sizeof a[0]`可计算元素个数；结果类型是`size_t`，打印用`%zu`。数组作为函数参数后通常调整为指针，这个公式便不再计算原数组长度。本节先采用固定长度，避免把变长数组与动态分配混为一谈。

#### 生活类比及适用边界

数组像一排编号储物格，每格都装同一类型物品；下标是格子编号。类比边界：C不会替你检查编号，越界访问不是“空格子”，而是未定义行为。

#### 学生的理解路径

先数元素，再写合法下标范围；接着把一个元素当普通变量；最后用循环让下标依次取合法值。求和时先确定累加器初值0，再解释每一次加法。

#### 教师板书与追问

**板书顺序：**①画5个格子并标0～4；②写定义和初始化；③圈出循环条件i<5；④逐项累加；⑤解释sizeof公式只适用于当前真正的数组对象。

**课堂追问及答案：**问：5个元素为什么不访问score[5]？答：从0计数，第5个元素是score[4]。问：只给两个初值时剩下元素怎样？答：定义时其余元素为0。

#### 常错纠正

把长度当最大下标→先写下标区间；sum未初始化→设为0；试图整体赋值→逐元素处理；以为数组会自动扩容→固定长度对象不会增加容量。

#### E04-01 完整例题

**目标：**计算5次测验的总分、平均分与最高分。

<!-- example: E04-01 -->
```c

{
    int score[] = {72, 88, 65, 90, 85};
    size_t count = sizeof score / sizeof score[0];

            highest = score[i];

```

| i | score[i] | 累加后sum | highest |
|---|---:|---:|---:|
|0|72|72|72|
|1|88|160|88|
|2|65|225|88|
|3|90|315|90|

### K04-02 二维数组：行、列与双层循环 ★★

#### 概念与语法

`int a[2][3]`是“含2个元素的数组”，其中每个元素又是含3个int的数组，因此共有6个整数。`a[r][c]`先选择行r，再选择该行中的列c；合法r是0～1，合法c是0～2。行和列不是可交换的两个标签。

C按行连续存储二维数组：第0行的3个元素后面才是第1行。推荐用嵌套花括号初始化：`int a[2][3]={{1,2,3},{4,5,6}};`，一行对应一组。定义时第一维可以由初始化推断，第二维必须让编译器知道，如`int a[][3] = {{1,2,3},{4,5,6}};`。

双层循环中外层负责行、内层负责列。求每行和时，行累加器必须在外层循环内部置0，否则会变为“截至本行的累计和”。二维数组的每行也是独立数组，不能因为整体存储连续就故意用某一行的越界下标跨到下一行。

#### 生活类比及适用边界

二维数组像电影院的座位表，先找排再找座。边界：数学表格可以随意标行列，C的声明已固定每行长度，越界座位不会被自动解释成下一排。

#### 学生的理解路径

先画2行3列，再用a[1][2]定位；随后写内层循环算一行，确认可行后用外层循环重复；最后检查累加器的归零位置。

#### 教师板书与追问

**板书顺序：**①标行列范围；②写嵌套初始化；③只算第0行；④加外层循环；⑤跟踪每行开始时row_sum=0。

**课堂追问及答案：**问：a[1][2]对应第几个自然计数的座位？答：第2行第3列。问：row_sum移到外层循环前会怎样？答：第二次输出会包含第一行的和。

#### 常错纠正

把两层循环上限对调→分别写行数和列数；漏重置行和→在每行开头置0；a[0][3]跨行→该行合法列下标只到2。

### K04-03 字符数组与以空字符结尾的字符串 ★★

#### 概念与语法

字符数组的元素类型是char；只有从起点开始、在可访问范围内遇到`'\0'`的字符序列，才可以按C字符串处理。`char word[4] = "cat";`实际包含c、a、t、`'\0'`四个元素。空字符的值是0，数字字符`'0'`是可见字符，两者不同；`NULL`又是空指针常量的常用宏，不能混为一谈。

`sizeof word`是数组总字节数，`strlen(word)`统计终止空字符之前的字节数，不包括`'\0'`。二者都产生size_t结果。字符串函数需要正确终止的字符串；对没有终止符的数组调用strlen或用%s打印可能越界。`char a[3]="cat";`在C中可构成3个字符的数组，但没有空间放终止符，不能当字符串使用。

读取一行可用`fgets(buffer, sizeof buffer, stdin)`，必须先检查返回值。读取成功时最多存入容量减1个字符并补`'\0'`，若读到换行则把换行保留在数组中。`buffer[strcspn(buffer,"\n")]='\0';`可去除已读取的换行。若本次只读到长行的一部分，剩余输入仍在输入流中，需要程序另行处理；本例明确只接收本次读取的前15个字符。strlen按字节计数，不能直接当作中文字符个数。

#### 生活类比及适用边界

字符串像一列文字卡片，末尾另放“到此结束”标记；容量是整个卡槽数，长度是结束标记前卡片数。边界：终止符不显示，但占空间；多字节文字可能一字占多个字节。

#### 学生的理解路径

先手画cat加终止符4格，再区分容量与长度；然后检查读取是否成功，去除换行后计算长度；最后考虑空行与过长行。

#### 教师板书与追问

**板书顺序：**①区分char数组/字符串；②画终止符；③比较sizeof和strlen；④写fgets返回值检查；⑤演示换行替换为空字符。

**课堂追问及答案：**问：容量16最多存多少普通单字节可见字符？答：作为字符串最多15个，另1个放终止符。问：输入空行长度是多少？答：去掉换行后为0。

#### 常错纠正

忘记终止符空间→容量至少长度+1；用sizeof当字符串长度→改用strlen；fgets失败仍读缓冲区→先检查；认为fgets总能读完整行→明确长度限制或检测截断。

### K04-04 二维字符数组与字符串指针数组 ★★

#### 概念与语法

`char names[3][8] = {"Li","Wang","Chen"};`分配3行，每行固定8字节，各行分别保存一个字符串。每行最多存7个单字节正文字符，剩下1字节留给终止符。names[1]代表第2行，在常见表达式中转换为指向该行首字符的指针；names[1][0]是字符W，可以修改。

另一种写法是`const char *names[] = {"Li","Wang","Chen"};`：数组元素是指针，分别指向字符串字面量。各字符串长度可以不同，无须为每个字符串分配同样大的行。指针元素可以改为指向另一个字符串，但不能通过它修改字面量。C的字符串字面量不具有可修改性；虽然历史类型规则不是const数组，仍应采用const char *表达只读意图。

这两种结构都常被口语称为“字符串数组”，但真实类型不同：二维字符数组存字符本身；指针数组存地址。`sizeof names[0]`在前者是行容量，在后者是一个指针的大小，后者不能拿来当字符串容量。比较内容用strcmp，不能用==代替；==比较指针时比较的是地址。

#### 生活类比及适用边界

二维字符数组像每人同样大小的姓名牌；指针数组像通讯录中的链接，链接指向不同长度的文字。边界：链接可换目标不表示目标文字可改，字面量应当只读。

#### 学生的理解路径

先比较每个元素到底是字符行还是指针；再分别回答“能改字符吗”“能换指向吗”；最后按行或按指针逐个打印字符串。

#### 教师板书与追问

**板书顺序：**①画3×8字符格；②画3个地址格和各自目标；③标出可写数组/只读字面量；④比较sizeof第0个元素；⑤用strcmp判断内容相等。

**课堂追问及答案：**问：const char *p中的const限制什么？答：不能通过p修改所指字符，p本身仍可重新赋值。问：字符串内容相等用什么？答：strcmp(a,b)==0，且二者都须正确终止。

#### 常错纠正

给二维数组的某一行直接赋字符串→数组行不能整体赋值；通过指针修改字面量→未定义行为；用==判断文本→改用strcmp。

## 第05章 指针与对象 ★★～★★

### K05-01 地址、指针的初始化与解引用 ★★

#### 概念与语法

每个对象在其生存期内占据存储空间。`&x`取得对象x的地址；`int *p = &x;`定义一个指向int的指针p，并用x的地址初始化。声明中的`*`表示p是指针，表达式中的`*p`表示访问p所指对象，这两种位置必须分开理解。

赋值`p = &y`改变指针本身的值，即改为指向y；赋值`*p = 20`改变当前所指对象的值。指针也有类型：int *表示访问一个int对象，不是“什么地址都能塞进去”。多个变量一起声明时，`int *p, q;`只有p是指针，q是int；初学阶段推荐分行声明。

没有有效目标时可以初始化为NULL，但NULL不能被解引用。未初始化的自动指针不能读出后再猜它指向哪里。安全解引用须同时满足：地址指向有效对象、对象仍在生存期内、访问类型和读写权限正确。`p != NULL`只排除了空指针，并不能证明所有其他条件。显示对象地址应写`printf("%p", (void *)p);`，地址每次运行可能不同，因此本例不把具体地址当确定输出。

#### 生活类比及适用边界

指针像写有住址的纸条，&是查住址，*是按纸条找到住户。边界：纸条不拥有房屋，房屋消失后纸条也不会自动更新；非空住址也未必仍有效。

#### 学生的理解路径

先画x和y两个对象，再单独画指针p；每遇到赋值先判断左边是p还是*p；读程序时用箭头记录指向，用格子里的数记录对象值。

#### 教师板书与追问

**板书顺序：**①定义x和y；②写&p与&x的区别；③p=&x画箭头；④*p赋值改格内数字；⑤p=&y只改箭头；⑥检查初始化和生存期。

**课堂追问及答案：**问：p=&y会改变x吗？答：不会，只改变p的指向。问：if(p!=NULL)之后一定能安全解引用吗？答：不一定，p还可能指向已失效对象或不允许写的对象。

#### 常错纠正

写int *p;后直接*p=值→先让p指向有效对象；把地址赋给普通int→使用匹配指针类型；把p的变化当作目标变化→分别跟踪箭头和数据。

### K05-02 指针与数组、指向数组的指针 ★★

#### 概念与语法

大多数表达式中，数组名会转换为指向首元素的指针，但数组本身不是指针变量。`int a[4]`配合`int *p=a`后，`p[i]`与`*(p+i)`等价；p+1前进一个int元素，底层字节距离为sizeof(int)，不是固定前进一个字节。`sizeof a`和`&a`等情境保留数组性质。

指针算术限于同一个数组对象内部以及尾后位置。可构造`a+4`作为尾后指针，用于比较或循环终止，但不能解引用。两个指针相减必须属于同一数组或其尾后位置，差表示元素数，类型为ptrdiff_t。不要比较、相减两个无关数组的指针来猜存储位置。

`int (*row)[3]`是指向“3个int组成的数组”的指针：括号让*先与row结合。若`int m[2][3]`，可写`int (*row)[3]=m;`。row+1前进一整行，`row[r][c]`访问二维数组元素。它与`int *row[3]`不同，后者是3个指针构成的数组。二维数组转换后是指向第一行的指针，并不是int **。

#### 生活类比及适用边界

普通元素指针像每次跨一个座位，行指针像每次跨一排座位。边界：步幅由所指类型决定，不能凭地址数值看起来相同就认为类型可随意互换。

#### 学生的理解路径

先用一维数组确认p+i的元素步长；再把“一行”当一个整体对象；最后从变量名向外读int (*row)[3]并解释row+1。

#### 教师板书与追问

**板书顺序：**①a[i]写成*(a+i)；②画尾后位置并打“不可解引用”标记；③圈住二维数组的一整行；④声明行指针；⑤用row[1][2]定位。

**课堂追问及答案：**问：尾后指针能否形成？答：可以，但不能解引用。问：m为何不能直接赋给int **？答：m转换后指向一行数组，目标中不是指针元素，其类型是int (*)[3]。

#### 常错纠正

以为数组名可执行a++→数组不是可修改指针变量；把二维数组当int **→使用列数匹配的行指针；把尾后位置当最后元素→最后元素在尾后位置之前。

### K05-03 指针数组与二级指针 ★★

#### 概念与语法

`int *refs[3]`定义一个数组，3个元素各是int *。它保存的是3个整数对象的地址，不一定指向连续的整数。`refs[i]`取出一个指针，`*refs[i]`才读取其目标整数。指针数组本身连续，目标对象可以分散。

若p是int *变量，`int **pp = &p;`令pp指向这个指针变量。`*pp`是p本身，`**pp`是p指向的int。因此`*pp=&y`能改变p的指向；`**pp=7`修改当前整数目标。二级指针的作用之一是让函数修改调用方的指针变量，第06章将从值传递角度解释。

指针数组在一般表达式中转换为指向第0个指针元素的指针，因此int *数组的首元素地址可保存为int **。这不代表所有二维结构都适合int **：二维int数组每行存整数，指针数组每格存地址，二者布局与类型不同。读取声明时先辨认变量是否为数组，再辨认每个元素的类型。

#### 生活类比及适用边界

二级指针像“写着另一张地址纸条所在抽屉位置的便条”；先找纸条，再找纸条指向的人。边界：每一层都要有效，外层非空不能保证内层有效。

#### 学生的理解路径

先画a、b两个整数，再画p，再画pp；分别执行**pp赋值与*pp赋值，观察变化发生在不同层。最后把多个p式格子排成指针数组。

#### 教师板书与追问

**板书顺序：**①写int *refs[3]并标元素类型；②refs[0]=&a；③pp=&p；④将*pp替换读成p；⑤将**pp替换读成*p。

**课堂追问及答案：**问：pp=&p时，*pp到底是什么？答：p这个指针对象。问：int **能直接代表int m[2][3]吗？答：不能，m的第一层元素是数组而非指针。

#### 常错纠正

少写或多写一个*→逐层标类型；指针数组元素没初始化就使用→每格放有效地址；以为改变*pp只改局部副本→它能访问调用者提供的指针对象。

### K05-04 对象生命周期与返回指针 ★★

#### 概念与语法

作用域回答名字在哪里可见，生命周期回答对象何时存在。函数内普通局部变量具有自动存储期，通常在进入所在块时创建、离开块时结束。函数可以返回整数值的副本，但不能把已结束生命周期的局部对象地址当作仍有效的数据使用。

安全返回指针的常见方式是：指向调用方传入且仍存活的对象；指向静态存储期对象；或指向仍未释放的动态分配对象。本章不展开动态分配。`static int value`局部静态对象的名字限于函数作用域，但对象在整个程序执行期间存在。每次调用返回同一对象地址，后续调用可能改变先前指针观察到的内容。

返回NULL可表示“未找到”，调用者必须先判断再解引用。本例在调用者数组中查找满足条件的元素，因此返回地址的有效期由调用者数组决定；返回以后原数组必须仍存在。`const int *`返回值约定不通过该指针修改数据，但并不会复制数据，也不会自动延长原对象生命周期。不要运行悬空指针示例后根据某次结果宣称它“仍然能用”。

#### 生活类比及适用边界

返回指针像交付一张借阅位置单，位置单有效依赖书架还在。边界：函数结束不一定让所有对象消失，static对象仍在；局部名字不可见也不等于对象不存在。

#### 学生的理解路径

对每个返回地址问三件事：目标是谁、谁负责维持它、调用结束后是否仍存在；找不到时再考虑NULL分支。

#### 教师板书与追问

**板书顺序：**①区分作用域和生命周期；②画调用方数组跨过函数调用仍存在；③在数组中找到元素并返回地址；④未找到返回NULL；⑤强调先判空再读取。

**课堂追问及答案：**问：返回局部int的值为何可以？答：返回的是值的副本，调用者不依赖局部对象继续存在。问：返回static对象地址是否每次得到独立副本？答：不是，各次指针指向同一对象。

#### 常错纠正

返回自动局部数组首地址→改用调用方缓冲区或明确的持久存储；把const当生命周期保证→const只约束访问；漏判NULL→先分支处理未找到。

## 第06章 函数与程序组织 ★～★★

学习方式：每节先画数据对象或调用过程，再独立预测例题输出，最后编译核对。所有完整程序均按C17编写；代码片段若标为非完整程序，不可单独编译。

<a id="K06-01"></a>

### K06-01 函数原型、定义与值传递 ★

#### 概念与语法

函数把一项操作封装为有名称的接口。原型`int square(int x);`声明返回int、接收一个int；定义`int square(int x) { return x*x; }`提供具体实现。原型末尾有分号，定义的函数体后不需要分号。现代C应在首次调用前给出匹配原型；可以把完整定义放在调用前，也可以先声明、后定义。

ANSI C风格原型列出参数类型。C17中`int f(void);`明确无参数，而`int f();`不是同样严格的无参数原型，它不提供参数类型和数量信息；本资料统一使用明确原型。函数返回类型、参数个数与类型必须匹配，形参名字可以与调用者变量不同。

实参是调用时提供的表达式，形参是被调用函数内接收值的局部对象。C采用值传递，修改普通形参不改变调用者原变量。即便传入指针，复制的仍是指针值；通过这个副本访问同一目标，才可改变调用者的数据。

在宿主环境中，程序由运行环境启动main；标准形式之一是`int main(void)`。main不是包住所有函数的容器，自定义函数与main在文件作用域分别定义。printf等库函数由标准库提供实现，经stdio.h获取声明；自定义函数由程序员定义，均按函数调用规则使用。main返回0表示成功，非0用于报告失败；普通非void函数必须在需要返回的路径提供正确值。

#### 生活类比及适用边界

函数像加工窗口：原型是窗口说明，实参是交进去的材料副本，返回值是交回的成品。边界：C普通参数不会自动共享原变量；指针副本可指向同一个对象，但仍是复制传入。

#### 学生的理解路径

先从调用处判断所需输入和输出，再写原型，接着写定义；跟踪实参复制到形参的瞬间，最后区分函数内改变和返回给调用方的结果。

#### 教师板书与追问

**板书顺序：**①画原型的返回类型/函数名/参数；②标声明与定义；③画实参n到形参x的复制；④执行函数体；⑤return回调用处；⑥观察main里的n。

**课堂追问及答案：**问：square内执行x=100，main里的n会怎样？答：不会因这条形参赋值改变。问：int f(void)中的void是否表示不返回值？答：不是，它表示无参数，返回类型仍是int。

#### 常错纠正

首次调用前没有原型→提前声明；把分号误加到函数头后→会把头与函数体分开；认为同名形参与实参是同一对象→画独立格子；把函数定义写进main→标准C不支持嵌套定义。

### K06-02 用指针与数组参数传递数据 ★★

#### 概念与语法

函数参数中的`int a[]`会调整为`int *a`，不是按值复制整个数组。调用时通常传入首元素地址，函数可通过该指针访问调用者数组。由于长度没有自动携带，接口应另传size_t n，并约定指针至少对应n个有效元素。不能在函数内用sizeof a计算调用方数组长度。

只读访问可写`const int a[]`，它调整为const int *：函数承诺不通过a修改元素。需要改变多个调用者变量，可传入各自地址作为输出参数；如`void swap(int *x,int *y)`通过*x与*y写回。参数x、y本身仍是局部指针副本，给x重新赋值不会改变调用方的指针。

二维数组参数需保留每行长度，例如`void print_rows(size_t rows, const int a[][3]);`中的a调整为指向含3个const int的数组的指针。行数由rows提供，列数3决定指针步长。若要修改调用者的指针变量，需传其地址并接收二级指针，这与“通过一级指针修改整数”是不同层次的操作。

#### 生活类比及适用边界

传数组像把仓库入口和货物数量交给管理员，入口地址的副本仍通向原仓库。边界：地址本身不告诉管理员有多少货物，错误长度可能越界；const只是当前访问通道的只读约定。

#### 学生的理解路径

先看函数要读数据还是改数据，再选const或可写指针；把长度写进接口；从main的一次数组定义出发，跟踪两个函数是否访问同一存储。

#### 教师板书与追问

**板书顺序：**①写a[]到*a的参数调整；②划掉函数内sizeof求长度的方案；③加n参数；④只读求和；⑤可写逐项增加；⑥main核对数据已改变。

**课堂追问及答案：**问：函数里a[0]=9会改原数组吗？答：若a指向调用方可写数组，会改。问：a=NULL会把调用方数组变空吗？答：不会，只改变局部指针副本。

#### 常错纠正

忘传长度→补充n并保证一致；写sizeof参数/sizeof元素→得到指针相关结果而非数组长度；只读函数用可写接口→加const表达意图；认为指针传递就是引用传递→仍是值传递。

#### E06-02 完整例题

**目标：**只读函数计算总和，再用可写数组参数统一加分。

```c

    return sum;
```

|调用|数组内容|返回或效果|

|total|60,70,80|返回210|
|add_bonus|65,75,85|无返回值，修改元素|


**输出依据：**上述跟踪过程给出最终值；printf中的固定标签按原样输出，格式说明符按变量类型替换，\n使每次输出在指定位置换行。

### K06-03 嵌套调用与递归 ★★

#### 概念与语法

函数A调用B、B再调用C称为嵌套调用；标准C允许这种调用链，但不允许在A的函数体中定义B。每次调用有本次调用的自动局部对象；返回时控制流回到调用位置继续执行。不要把“嵌套调用”与“嵌套定义”混淆。

函数直接或间接调用自身就是递归。可靠递归须同时具备终止条件、向终止条件推进的规模变化，以及正确合并较小问题结果的规则。以阶乘为例，0!=1；n>0时n!=n×(n−1)!。达到基例后逐层返回结果，而非一次跳回最外层。

递归通常消耗调用栈资源，深度很大可能耗尽资源；它不是万能的循环替代品。整数类型也有范围：本例只计算0～10的阶乘，用unsigned long long保存，不把整数溢出后的结果当合法答案。C17不规定多个函数实参从左到右求值；需要固定先后顺序时，先用独立语句完成各调用再打印。

#### 生活类比及适用边界

递归像把任务逐层委托给“处理更小问题的自己”，最底层给出直接答案，再沿原路合并。边界：每层都有成本；必须有人能直接回答，不能无限委托。

#### 学生的理解路径

先用n=0检查基例，再用n=1检查能否到基例，最后手算n=4的下降与回升。把“调用时做什么”和“返回时做什么”分成两列。

#### 教师板书与追问

**板书顺序：**①画main→report→factorial调用链；②写基例；③写规模n-1；④展开factorial(4)；⑤自底向上乘回；⑥讨论深度与数值范围。

**课堂追问及答案：**问：if(n==0)删掉会怎样？答：递归不再具有正确终止条件，不能得到合法阶乘计算。问：n-1改成n会怎样？答：问题规模不缩小，一直递归直至资源耗尽等失败。

#### 常错纠正

只写递归式无基例→先写终止条件；基例写错为0→整个乘积变0；把调用链当标准C嵌套定义→各函数放文件作用域；用深递归计算简单累加→可考虑循环节省栈。

#### E06-03 完整例题

**目标：**由report嵌套调用递归阶乘函数，显示4!和0!。

<!-- example: E06-03 -->
```c

{
    if (n == 0) return 1;
    return n * factorial(n - 1);

{
```

### K06-04 函数指针调用与void的不同含义 ★★

#### 概念与语法

函数也可通过指针间接调用。`int (*op)(int,int)`定义一个指针，指向“接收两个int并返回int的函数”。括号不可省：`int *op(int,int)`声明的是返回int *的函数。函数名在多数表达式中可转换成函数指针，写`op=add;`或`op=&add;`都可。

若op指向签名匹配的函数，可用`op(2,3)`或`(*op)(2,3)`调用。更换op的目标即可在同一调用位置选择不同操作。未初始化或为空的函数指针不能调用；不能通过强制转换把不兼容的函数类型“修好”后随意调用。函数指针与普通对象指针是不同类别，不应假设可用void *通用保存并调用。

void有三种常见位置：返回类型`void show(int x)`表示不返回结果值，可以写`return;`提前结束；参数列表`int ready(void)`表示不接收参数；`void *`是可表示对象地址的通用对象指针类型，不是无返回值函数，也不能直接解引用做对象访问或执行标准C指针算术。对象指针可与void *转换，但还原后要保证目标类型、对齐和生存期正确。

函数指针适合把“选择哪种处理”作为数据传给另一个函数，常称回调。本节只用简单算术函数，先掌握声明和间接调用，不把复杂库接口当记忆负担。

#### 生活类比及适用边界

函数指针像可更换的服务窗口号码：参数和结果的接口一致，换号码便换处理规则。边界：指向的数据类型不同于普通地址；接收参数或返回类型不匹配的窗口不能硬套同一调用规则。

#### 学生的理解路径

先写两个同接口函数，再照着接口声明指针；赋值后调用一次，改指向后再调用；最后把void出现位置逐一翻译成中文。

#### 教师板书与追问

**板书顺序：**①写add与max2原型；②从int (*op)(int,int)读出接口；③赋add并调用；④赋max2并调用；⑤void返回、void参数、void *三栏对照。

**课堂追问及答案：**问：void show(void)中两个void分别表示什么？答：前者无返回值，后者无参数。问：op=add与op=add(2,3)一样吗？答：不同，前者保存函数地址，后者先调用并得到int，不能赋给该函数指针。

#### 常错纠正

漏声明括号→变成返回指针的函数；赋值时加括号实参→变成立即调用；用不匹配签名→改为一致接口；把void函数当整数表达式使用→没有可用返回值。

### 第07—09章讲义：结构、链表与常用库函数

所有完整程序独立编译，采用 C17。程序中的字符串输出用英文，便于跨终端核对；教学说明使用中文。后续章节可沿用前面的概念，但每个完整程序都包含自己的头文件与辅助函数。

## 起步桥梁：读懂地址、指针与对象

对象是实际保存数据的一块存储，指针变量保存对象地址。`int x=3; int *p=&x;` 中，声明里的 `*` 表示 p 的类型是“指向 int 的指针”；表达式 `&x` 取 x 的地址；表达式 `*p` 访问该地址上的 int 对象。执行 `*p=4;` 会使 x 变成4。`p=NULL` 只表示当前没有指向可访问对象，此时不能再用 `*p`。不要把“给指针赋地址”与“给指向的对象赋数据”混为一谈。

结构指针仍遵守相同规则：`p->value` 就是 `(*p).value`。函数参数按值传递；若函数要改变调用者的指针变量，就传该变量的地址，通过二级指针改它。第08章会从画箭头开始说明，不要求预先熟悉二级指针技巧。

输入约定：整型练习输入的十进制整数必须可由 int 表示；程序检查题设数值范围与转换是否成功，不承担任意超长数字文本的解析。scanf转换失败不是所有输入错误的完整检测器。字符串输入题若给出长度保证，就把它作为题设前提。资源失败与非法输入的输出按各题契约区分。

## 第07章 结构体与动态存储

<a id="K07-01"></a>

### K07-01 结构类型、变量、初始化与成员访问 ★

**概念与语法**

`struct` 把若干个有名称、可以不同类型的数据成员组成一种类型。例如 `struct Student { int number; double score; };` 定义的是类型：`number` 是编号，`score` 是分数。末尾分号属于类型定义，不可省略。类型像图纸，本身没有保存某位学生的信息；`struct Student s;` 才定义一个实际对象。C 中结构标记名 `Student` 不会自动成为普通类型别名，所以这里声明变量必须写 `struct Student`。

声明时可以按成员顺序初始化：`struct Student s = {1001, 86.5};`；也可以使用指定成员初始化：`struct Student s = {.score = 86.5, .number = 1001};`。使用初始化列表时，未显式初始化的成员按零初始化；自动局部变量完全没有初始化时，其成员不能直接读取。`s.score` 通过点运算符访问成员，既可读取也可赋值。相同结构类型的对象可以整体赋值，例如 `b = a`；C 不提供结构整体的 `==` 比较，应根据业务逐个比较成员。

结构可能因为对齐含有填充字节，因此不要把 `sizeof(struct Student)` 必然当作各成员大小之和。本节只按成员存取，不依赖物理布局。

**生活类比与适用边界**

像一张学生登记卡：类型规定卡片有哪些栏目，变量是一张填有具体信息的卡。两张卡有同样的栏目并不代表内容相同；卡片类比也不能推出结构成员在内存中紧密排列。

**学生怎样理解**

先区分“定义类型”和“创建对象”，再读 `s.score = s.score + 2.0`：取出 s 的 score，计算新值，再存回同一个成员。整体复制后，再改副本的普通数值成员，不会修改原对象。

**教师板书顺序、追问与参考答案**

①板书类型框并标出分号，问“此时有学生数据吗？”答：只有类型，没有学生对象。②板书 a、b 两个对象框，问“b=a 复制什么？”答：各成员的值。③写 b.score+=2，问“a.score 会变吗？”答：不会，两个对象的数值成员各自存放。④把初始化列表改成 `{.number=1001}`，问 score 是多少？答：0.0。

**常错与纠正**

把 `struct Student` 写成 `Student`：没有 typedef 时不是同一个写法；用 `a == b` 比较结构：应比较目标成员；漏写类型定义末尾分号：在 `}` 后补 `;`；读取未初始化成员：先给对象有效初值。

<a id="E07-01"></a>

#### E07-01 完整例题

目标：观察结构初始化、整体复制与独立修改。①定义一种学生类型。②创建 a 并给两成员初值。③用 a 初始化 b，得到第二个对象。④只提高 b 的分数。⑤分别输出两对象以验证复制后的独立性。

<!-- example: E07-01 -->
```c

int main(void) {
    struct Student a = {1001, 86.5};
    struct Student b = a;

    printf("b: %d %.1f\n", b.number, b.score);

}
```

**变量或链接跟踪**：`a={1001,86.5}` → `b={1001,86.5}` → `b.score=88.5`；a 始终为 `{1001,86.5}`。


### K07-02 结构数组与结构指针 ★★

**概念与语法**

`struct Item a[3]` 是含 3 个结构对象的数组，不是一个结构里含 3 个数组。每个元素都有独立的成员：`a[i].quantity` 先确定第 i 个结构，再访问 quantity。数组下标从 0 开始，长度为 n 时合法下标为 0～n−1。

`struct Item *p = &a[0];` 定义指向结构的指针。指针保存对象地址，不自动创建被指向的结构。访问成员可写 `(*p).quantity`，括号必不可少；`p->quantity` 是其常用等价写法。`p.quantity` 错误，因为 p 自身是指针。只有当 p 指向仍存活的合法结构对象时，才允许 `p->成员`；空指针不能解引用。

当指针指向数组元素时，`p + 1` 指向下一个结构对象，移动的是一个完整元素的距离，不是一个字节。`p[i]` 等价于 `*(p+i)`。可以形成数组尾后指针，但不能解引用它。初学阶段遍历优先用下标或明确的元素数量，不通过猜测地址终点。

**生活类比与适用边界**

结构数组像货架上一排相同格式的库存卡；指针像手指，指向其中一张卡。换一张卡不等于复制卡片；手指悬空或指向货架之外时，不能继续读取卡片。

**学生怎样理解**

看到 `&a[1]` 应说出“第二个对象的地址”；看到 `p->quantity += 2` 应说出“修改 p 指向的那个对象”。指针 p 改变和被指向对象成员改变是两种操作。

**教师板书顺序、追问与参考答案**

①画三个对象框 a[0]、a[1]、a[2]。②写 p=&a[1] 并画箭头，问 p 指向第几个？答：第二个。③写 p->quantity+=2，问哪个对象变？答：a[1]。④写 (*p).quantity，问为何括号？答：先解引用取得结构，再取成员。⑤问 a[3] 能否读取？答：不能，已越界。

**常错与纠正**

用 `p.quantity`：改为 `p->quantity`；把 `*p.quantity` 当成解引用后取成员：应写 `(*p).quantity`；循环条件写 `i<=3`：长度 3 时应为 `i<3`；声明指针后直接使用：先让它指向有效对象。

<a id="E07-02"></a>

#### E07-02 完整例题

目标：通过结构指针修改数组中一个对象，再遍历求和。①创建三种商品。②p 指向第二个元素。③用箭头运算符补货两件。④从下标 0 到 2 累加数量；每次累加的是修改后的实际值。

<!-- example: E07-02 -->
```c
#include <stdio.h>

int main(void) {
    struct Item a[3] = {{10, 2}, {20, 3}, {30, 4}};
    struct Item *p = &a[1];
    p->quantity += 2;
    int total = 0;
    for (int i = 0; i < 3; ++i) {
        total += a[i].quantity;
        printf("%d:%d\n", a[i].code, a[i].quantity);
    }
    printf("total=%d\n", total);
    return 0;
}
```

**变量或链接跟踪**：数量最初 `[2,3,4]` → 指针补货后 `[2,5,4]`；total 随循环为 `0→2→7→11`。

**实际输出**

```text

20:5
30:4
total=11
```

**输出原因**：按上面的状态变化逐行读取成员或计算返回值；各打印语句的顺序就是输出顺序。数量最初 `[2,3,4]` → 指针补货后 `[2,5,4]`；total 随循环为 `0→2→7→11`。

<a id="K07-03"></a>

### K07-03 含数组、含指针的结构与嵌套结构 ★★

**概念与语法**

结构可以含数组成员，例如 `char name[16]`：每个结构对象自身拥有这一整块数组存储。结构也可以含指针成员，例如 `const char *category`：结构中只存地址，字符串内容可能位于别处。二者在 `sizeof`、可修改性和复制后关系上不同。初始化时可以给字符数组成员字符串；创建完成后不能写 `a.name = "Li"`，数组不可整体赋值，应在容量足够时用字符串复制函数或逐元素写入。

结构整体赋值会复制数组成员的内容，也会复制指针成员的地址。地址被复制后，两个对象的指针可能指向同一份外部数据，这通常称为浅复制；不会自动深度复制被指向的数据。指针指向的目标必须活得足够久。字符串字面量具有静态存储期，但不可通过指针修改；所以例题使用 `const char *`。

嵌套结构是把另一种结构作为成员，例如 `struct Date birthday`。访问时从外到内逐层写 `p.birthday.year`；若 p 是指针，则写 `p->birthday.year`。一次箭头只表示当前这一层左侧是指针，不能把所有点都机械改为箭头。

**生活类比与适用边界**

数组成员像放在个人档案袋里的纸质姓名卡，复制档案时卡上文字也复制；指针成员像记录共享公告板的位置，复制位置后仍查看同一块板。嵌套结构像档案中的日期小表，需先找到档案，再找到小表的年份。类比不意味着程序会自动管理共享板的寿命。

**学生怎样理解**

判断复制关系时问两个问题：“成员本身是什么类型？”“外部目标由谁保存？”数组内容属于对象，普通数值属于对象，指针目标未必属于对象。嵌套访问从左到右解释，不死记符号串。

**教师板书顺序、追问与参考答案**

①画档案外框，name 数组画在框内，category 画箭头通向框外。②复制 a 到 b，问 name[0] 与 category 分别复制什么？答：字符值与地址值。③修改 b.name[0]，问 a 是否改变？答：不变。④写 b.birthday.year，问中间 birthday 是指针吗？答：不是，所以使用点。⑤问能否改字符串字面量首字母？答：不能。

**常错与纠正**

以为结构复制后所有内容都完全独立：指针目标可能共享；把字符数组当指针赋值：数组成员改内容需逐字符或安全复制；保存函数局部数组的地址并返回：局部数组寿命结束后地址失效；对字符串字面量写入：属于未定义行为。

### K07-04 动态分配、释放与所有权 ★★

**概念与语法**

自动局部变量通常在离开所属作用域后失效；需要让节点在函数返回后继续存在时，可申请动态存储。`malloc`、`free` 声明在 `<stdlib.h>`。`struct Node *p = malloc(sizeof *p);` 申请足够存放一个节点的字节数：`sizeof *p` 在这里不读取 p 指向的内容，而是依据类型确定大小。C 中无需强制转换 malloc 的返回值；必须包含正确头文件。

malloc 成功时返回存储地址，但其中成员尚未初始化；失败返回空指针 NULL。先检查，再写入各成员。不要写成 `malloc(sizeof p)`，那通常只是指针自身大小。`free(p)` 归还一次有效动态分配；之后不能再访问该对象，也不能重复释放。`free(NULL)` 是允许的。

“所有权”不是 C 自动检查的语法，而是程序设计约定：明确由谁负责最终释放。若 p、q 指向同一动态对象，通常指定一个负责释放者；释放一次后两个地址都不能再用于访问。把 p 置 NULL 只改变 p，不会自动修正其他别名。严格说，对象生命周期结束后指向它的指针值变为不确定值，不能继续求值它来打印、比较或解引用；可直接给这些指针变量重新赋有效值或NULL。每次成功分配最终要对应一次释放；分配失败前已成功取得的其他节点也要清理。第08章把这条约定推广为“链表拥有全部节点，销毁函数逐个释放”。

**生活类比与适用边界**

像租用储物柜：malloc 申请一个柜子，返回柜号；柜里不是自动整理好的，必须自己放入数据；free 归还柜子。抄一份柜号不会租到第二个柜子，柜子归还后两份柜号都不能继续使用。此类比不能保证每次申请成功。

**学生怎样理解**

按“申请→判空→初始化→使用→释放”的固定顺序读代码。指针变量自身仍存在，不代表它曾指向的动态对象仍存在。程序在失败分支提前返回前，应盘点此前取得的资源。

**教师板书顺序、追问与参考答案**

①画指针 p 与堆对象两个框。②写 malloc，问失败时 p 是什么？答：NULL。③先画判空分支再写 p->value，问能否调换？答：不能，失败时会解引用空指针。④画 q=p，问分配了几个对象？答：一个。⑤free(p) 后问 q 能否读取？答：不能。⑥写 p=NULL，问 q 会自动变 NULL 吗？答：不会。

**常错与纠正**

未判空就写成员：先检查分配结果；申请 `sizeof p`：改为 `sizeof *p`；释放后打印成员：先使用再释放；多个别名各释放一次：一个对象只释放一次；把最后一个地址覆盖而不释放：丢失所有权造成泄漏。

## 第08章 单向链表

<a id="K08-01"></a>

### K08-01 单向链表的节点与尾插建立 ★★

**概念与语法**

单向链表由若干节点构成。每个节点含“数据域 value”和“链接域 next”；next 保存后继节点的地址，末节点的 next 为 NULL。head 保存首节点地址；空链表 head 为 NULL。节点不要求在内存中连续，不能像数组那样用 head[i] 查第 i 个节点，必须沿 next 逐步走。

`struct Node { int value; struct Node *next; };` 可以在结构内部声明指向同类型的指针，因为指针大小可确定；不能直接写一个自身类型的完整成员，否则对象会无限套娃。这里用不带头结点的链表：head 直接指向第一个有实际数据的节点，不要和“额外创建的哨兵头结点”混淆。

尾插法维护 head 与 tail 两个地址。建立前二者均为 NULL。每次先申请新节点、判空，再设置 value 和 next=NULL。第一节点使 head 与 tail 都指向它；之后令旧 tail->next 指向新节点，再更新 tail。顺序不能颠倒，否则找不到旧尾的链接位置。

辅助函数通过 `struct Node **head` 接收调用者指针变量的地址。理解为“能找到外面的 head 变量”：`*head = node` 才能改变调用者的链表入口。调用 `append(&head, &tail, value)`；函数里的 *head 是节点指针，**head 才是节点对象。分配失败返回 0，不改变原链；调用者必须释放先前已建好的所有节点。销毁时先保存 next，再 free 当前节点，最后沿保存地址继续，绝不能 free 后再读取当前节点的 next。

**生活类比与适用边界**

像寻宝纸条：第一张纸条的位置由 head 记录，每张纸条写着内容和下一张的位置，最后写“结束”。tail 是额外记录的最后一张位置，方便把新纸条接上。纸条可以放在不同房间，所以“地址加一”找不到下一张。

**学生怎样理解**

从三个地址读起：head 是入口，tail 是出口，node 是待加入的新对象。二级指针并非更复杂的节点，只是把“外面哪个指针变量需要更新”传进去。先学会纸上连接两个节点，再阅读循环。

**教师板书顺序、追问与参考答案**

①画空链 head=NULL、tail=NULL。②画新节点 [10|NULL]，问第一次要改谁？答：head、tail。③画 [20|NULL]，先画 tail->next 箭头，再移动 tail。④追问反过来会怎样？答：丢失旧尾位置，可能产生自环。⑤画 &head 指向 head 变量，问 *head 是什么？答：外面的头指针值。⑥假设第三次申请失败，问释放几个？答：前两节点都释放，新节点未取得无须释放。

**常错与纠正**

把 next 定义为完整 struct Node：必须是指针；新节点 next 未置 NULL：遍历会走到不确定地址；先更新 tail 再连接：会接错；建立失败只 return：已建链泄漏；释放后读取 head->next：先保存 next。

<a id="E08-01"></a>

#### E08-01 完整例题

目标：尾插建立 10→20→30 并释放。①理解 append 的三个阶段：创建、连接、更新尾指针。②循环把数组值逐个交给 append。③任一申请失败，destroy 清理已有前缀后退出。④成功后从 head 输出，最后调用 destroy 归还所有节点。这里数组只是提供示例输入，并不储存链表的链接关系。

<!-- example: E08-01 -->
```c
#include <stdio.h>
#include <stdlib.h>
struct Node { int value; struct Node *next; };
static void destroy(struct Node *head) {
    while (head != NULL) {
        struct Node *next = head->next;
        free(head);
        head = next;
    }
}
static int append(struct Node **head, struct Node **tail, int value) {
    struct Node *node = malloc(sizeof *node);
    if (node == NULL) return 0;
    node->value = value;
    node->next = NULL;
    if (*tail == NULL) *head = node;
    else (*tail)->next = node;
    *tail = node;
    return 1;
}
static void print_list(const struct Node *head) {
    if (head == NULL) { puts("EMPTY"); return; }
    for (const struct Node *p = head; p != NULL; p = p->next) {
        printf("%d%s", p->value, p->next == NULL ? "\n" : " ");
    }
}
int main(void) {
    struct Node *head = NULL, *tail = NULL;
    int values[3] = {10, 20, 30};
    for (int i = 0; i < 3; ++i) {
        if (!append(&head, &tail, values[i])) {
            puts("ALLOC_FAIL");
            destroy(head);
            return 1;
        }
    }
    print_list(head);
    destroy(head);
    return 0;
}
```

**实际输出**

```text

```

**输出原因**：按上面的状态变化逐行读取成员或计算返回值；各打印语句的顺序就是输出顺序。第1轮：head=tail=N1，N1=[10|NULL]。第2轮：N1.next=N2、tail=N2。第3轮：N2.next=N3、tail=N3，N3.next=NULL。销毁按 N1→N2→N3，各释放一次。

### K08-02 单向链表遍历与统计 ★★

**概念与语法**

遍历是从头到尾访问每一个节点。典型框架为 `p=head;`，只要 `p!=NULL` 就处理当前节点，然后执行 `p=p->next`。判断必须发生在解引用之前：`p->value` 和 `p->next` 都要求 p 指向有效节点。空链 head=NULL 时循环执行零次，天然得到节点数 0、总和 0。

用于观察数据的游标可声明为 `const struct Node *p`，表示不通过 p 修改节点；p 自身仍可移动。遍历一般使用独立游标，保留 head 作为整个链表的入口。若直接反复改 head，可能使原首节点无法找回，后续既不能再遍历也无法完整释放。

访问 n 个节点要沿 n 次链接，时间复杂度为 O(n)，额外只需游标与少量统计变量。想取第 k 个节点仍必须从入口走 k−1 步；不能把非连续节点当作数组。在本章假定链表无环、链接有效且遍历期间没有别处删除节点；如果 next 形成环，单纯等待 NULL 的循环不会终止。

**生活类比与适用边界**

像沿单行路线检查每一站：游标记录当前站，head 是地图上的起点标记。你前进时不擦掉起点；遇到“无下一站”才结束。若路线绕成圈，按这个规则会一直转圈。

**学生怎样理解**

每次循环进入时，p 指向“尚未统计的当前节点”。处理后才走下一步。把“取值”“累加”“移动”三个动作分开追踪，不将 p=p->next 误认为修改节点内容。

**教师板书顺序、追问与参考答案**

①画 3→−1→5，p 从首节点开始。②写 count=0,sum=0。③每访问一节点填一次统计表。④问为什么不能写 while(p->next!=NULL)？答：空链会非法访问，且末节点不被处理。⑤问最后 p 为 NULL 是否 head 也变 NULL？答：不会，它们是不同变量。⑥空链循环几次？答：零次。

**常错与纠正**

使用 `while(p->next)`：会漏掉末节点，并在空链解引用 NULL；漏写 p=p->next：无限循环；用 p++ 找下一节点：链表节点不连续；遍历时丢失 head：使用额外游标；最大值初始化为 0：全负链会出错，应先处理空链再用首值。

#### E08-02 完整例题

<!-- example: E08-02 -->
```c

#include <stdlib.h>

    while (head != NULL) {
        struct Node *next = head->next;
        free(head);
        head = next;
    }
}

    struct Node *node = malloc(sizeof *node);
    if (node == NULL) return 0;
    node->value = value;
    node->next = NULL;
    if (*tail == NULL) *head = node;
    else (*tail)->next = node;
    *tail = node;
```

### K08-03 插入节点：先接后继，再改入口 ★★

**概念与语法**

插入位置用从 0 开始的编号表示：向长度 n 的链表插入时，0 是头插，n 是尾插，0～n 共 n+1 个合法位置。把新节点 node 放在 A 与 B 之间，必须先令 node->next=B，再令 A->next=node；头插时 A 不存在，要修改 head。尾插时 B 为 NULL。空链唯一合法位置为 0。

可以分别处理头部与普通位置，也可以用“指向链接的指针”统一处理。`struct Node **link = head;` 中，形参 head 是调用者头指针的地址，因此 link 一开始指向保存首节点地址的那个变量。`*link` 是待插入位置原来的后继节点地址。每向前走一节点执行 `link=&(*link)->next`，让 link 改为指向当前节点内部的 next 成员。

定位完成后，用两句统一连接：`node->next=*link; *link=node;`。第一句保留旧后缀；第二句把入口改成新节点。这里没有复制整段链表，只修改地址。先验证位置再分配，非法位置不产生需要释放的新对象；申请失败不改变旧链。定位耗时 O(position)，连接本身 O(1)。

例题的 tail 只在建链阶段使用，插入函数只维护 head 与 next。此后不再依赖原 tail；如果一个实际接口承诺一直维护尾指针，就必须在尾插、空链插入时同步更新它。不能把未维护的 tail 继续用于下一次 append。

**生活类比与适用边界**

像在两节车厢之间挂入新车厢：先把新车厢的后钩接到后半列车，再把前方的钩改接新车厢。link 像指向“需要改接的那个挂钩”的手指；头部对应车站保存的首车位置。类比只说明单向链接，实际代码并没有后向指针。

**学生怎样理解**

不要把 link 和 *link 混为一谈：link 指向某个指针槽位，*link 是该槽位目前保存的节点地址。写 `*link=node` 修改的是槽位，不是 node 的数据。把位置画在节点之间，比把位置写在节点上更不易错。

**教师板书顺序、追问与参考答案**

①画两节点及三个可插位置 0、1、2。②从 head 槽位起移动 link，问 position=1 时 link 指向哪？答：首节点的 next 成员。③圈出 *link，即旧第二节点。④先写 node->next=*link，问此刻旧链是否已变？答：没有。⑤再写 *link=node。⑥若颠倒两句会怎样？答：node->next 可能指回 node，旧后缀丢失。⑦空链位置1为何非法？答：需要跨过不存在的节点。

**常错与纠正**

插入位置只允许 0～n−1：漏掉合法尾插 n；先覆盖旧链接再保存：丢失后缀或形成自环；只改函数的局部 head 副本：外部入口不变，应传地址或返回新头；新增节点未检查 malloc：失败时非法访问；插入后继续使用未更新的 tail：可能破坏链表。

#### E08-03 完整例题

目标：在 10 与 30 之间插入 20。①先建立两节点。②position=1，使 link 从头指针槽位移动到首节点 next 槽位。③新节点 next 接旧第二节点。④把首节点 next 改为新节点。⑤输出并销毁。读取 status 区分位置错误、申请失败和成功。

<!-- example: E08-03 -->
```c
#include <stdio.h>
#include <stdlib.h>
struct Node { int value; struct Node *next; };
static void destroy(struct Node *head) {
    while (head != NULL) {
        struct Node *next = head->next;
        free(head);
        head = next;
    }
}
static int append(struct Node **head, struct Node **tail, int value) {
    struct Node *node = malloc(sizeof *node);
    if (node == NULL) return 0;
    node->value = value;
    node->next = NULL;
    if (*tail == NULL) *head = node;
    else (*tail)->next = node;
    *tail = node;
    return 1;
}
static void print_list(const struct Node *head) {
    if (head == NULL) { puts("EMPTY"); return; }
    for (const struct Node *p = head; p != NULL; p = p->next) {
        printf("%d%s", p->value, p->next == NULL ? "\n" : " ");
    }
}
static int insert_at(struct Node **head, int position, int value) {
    if (position < 0) return 0;
    struct Node **link = head;
    for (int i = 0; i < position; ++i) {
        if (*link == NULL) return 0;
        link = &(*link)->next;
    }
    struct Node *node = malloc(sizeof *node);
    if (node == NULL) return -1;
    node->value = value;
    node->next = *link;
    *link = node;
    return 1;
}
int main(void) {
    struct Node *head = NULL, *tail = NULL;
    if (!append(&head, &tail, 10) || !append(&head, &tail, 30)) {
        puts("ALLOC_FAIL"); destroy(head); return 1;
    }
    int status = insert_at(&head, 1, 20);
    if (status != 1) {
        puts(status < 0 ? "ALLOC_FAIL" : "BAD_POSITION");
        destroy(head); return status < 0 ? 1 : 0;
    }
    print_list(head);
    destroy(head);
    return 0;
}
```

**实际输出**

```text

```

### K08-04 删除节点与释放：覆盖所有边界 ★★

**概念与语法**

本节删除“第一个值等于 target 的节点”。若有重复值，仅删除最先遇到的一个；未找到则链表不变。删除不是把 value 设为 0，也不是只调用 free；必须先让链表绕过该节点，保持其余节点可达，再释放被删除对象。

仍用 link 指向待检查入口槽位。寻找时循环条件 `*link != NULL && (*link)->value != target` 依靠 && 的短路规则：左侧为假便不访问右侧，空链与查找结束都安全。找到后令 `victim=*link` 暂存待删对象，`*link=victim->next` 接好剩余链，最后 `free(victim)`。

这三步统一处理头删、中删、尾删和单节点删除：头删修改 head；中删修改前驱 next；尾删把前驱 next 置 NULL；删掉唯一节点把 head 置 NULL。空链或未找到直接返回 0，不释放任何节点。删除成功返回 1。销毁函数随后只处理仍在链上的节点，不会再释放 victim。

本节 tail 仅用于初始建立，删除后不再使用；若要长期保留尾指针，删除旧尾时必须更新它，清空链时还须令 tail=NULL。任何指向 victim 的其他别名均立即失效。查找 O(n)，找到后改接与释放 O(1)。

**生活类比与适用边界**

像从单向通讯名单中移除一人：先让前一人的联系地址跳到后一人，再销毁被移除人的卡片。若先销毁卡片，就无法安全读取下一人的地址。末尾被删时，前一人的“下一位”改成空。

**学生怎样理解**

把“从链上摘下”与“释放内存”分成两个概念：只摘下不释放会泄漏，只释放不摘下会留下悬空链接。写删除函数时先在纸上检查五种情况：空链、头、尾、唯一节点、未找到。

**教师板书顺序、追问与参考答案**

①画 5→8→5，指定只删第一个5。②圈 victim 并记录后继8。③把 head 改到8，再划掉 victim。④问最后一个5是否删除？答：不删除。⑤改画单节点5，问删除后 head？答：NULL。⑥问未找到是否调用 free？答：不调用。⑦问 free 后能否取 victim->next？答：不能，后继必须此前读出。

**常错与纠正**

先 free(victim) 再读 next：释放后访问；只让局部 victim 指向下一节点：链上链接没有改变；找到后持续循环却未更新有效游标：可能使用已释放地址；把所有重复项都删掉：不符合“第一个”的契约；未找到也释放某节点：误删数据。

<a id="E08-04"></a>

#### E08-04 完整例题

目标：删除首个5并保留另一个5。①建链 5→8→5。②link 起初指向 head，马上匹配。③victim 保存原首节点，head 改为其后继8。④释放原首节点并返回1。⑤输出余链8→5，再统一销毁剩余两节点。

<!-- example: E08-04 -->
```c
#include <stdio.h>
#include <stdlib.h>
struct Node { int value; struct Node *next; };
static void destroy(struct Node *head) {
    while (head != NULL) {
        struct Node *next = head->next;
        free(head);
        head = next;
    }
}
static int append(struct Node **head, struct Node **tail, int value) {
    struct Node *node = malloc(sizeof *node);
    if (node == NULL) return 0;
    node->value = value;
    node->next = NULL;
    if (*tail == NULL) *head = node;
    else (*tail)->next = node;
    *tail = node;
    return 1;
}
static void print_list(const struct Node *head) {
    if (head == NULL) { puts("EMPTY"); return; }
    for (const struct Node *p = head; p != NULL; p = p->next) {
        printf("%d%s", p->value, p->next == NULL ? "\n" : " ");
    }
}
static int delete_first(struct Node **head, int target) {
    struct Node **link = head;
    while (*link != NULL && (*link)->value != target) {
        link = &(*link)->next;
    }
    if (*link == NULL) return 0;
    struct Node *victim = *link;
    *link = victim->next;
    free(victim);
    return 1;
}
int main(void) {
    struct Node *head = NULL, *tail = NULL;
    int values[3] = {5, 8, 5};
    for (int i = 0; i < 3; ++i) {
        if (!append(&head, &tail, values[i])) {
            puts("ALLOC_FAIL"); destroy(head); return 1;
        }
    }
    printf("deleted=%d\n", delete_first(&head, 5));
    print_list(head);
    destroy(head);
    return 0;
}
```

**变量或链接跟踪**：初态 head=N1(5)、N1.next=N2(8)、N2.next=N3(5)。victim=N1；改接后 head=N2；free(N1) 后剩余 N2→N3。destroy 只释放 N2、N3。

**实际输出**

```text

```

**输出原因**：按上面的状态变化逐行读取成员或计算返回值；各打印语句的顺序就是输出顺序。初态 head=N1(5)、N1.next=N2(8)、N2.next=N3(5)。victim=N1；改接后 head=N2；free(N1) 后剩余 N2→N3。destroy 只释放 N2、N3。

**对应练习**：T08-04-S、T08-04-F、T08-04-P。

## 第09章 常用库函数

### K09-01 数学库：含义、定义域与链接 ★★

**概念与语法**

数学函数声明在 `<math.h>`。本节使用的 double 版本有：`cos(x)` 求弧度 x 的余弦；`sqrt(x)` 求平方根，实数范围要求 x≥0；`pow(x,y)` 求 x 的 y 次幂；`exp(x)` 求 e 的 x 次幂；`fabs(x)` 求浮点绝对值；`log(x)` 求自然对数 ln(x)；`log10(x)` 求常用对数。后两者要求 x>0，不能把 log 误认为以10为底。

cos 输入是弧度，不是角度：180度对应 π 弧度。C17 不保证存在 `M_PI` 宏，需要时自己提供足够精度的 π 常量。pow 的实数定义域尤其要小心：负底数与非整数指数通常无实数结果；0 的负指数不合法；0^0 不应在跨平台练习中当作有统一数学含义的普通输入。`fabs` 面向浮点数，不能拿 `<stdlib.h>` 的 `abs(int)` 替代，否则可能先截去小数。

满足定义域仍可能超出浮点表示范围，例如 exp 的大正数参数可能溢出。不要依赖域错误“必定崩溃”或“必定输出某个固定字符串”；先校验输入，必要时用 `isfinite` 检查有限性，按任务约定处理范围问题。浮点结果通常是近似值，输出小数位数是显示规则，不能由显示相等推出内部值逐位相等。

命令行示例：`clang -std=c17 program.c -lm -o program`。在需要独立数学库链接的系统上，`-lm` 应放在源文件或目标文件之后；部分平台不单独要求它。`#include <math.h>` 提供声明，链接数学库提供实现，两者作用不同。本资料验证统一带 `-lm`。

**生活类比与适用边界**

像按键计算器：sqrt、cos、log 是不同按钮，按钮允许的输入与单位不同。输入180后按 cos 并不自动表示180度；程序也不能靠“数学函数会处理”跳过题目要求的输入检查。

**学生怎样理解**

调用前说清三件事：函数计算什么、输入允许什么、输出怎样显示。例如 log(1.0)=0，而 log10(100.0)=2；sqrt(9.0)=3，不能把 sqrt(-9.0) 当普通实数算式。

**教师板书顺序、追问与参考答案**

①画函数/含义/输入三列表。②先算 sqrt(9)、pow(2,3)。③对照 log(1) 与 log10(100)，问 log 底数？答：e。④问 cos(180) 是否−1？答：不是按角度理解，它把180当弧度。⑤问 fabs(-2.5) 与 abs(-2.5) 是否等价？答：不等价，abs 接收整数。⑥问包含 math.h 后为何仍可能链接报错？答：某些系统还需链接数学库。

**常错与纠正**

把 log 当 log10：按底数区分；sqrt 输入负数：先校验；cos 输入角度：先换为弧度；使用 abs 处理浮点：改 fabs；以为 pow 总有实数结果：检查底数和指数；把 -lm 写进 C 源码：它是编译链接选项。

### K09-02 字符分类与大小写转换 ★

**概念与语法**

`<ctype.h>` 提供单个字节字符的分类与转换：`isalnum(c)` 判断字母或数字，`isalpha(c)` 判断字母，`isdigit(c)` 判断十进制数字，`islower(c)` 判断小写字母，`toupper(c)` 把可转换的小写字母转成大写，其余字符保持原值。分类函数返回0表示否，非0表示是；真值不保证恰好为1，显示布尔值时可写 `isalpha(c) != 0`。

这些函数的实参必须是 EOF，或者能够用 unsigned char 表示的值。普通 char 在某些平台上有符号，包含高位字节时可能变成负数；直接交给 ctype 函数会越出契约。因此从 char 数组取出的字符应先写 `unsigned char c=(unsigned char)s[i]`，或调用 `isalpha((unsigned char)s[i])`。

`getchar()` 返回 int，因为它既要表示所有 unsigned char 值，又要表示特殊值 EOF。正确顺序是先用 int 接收并与 EOF 比较，再分类或转换。不要把返回值先存到 char 或先强转 unsigned char 后再判断 EOF，否则可能丢失结束标志。已确认不是 EOF 的 getchar 返回值本身可直接传给这些函数。

字符分类与转换可能受当前 C locale 影响；程序启动默认 C locale，本例按基本英文字母和数字理解。这里处理字节，不能直接把 UTF-8 中文或任意 Unicode 字母按人眼字符分类。toupper 返回转换后的整数值，不会自动修改原数组。

**生活类比与适用边界**

像给一个个字符盖分类章：同一个 a 同时属于“字母”“字母或数字”“小写”，而7只属于“数字”“字母或数字”。toupper 像给出一个改写后的副本，不会悄悄改掉原卡片。EOF 则是“没有下一张卡”的状态，不是一张普通字符卡。

**学生怎样理解**

先分清“分类返回真假”和“转换返回字符”。isalpha 的结果应拿来判断，toupper 的结果应保存或输出。读取变量用 int 是为了把真正字符与读到末尾区分开。

**教师板书顺序、追问与参考答案**

①对 a、Z、7、? 画分类表。②问 isalpha(a) 必须等于1吗？答：只保证非0。③写 int ch=getchar()，问为何不用 char？答：必须保留 EOF。④在循环内调用 toupper(ch)，问会修改 ch 吗？答：不会，除非把返回值赋回去。⑤读数组 s[i] 时问为什么转 unsigned char？答：避免 char 的负值违反函数参数要求。

**常错与纠正**

用 `isalpha(c)==1` 判断：应检查非0；将 getchar 返回值存 char：可能混淆 EOF；把负 char 直接传 ctype：先转 unsigned char；判断 EOF 前就强转：可能丢失结束标志；认为 toupper 改了原变量：需要接收返回值。

### K09-03 字符串复制与连接：容量包含结束符 ★★

**概念与语法**

C 字符串是在字符数组中以 `\0` 结束的字符序列。`"cat"` 有3个可见字符，但存放它至少需要4个 char。字符串函数声明在 `<string.h>`。`strcpy(dest,src)` 将 src 的字符以及最后的 `\0` 一起复制到 dest，覆盖 dest 原内容；目标至少需要 `strlen(src)+1` 字节。它不会自动分配空间，也不检查容量。

`strcat(dest,src)` 先找到 dest 当前结束符，再从那里接上 src（包含其结束符）。目标开始时必须已经是有效字符串：可写 `char out[16]="";` 建立空字符串，不能对未初始化的字符数组直接 strcat。连接后需要容量 `原长度+追加长度+1`。源与目标不能重叠，目标必须可写；不能把字符串字面量当目标。

实际数组在当前作用域可用 `sizeof out` 取得容量，包括所有数组槽位；传入函数的 `char *out` 或形参数组已是指针，`sizeof out` 不再给出原数组容量，应另外传容量。检查复制可用 `strlen(src)<capacity`；连接在已知目标长度小于容量时，可用 `strlen(src)<capacity-strlen(dest)`，为结束符保留至少一格。不要把 strncpy 误当自动安全替代，它有不同的补零和结束符规则，本节不使用。

**生活类比与适用边界**

像往有固定格数的标签条写字：最后还要留一格放“结束”标记。strcpy 从开头重写，strcat 从已有文字的结束标记处接着写；标签条不会因为写多了自动变长。

**学生怎样理解**

每次动手前写三个数：目标容量、当前字符长度、即将增加的字符长度。把末尾结束符也算进去。长度可等于容量−1，不能等于容量。空字符串也占用一个结束符位置。

**教师板书顺序、追问与参考答案**

①画16格数组，写入 red 和结束符。②问 strlen 是多少？答：3；sizeof 数组是多少？答：16。③追加 - 再追加 pen，逐次移动结束符。④问7字符需几格？答：8。⑤写 char x[4]="cat"，问能再追加一个!吗？答：不能，需要5格。⑥问未初始化数组能否直接 strcat？答：不能，找不到可靠的结束符。

**常错与纠正**

只给可见字符数量的空间：还需1格结束符；把 sizeof 指针当容量：显式传入容量；对未初始化目标 strcat：先建空串或复制有效串；源目标重叠：strcpy/strcat 不支持重叠；先执行再检查：越界已经发生，必须先检查。

<a id="E09-03"></a>

#### E09-03 完整例题

目标：检查容量后构造 red-pen。①目标数组置为空串。②检查再复制 red，结束符在下标3。③检查剩余空间后追加分隔符，结束符移到下标4。④同样追加 pen，结束符移到下标7。⑤打印可见文字及长度/容量，展示二者不同。

<!-- example: E09-03 -->
```c
#include <stdio.h>
#include <string.h>
int main(void) {
    char out[16] = "";
    const char *first = "red";
    const char *second = "pen";
    if (strlen(first) >= sizeof out) { puts("TOO_LONG"); return 0; }
    strcpy(out, first);
    if (strlen("-") >= sizeof out - strlen(out)) { puts("TOO_LONG"); return 0; }
    strcat(out, "-");
    if (strlen(second) >= sizeof out - strlen(out)) { puts("TOO_LONG"); return 0; }
    strcat(out, second);
    printf("%s\n", out);
    printf("length=%zu capacity=%zu\n", strlen(out), sizeof out);
    return 0;
}
```

**变量或链接跟踪**：out 内容 `""→"red"→"red-"→"red-pen"`；长度 `0→3→4→7`；容量始终16；最终使用8格，其中一格是结束符。

**实际输出**

```text
red-pen
length=7 capacity=16
```

**输出原因**：按上面的状态变化逐行读取成员或计算返回值；各打印语句的顺序就是输出顺序。out 内容 `""→"red"→"red-"→"red-pen"`；长度 `0→3→4→7`；容量始终16；最终使用8格，其中一格是结束符。

### K09-04 字符串长度与字典序比较 ★

**概念与语法**

`strlen(s)` 返回第一个 `\0` 之前的字符单元数量，类型是 `size_t`，输出使用 `%zu`。它不包含结束符，也不是数组容量；遇到嵌入的结束符会提前停止。字符串必须能在可访问范围内找到结束符，否则函数可能读出界。对于 UTF-8 文本，它数的是字节而非人眼看到的汉字个数。

`strcmp(a,b)` 按字符串的第一个不同字节比较，字符按 unsigned char 值解释；如果前缀相同，较先结束的字符串较小。返回值<0表示 a在前，=0表示内容相同，>0表示 a在后。标准只承诺符号，不承诺一定为−1或1，也不承诺是具体字符编码差。因此判断写 `cmp<0`、`cmp==0`、`cmp>0`。

长度比较与字典序比较是两项不同任务：较短的字符串不一定字典序更小。例如在本例基本英文字符环境中，"zoo" 长3而 "apple" 长5，但 z 排在 a 后。`a==b` 比较地址而不是字符串内容；内容相同的两个数组通常有不同地址。用 strlen 判断相等也不充分，"cat" 与 "dog" 等长但内容不同。

比较函数的参数只需读，因此可通过 const char * 传入。strlen、strcmp 都以结束符为界，而不是按数组预留容量操作；只要字符串合法，数组剩余格中的值与本次比较无关。

**生活类比与适用边界**

长度像数一行里写了几格字，字典序像查词典时从左到右看第一个不同字母。两件事标准不同：一个短单词完全可能排在长单词后。内存地址则像书放在哪个抽屉，与书名是否相同无关。

**学生怎样理解**

遇到“比较两个字符串”要先问比较长度还是内容顺序。读取 strcmp 结果只看正、负、零；不要把某一次机器上输出的正数当成通用标准。

**教师板书顺序、追问与参考答案**

①写 zoo 和 apple，先数3、5，再比较首字符。②问短的是否一定排前？答：否。③写 cat 与 catalog，问前缀相同时谁小？答：cat 先结束所以小。④假设 strcmp 返回7，问能断言哪项？答：第一个串较大，不能推定其他实现也返回7。⑤写 a==b，问比较什么？答：地址。⑥strlen 空串是多少？答：0。

**常错与纠正**

用 %d 输出 size_t：改 %zu；用 == 比较字符串内容：改 strcmp；要求 strcmp==1 才表示大于：应 >0；strlen 包含结束符：不包含；按长度决定字典序：应检查首个不同字节；没有结束符也调用 strlen：可能读越界。

<a id="E09-04"></a>

#### E09-04 完整例题

目标：把长度与内容顺序分开报告。①strlen 得到3与5。②strcmp 比较首字符，结果为某个正数。③仅按符号输出 a>b，不输出依赖实现的具体返回数。④再验证相同文字比较结果为0。

<!-- example: E09-04 -->
```c
#include <stdio.h>
#include <string.h>
int main(void) {
    const char *a = "zoo";
    const char *b = "apple";
    printf("lengths=%zu,%zu\n", strlen(a), strlen(b));
    int cmp = strcmp(a, b);
    if (cmp < 0) puts("a<b");

    else puts("a>b");

}
```

**变量或链接跟踪**：a长度3，b长度5；cmp>0（具体正值不作假设）；strcmp("cat","cat")=0，因此 equal 为1。

**实际输出**

```text

```

**输出原因**：按上面的状态变化逐行读取成员或计算返回值；各打印语句的顺序就是输出顺序。a长度3，b长度5；cmp>0（具体正值不作假设）；strcmp("cat","cat")=0，因此 equal 为1。

## 第10章 输入输出和文件操作

<a id="K10-01"></a>

### K10-01 格式化输入输出与转换失败 ★

**概念与语法**：`printf("格式", 值...)` 把值排成文本；`scanf("格式", 地址...)` 按规则转换并写入对象。转换规格与实参类型必须匹配，类型错配可能产生未定义行为，并非只会显示错字。`printf` 返回输出字符数，出错返回负值；`scanf` 返回成功赋值的项目数，在首次转换前发生输入失败时返回 `EOF`。

|用途|输出格式与参数|输入格式与参数|
|---|---|---|
|有符号整数|`%d`，`int`值|`%d`，`int *`地址|
|无符号整数|`%u`，`unsigned int`|`%u`，`unsigned int *`|
|浮点数|`%f`，`double`（`float`会提升）|`%f`写`float *`；`%lf`写`double *`|
|单字符|`%c`，经提升的字符值|`%c`，`char *`，默认不跳过空白|
|字符串|`%s`，以空字符结尾的字符串|如`%7s`配`char s[8]`，给结尾空字符留1位|
|数组长度|`%zu`，`size_t`|`%zu`，`size_t *`|

`%.2f` 保留小数点后2位用于显示；`%6d` 是最小输出宽度，不会截断更长整数。输入中的普通空白可匹配任意数量空白；`" %c"`可跳过旧换行，而`"%c"`会读到它。不要把换行习惯性写在 `scanf("%d\n", ...)` 尾部：它可能继续等待下一个非空白字符。读取数字后再 `fgets` 时，行尾换行仍可能留在流中，应明确整行输入策略。

**生活类比与边界**：`printf`像按标签打印快递单，`scanf`像按表格栏位收件；标签和栏位类型必须对应。类比不意味着程序会理解内容含义：`-3`可以成功转换成整数，但若是人数仍需业务检查。`%s`只能读一个不含空白的词，不能读完整姓名行。

**学生理解过程**：①区分变量值与变量地址；②在每个转换符下写目标类型；③预测输入`3 x`只能赋值1项；④把“转换成功”和“范围合法”分两层检查；⑤成功后才使用变量。若循环重试，失败的`x`不会自动被消费，必须丢弃该行或改用整行解析。

**教师板书顺序与追问**：先板书`int n; double price;`，再画“输入字符→转换→变量”的箭头，再填`%d %lf`和`&n, &price`，最后写`result == 2`门槛。追问“返回1说明价格为0吗？”答：不说明，第二项没有完成赋值，不能读取未初始化价格。追问“空文件与第一个字符是x有何不同？”答：前者通常返回EOF，后者匹配失败返回0。

**常错纠正**：把`scanf("%d", n)`改为`&n`；把读`double`的`%f`改成`%lf`；不要用未赋值变量继续算总额；不要把`EOF`理解成某个文件中的普通字节。`scanf`的范围前提应写进题目，而不是以“返回值检查了，所以任何数字都安全”代替。

<a id="E10-01"></a>

#### E10-01 两项输入的成功与失败分流

**目标**：读数量和单价，仅在两项转换完成后计算总额。输入限定`n`为0—100，`price`为0—1000的有限数，示例聚焦格式转换；合法范围由题目保证。

<!-- example: E10-01 -->
```c
#include <stdio.h>
int main(void) {
    int n;
    double price;
    int result = scanf("%d %lf", &n, &price);
    if (result != 2) {
        if (result == EOF) puts("No input");
        else printf("Invalid input: assigned=%d\n", result);
        return 1;
    }
    printf("n=%d price=%.2f total=%.2f\n", n, price, n * price);
    return 0;
}
```

**分步解释**：先声明接收对象；一次读取两项并保存返回值；失败分支先退出；成功分支使用`%.2f`显示单价与总价。

|输入|已赋值对象|result|走向|
|---|---|---:|---|
|`3 2.5`|n=3、price=2.5|2|输出总额7.50|
|`3 x`|只有n=3|1|输出`Invalid input: assigned=1`，退出1|
|`x`|无|0|输出`Invalid input: assigned=0`，退出1|
|空输入|无|EOF|输出`No input`，退出1|

默认输出为`n=3 price=2.50 total=7.50`。原因是乘法结果7.5经过两位小数格式化；格式化不改变变量保存的值。

<a id="K10-02"></a>

### K10-02 字符、字符串和安全整行输入 ★

**概念与语法**：`getchar()`返回`int`，正常时是读到的无符号字符值，失败时是EOF；`putchar(ch)`写一个字符。`puts(s)`写字符串并额外写一个换行；`fputs`不额外写换行。`fgets(s, capacity, stream)`最多读`capacity-1`个字符，成功后添加`'\0'`，若读到换行则保留它；读前就到EOF或读失败时返回NULL。

`char line[8]`只有7个内容字节的位置。输入7个字母再换行时，首次`fgets`可能只得到7个字母，换行还在流中；不能仅凭缓冲区没有换行就认定输入过长。应再读一个字符：若为换行或正常EOF，恰好装满；若为其他字符，确实过长，需要清空余行。历史函数`gets`不接收容量，无法防止越界，C11已移除，C17程序不得调用；考试出现时只分析其历史缺陷，不仿写。

**生活类比与边界**：缓冲区像8格抽屉，其中1格固定放“结束牌”`'\0'`，所以最多存7格内容；换行若也存入，会占内容格。此类比针对字节，不适用于“一个汉字占一格”。`'\0'`是字符串终止符，`'\n'`是实际行分隔符，二者不同。

**学生理解过程**：①画8格数组，先预留结尾；②分别把`hello\n`、7字符加换行、8字符加换行填进去；③观察第8字符究竟是换行还是内容；④理解排空余行防止影响下一次输入；⑤去掉已有换行后再`puts`，避免多打印空行。

**教师板书顺序与追问**：先画字符数组，再写fgets三项参数，再写“NULL检查→找换行→容量边界→输出”。问“空行是否等于EOF？”答：空行仍成功读到`\n`，去掉后是空字符串；EOF前一个字符都没读到才会返回NULL。问“为何ch是int？”答：必须同时表达字符值和EOF哨兵。

**常错纠正**：不把`char ch = getchar()`用于EOF判断；不写`fgets(line, 100, stdin)`去填8字节数组；不把`puts`当成不带换行的输出；不直接执行`line[strlen(line)-1]='\0'`，因为末尾不一定是换行。

<a id="E10-02"></a>

#### E10-02 最多7字节的完整行

**目标**：接收至多7字节内容，正确区分空行、恰好装满、超长和EOF。接受末行无换行。

<!-- example: E10-02 -->
```c
#include <stdio.h>
#include <string.h>
int main(void) {
    char line[8];
    if (fgets(line, sizeof line, stdin) == NULL) {
        puts(ferror(stdin) ? "Read error" : "No line");
        return 1;
    }
    size_t n = strlen(line);
    if (n > 0 && line[n - 1] == '\n') line[--n] = '\0';
    else {
        int ch = getchar();
        if (ch != '\n' && ch != EOF) {
            do { ch = getchar(); } while (ch != '\n' && ch != EOF);
            puts("Too long");
            return 1;
        }
        if (ferror(stdin)) return 1;
    }
    printf("length=%zu\n", n);
    for (size_t i = 0; i < n; ++i) putchar((unsigned char)line[i]);
    putchar('\n');
    puts("Done");
    return 0;
}
```

**分步解释**：先读并检查返回值；若已包含换行就移除并减长度；否则多读1字符判定是否超长，超长时丢弃余行；最后逐字符输出，再用`puts`结束。

|输入|首次缓冲区内容|补读结果|判定|
|---|---|---|---|
|`hello\n`|`hello\n\0`|不需补读|长度5|
|`1234567\n`|`1234567\0`|换行|恰好7，接受|
|`12345678\n`|`1234567\0`|字符8|超长，清余行|
|`\n`|`\n\0`|不需补读|长度0|
|`abc`后EOF|`abc\0`|EOF|长度3，接受|

`hello`的输出为三行`length=5`、`hello`、`Done`。超长只输出`Too long`并退出1；没有任何输入输出`No line`并退出1。这里既保留安全容量，也没有把“恰好装满”误报为溢出。

<a id="K10-03"></a>

### K10-03 文件句柄、文本文件与二进制文件 ★★

**概念与语法**：`FILE *fp`是C库维护的流句柄，不是文件内容本身。`fopen("路径", "模式")`成功返回句柄，失败返回NULL；`fclose(fp)`成功返回0，失败返回EOF，关闭后不能继续使用该流。`r`读已有文件；`w`建立或截断文件；`a`追加；`r+`读写已有文件，`w+`读写但先截断。更新流的读写切换有定位/刷新规则，初学题用“关闭再重开”保持清晰。

`fprintf(fp, ...)`把值格式化为文本，`fscanf(fp, ...)`把文本转换为值。数字100的文本通常是三个数字字符，不是内存中`int`对象的原样字节。文本模式可能对换行作系统相关转换；二进制模式`rb/wb`用于按字节处理，保留二进制数据。不要把“二进制文件”理解成内容一定不可见，也不要把直接写入`int`对象当成跨平台格式：字节序、类型大小和对象表示可能不同。

`fwrite(ptr, size, count, fp)`、`fread(ptr, size, count, fp)`返回完整写入/读入的元素数。本章附例用`unsigned char`和`size=1`展示明确字节；它不等同于设计了通用的跨平台序列化协议。成功打开也不保证后续写入、刷新、关闭都成功，因此写入与关闭都检查。

**生活类比与边界**：`FILE *`像借阅柜台发的借书凭据：拿凭据能读写，归还后不能再用；`r`像只看原书，`w`像换一本空白本。类比的边界在于文件句柄还包含缓冲和当前位置，磁盘内容不会因变量名叫fp就自动载入内存。

**学生理解过程**：①区分路径字符串、句柄、文件内容；②先写出每种模式对旧内容的影响；③跟踪“开→操作→检查→关”的生命周期；④读格式化数据时以返回值驱动循环；⑤区分正常到尾、格式不符、设备读错误。

**教师板书顺序与追问**：先画文件和FILE对象之间的箭头，再列r/w/a，再写文本数字`80 90 100`，最后写读取返回值循环。问“fscanf返回0可否继续原样循环？”答：不可，坏字符没被消费，会反复失败。问“文本文件加一个b就把十进制100变成整数内存吗？”答：不会，写入函数和编码方式决定内容，模式只影响流的处理规则。

**常错纠正**：使用fp前必须检查NULL；不要把`fprintf`少写fp变成`printf`；不要把`fclose`遗漏在成功分支；不要用`while (!feof(fp))`猜下一次读取；不要通过在旧资料路径上开`w`学习写文件。

<a id="E10-03"></a>

#### E10-03 写入成绩，再重开统计

**目标**：在临时目录生成`scores.txt`，使用文本格式读回并得到条数、总分。

<!-- example: E10-03 -->
```c
#include <stdio.h>
int main(void) {
    FILE *fp = fopen("scores.txt", "w");
    if (fp == NULL) { puts("Open error"); return 1; }
    int bad = fprintf(fp, "80 90 100\n") < 0;
    if (fclose(fp) == EOF) bad = 1;
    if (bad) { puts("Write error"); return 1; }
    fp = fopen("scores.txt", "r");
    if (fp == NULL) { puts("Open error"); return 1; }
    int value, count = 0, sum = 0, result;
    while ((result = fscanf(fp, "%d", &value)) == 1) {
        sum += value;
        ++count;
    }
    bad = ferror(fp) || result != EOF;
    if (fclose(fp) == EOF) bad = 1;
    if (bad) { puts("Read/format error"); return 1; }
    printf("count=%d sum=%d\n", count, sum);
    return 0;
}
```

**分步解释**：写模式建立练习文件，检查写入和关闭；读模式重新打开，此时位置在开头；只有`fscanf==1`才累加；循环退出后检查是EOF还是坏格式。

|读取轮次|返回值|value|count|sum|
|---|---:|---:|---:|---:|
|1|1|80|1|80|
|2|1|90|2|170|
|3|1|100|3|270|
|4|EOF|不再使用|3|270|

输出`count=3 sum=270`，文件内容为`80 90 100`后跟换行。最后失败的读取不应再加一次100，否则是“处理旧值”的典型错误。

<a id="E10-03B"></a>

#### E10-03B 逐字节二进制往返

**目标**：写入三个指定字节，再读回，避免把换行字节10当成文本行结构。

<!-- example: E10-03B -->
```c
#include <stdio.h>
int main(void) {
    const unsigned char source[] = {0, 10, 255};
    unsigned char target[3];
    FILE *fp = fopen("bytes.bin", "wb");
    if (fp == NULL) return 1;
    int bad = fwrite(source, 1, sizeof source, fp) != sizeof source;
    if (fclose(fp) == EOF) bad = 1;
    if (bad) return 1;
    fp = fopen("bytes.bin", "rb");
    if (fp == NULL) return 1;
    bad = fread(target, 1, sizeof target, fp) != sizeof target;
    if (fclose(fp) == EOF) bad = 1;
    if (bad) return 1;
    printf("%u %u %u\n", (unsigned)target[0], (unsigned)target[1], (unsigned)target[2]);
    return 0;
}
```

**分步解释**：以wb写3个单字节元素并关闭；以rb读取恰好3个元素；全部成功后才显示其数值。

|数组下标|原字节数值|十六进制|读回显示|
|---|---:|---|---:|
|0|0|00|0|
|1|10|0A|10|
|2|255|FF|255|

输出`0 10 255`。生成文件的十六进制内容是`00 0A FF`，不能用`%s`显示：首字节0会被当成字符串结束。本机CHAR_BIT为8，故该文件为3个通常意义上的8位字节。

<a id="K10-04"></a>

### K10-04 逐字符、逐行操作与文件查找 ★★

**概念与语法**：`fgetc(fp)`读一个字符并以int返回，`fputc(ch, fp)`写一个字符；`fgets(buf, cap, fp)`读一段到换行或容量边界，`fputs(buf, fp)`原样写字符串且不加换行。`feof(fp)`查询流的文件结束标志，`ferror(fp)`查询错误标志；二者都是“已经发生的状态”，不是预测下一次操作的函数。

正确框架是“执行读取→根据结果决定是否处理→退出后检查错误”。一次读取返回EOF可能是到尾也可能是错误，需要`ferror`区分。打开空文件后立即`feof`一般仍为0，尝试读取触及末尾后才设定结束标志。逐行查找可用`strstr(line, "cat")`做区分大小写的子串匹配，`bobcat`也匹配；整词搜索需要额外定义单词边界，不能把子串搜索当作整词搜索。

**生活类比与边界**：文件像一卷纸带，fgetc每次前进一格，fgets前进到换行或手中容器装满；feof像读到纸带末端才亮的灯。容器装满不意味着纸带的一整行结束，因此按fgets调用次数统计行号只适用于行长度有明确上限的题。

**学生理解过程**：①拿空文件预测“循环体执行0次”；②手算有换行和无换行末行；③在成功读入后再复制/查找；④确定查找是字符、子串还是整词；⑤说明容量是否能覆盖完整行，超长行必须拼接或采用跨块匹配算法。

**教师板书顺序与追问**：先写`while ((ch=fgetc(in)) != EOF)`，在括号上标“先读”，在循环体标“后处理”；再写退出后的ferror；最后画fgets的行边界。问“先feof再读为什么会多处理一次？”答：最后一次成功读取后结束标志可能仍未设定，下次读才失败，若无返回值检查就会处理旧数据。问“cat跨两个缓冲块还能strstr找到吗？”答：单块查找不能，需保存衔接部分或限制行长。

**常错纠正**：不要以char保存fgetc结果；不要用fputs再人为补换行导致文件多空行；不要用`strstr(...) > 0`判断指针，应写`!= NULL`；计数字节与统计行数是两种任务。

<a id="E10-04"></a>

#### E10-04 复制文件并统计读取字符数

**目标**：把夹具`input.txt`复制到新文件`copy.txt`。默认夹具为`cat\ndog\n`。统计文本流读出的字符数，在本机ASCII夹具上为8；不把这一数值概括成所有平台的磁盘字节数。

<!-- example: E10-04 -->
```c
#include <stdio.h>
int main(void) {
    FILE *in = fopen("input.txt", "r");
    if (in == NULL) { puts("Open error"); return 1; }
    FILE *out = fopen("copy.txt", "w");
    if (out == NULL) { fclose(in); puts("Open error"); return 1; }
    int ch, bad = 0;
    size_t count = 0;
    while ((ch = fgetc(in)) != EOF) {
        if (fputc(ch, out) == EOF) { bad = 1; break; }
        ++count;
    }
    if (ferror(in)) bad = 1;
    int ended = feof(in) != 0;
    if (fclose(in) == EOF) bad = 1;
    if (fclose(out) == EOF) bad = 1;
    if (bad) { puts("I/O error"); return 1; }
    printf("characters=%zu eof=%d\n", count, ended);
    return 0;
}
```

**分步解释**：分别打开输入和输出；逐字符检查读写结果；只有成功写出才加计数；保存结束标志；两个文件都尝试关闭并收集错误。

|读到内容|累计count|循环是否继续|
|---|---:|---|
|c、a、t|3|继续|
|换行|4|继续|
|d、o、g、换行|8|继续|
|EOF|8|退出，不复制EOF|

输出`characters=8 eof=1`；空文件输出`characters=0 eof=1`且副本为空。输入文件不存在时输出`Open error`并退出1；EOF不是需要写进目标文件的字符。

<a id="E10-04B"></a>

#### E10-04B 输出含cat的行

**目标与边界**：夹具`lines.txt`内容为`cat naps\ndog\nbobcat`。每行内容不超过78个ASCII字节，故80字节数组足以容纳内容、换行、结尾空字符。进行区分大小写的子串查找，输出行号，并允许末行不带换行。

<!-- example: E10-04B -->
```c
#include <stdio.h>
#include <string.h>
int main(void) {
    FILE *fp = fopen("lines.txt", "r");
    if (fp == NULL) { puts("Open error"); return 1; }
    char line[80];
    size_t number = 0, hits = 0;
    int bad = 0;
    while (fgets(line, sizeof line, fp) != NULL) {
        ++number;
        if (strstr(line, "cat") != NULL) {
            printf("%zu:", number);
            if (fputs(line, stdout) == EOF) { bad = 1; break; }
            if (strchr(line, '\n') == NULL) putchar('\n');
            ++hits;
        }
    }
    if (ferror(fp) || ferror(stdout)) bad = 1;
    if (fclose(fp) == EOF) bad = 1;
    if (bad) return 1;
    printf("hits=%zu\n", hits);
    return 0;
}
```

**分步解释**：成功读入一整行才增加行号；strstr非NULL才输出；原文若无换行，为终端显示补一个；结束后检查读取错误与关闭状态。

|行号|内容|是否包含cat|hits|
|---|---|---|---:|
|1|cat naps|是|1|
|2|dog|否|1|
|3|bobcat|是|2|

输出依次为`1:cat naps`、`3:bobcat`、`hits=2`。`CAT`不匹配，`bobcat`匹配，因为算法查找区分大小写的连续子串。空文件只输出`hits=0`。

## 第11章 预处理、命令行与多文件程序

<a id="K11-01"></a>

### K11-01 预处理、头文件与编译过程 ★

**概念与语法**：预处理指令以`#`开始，如`#include <stdio.h>`、`#define LIMIT 3`、`#if`、`#ifdef`、`#ifndef`。它们不是程序运行中的普通语句，通常不写末尾分号。`#include`使头文件内容在预处理阶段参与当前翻译单元；头文件常放类型、宏和函数声明，库函数的实现通常由链接阶段引入，不是“include就复制了整个标准库”。

学习时把构建分成四步：预处理展开包含和宏→编译分析并生成汇编等中间表示→汇编得到目标文件→链接目标文件和库成为可执行程序。这是实用分层；C标准的翻译阶段更细，具体工具可以合并步骤。`clang -E source.c`查看预处理结果，`clang -S source.c`生成汇编，`clang -c source.c`生成目标文件，最后把目标文件交给clang链接。

`<...>`按实现定义的系统头文件规则查找，`"..."`优先使用实现定义的本地查找规则，失败后再按尖括号形式处理；“永远只查某一个固定目录”是不准确的。宏替换不是运行时赋值；条件编译可使一段代码根本不进入后续编译，而普通if的两分支通常都必须满足编译要求。

**生活类比与边界**：预处理像印试卷前插入统一页眉、替换模板空格，编译像按语法审核，链接像把各章节装订齐；类比不表示编译器能判断所有算法是否正确，合法程序仍可能算错。

**学生理解过程**：①先判断`#`指令发生在运行前；②手工将LIMIT替换成3；③区分函数声明与函数定义；④把语法错误、缺头文件、未定义符号分别放在合适阶段；⑤用-E看宏真的消失了。

**教师板书顺序与追问**：画“源文件→预处理→目标文件→链接→执行”主线，在链接旁放“另一目标文件/库”；再插入宏和include示意。问“找不到头文件是运行错误吗？”答：不是，预处理阶段就无法完成。问“函数已声明为何链接还报未定义符号？”答：编译知道如何调用，但链接找不到实现。

**常错纠正**：`#define LIMIT 3;`会把分号带入替换，应去掉；不要把头文件等同于库文件；不要把条件编译和运行时if混为一谈；改头文件后应重新构建依赖它的源文件。

<a id="E11-01"></a>

#### E11-01 从宏到循环

**目标**：辨认对象宏替换以及有保护的默认宏值。

<!-- example: E11-01 -->
```c
#include <stdio.h>
#define LIMIT 3
#ifndef LABEL
#define LABEL "C17"
#endif
int main(void) {
    printf("%s:", LABEL);
    for (int i = 1; i <= LIMIT; ++i) printf(" %d", i);
    putchar('\n');
    return 0;
}
```

**分步解释**：包含stdio声明；定义LIMIT；只有LABEL尚未定义才提供默认值；编译后循环逐项输出。

|阶段|关键内容|含义|
|---|---|---|
|源文件|`i <= LIMIT`|尚有宏名|
|预处理后|`i <= 3`|替换为记号3|
|循环i=1、2、3|逐个打印|分别输出空格加数值|
|i=4|条件为假|输出结尾换行|

输出`C17: 1 2 3`。先执行预处理再运行循环，LIMIT没有运行时内存对象，也不需要执行“赋值3”。

<a id="K11-02"></a>

### K11-02 对象宏、函数宏、括号与副作用 ★★

**概念与语法**：对象宏`#define RATE 2`替换一个记号序列；函数宏`#define SQUARE(x) ((x) * (x))`根据实参记号替换。函数宏名与定义中的左括号之间不能有空白，否则会变成对象宏。替换不是函数调用，没有参数类型检查，也没有“参数天然只求值一次”的保证。

正确括号有两层：每个参数引用加括号，整个表达式再加括号。若写`#define BAD(x) x*x`，`BAD(2+1)`变成`2+1*2+1`，按优先级得到5；只写`(x)*(x)`仍会在`30 / BAD(2+1)`等上下文出错。即使双层括号齐全，`SQUARE(i++)`展开后仍重复修改i且在乘法两操作数间未定序，属于未定义行为，不能靠“左边先算”预测。

表达式宏适合无副作用的简单实参；需要只求值一次时，优先普通函数或合适的`static inline`函数。函数中的整数乘法也有可表示范围限制，不能因换成函数就忽略溢出。

**生活类比与边界**：宏像复印模板，把实参文字贴到每个空位；函数像窗口先收取一个数，再用该数运算。复印类比解释重复出现，但预处理替换以记号为单位，不是对所有字符做简单字符串替换。

**学生理解过程**：①不运行，先展开宏；②在展开式上按优先级画括号；③数实参被替换几次；④检查是否含++、赋值、函数调用等副作用；⑤若希望只计算一次，提取临时变量或改函数。

**教师板书顺序与追问**：先展示BAD再展开，再逐层补括号，最后写`SQUARE(i++)`并在两个i++下划线。问“双层括号能解决副作用吗？”答：不能，只能维护运算分组。问“square(i++)为何较安全？”答：函数实参中的i++只出现并求值一次，函数收到旧值，调用完成后i已增加。

**常错纠正**：宏不是带类型的函数；不把所有重复求值都一概叫未定义行为，例如只读函数调用重复发生可能是性能或逻辑问题，而`SQUARE(i++)`是未定序修改问题；不在一条printf实参里同时读取并修改同一个i来演示确定结果。

<a id="E11-02"></a>

#### E11-02 括号与单次求值

**目标**：安全展示`SQUARE(a+1)`与`square(a++)`，刻意不运行有未定义行为的宏调用。

<!-- example: E11-02 -->
```c
#include <stdio.h>
#define RATE 2
#define SQUARE(x) ((x) * (x))
static int square(int x) { return x * x; }
int main(void) {
    int a = 3;
    printf("macro=%d\n", SQUARE(a + 1));
    printf("function=%d\n", square(a++));
    printf("a=%d rate=%d\n", a, RATE);
    return 0;
}
```

**分步解释**：宏接收无副作用的`a+1`；函数调用接收a++的旧值3；下一条语句才读取更新后的a。

|语句|运算过程|a在语句后|
|---|---|---:|
|`SQUARE(a+1)`|`(3+1)*(3+1)=16`|3|
|`square(a++)`|先提供旧值3，函数算3×3|4|
|最后printf|读取a=4与宏RATE=2|4|

输出三行`macro=16`、`function=9`、`a=4 rate=2`。顺序由独立语句的执行先后保证，不依赖printf实参的求值顺序。

<a id="K11-03"></a>

### K11-03 argc、argv与实用命令行 ★★

**概念与语法**：本知识点使用C标准允许的另一种入口`int main(int argc, char *argv[])`。`argc`是参数个数，`argv`存放字符串指针，`argv[argc]`为NULL；通常`argv[0]`表示程序名，用户参数从1开始。检查argc后才能访问相应元素。标准允许某些特殊环境argc为0，本教材终端测试环境argc至少1。

命令行传入的`"12"`仍是字符串，不是整数。`strtol(s, &end, 10)`提供停止位置，配合`errno=0`、`errno==ERANGE`、`end==s`、`*end!='\0'`与INT_MIN/INT_MAX检查，能区分空串、尾随坏字符与溢出。`atoi`缺少这些诊断信息，不适合需要严格验错的例题。

终端的引号由命令行解释器处理：`./repeat 2 "hello C"`通常给程序传入三个参数（含程序名），引号本身通常不在字符串里。若不加引号，空格往往会分隔成多个参数；这属于调用环境的规则，不是C在main内重新拆词。

**生活类比与边界**：argv像启动时交给程序的一叠纸条，每张都写字符串；argc像纸条张数。类比不能把argv[0]保证成绝对路径，它可能只是调用名或空字符串。

**学生理解过程**：①画argv索引表并圈出0；②先检查参数数量；③对每个数字字符串检查整串转换；④在算术之前检查结果是否溢出；⑤分别运行正确参数、缺参数、坏字符三个版本。

**教师板书顺序与追问**：先画`./add 12 -5`的索引映射，再写argc门禁，再画strtol停止位置，最后检查加法边界。问“12x能转出12就算输入合法吗？”答：本题要求整串是整数，end停在x，必须拒绝。问“两个数各自能放进int，和一定能吗？”答：不能，需在加法前检查INT_MAX/INT_MIN边界。

**常错纠正**：不直接把argv[1]当成int；不在argc检查前读取argv[2]；不忽略end；不先执行会溢出的加法再判断结果；本例strtol允许前导空白和正负号，但拒绝尾随空白/字符，这是明确的解析规则。

<a id="E11-03"></a>

#### E11-03 命令行安全加法

**目标**：运行`./add 12 -5`，输出两整数和；错参数或范围错误退出1。

<!-- example: E11-03 -->
```c
#include <stdio.h>
#include <stdlib.h>
#include <errno.h>
#include <limits.h>
int main(int argc, char *argv[]) {
    if (argc != 3) { puts("Usage: add INTEGER INTEGER"); return 1; }
    int values[2];
    for (int i = 0; i < 2; ++i) {
        char *end;
        errno = 0;
        long v = strtol(argv[i + 1], &end, 10);
        if (end == argv[i + 1] || *end != '\0' || errno == ERANGE || v < INT_MIN || v > INT_MAX) {
            puts("Invalid integer"); return 1;
        }
        values[i] = (int)v;
    }
    int a = values[0], b = values[1];
    if ((b > 0 && a > INT_MAX - b) || (b < 0 && a < INT_MIN - b)) {
        puts("Sum out of range"); return 1;
    }
    printf("sum=%d\n", a + b);
    return 0;
}
```

**分步解释**：要求两个用户参数；依次转换并验证；保存成int；正数加法检查上界，负数加法检查下界；最后计算。

|检查|默认值/结果|说明|
|---|---|---|
|argc|3|程序名加两个参数|
|argv[1]|`12`→12|end指向字符串结束|
|argv[2]|`-5`→-5|可表示且完整转换|
|边界条件|均不触发|12与-5相加安全|
|输出|`sum=7`|正常退出0|

缺参数输出`Usage: add INTEGER INTEGER`；`12x 1`输出`Invalid integer`；在本机32位int上`2147483647 1`输出`Sum out of range`。最后一组依赖本机INT_MAX值，迁移平台应使用该平台界限重新设置测试。

<a id="K11-04"></a>

### K11-04 extern、static与头文件保护 ★★

**概念与语法**：声明告诉编译器名字和类型，定义提供对象存储或函数体。文件作用域的`extern int total;`通常是“对象在别处定义”的声明；`int total = 0;`是定义，整个程序应有正确且唯一的外部定义。带初始化的`extern int total = 0;`仍是定义，不能把extern机械等同于“永不定义”。

文件作用域的`static int calls;`和`static void helper(void)`具有内部链接，仅本翻译单元能直接通过该名字引用；不同文件可拥有同名而互不相干的static对象。函数内`static int count;`则具有静态存储期，调用之间保留值，但名字仍仅在块作用域可见。作用域、链接属性、存储期是三个不同问题。

头文件保护`#ifndef NAME`→`#define NAME`→声明→`#endif`防止同一个翻译单元内重复展开同一头文件。它不能解决“多个.c文件各自包含头文件中的全局变量定义”造成的链接问题。头文件放extern声明与函数原型，.c文件放定义；保护宏使用项目化名称，避免保留标识符样式和撞名。

**生活类比与边界**：头文件像公开菜单，.c文件像厨房实现；extern是“这道菜由某个厨房供应”的声明，文件static是后厨内部工具。类比不能把函数内static解释成别的文件也能看到，存活很久不等于公开可见。

**学生理解过程**：①在每行旁标声明/定义；②给total画跨文件连线，给calls画文件内部圈；③连续两次调用观察状态累积；④故意重复include验证保护；⑤一次链接所有.c文件，理解只编译main.c会缺实现。

**教师板书顺序与追问**：先分三栏counter.h、counter.c、main.c，再把声明与唯一的定义配对，再写static边界与保护宏。问“把int total=0放头文件并加保护就安全了吗？”答：不安全，保护只管各自翻译单元内部，两个.c仍分别产生定义。问“函数内static和文件static作用相同吗？”答：不同，前者主要体现局部名字和持久对象，后者还影响名字的链接属性。

**常错纠正**：不要用`#include "counter.c"`代替正规多文件链接；不在头文件里随意定义可变外部对象；不能在main.c中直接访问counter.c的static calls；不要在一条printf里多次调用修改同一个计数的函数并假定调用顺序。

<a id="E11-04"></a>

#### E11-04 三文件共享总分、隐藏调用次数

**目标**：total对外可见，calls仅在counter.c内部可见，通过函数读取；每个文件按下面名字单独保存于同一临时目录。

<!-- file: E11-04/counter.h -->
```c
#ifndef STUDY_COUNTER_H
#define STUDY_COUNTER_H
extern int total;
void add_score(int value);
int call_count(void);
#endif
```

<!-- file: E11-04/counter.c -->
```c
#include "counter.h"
int total = 0;
static int calls = 0;
void add_score(int value) { total += value; ++calls; }
int call_count(void) { return calls; }
```

<!-- file: E11-04/main.c -->
```c
#include <stdio.h>
#include "counter.h"
#include "counter.h"
int main(void) {
    add_score(3);
    add_score(4);
    printf("total=%d calls=%d\n", total, call_count());
    return 0;
}
```

**编译验证**：`clang -std=c17 -Wall -Wextra -Wpedantic main.c counter.c -o counter_demo`，再运行`./counter_demo`。头文件不作为独立源文件参与链接。

**分步解释**：main通过头文件获知接口；counter.c提供唯一total定义与内部calls；两次调用依次累加；main通过公开函数读取calls。

|时刻|total|calls|可直接访问calls的文件|
|---|---:|---:|---|
|启动|0|0|counter.c|
|add_score(3)后|3|1|counter.c|
|add_score(4)后|7|2|counter.c|

输出`total=7 calls=2`。main中重复include仍能通过预处理；这说明头文件保护起效，不说明变量可以在头文件中重复定义。此例输入固定且总和小，若推广成无限次累计，应另外检查整数溢出。

## 第12章 排序、查找、多项式与进制转换

<a id="K12-01"></a>

### K12-01 冒泡排序与选择排序 ★★

**概念与语法**：排序把记录按关键字排列，例如整数升序。冒泡排序不断比较相邻元素，逆序才交换；从左到右扫描一轮，把当前未排序区间最大值送到右端。选择排序先遍历未排序区间找最小值下标，再只把它与区间首位交换。二者都用双重循环，但“找什么、什么时候交换、哪边已确定”不同，不能只背相似的循环外形。

**循环不变式与代价**：冒泡每轮开始时右侧后缀已就位，end是未排序区间右边界（不包含end）；一次扫描结束，最大值就位到end-1。选择每轮开始时左侧前缀已就位，i是当前要填的位置；内层遍历中min_index总指向已检查部分的最小值。最坏比较次数均为n(n-1)/2，时间O(n²)、额外空间O(1)。带changed标志的冒泡遇到已排序数组只需一轮，最佳O(n)；普通选择即使已排序仍需O(n²)比较。

**稳定性**：本例冒泡只在`>`时交换，相等项不越过，稳定；选择的远距离交换可能越过相等项，通常不稳定。例如带身份的`[2甲, 2乙, 1]`，选择第一次交换后成`[1, 2乙, 2甲]`，甲乙顺序倒转。纯整数输出看不出身份，仍需理解性质。

**生活类比与边界**：冒泡像相邻同学比身高、矮的逐渐向前；选择像老师每次从剩余同学中找最矮者站到队首空位。排序函数并不懂身高的业务含义，只根据比较关系；“选择只交换一次”指每轮最多一次，而非整个排序一次。

**学生理解过程**：①给未排序区间画框；②手演一轮而不是直接写最终答案；③圈出一轮后永不再改的位置；④把区间收缩译为循环条件；⑤用空、单元素、重复值、已排序、逆序数据检查边界和稳定性。

**教师板书顺序与追问**：并排写同一个`4 1 3 1`，左边每比较一次相邻项就画箭头，右边先走完整轮标最小下标再交换；最后标出两个方向的已排区。问“选择内层每遇到更小值立即交换还等同于本算法吗？”答：那是另一种交换实现，不是本例‘先选下标、最后一次交换’的选择过程。问“冒泡为什么j+1<end？”答：j和j+1都必须落在未排序区间。

**常错纠正**：不要用`j < end`却访问a[j+1]；min_index每轮必须重新设为i；交换必须用临时变量，不能先覆盖一侧；size_t是无符号，避免空数组时计算n-1引起下溢，本例用end>1保护。

<a id="E12-01A"></a>

#### E12-01A 带提前结束的冒泡排序

**目标**：升序排列`4 1 3 1`，解释每轮固定的最大值。函数也接受n=0（不会访问数组）；示例最后明确调用一次验证空区间。

<!-- example: E12-01A -->
```c
#include <stdio.h>
static void bubble_sort(int a[], size_t n) {
    for (size_t end = n; end > 1; --end) {
        int changed = 0;
        for (size_t j = 0; j + 1 < end; ++j) {
            if (a[j] > a[j + 1]) {
                int t = a[j]; a[j] = a[j + 1]; a[j + 1] = t;
                changed = 1;
            }
        }
        if (!changed) break;
    }
}
int main(void) {
    int a[] = {4, 1, 3, 1};
    size_t n = sizeof a / sizeof a[0];
    bubble_sort(a, n);
    for (size_t i = 0; i < n; ++i) printf("%s%d", i ? " " : "", a[i]);
    putchar('\n');
    bubble_sort(a, 0);
    return 0;
}
```

**分步解释**：end从n缩小；changed每轮清零；相邻逆序才交换；一轮完全无交换说明剩余区间已排序，可以结束。

|轮次|比较后的完整数组|本轮固定|
|---|---|---|
|初始|4 1 3 1|无|
|end=4|1 3 1 4|末尾4|
|end=3|1 1 3 4|倒数第2位3|
|end=2|1 1 3 4|无交换，提前结束|

第一轮内部变化为`1 4 3 1`→`1 3 4 1`→`1 3 1 4`，输出`1 1 3 4`。不要把一轮后的状态误写为全部有序；第一轮只能保证最大值就位。

<a id="E12-01B"></a>

#### E12-01B 保存下标的选择排序

**目标**：用同一数组比较选择排序与冒泡排序的过程；每轮先找位置，再交换。

<!-- example: E12-01B -->
```c
#include <stdio.h>
static void selection_sort(int a[], size_t n) {
    for (size_t i = 0; i < n; ++i) {
        size_t min_index = i;
        for (size_t j = i + 1; j < n; ++j)
            if (a[j] < a[min_index]) min_index = j;
        if (min_index != i) {
            int t = a[i]; a[i] = a[min_index]; a[min_index] = t;
        }
    }
}
int main(void) {
    int a[] = {4, 1, 3, 1};
    size_t n = sizeof a / sizeof a[0];
    selection_sort(a, n);
    for (size_t i = 0; i < n; ++i) printf("%s%d", i ? " " : "", a[i]);
    putchar('\n');
    selection_sort(a, 0);
    return 0;
}
```

**分步解释**：i指向待填位置；min_index从i开始；只在更小值出现时更新；内层完成后交换一次。

|i|选出的最小值下标|轮末数组|已排前缀|
|---:|---:|---|---|
|0|1|1 4 3 1|1|
|1|3|1 1 3 4|1 1|
|2|2|1 1 3 4|1 1 3|
|3|3|1 1 3 4|全部|

输出同为`1 1 3 4`，过程却不同。第一次选第一个1，因为内层比较用`<`而不是`<=`；这仍不能使整个选择算法稳定，远距离交换可能颠倒其他相等项。

<a id="K12-02"></a>

### K12-02 插入排序：保存、移动、插入 ★★

**概念与语法**：插入排序维护一个已排序前缀。第i轮先把a[i]保存到key，再把前缀中大于key的元素逐个右移，最后把key填入留下的位置。外层从i=1开始，因为一个元素已经有序；内层用j表示当前空位，`j>0 && a[j-1]>key`先检查边界，再访问左邻项，依赖&&短路求值。

**不变式与代价**：每轮开始时a[0..i)有序；移动过程中比key大的尾段整体右移且顺序不变；填入key后a[0..i+1)有序。最坏逆序需约n(n-1)/2次移动，O(n²)；已排序只做线性检查，O(n)；额外空间O(1)。只移动严格大于key的元素使相等项不被跨越，因此此实现稳定。

**生活类比与边界**：像整理手中扑克牌：左手已有序，拿新牌，挪开较大的牌，插入空位。数组不能像真实扑克牌随意扩容，右移前必须有可用位置；排序原有n项时空位来自暂存key，向满数组新增元素则需要额外容量。

**学生理解过程**：①把待插值抄到key，明确a[i]位置可覆盖；②从右向左只移动比key大的项；③每移一步让j减1；④在退出位置放回key；⑤用相等项验证为何用>而非>=。

**教师板书顺序与追问**：先画有序前缀和key盒子，再画右移箭头，最后写插入语句并圈出其在while之外。问“为什么不能不保存key？”答：右移可能覆盖a[i]，原值丢失。问“把a[j]=key写到while里会怎样？”答：会混淆空位移动与最终落点，容易覆盖或错误重复插入，规范写法在循环后一次完成。

**常错纠正**：不在j为0时访问a[j-1]；不把短路条件反写成先访问再检查；不把右移写成相反方向的复制；size_t下不写j>=0当循环终止条件，因为永远成立。

<a id="E12-02"></a>

#### E12-02 把2插入已有序的前缀

**目标**：升序排列`5 2 4 2`，显式区分保存值、移动值、插入值。

<!-- example: E12-02 -->
```c
#include <stdio.h>
static void insertion_sort(int a[], size_t n) {
    for (size_t i = 1; i < n; ++i) {
        int key = a[i];
        size_t j = i;
        while (j > 0 && a[j - 1] > key) {
            a[j] = a[j - 1];
            --j;
        }
        a[j] = key;
    }
}
int main(void) {
    int a[] = {5, 2, 4, 2};
    size_t n = sizeof a / sizeof a[0];
    insertion_sort(a, n);
    for (size_t i = 0; i < n; ++i) printf("%s%d", i ? " " : "", a[i]);
    putchar('\n');
    insertion_sort(a, 0);
    return 0;
}
```

**分步解释**：每轮保留key；用j寻找空位；while只搬动元素；退出后写回key。n=0时外层不执行。

|i|key|依次右移|插入下标|轮末数组|
|---:|---:|---|---:|---|
|1|2|5|0|2 5 4 2|
|2|4|5|1|2 4 5 2|
|3|2|5、4|1|2 2 4 5|

输出`2 2 4 5`。最后一轮不会把原先的2右移，因为2>2为假，因此新2放在旧2之后。这个过程直接解释了稳定性。

### K12-03 线性查找与二分查找 ★★

**概念与语法**：线性查找按下标从左到右比较，找到即返回，因此天然返回首次出现位置，未排序数组也能使用，最坏O(n)。二分查找要求数组按同一比较关系有序，每步根据中点排除一半候选区间，最坏O(log n)；数组只有“看起来大致有序”不够。

本例二分实现lower_bound：求第一个不小于target的位置，可返回n，表示所有元素都小于target。维护左闭右开区间`[low, high)`，初始`[0,n)`；取`mid=low+(high-low)/2`避免直接low+high可能溢出。若a[mid]<target，则左侧含mid都不可能是答案，low=mid+1；否则答案可能是mid或其左边，high=mid。结束low==high，之后仍需`p<n && a[p]==target`确认真的找到。

**不变式**：low左侧元素都小于target，high及其右側元素都不小于target，尚待判定区间不断缩小。这个框架能处理空数组、重复元素和越界目标，不使用`n-1`初始化无符号右端点。

**生活类比与边界**：线性像挨个找座位，二分像按编号翻有序名册；没有按编号排序的名册不能靠对半判断排除一半。查到排序后数组中的下标并不自动等于原始数据下标，若要保留原始身份需要一起存储编号。

**学生理解过程**：①确认排序前提；②在纸上写区间及开闭边界；③每轮记low、high、mid；④说明排除部分为什么不含答案；⑤循环结束再区分插入位置与确实匹配。

**教师板书顺序与追问**：先演线性扫描，再在同一数组上画[low,high)，再推导两种更新，最后加存在性检查。问“a[mid]==target就返回会不会一定得到第一个？”答：不会；本例相等时仍收缩high，继续向左寻找。问“p==n时能先访问a[p]吗？”答：不能，应先用p<n的短路检查。

**常错纠正**：不要在无序数组上二分；不要混用左闭右开与左右闭合的更新公式；不要把low=mid用于可能mid==low的分支，否则区间可能不缩小；不要把返回n当作合法元素下标。

<a id="E12-03"></a>

#### E12-03 同时观察线性位置与lower_bound

**目标**：固定数组`1 3 3 7 9`，输入一个int范围内整数，输出首次匹配位置与第一个不小于目标的位置。

<!-- example: E12-03 -->
```c
#include <stdio.h>
static size_t linear_find(const int a[], size_t n, int target) {
    for (size_t i = 0; i < n; ++i) if (a[i] == target) return i;
    return n;
}
static size_t lower_bound(const int a[], size_t n, int target) {
    size_t low = 0, high = n;
    while (low < high) {
        size_t mid = low + (high - low) / 2;
        if (a[mid] < target) low = mid + 1;
        else high = mid;
    }
    return low;
}
int main(void) {
    const int a[] = {1, 3, 3, 7, 9};
    size_t n = sizeof a / sizeof a[0];
    int target;
    if (scanf("%d", &target) != 1) return 1;
    size_t p = lower_bound(a, n, target);
    printf("linear=%zu lower=%zu\n", linear_find(a, n, target), p);
    if (p < n && a[p] == target) printf("found=%zu\n", p);
    else puts("Not found");
    return 0;
}
```

**分步解释**：线性函数使用n作未找到哨兵；二分函数返回插入位置；main验证该位置是否真等于目标。

|目标3的轮次|low|high|mid|a[mid]|更新|
|---|---:|---:|---:|---:|---|
|1|0|5|2|3|high=2|
|2|0|2|1|3|high=1|
|3|0|1|0|1|low=1|
|结束|1|1|—|—|返回1|

输入3输出`linear=1 lower=1`及`found=1`；输入0输出`linear=5 lower=0`及`Not found`。原因是lower=0仅说明应插在最前，并不表示数组中已有0。输入10返回lower=5，必须避免a[5]越界。

### K12-04 Horner多项式与进制转换 ★★

**概念一：Horner法**。对`P(x)=a₀xⁿ+a₁xⁿ⁻¹+…+aₙ`，按降幂顺序存系数，改写为`(...((a₀x+a₁)x+a₂)... )x+aₙ`。初始化value=a₀，每个后续系数做一次`value=value*x+a[i]`，n次乘法、n次加法，时间O(n)、额外空间O(1)。中间缺次项的系数必须补0；常数多项式只有一个系数，无需循环。浮点结果可能舍入，重写公式不能保证精确实数运算。

**概念二：整数转进制**。对非负整数N和基数b（2—16），反复用`N%b`得到最低位，用`N/=b`去掉该位；余数产生顺序与书写顺序相反，必须逆序输出。零要至少产生一位，故用do-while。余数10—15映射A—F。输出缓冲区按整数最大二进制位数加1分配，不靠猜测固定长度。

**二者联系**：从b进制文本读回整数时，按从高位到低位执行`value=value*b+digit`，结构就是Horner累乘累加。整数转出是反复除取余，文本读入是反复乘基数加下一位，方向相反。读入时还要验证digit<b并在运算前检查溢出。

**生活类比与边界**：Horner像一层层套盒子，每展开一层“乘x再加下一项”；进制除法像把物品每b个装一箱，余数是当前层散件。类比解释流程，但负数、浮点小数和不同字符编码是额外问题，本例仅处理非负整数且限定基数2—16。

**学生理解过程**：①把多项式按降幂写齐，给缺项填0；②手工嵌套改写；③跟踪每次value；④对26除16手算商余数；⑤倒读余数形成1A；⑥用1×16+10反向验证。

**教师板书顺序与追问**：先把`2x³−3x²+5`改成`((2x−3)x+0)x+5`，再写循环；右侧写26=1×16+10与1=0×16+1，再反向连接。问“漏掉0系数会怎样？”答：变成另一个次数更低的多项式。问“while(value!=0)对输入0会怎样？”答：一次不执行，打印空串；do-while可输出0。

**常错纠正**：不把升幂系数直接送进降幂版本；不使用`^`表示乘方，C中它是按位异或；不正序输出取余结果；不让基数为0或1进入循环；负数不能直接套unsigned输入来声称支持负号。

<a id="E12-04A"></a>

#### E12-04A Horner计算三次多项式

**目标**：计算`2x³−3x²+5`，输入有限x且−10≤x≤10；非法格式或区间外输入退出1。

<!-- example: E12-04A -->
```c
#include <stdio.h>
int main(void) {
    const double coefficients[] = {2, -3, 0, 5};
    double x;
    if (scanf("%lf", &x) != 1 || x < -10 || x > 10) return 1;
    double value = coefficients[0];
    size_t count = sizeof coefficients / sizeof coefficients[0];
    for (size_t i = 1; i < count; ++i) value = value * x + coefficients[i];
    printf("P(%.2f)=%.2f\n", x, value);
    return 0;
}
```

**分步解释**：系数按`2,-3,0,5`存储；初值为最高次系数2；每读取下一系数，就乘x再加该系数；格式化显示。

|输入x=2时|新系数|更新式|value|
|---|---:|---|---:|
|初始化|2|直接保存|2|
|i=1|-3|2×2−3|1|
|i=2|0|1×2+0|2|
|i=3|5|2×2+5|9|

输出`P(2.00)=9.00`。代回原式为16−12+5=9；x=0输出5，恰是常数项；x=−1输出0。这里使用有界小系数，避免把数值稳定性与输入溢出问题混入首次算法学习。

#### E12-04B 非负整数转2—16进制

**目标**：输入unsigned int范围内的非负十进制整数及基数2—16；输出大写目标进制表示，不带前缀、不带多余前导零。

<!-- example: E12-04B -->
```c
#include <stdio.h>
#include <limits.h>
int main(void) {
    unsigned int value, base;
    if (scanf("%u %u", &value, &base) != 2 || base < 2 || base > 16) return 1;
    const char digits[] = "0123456789ABCDEF";
    char out[sizeof(unsigned int) * CHAR_BIT + 1];
    size_t used = 0;
    do {
        out[used++] = digits[value % base];
        value /= base;
    } while (value != 0);
    while (used > 0) putchar(out[--used]);
    putchar('\n');
    return 0;
}
```

**分步解释**：验证基数；至少做一次除取余；按余数索引字符表保存；从已保存末尾倒着输出。容量预留+1虽未在本例中写入字符串结尾，也足以用于今后改成字符串版本。

|输入26、16时|当前value|余数|保存字符|下一value|
|---|---:|---:|---|---:|
|第1轮|26|10|A|1|
|第2轮|1|1|1|0|
|逆序输出|—|—|1A|—|

输出`1A`，因为26=1×16+10；输入13、2时依次保存`1,0,1,1`，逆序为`1101`；输入0、2时仍执行一轮，输出`0`。基数1退出1，无输出，防止除以1导致无法缩小。
