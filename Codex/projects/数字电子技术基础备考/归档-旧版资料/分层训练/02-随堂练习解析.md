# 48道随堂练习：分步解析

配套[细分讲义](01-知识点细分讲义.md)。先独立做S01–S48，再核对这里。题号对应知识点K01–K48。

## 数制与逻辑门

### S01｜整数位权：从二进制读出数值

**题目回顾：** 将 11001₂ 转为十进制；说明它使用的最高位权。

**解析：** 位权为16、8、4、2、1，结果16＋8＋1＝25；最高位权为16。

### S02｜十进制整数转二进制

**题目回顾：** 把十进制21转为二进制，并反向验算。

**解析：** 21＝16＋4＋1，所以是10101₂；反算16＋4＋1＝21。

### S03｜二进制小数的位权

**题目回顾：** 求11.011₂的十进制值。

**解析：** 整数3，小数0/2＋1/4＋1/8＝0.375，合计3.375。

### S04｜十进制小数转二进制

**题目回顾：** 将0.625转为二进制，并用位权验算。

**解析：** 乘2依次得到1.25、0.5、1，取位1、0、1，故.101₂；1/2＋1/8＝0.625。

### S05｜二进制与十六进制的对应

**题目回顾：** 把3A₁₆写成八位二进制和十进制。

**解析：** 3对应0011，A对应1010，合为00111010₂；3×16＋10＝58。

### S06｜8421 BCD：按十进制数字分组编码

**题目回顾：** 给出59的普通二进制和BCD。

**解析：** 59＝32＋16＋8＋2＋1，普通二进制111011；BCD按5、9分组，为0101 1001。

### S07｜逻辑门：与、或、非、异或

**题目回顾：** A＝B＝1时，求或、异或、同或。

**解析：** 或为1，异或为0，同或为1：同时为1满足“至少一个”，不满足“恰好不同”。

### S08｜逐行列真值表

**题目回顾：** 按AB＝00、01、10、11列出F＝A＋B̄的输出，并解释01那一行。

**解析：** 输出1、0、1、1。01时A＝0，B̄＝0，所以为0。

## 逻辑代数与卡诺图

### S09｜化简先练提取与吸收

**题目回顾：** 化简AB＋ĀB；再化简B＋BC。

**解析：** AB＋ĀB＝B(A＋Ā)＝B；B＋BC＝B，分别使用互补律和吸收律。

### S10｜德摩根：整体取反的两步

**题目回顾：** 求G＝(A＋B)C的反函数，并展开到变量取反。

**解析：** Ḡ＝(A＋B)̄＋C̄＝ĀB̄＋C̄，先反最外层的与，再反内部的或。

### S11｜最小项：从输出1的行写函数

**题目回顾：** 按ABC位序写m2、m7，并写Σm(2,7)。

**解析：** 2是010，m2＝ĀBC̄；7是111，m7＝ABC；函数为ĀBC̄＋ABC。

### S12｜最大项：从输出0的行写函数

**题目回顾：** 两变量AB，F在1、3号行输出0，写最大项之积并化简。

**解析：** M1＝A＋B̄，M3＝Ā＋B̄；乘积为B̄，因为B＝1的两行都为0，B＝0的两行都为1。

### S13｜三变量卡诺图：先圈四格

**题目回顾：** 化简Σm(2,3,6,7)，指出保留的是哪个变量。

**解析：** BC＝11、10两列都是1，圈四格后A、C消去，只剩B＝1，结果B。

### S14｜四变量卡诺图：读出不变变量

**题目回顾：** 化简Σm(0,1,4,5,8,9,12,13)，说明哪个变量被固定。

**解析：** 所有编号的C位为0，其余三位可任意变化，因此可圈八格，结果C̄。

### S15｜无关项：允许使用的自由

**题目回顾：** 必需1为0、2，无关项为4、6，其他为0，求一个利用无关项的简式。

**解析：** 借4、6把所有C＝0的四格圈起来，得到C̄；这个实现会令4、6也输出1，题设允许。

### S16｜冒险入门：稳态表没有描述延迟

**题目回顾：** 对F＝AB＋ĀC，在B＝C＝1时进行相同分析，补充哪个项可覆盖A的切换？

**解析：** 稳态F＝A＋Ā＝1；补BC即可。BC为1时原函数已经为1，因此不改稳态功能。

## 组合电路与常用模块

### S17｜组合电路设计：先写条件，再列情况

**题目回顾：** E＝1表示报警使能，T/S分别表示温度或烟雾异常；任一异常且使能时报警，写表达式和门连接。

**解析：** F＝E(T＋S)。T与S先接或门，其结果与E接与门；E＝0时无论传感器输入如何都不报警。

### S18｜半加器：和位与进位分开算

**题目回顾：** 半加器输入10、11分别得到什么CS？

**解析：** 10得到CS＝01；11得到CS＝10。前者数值1，后者数值2。

### S19｜全加器：多一个输入进位

**题目回顾：** A＝1、B＝1、Cin＝0时求S、Cout，用2Cout＋S验算。

**解析：** S＝0，Cout＝1；2×1＋0＝2，等于输入数值和。

### S20｜BCD加法：何时加6

**题目回顾：** 计算BCD的8＋9，并给出第一次结果、修正后个位及十进制进位。

**解析：** 第一次为1 0001（17）；低四位0001＋0110＝0111，个位7，十进制进位1，结果0001 0111。第二次未产生二进制进位，十进制进位仍为1。

### S21｜译码器：地址变为一路有效

**题目回顾：** 已使能的低有效二线—四线译码器，输入01，按Y0至Y3写输出。

**解析：** 选中1号，Y1＝0，其他1，输出1、0、1、1。

### S22｜编码器：编号与有效标志

**题目回顾：** 仅R0＝1和全部请求＝0时，分别写编号与V。

**解析：** 仅R0有效：编号00、V＝1；全无请求：可约定编号00、V＝0。

### S23｜MUX：固定地址，求数据端

**题目回顾：** 用地址AB的四选一实现三人多数表决F＝AB＋AC＋BC，求四个数据端。

**解析：** AB＝00时F＝0；01时F＝C；10时F＝C；11时F＝1。故I0＝0、I1＝C、I2＝C、I3＝1。

### S24｜DEMUX：把数据送到选定通道

**题目回顾：** AB＝11，先后输入D＝0、1，按Z0到Z3写两次输出。

**解析：** D＝0时0、0、0、0；D＝1时0、0、0、1。

### S25｜无符号比较：从最高不同位判断

**题目回顾：** 比较0111₂与1000₂，并说明为何后者低三位全0仍更大。

**解析：** 最高位0＜1，所以7＜8。后者最高位权8大于低三位权重之和4＋2＋1＝7。

## 电气基础与触发器

### S26｜电平阈值与噪声容限

**题目回顾：** VOH至少3.0V，VIH至少2.2V，VOL最多0.4V，VIL最多0.9V，求两种容限。

**解析：** NMH＝0.8V，NML＝0.5V。分别从输出保证减高态要求、低态要求减输出保证。

### S27｜扇出：分别检查高态与低态

**题目回顾：** 高态最多支持15个，低态电流比值为9.6，最终扇出取多少？

**解析：** 取不超过两者的最大整数9；接10个会超过低态约束。

### S28｜推挽、开漏与高阻态

**题目回顾：** 两只推挽输出分别输出1、0，能否直接相连作为正常逻辑连接？若两只三态都Z，线路是否必定为0？

**解析：** 前者不能，会产生争用；后者也不保证0，要看外部上拉、下拉或其他驱动。

### S29｜D触发器：只在有效沿抄入数据

**题目回顾：** Q初始1，四个有效沿的D依次为0、1、0、0，写每次沿后Q。

**解析：** 依次0、1、0、0，每拍直接取该沿采到的D。最后一拍没有翻转。

### S30｜JK触发器：保持、清零、置一、翻转

**题目回顾：** 初始Q＝1，JK依次11、10、00，求每拍状态。

**解析：** 11使1翻为0；10置1；00保持1，故0、1、1。

### S31｜T触发器与简单功能转换

**题目回顾：** 初始Q＝1，T为0、1、1、0，写Q；再说明JK为何令J＝K＝T就能实现T。

**解析：** Q为1、0、1、1。T＝0对应JK＝00保持，T＝1对应JK＝11翻转，全部情况一致。

### S32｜SR锁存与透明D锁存

**题目回顾：** 高有效SR初始Q＝0，输入依次10、00、01、00，写稳定输出并指出禁止输入。

**解析：** 输出1、1、0、0；禁止输入为S＝R＝1，不能用合法状态方程推断其确定保持结果。

### S33｜建立、保持与异步清零

**题目回顾：** 采样沿30ns，建立3ns、保持2ns，给出稳定窗口。若异步清零在25ns有效，必须等30ns才清零吗？

**解析：** 数据稳定窗口为27至32ns。异步清零不必等30ns，25ns有效后经自身传播延迟即可清零。

## 时序分析、计数与寄存器

### S34｜时序分析：驱动方程变状态表

**题目回顾：** 若D1＝Q̄1、D0＝Q1，分别求00、01、10、11的下一状态。

**解析：** Q1＝0时D1D0＝10，所以00、01都去10；Q1＝1时为01，所以10、11都去01。

### S35｜同步设计：从状态含义求D输入

**题目回顾：** 设计可使能翻转的一位电路：E＝0保持，E＝1翻转。用D实现，初始Q＝0，E为1、0、1时输出序列？

**解析：** D＝Q⊕E；沿后Q依次1、1、0。也可直接使用T触发器令T＝E。

### S36｜状态化简：输出相同还要看后继

**题目回顾：** A、B输出均0，C输出1；输入1时A去C、B回B。A、B能合并吗？给一个区分输入。

**解析：** 不能。只输入一个1，A后继输出1，B后继输出0，已经可区分，不必知道其他输入下的转移。

### S37｜模数、状态数与触发器数量

**题目回顾：** 循环0至6后回0，求模数和至少需要的触发器数。

**解析：** 模7；两位只有4态，三位8态，所以至少3只。

### S38｜同步清零与异步清零的检测时刻

**题目回顾：** 0至11循环时，同步清零通常检测几？理想异步反馈清零检测几？

**解析：** 同步检测11，在下一沿归零；异步检测刚进入的12并清零。两者生效时刻不同。

### S39｜同步装入与级联的基本方法

**题目回顾：** 四位从4数至15后装入4，求模数；两位十进制当前为29，下一拍个位归零时十位应做什么？

**解析：** 模数16−4＝12；29的个位产生进位，十位2加1为3，结果30。

### S40｜寄存器：并行装入与移位

**题目回顾：** 同一规则，初始0011，输入依次0、1，求两拍后的各个状态。

**解析：** 第一拍0110，第二拍1101。第二拍以第一拍的0110为旧状态继续。

### S41｜环形与Johnson：先从指定初态列循环

**题目回顾：** 对上述Johnson规则，从010和101出发各会怎样？

**解析：** 010→101→010形成两态闭环，不能进入从000开始的六态循环。

### S42｜简单异步控制与脉动传播

**题目回顾：** 两只下降沿T触发器均T＝1，低位接外部时钟，高位接低位Q0。旧Q1Q0＝01，外部有效沿后先后经过什么？

**解析：** Q0先由1变0，状态暂为00；Q0下降沿使Q1再翻为1，最终10，即01→00→10。

## D/A与A/D转换

### S43｜DAC：位数、步长和码值

**题目回顾：** 5位同类DAC，Vref＝6.4V，输入10011，求步长、输出和最大输出。

**解析：** Δ＝6.4/32＝0.2V；10011为19，输出3.8V；最大31码输出6.2V。

### S44｜DAC的位权与R–2R结构

**题目回顾：** 同一模型输入0110时，各位贡献及总输出是多少？R–2R中的2表示几倍阻值？

**解析：** 四位贡献0、2、1、0V，总3V；2R表示R的两倍阻值，网络仍可形成多位二进制权重。

### S45｜ADC：代码对应输入区间

**题目回顾：** 4位ADC范围[0,8)V，输入6.2V，求输出码和区间。

**解析：** Δ＝0.5V，floor(6.2/0.5)＝12，即1100；区间[6.0,6.5)V。

### S46｜量化误差与分辨率

**题目回顾：** 输入6.2V落在[6.0,6.5)V，用中心重建求电压及误差；若改用下界重建呢？

**解析：** 中心6.25V，误差＋0.05V；下界6.0V，误差−0.2V。两者代表值不同，不能混用误差公式。

### S47｜SAR：逐位试码的四个动作

**题目回顾：** 同一ADC输入3.2V，列三轮试探码、电压和最终码。

**解析：** 100→4V，撤销；010→2V，保留；011→3V，保留；最终011，对应[3,4)V。

### S48｜ADC结构比较：并行与积分

**题目回顾：** 4位基本Flash需几只比较器？理想双积分Vin＝1.5V、Vref＝3V、T1＝20ms，求T2。

**解析：** Flash为15只；T2＝(1.5/3)×20＝10ms。
