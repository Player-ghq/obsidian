# B卷｜代数化简与卡诺图：答案与解析

配套[B卷题目](B卷-题目.md)。先对照推导过程，再看最后结果。

## 基础题

### B01｜★☆☆☆☆

**题目回顾：** 化简X＋XY，并用一句话解释为何可消去XY。

**解析：** 结果X。XY若为1则X已为1；X为0时XY也为0，附加项不改变输出。

### B02｜★☆☆☆☆

**题目回顾：** 化简AĀ＋BC，注明所用规律。

**解析：** AĀ＝0（互补律），所以0＋BC＝BC（或的0元规则）。

### B03｜★☆☆☆☆

**题目回顾：** 写出AB的反函数。

**解析：** (AB)取反＝Ā＋B̄；先与再取反等价于各自取反后求或。

### B04｜★☆☆☆☆

**题目回顾：** 写出A＋B的反函数。

**解析：** (A＋B)取反＝ĀB̄；不是Ā＋B̄。

### B05｜★☆☆☆☆

**题目回顾：** 变量顺序ABC，写出最小项m6。

**解析：** 6＝110₂，前两变量原样、C取反，m6＝ABC̄。

### B06｜★☆☆☆☆

**题目回顾：** 变量顺序ABC，写出最大项M5，并在101输入下验算。

**解析：** 5＝101₂，所以M5＝Ā＋B＋C̄。在101时三项均0，或项确为0。

### B07｜★☆☆☆☆

**题目回顾：** 两变量函数仅在01、10、11输出1，写Σm形式和ΠM形式。

**解析：** 1行编号1、2、3，所以Σm(1,2,3)；唯一0行编号0，所以ΠM(0)。函数也就是A＋B。

### B08｜★☆☆☆☆

**题目回顾：** 三变量卡诺图的BC列序应怎样排列？00、01、10、11为何不适合作为连续相邻列序？

**解析：** 应为00、01、11、10。普通递增顺序中01到10改变两位，不符合相邻格只变一位的条件。

### B09｜★☆☆☆☆

**题目回顾：** ABC位序，m1和m3是否相邻？m1和m2呢？

**解析：** 001与011只差B，相邻；001与010差B、C两位，不相邻。

### B10｜★☆☆☆☆

**题目回顾：** 化简ABC＋ABC̄，并说明在卡诺图上消去了哪个变量。

**解析：** 提取AB，得AB(C＋C̄)＝AB；这两个相邻最小项只差C，合并消去C。

## 独立应用题

### B11｜★★☆☆☆

**题目回顾：** 化简AB＋AB̄＋ĀC，并用A＝0/1检查你的结果。

**解析：** 前两项合为A，得到A＋ĀC。A＝1时为1，A＝0时为C，正是A＋C；因此简式A＋C。

### B12｜★★☆☆☆

**题目回顾：** 求F＝(A＋B)(C＋D)的反函数，最后仅对单个变量取反。

**解析：** 先反外层与：F̄＝(A＋B)取反＋(C＋D)取反；再反两组或，得到ĀB̄＋C̄D̄。

### B13｜★★☆☆☆

**题目回顾：** 画三变量卡诺图，化简Σm(0,1,4,5)。

**解析：** BC列00、01在两行均为1，其余0。圈四格后A、C变化，B固定0，所以F＝B̄。

### B14｜★★☆☆☆

**题目回顾：** 化简Σm(1,3,7)，给出两个圈各自覆盖哪些最小项。

**解析：** 圈1、3得到ĀC；圈3、7得到BC。F＝ĀC＋BC＝C(Ā＋B)。3可重复覆盖，不能把不存在的5也圈入。

### B15｜★★☆☆☆

**题目回顾：** 四变量ABCD，化简Σm(0,2,4,6,8,10,12,14)，说明为何不依赖A、B、C。

**解析：** 这些恰好是所有偶数编号，D固定0，其余三位遍历全部组合。可圈八格，F＝D̄。

### B16｜★★☆☆☆

**题目回顾：** ABC位序，必需1为1、5，无关项为3、7，其余0。求一个利用无关项的简式。

**解析：** 把1、3、5、7圈四格，得到C。规定的0都是C＝0，未被覆盖，故满足要求。

### B17｜★★☆☆☆

**题目回顾：** 对F＝AB＋ĀC列真值表，并写最小项编号集合和最大项编号集合。

**解析：** ABC按000至111排列，输出0、1、0、1、0、0、1、1。故F＝Σm(1,3,6,7)＝ΠM(0,2,4,5)。A＝0时看C，A＝1时看B，可逐半核对。

## 提高选做题

### B18｜★★★☆☆

**题目回顾：** 化简Σm(2,3,4,5)。它与A、B的什么关系相同？C为何不影响结果？

**解析：** 2、3合为ĀB；4、5合为AB̄，故F＝ĀB＋AB̄＝A⊕B。每对中C均可0或1，所以C被消去。

### B19｜★★★☆☆

**题目回顾：** 两级与或实现F＝AB＋ĀC。B＝C＝1，A切换时可能出现什么静态冒险？增加哪一项？说明稳态为何不变。

**解析：** 稳态F＝A＋Ā＝1；路径延迟可导致两项短暂同为0，形成静态1冒险。增加BC。当BC＝1时原函数已为1，BC＝0时不影响输出，因此稳态不变。

### B20｜★★★☆☆

**题目回顾：** 必需1为1、3，无关项为5、7，其余0。F1＝ĀC和F2＝C是否都正确？若5、7改为必须0，哪个仍正确？

**解析：** 两式在全部规定输入上都正确，只在5、7有差异：F1取0，F2取1。需求收紧后只有F1符合；F2会在新规定的0行输出1。
