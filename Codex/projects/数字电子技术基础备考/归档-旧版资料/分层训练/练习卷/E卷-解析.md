# E卷｜时序电路与计数器：答案与解析

配套[E卷题目](E卷-题目.md)。先对照推导过程，再看最后结果。

## 基础题

### E01｜★☆☆☆☆

**题目回顾：** 三只二进制触发器共有多少种状态编码？能否据此断定一定是模8计数器？

**解析：** 有8种编码；不能断定模8，实际循环还由驱动逻辑、初态和转移决定。

### E02｜★☆☆☆☆

**题目回顾：** 0至8循环，模数多少，至少需几位状态？

**解析：** 共9个状态，模9；3位最多8态不够，至少4位。

### E03｜★☆☆☆☆

**题目回顾：** 一位状态方程Q⁺＝Q̄，初态0，前两次更新后Q分别是多少？

**解析：** 依次1、0，每次翻转。

### E04｜★☆☆☆☆

**题目回顾：** 两只公共时钟D触发器D1＝Q0、D0＝Q1，当前01，下一状态是多少？

**解析：** D1＝1、D0＝0，下一状态10；两个D都使用旧状态。

### E05｜★☆☆☆☆

**题目回顾：** 希望0→1→2→3→4→0，采用同步清零应在当前哪个值请求清零？

**解析：** 当前4时请求，下一沿直接归0。

### E06｜★☆☆☆☆

**题目回顾：** 同样的0至4循环，理想异步反馈清零通常检测哪个数？

**解析：** 刚进入5时检测并立即清零；5可在物理输出短暂出现。

### E07｜★☆☆☆☆

**题目回顾：** 四位计数器从12数到15，再同步装入12，模数多少？

**解析：** 状态12、13、14、15，共4态，模4，也等于16−12。

### E08｜★☆☆☆☆

**题目回顾：** Q⁺＝(Q2,Q1,Q0,x)，旧四位Q＝1101，x＝0，下一状态？

**解析：** 移出左端1，保留101，右端补0，得到1010。

### E09｜★☆☆☆☆

**题目回顾：** 三位环形规则Q⁺＝(Q1,Q0,Q2)，当前001，下一状态？

**解析：** 旧Q1Q0为01，旧Q2为0，得到010。

### E10｜★☆☆☆☆

**题目回顾：** 三位Johnson规则Q⁺＝(Q1,Q0,Q̄2)，当前000，下一状态？

**解析：** 前两位0、0，末位取反旧Q2得1，结果001。

## 独立应用题

### E11｜★★☆☆☆

**题目回顾：** D1＝Q̄1，D0＝Q0，列全部四个状态转移，并找出所有闭合循环。

**解析：** 00→10，01→11，10→00，11→01。两个两态循环为00↔10与01↔11；Q0保持，Q1翻转。

### E12｜★★☆☆☆

**题目回顾：** 设计两位D触发器计数器，00→01→10→00，并要求11下一拍也到00。列状态表并求D1、D0。

**解析：** 完整表00→01、01→10、10→00、11→00。D1仅在01为1，故D1＝Q̄1Q0；D0仅在00为1，故D0＝Q̄1Q̄0。非法11能一拍恢复。

### E13｜★★☆☆☆

**题目回顾：** 两位二进制加1计数器带使能E：E＝0保持，E＝1按00、01、10、11循环。用D实现，求D0、D1。提示找出每位的翻转条件。

**解析：** 低位在E＝1时翻转，D0＝Q0⊕E；高位仅在E＝1且旧Q0＝1时翻转，D1＝Q1⊕(EQ0)。E＝0时两式分别等于旧Q0、Q1，满足保持。

### E14｜★★☆☆☆

**题目回顾：** 目标0至5循环，却在当前6时才请求同步清零。从0开始实际循环是什么，模数多少？

**解析：** 同步清零下一沿才生效，因此经过0、1、2、3、4、5、6再回0，模7。目标模6应在5请求。

### E15｜★★☆☆☆

**题目回顾：** 两位十进制同步计数器当前49，下一个公共时钟沿怎样更新个位和十位？当前48时又怎样？

**解析：** 49时旧个位为9，个位归0并使能十位4→5，得到50；48时个位8→9，没有进位，十位保持4，得到49。

### E16｜★★☆☆☆

**题目回顾：** 四位移位Q⁺＝(Q2,Q1,Q0,x)，初始0000，输入依次1、0、1、1。列四拍状态。

**解析：** 0001、0010、0101、1011。每拍都基于上一拍的结果继续移位，不能每次从0000重算。

### E17｜★★☆☆☆

**题目回顾：** Moore状态A、B输出0，C输出1；A的0/1后继为C/A，B为C/B，C为C/A。能合并哪些状态？给简化表。

**解析：** 先按输出分{A,B}、{C}。A、B遇0同去C，遇1都留在{A,B}，可合并为G。简化后G输出0、C输出1；两状态遇0都去C，遇1都去G。

## 提高选做题

### E18｜★★★☆☆

**题目回顾：** 三位Johnson规则Q⁺＝(Q1,Q0,Q̄2)。列从000与010出发的循环，并判断是否从任意初态都进入六态循环。

**解析：** 000→001→011→111→110→100→000为六态环；010→101→010为两态环。两环覆盖全部8态且不相交，故不具备任意初态自动进入预期六态环的性质。

### E19｜★★★☆☆

**题目回顾：** 用高有效SR实现：UV＝10置1，01清0，00或11保持。写S、R；初态Q＝0，按00→10→11→01→00，且每次只变一位、充分稳定，写Q。

**解析：** S＝UV̄，R＝ŪV，稳态不可能同时为1。对应Q为0、1、1、0、0；相等输入时保持历史。该推导在题设变化协议下使用，未保证任意同时变化的动态行为。

### E20｜★★★☆☆

**题目回顾：** 设计允许重叠的连续两个1检测器。每拍读x，状态Q记录上一位（初始0）；当上一位与当前位都是1时，采样沿前的Mealy输出z＝1。求状态表、D与z，并求输入111的输出串。

**解析：** Qx＝00时Q⁺0/z0，01时1/0，10时0/0，11时1/1。新状态只需保存当前位，D＝x；z＝Qx。从初始0输入111，输出0、1、1；第二次命中的最后一个1还能与下一个1重叠检测。
