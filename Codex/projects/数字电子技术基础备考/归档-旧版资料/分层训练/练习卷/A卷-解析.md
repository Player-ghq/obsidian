# A卷｜数制与逻辑门：答案与解析

配套[A卷题目](A卷-题目.md)。先对照推导过程，再看最后结果。

## 基础题

### A01｜★☆☆☆☆

**题目回顾：** 八位无符号二进制数共有多少种组合？最大可表示的整数是多少？

**解析：** 每位有2种取值，组合数2⁸＝256；从0计起，最大为255，而不是256。

### A02｜★☆☆☆☆

**题目回顾：** 把100101₂转为十进制，写出参与相加的位权。

**解析：** 为32＋4＋1＝37。两个1之间的0仍占位，不能省略其位置后重新排列权重。

### A03｜★☆☆☆☆

**题目回顾：** 把十进制14写成四位二进制，并验算。

**解析：** 14＝8＋4＋2，四位写1110；反算8＋4＋2＋0＝14。

### A04｜★☆☆☆☆

**题目回顾：** 二进制小数0.11₂对应十进制多少？

**解析：** 小数第一位权1/2，第二位权1/4，相加0.75。不是十进制的0.11。

### A05｜★☆☆☆☆

**题目回顾：** 计算101.1₂的十进制值。

**解析：** 整数101₂＝5，小数.1₂＝0.5，总计5.5。

### A06｜★☆☆☆☆

**题目回顾：** 把2F₁₆写成八位二进制和十进制。

**解析：** 2→0010，F→1111，得到00101111；十进制2×16＋15＝47。

### A07｜★☆☆☆☆

**题目回顾：** 写出十进制38的8421 BCD码，标明两个分组。

**解析：** 数字3→0011，数字8→1000，BCD为0011 1000；分别编码十位和个位。

### A08｜★☆☆☆☆

**题目回顾：** 1001和1010，哪一个可作为单个合法8421 BCD数字？为什么？

**解析：** 1001表示数字9，合法；1010表示二进制10，超出单个十进制数字0–9，不能作合法BCD数字。

### A09｜★☆☆☆☆

**题目回顾：** A＝0、B＝1时，求与非、或非和异或输出。

**解析：** AB＝0，取反得与非1；A＋B＝1，取反得或非0；两输入不同，异或1。

### A10｜★☆☆☆☆

**题目回顾：** A＝1时Ā是多少？A＝B＝1时同或输出是多少？

**解析：** Ā＝0；同或判断两输入相同，11时输出1。

## 独立应用题

### A11｜★★☆☆☆

**题目回顾：** 分别用二次幂拆分法和除2取余法，把45转成二进制。

**解析：** 拆分：45＝32＋8＋4＋1，所以101101。除2的商/余依次22/1、11/0、5/1、2/1、1/0、0/1，倒读余数同样为101101。

### A12｜★★☆☆☆

**题目回顾：** 把0.8125转成二进制小数，并用位权检查。

**解析：** 乘2依次取位：1.625取1，余.625；1.25取1，余.25；.5取0；1取1，得.1101₂。位权和1/2＋1/4＋1/16＝.8125。

### A13｜★★☆☆☆

**题目回顾：** 将A7₁₆转为二进制和十进制，再说明为何A不是两个十六进制数字“1和0”。

**解析：** A7→1010 0111，十进制10×16＋7＝167。A是十六进制的一位符号，代表十进制10；十六进制10本身则代表十进制16。

### A14｜★★☆☆☆

**题目回顾：** 比特串0010 0101按BCD和按八位无符号二进制解读，分别是多少？

**解析：** BCD分组为2、5，表示25；作为普通二进制是32＋4＋1＝37。差异来自编码方式，不是算术冲突。

### A15｜★★☆☆☆

**题目回顾：** 为F＝AB̄列完整真值表，增加一列B̄。

**解析：** 按AB＝00、01、10、11，B̄为1、0、1、0，F为0、0、1、0。只有“有A且无B”的10行输出1。

### A16｜★★☆☆☆

**题目回顾：** 列F＝(A＋B)C的八行真值表，并指出哪些输入使F＝1。

**解析：** 按ABC＝000、001、010、011、100、101、110、111，输出0、0、0、1、0、1、0、1。1行是011、101、111；必须C＝1且A/B至少一个为1。

### A17｜★★☆☆☆

**题目回顾：** 把二输入与非门的两个输入都接A，输出是什么？用A＝0和1分别验证。

**解析：** F＝(AA)取反＝Ā。A＝0时输出1，A＝1时输出0，因此与非门可这样当非门。

## 提高选做题

### A18｜★★★☆☆

**题目回顾：** “四位能表示16种组合，所以四位BCD也能表示十进制0–15。”这句话哪一部分正确、哪一部分错误？

**解析：** 四位有16种组合正确；BCD只把其中0000–1001用作十进制数字0–9，其余6种不作为合法单个数字。因此组合能力不等于指定编码允许的数值集合。

### A19｜★★★☆☆

**题目回顾：** 两个开关A、B：“至少一个按下”与“恰好一个按下”分别写表达式，并列出唯一输出不同的输入。

**解析：** 前者A＋B，后者A⊕B。AB＝11时前者1、后者0；00、01、10时两者输出相同。

### A20｜★★★☆☆

**题目回顾：** 不使用代数化简，只列真值表，判断F＝(A＋B)(Ā＋B̄)是否等于异或。

**解析：** 按AB＝00、01、10、11，第一括号0、1、1、1；第二括号1、1、1、0；相与后0、1、1、0，与异或完全一致。
