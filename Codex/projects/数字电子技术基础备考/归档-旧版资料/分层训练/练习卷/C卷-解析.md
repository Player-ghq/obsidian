# C卷｜组合电路与常用模块：答案与解析

配套[C卷题目](C卷-题目.md)。先对照推导过程，再看最后结果。

## 基础题

### C01｜★☆☆☆☆

**题目回顾：** 半加器输入A＝B＝0，求S、C。

**解析：** 0＋0＝0，S＝0、C＝0；由异或和与门公式也得到相同结果。

### C02｜★☆☆☆☆

**题目回顾：** 全加器A＝1、B＝0、Cin＝1，求S、Cout。

**解析：** 数值和2＝10₂，所以S＝0、Cout＝1。

### C03｜★☆☆☆☆

**题目回顾：** 高有效二线—四线译码器已使能，输入10，按Y0至Y3写输出。

**解析：** 地址为2，输出0、0、1、0。

### C04｜★☆☆☆☆

**题目回顾：** 低有效二线—四线译码器已使能，输入11，哪个输出为0，其余如何？

**解析：** 选中3号，Y3＝0，Y0、Y1、Y2＝1。

### C05｜★☆☆☆☆

**题目回顾：** 优先级3＞2＞1＞0，R2、R1有效，其他0，求编号与有效标志。

**解析：** 2号优先，编号10，V＝1。1号虽请求但不改变获选编号。

### C06｜★☆☆☆☆

**题目回顾：** 二选一MUX，I0＝1、I1＝0、S＝1，输出是什么？

**解析：** S＝1选I1，输出0；不能把两路数据求或。

### C07｜★☆☆☆☆

**题目回顾：** 高有效四路分配器，地址01、数据D＝1，按Z0至Z3写输出。

**解析：** 只有1号通道传入1，输出0、1、0、0。

### C08｜★☆☆☆☆

**题目回顾：** 比较无符号1100₂与1011₂，指出第一个不同位。

**解析：** 最高位均1，次高位分别1、0，故1100较大；十进制12＞11。

### C09｜★☆☆☆☆

**题目回顾：** 两个四位无符号数相加，不含额外输入进位，最大数值和是多少？完整保存结果至少几位？

**解析：** 最大15＋15＝30＝11110₂，需5位。四位只能保存低四位而遗漏可能的进位。

### C10｜★☆☆☆☆

**题目回顾：** BCD的9＋0，第一次二进制和是什么？需不需要加6？

**解析：** 1001＋0000＝1001，即9，仍为合法个位，且无进位，不加6。

## 独立应用题

### C11｜★★☆☆☆

**题目回顾：** 设计两按钮恰好一个按下才报警的组合逻辑。给真值表输出序列、表达式和可用门。

**解析：** AB按00、01、10、11，输出0、1、1、0。F＝ĀB＋AB̄＝A⊕B，可用异或门，或用非、与、或门实现。

### C12｜★★☆☆☆

**题目回顾：** 三输入至少两个为1时输出1。列出1行并化简，说明111是否通过。

**解析：** 1行为011、101、110、111，即Σm(3,5,6,7)。两两合并得AB＋AC＋BC。111有三个1，满足“至少两个”，应通过。

### C13｜★★☆☆☆

**题目回顾：** 用二选一MUX实现F＝A⊕B，选择端S＝A，求I0、I1。

**解析：** A＝0时F＝B，故I0＝B；A＝1时F＝B̄，故I1＝B̄。固定选择端再求剩余变量函数。

### C14｜★★☆☆☆

**题目回顾：** 低有效二线—四线译码器已使能，输出为Y0…Y3。要实现F＝Σm(1,2)，用Y1、Y2接什么门？说明两种输入情况。

**解析：** 接二输入与非门：F＝(Y1Y2)取反。选中1或2时至少一个为0，输出1；选中0或3时Y1、Y2均1，输出0。

### C15｜★★☆☆☆

**题目回顾：** 计算BCD的4＋8，写第一次结果、修正运算和最终BCD。

**解析：** 0100＋1000＝1100，即12；加0110得1 0010。最终BCD为0001 0010，表示12。

### C16｜★★☆☆☆

**题目回顾：** 计算BCD的9＋9＋1。十进制进位能否只看第二次修正加法的进位？

**解析：** 首次和19＝1 0011；低四位0011＋0110＝1001，最终个位9、十位进位1，BCD为0001 1001。第二次加法无进位，但首次已越过16，因此不能只看第二次进位。

### C17｜★★☆☆☆

**题目回顾：** 用两级全加器计算两位数11₂＋01₂，最低位输入进位0。写每一级S与进位，再写完整结果。

**解析：** 低位1＋1＋0＝2，S0＝0、C1＝1；高位1＋0＋1＝2，S1＝0、C2＝1；结果C2S1S0＝100₂。

## 提高选做题

### C18｜★★★☆☆

**题目回顾：** 比较两位无符号数A1A0与B1B0。写出“大于”输出G的表达式。提示：分为高位已决定与高位相等再比较低位两类。

**解析：** 高位直接大于为A1B̄1；高位相等条件E＝A1B1＋Ā1B̄1；高位相等且低位大于为EA0B̄0。所以G＝A1B̄1＋(A1B1＋Ā1B̄1)A0B̄0。

### C19｜★★★☆☆

**题目回顾：** 四路高有效优先编码，优先级3＞2＞1＞0，无请求编号约定00。推导Y1、Y0、V；提示先判断哪些获选编号的某位为1。

**解析：** Y1在获选3或2时为1，所以Y1＝R3＋R2。Y0在获选3或1时为1，简式Y0＝R3＋R̄2R1；R3若有效会直接压过其他请求。V＝R3＋R2＋R1＋R0，无请求时区分编号00。

### C20｜★★★☆☆

**题目回顾：** 三输入恰好两个1时F＝1，用地址AB的四选一MUX实现。按四个地址逐一求数据端，不能沿用“至少两个”的答案。

**解析：** AB＝00时不可能有两个1，I0＝0；01或10时必须C＝1，I1＝I2＝C；11时已有两个1，需C＝0，I3＝C̄。最后一项与多数表决的常数1不同。
