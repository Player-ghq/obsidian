# D卷｜电平与触发器：答案与解析

配套[D卷题目](D卷-题目.md)。先对照推导过程，再看最后结果。

## 基础题

### D01｜★☆☆☆☆

**题目回顾：** VOH(min)＝3.3V、VIH(min)＝2.3V，求高态噪声容限。

**解析：** 3.3−2.3＝1.0V，使用输出最差保证值与接收最低要求。

### D02｜★☆☆☆☆

**题目回顾：** VOL(max)＝0.4V、VIL(max)＝0.8V，求低态噪声容限。

**解析：** 0.8−0.4＝0.4V，方向是接收低态上限减输出低态上限。

### D03｜★☆☆☆☆

**题目回顾：** 忽略其他约束，输出可提供2mA，各负载需0.2mA，最多几个？

**解析：** 2/0.2＝10，最多10个；这仅是给定单项电流条件。

### D04｜★☆☆☆☆

**题目回顾：** 高阻态Z能否直接视为逻辑0？

**解析：** 不能。Z表示该输出不主动驱动，实际线电平取决于其他驱动或偏置。

### D05｜★☆☆☆☆

**题目回顾：** 上升沿D触发器当前Q＝1，D变0但没有有效沿，Q如何？

**解析：** 仍保持1。只有有效沿采到0之后，才按理想模型更新为0。

### D06｜★☆☆☆☆

**题目回顾：** JK当前Q＝1，JK＝00，下一状态是多少？

**解析：** 00为保持，下一状态1，不是清零。

### D07｜★☆☆☆☆

**题目回顾：** JK当前Q＝1，JK＝01，下一状态是多少？

**解析：** 01为清零，下一状态0。

### D08｜★☆☆☆☆

**题目回顾：** JK当前Q＝0，JK＝11，下一状态是多少？

**解析：** 11为翻转，旧0翻为1。

### D09｜★☆☆☆☆

**题目回顾：** T触发器当前Q＝0、T＝0，下一状态是多少？

**解析：** T＝0保持，下一状态0；若旧Q为1，则会保持1。

### D10｜★☆☆☆☆

**题目回顾：** 高有效基本SR锁存器的禁止组合是什么？为何不能当作普通“置1”操作？

**解析：** S＝R＝1为禁止组合，会破坏正常存储状态的条件；不能用仅在合法输入下成立的状态方程解释成确定的置1。

## 独立应用题

### D11｜★★☆☆☆

**题目回顾：** 高态可供1mA、每输入需0.05mA；低态可吸收4mA、每输入需0.4mA。电平兼容且忽略交流负载，最大扇出多少？

**解析：** 高态20，低态10，两者都要满足，故取10。

### D12｜★★☆☆☆

**题目回顾：** 接收器保证低电平不超过0.8V、高电平至少2.0V。输入1.5V时，能否保证读成0或1？

**解析：** 不能保证。1.5V落在两个保证范围之间，不应擅自按更接近哪一端作数字判断。

### D13｜★★☆☆☆

**题目回顾：** D触发器初始0，四个有效沿前D依次1、0、0、1。列各沿后Q，并指出哪次采样没有翻转。

**解析：** Q依次1、0、0、1；第三次沿前Q已为0，再采0，无翻转。

### D14｜★★☆☆☆

**题目回顾：** JK触发器初始Q＝1，依次给01、11、00、10，求每拍Q，写每拍动作。

**解析：** 清0→0；翻转0→1；保持→1；置1→1。因此序列0、1、1、1。

### D15｜★★☆☆☆

**题目回顾：** T触发器初始0，输入依次1、0、1、0、1，列状态序列。

**解析：** 翻1、保持1、翻0、保持0、翻1，结果1、1、0、0、1。

### D16｜★★☆☆☆

**题目回顾：** 理想高电平透明D锁存器，E只在[10,20)ns为1，初始Q＝D＝0。D在5ns变1、15ns变0、25ns变1。列Q变化时刻。

**解析：** 5ns未使能，Q保持0；10ns开启透明时D为1，Q变1；15ns跟随D变0；20ns关闭锁住0；25ns不再跟随，仍0。真正变化只有10ns和15ns。

### D17｜★★☆☆☆

**题目回顾：** 采样沿50ns，建立4ns、保持2ns。写数据稳定窗口；若D在48ns改变，是否满足本次采样要求？

**解析：** 需要从46ns稳定至52ns。48ns变化在建立窗口内，距边沿仅2ns，小于4ns要求，因此不满足，不能保证采样结果。

## 提高选做题

### D18｜★★★☆☆

**题目回顾：** 用一个D触发器实现JK功能，求D，并分别令旧Q＝0、1解释公式。

**解析：** 令D＝JQ̄＋K̄Q。旧Q＝0时D＝J，对应JK在旧0时由J决定是否置1；旧Q＝1时D＝K̄，对应K决定是否清0。

### D19｜★★★☆☆

**题目回顾：** D触发器初始0，D始终1，上升沿10、20、30ns。低有效异步清零在15ns有效、25ns释放，时序要求均满足。忽略传播延迟，列Q变化。

**解析：** 10ns采1，Q变1；15ns异步清零立即使Q变0；20ns清零仍有效，保持0；25ns释放不采样；30ns再采1，Q变1。变化时刻10、15、30ns。

### D20｜★★★☆☆

**题目回顾：** JK始终11，初始Q＝0，每个上升沿翻转。列前六个沿后的Q；理想时钟8MHz时输出频率多少？解释。

**解析：** 序列1、0、1、0、1、0。两个时钟周期后Q完成一次完整周期，因此输出周期为时钟的2倍，频率4MHz；这里忽略延迟并按周期性时钟计算。
