# F卷｜数据转换与基础综合：答案与解析

配套[F卷题目](F卷-题目.md)。先对照推导过程，再看最后结果。

## 基础题

### F01｜★☆☆☆☆

**题目回顾：** 模拟传感器电压转为计算机使用的数字码，需要ADC还是DAC？数字控制字转为电压呢？

**解析：** 前者ADC，后者DAC；先判断模拟到数字还是数字到模拟。

### F02｜★☆☆☆☆

**题目回顾：** 4位二进制DAC有多少个输入码？最大码的整数值是多少？

**解析：** 有16个码，编号0–15，最大整数值15。

### F03｜★☆☆☆☆

**题目回顾：** 理想8位DAC，Vo＝Vref·D/256，Vref＝2.56V，求LSB步长。

**解析：** 2.56/256＝0.01V，即10mV。

### F04｜★☆☆☆☆

**题目回顾：** 理想4位DAC，Vref＝8V，输入0111，求输出。

**解析：** 步长8/16＝0.5V，0111为7，输出3.5V。

### F05｜★☆☆☆☆

**题目回顾：** 4位二进制比例DAC参考8V，最高位单独为1时贡献多少电压？

**解析：** 最高位对应D＝8，贡献8×8/16＝4V，即Vref/2。

### F06｜★☆☆☆☆

**题目回顾：** 3位ADC范围[0,8)V，采用D＝floor(Vin/Δ)。输入4.9V时输出码是什么？

**解析：** Δ＝1V，向下取整得D＝4，三位编码100，对应[4,5)V。

### F07｜★☆☆☆☆

**题目回顾：** 3位ADC范围[0,4)V，向下分箱。代码011代表哪段输入区间？

**解析：** Δ＝0.5V，代码3对应[3×0.5,4×0.5)＝[1.5,2.0)V。

### F08｜★☆☆☆☆

**题目回顾：** 基本3位Flash ADC需要多少个比较器？

**解析：** 2³−1＝7，用7个内部阈值分成8个区间。

### F09｜★☆☆☆☆

**题目回顾：** 基本逐位SAR为5位，不计其他开销，需要几轮逐位判决？

**解析：** 5轮，每轮确定一位。真实器件采样、控制等额外开销不在这个计数内。

### F10｜★☆☆☆☆

**题目回顾：** 理想双积分Vin＝1V、反向参考幅值4V、固定积分时间20ms，求回零时间。

**解析：** T2＝(Vin/Vref)T1＝(1/4)×20＝5ms。

## 独立应用题

### F11｜★★☆☆☆

**题目回顾：** 理想6位DAC参考3.2V，输入101010。求步长、输出以及最大码输出。

**解析：** 步长3.2/64＝0.05V；101010为42，输出2.1V；最大码63，输出3.15V。

### F12｜★★☆☆☆

**题目回顾：** 4位DAC参考8V，希望输出最接近3.3V，按最近码取值。求代码、输出和误差（输出减目标）。

**解析：** 步长0.5V，目标码3.3/0.5＝6.6，最近整数7，即0111。输出3.5V，误差＋0.2V；选6输出3.0V，误差−0.3V，绝对值更大。

### F13｜★★☆☆☆

**题目回顾：** 4位ADC范围[0,4)V，向下分箱，输入2.6V。求步长、代码和区间。

**解析：** Δ＝4/16＝0.25V；floor(2.6/0.25)＝10，编码1010；区间[2.5,2.75)V。

### F14｜★★☆☆☆

**题目回顾：** 延续F13，分别按区间中心和下界重建，计算两种电压与误差。

**解析：** 中心(2.5＋2.75)/2＝2.625V，误差＋0.025V；下界2.5V，误差−0.1V。代表值不同，误差界也不同。

### F15｜★★☆☆☆

**题目回顾：** 均匀ADC输入跨度4.096V，按区间中心重建，要求理想量化误差绝对值不超过1mV，至少几位？可以用逐位试算。

**解析：** 要求半步长4.096/2^(n＋1)≤0.001V。10位时半步长2mV不够；11位时半步长1mV，满足，至少11位。

### F16｜★★☆☆☆

**题目回顾：** 4位SAR内部DAC为8D/16伏，输入保持6.3V。从最高位试置1，输入≥试探电压则保留。列四轮并给最终码。

**解析：** 试1000→4V，保留；1100→6V，保留；1110→7V，撤销此位回1100；1101→6.5V，撤销回1100。最终12码1100，对应[6.0,6.5)V。

### F17｜★★☆☆☆

**题目回顾：** 4位ADC范围[0,8)V，向下分箱，输入3.4V；把代码直接送入理想DAC Vo＝8D/16。求代码、DAC输出与输出减原输入的误差；能否精确恢复？

**解析：** ADC步长0.5V，取码floor(6.8)＝6，即0110。DAC输出6×0.5＝3.0V，误差−0.4V。量化已丢失区间内细节，直接送回DAC不自动恢复原值。

## 提高选做题

### F18｜★★★☆☆

**题目回顾：** 比较相同4.096V跨度的8位与12位均匀ADC。8位仅有中心重建量化误差；12位另有固定＋20mV输出重建偏差。假设无饱和且其他误差为0，分别求误差范围；位数多是否一定更准？

**解析：** 8位Δ＝16mV，量化误差界为±8mV。12位Δ＝1mV，量化误差界±0.5mV，加固定偏差后总误差在约＋19.5至＋20.5mV内（边界按分箱约定）。该条件下12位名义分辨率更细，但实际误差反而更大。

### F19｜★★★☆☆

**题目回顾：** 3位计数器驱动理想瞬时DAC Vo＝8D/8伏。011→100时，Q2先在1ns升高，Q1在2ns下降，Q0在3ns下降。比较器瞬时判断Vo≥6V。列中间码与比较输出，解释稳态前后均低是否排除脉冲。

**解析：** 0–1ns为011，3V，输出0；1–2ns为111，7V，输出1；2–3ns为101，5V，输出0；3ns后100，4V，输出0。稳态前后低仍可有1ns高脉冲，原因是多位不同步切换；此处使用题设瞬时模型。

### F20｜★★★☆☆

**题目回顾：** 模4同步计数器按稳定状态0、1、2、3循环，接2位理想DAC Vo＝4D/4伏，再接比较器Vo≥2V输出1。列各状态电压与比较输出。时钟1kHz、忽略切换延迟，比较输出周期和占空比是多少？

**解析：** 状态0、1、2、3对应电压0、1、2、3V，比较输出0、0、1、1。每个状态持续1ms，完整周期4ms，输出频率250Hz，高电平2ms，占空比50%。
