# 考研数学一

考试目标：2026-12-19 全国硕士研究生招生考试。

## 每日任务

每天 07:00 生成两道题：

1. 极限 1 题。
2. 积分 1 题。

题目保存到 `每日两题/YYYY-MM-DD.md`，解析折叠在题目下方。先限时独立作答，再展开解析，最后填写正确性、实际用时和错误原因。

## 分类规则

每题必须标注一级题型、二级题型、核心方法、难度和预计用时。自动出题前读取 `题型索引.md` 及近期每日记录，优先安排未覆盖或错误率较高的子题型，避免连续生成仅更换数字的同构题。

## 目录

- `题型索引.md`：题型分类、覆盖次数和最近练习日期。
- `每日两题/`：每日题目与复盘。
- `templates/每日两题模板.md`：固定笔记结构。
- `docs/superpowers/`：设计和实施记录。
