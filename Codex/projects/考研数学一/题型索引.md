# 数学一极限与积分题型索引

## 调度规则

1. 每天各选一个极限、积分子题型。
2. 优先覆盖次数为 0 的题型，其次选择近期错误或超时的薄弱题型。
3. 同一二级题型不连续两天出现；不得只更换数字重复同一解题结构。
4. 生成题目后更新覆盖次数和最近练习日期；用户复盘后再补充薄弱标记。
