## 工作原则

- 以考纲组织内容，以 PDF 文件名和来源页码提供证据。
- 区分来源原意、内容提炼和备考判断。
- 不根据文件名或目录推测未读取的内容。
- 扫描不清、OCR 不确定或资料冲突时明确标记，不编造结论。
