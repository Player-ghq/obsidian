# 运动生理学备考项目实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 创建一个以考纲为主线、可接收大型 PDF 语料并生成每日 90 分钟背诵任务的 Obsidian 项目骨架。

**Architecture:** 项目以 Markdown 文件为唯一数据载体。顶层文件负责项目状态、语料索引、考纲覆盖和学习进度；四个子目录分别承载知识点、每日任务、题库以及资料冲突，所有后续知识内容保留 PDF 文件名和页码证据。

**Tech Stack:** Obsidian、Markdown、PDF 文本提取与页面核验。
