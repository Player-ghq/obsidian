# 《囚徒健身全集》幕布式思维导图

- 《囚徒健身全集》
  - 阅读定位
    - 自重训练哲学
    - 动作进阶库
    - 力量、肌肉、爆发力、关节和意志训练的整合框架
    - 不等于直接照搬的训练计划
  - 核心问题
    - 现代训练过度依赖器械
    - 训练者追求外观多于实用力量
    - 很多人跳过基础，急着练高难动作
    - 力量、肌肉、爆发力和关节韧性被割裂
  - 核心答案
    - 自身体重就是训练工具
    - 少数高价值动作覆盖全身
    - 每类动作建立从易到难的升级链
    - 达到标准后再进阶
    - 写训练日志
    - 管理恢复
    - 长期坚持
  - 第一册：《囚徒健身》
    - 功能
      - 建立自重力量主线
      - 提供六艺十式
      - 教训练者成为自己的教练

  - 第三册：《囚徒爆发力》

      - 把力量转化为速度、敏捷和技巧
    - 第一部分：爆发力、实用速度、敏捷性
      - 五大原则
        - 依靠自身体重
        - 斯巴达式训练
        - 全身训练
        - 专注少数动作
        - 逐步升级
      - 关键区分
        - 爆发力不是力竭
        - 快速和力竭常冲突
        - 技巧质量下降就停止
    - 第二部分：六功

        - 起跳
        - 团身
        - 落地

        - 上肢弹性
      - 打挺
        - 全身协调
        - 髋和脊柱弹性
        - 高风险，暂不练
      - 前翻
        - 身体速度
        - 技巧和空间感
        - 高风险，需保护
      - 后翻
        - 敏捷
        - 空中控制
        - 高风险，需保护
      - 上杠
        - 拉力爆发
        - 抓握
        - 肩胛和核心
    - 第三部分：计划

        - Power
        - Agility
        - Reflex
        - Coordination
      - 平行训练
        - 爆发力
        - 技巧
      - 三规和六矩
        - 质量
        - 安全
        - 升级
      - 限时训练
        - 用于技巧发展
      - 模板
        - 少量高质量
        - 不练到崩溃
    - 我的使用
      - 低风险跳跃
      - 快速俯卧撑低阶
      - 落地技术
      - 不做空翻类

        - 引体

        - 桥

      - 写训练日志
        - 动作版本
        - 组数
        - 次数
        - 质量
        - 恢复
      - 休息
        - 为下一次进步准备
      - 吃得足够
        - 转译为热量和蛋白质足够
      - 多睡
        - 恢复和激素环境
      - 训练意志
        - 忍受重复和困难
      - 变强壮
        - 肌肉增长需要力量进步支撑
    - 纯粹力量十诫

      - 高频重复
      - 肌肉协同

      - 呼吸控制
      - 肌腱训练

      - 神经易化
      - 偶尔快速动作
      - 精神力量
    - 训练计划
      - 增肌
        - 中高次数
        - 接近耗竭
        - 足够休息
      - 力量
        - 低次数
        - 高张力
        - 多练习
      - 技能
        - 低疲劳
        - 高频
        - 完美动作
  - 训练目标区分
    - 技能训练
      - 低疲劳
      - 多频次
      - 追求动作质量
    - 力量训练
      - 低次数
      - 高张力
      - 长休息
    - 增肌训练
      - 中高次数
      - 接近耗竭
      - 恢复充足
    - 爆发力训练
      - 高速度
      - 低疲劳
      - 质量下降即停
  - 给我的执行版
    - 7 天盘点
      - 找每条动作链当前版本
      - 第二天不痛才算合格
    - 每周维护模板
      - 推
      - 拉
      - 腿
      - 核心
      - 后链
      - 抓握
    - HYROX 迁移
      - 农夫走
        - 悬吊
        - 抓握
      - 雪橇推拉
        - 腿髋力量
        - 躯干刚性
      - 沙袋弓步
        - 单腿控制
      - 墙球
        - 深蹲耐力
        - 肩部耐力
      - 跑步
        - 小腿足踝
        - 落地弹性
    - 考研阶段边界
      - 训练不影响学习
      - 每次 20-30 分钟即可
      - 疲劳大时只做最小维护
      - 睡眠不足不加量
  - 不做清单
    - 不跳级练最终式
    - 不在无保护时练前翻后翻
    - 不硬顶桥
    - 不冒险练颈桥
    - 不把爆发力练到力竭
    - 不把四册所有动作塞进计划
    - 不让训练破坏考研节奏
  - 红旗边界
    - 神经放射痛
    - 麻木或肌力下降
    - 倒立头晕
    - 跳跃落地疼痛
    - 桥类腰椎挤压痛
    - 训练影响第二天学习
