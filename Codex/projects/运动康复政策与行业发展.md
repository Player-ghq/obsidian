# 运动康复政策与行业发展

## 2026-07-14｜健康中国、十四五与十五五国民健康规划

### 核心判断

- “十四五”国民健康规划的主线是疫情后补短板：织牢公共卫生防护网，强化基层、医防融合、慢病防控、老龄健康和康复护理服务供给。
- “十五五”国民健康规划的主线是高质量整合：以全方位全周期整合型健康服务体系为主线，强调主动健康、数智化转型、中西医协同、康复护理扩容和健康产业提质升级。
- 《健康中国2030规划纲要》为运动康复提供了长期政策定位：体医融合、运动处方、非医疗健康干预、慢病预防与康复、重点人群体质健康干预。

### 十四五与十五五侧重点差异

| 维度 | 十四五国民健康规划 | 十五五国民健康规划 |
|---|---|---|
| 政策背景 | 新冠疫情后，公共卫生安全和基层服务短板突出 | 健康中国2030收官阶段，强调高质量和系统整合 |
| 服务逻辑 | 从“以治病为中心”转向“以人民健康为中心” | 从医疗卫生服务进一步转向全周期健康管理服务 |
| 关键词 | 公共卫生防护网、预防为主、基层、医防融合、慢病、老龄化、康复护理 | 主动健康、整合型服务、数智化、中西医协同、康复护理扩容、健康消费 |
| 慢病与健康促进 | 遏制重大慢性病发病率上升，推进“三减三健”、全民健身、运动处方 | 强调慢病“防治康管”全链条，体重、睡眠、心理、骨骼等具体问题更突出 |
| 康复相关 | 老年康复护理、残疾人康复、康复大学、康复人才培养、基层康复护理能力 | 明确“康复护理扩容提升工程”：二级医院为主体、基层为网底，三级医院指导支持，增加康复医师和康复治疗师供给 |
| 产业方向 | 科学健身、智能康复辅助器具、健康管理、运动健身保险、健康养老融合 | 康复护理短缺领域鼓励社会力量进入，发展康复疗养、康复辅助器具、智慧养老和健康消费 |

### 健康中国与运动康复专业的关系

运动康复处在体育、医学、预防、康复、慢病管理、老龄健康和健康产业的交叉点。

《健康中国2030规划纲要》明确提出加强体医融合和非医疗健康干预，建立运动处方库，发挥科学健身在健康促进、慢性病预防和康复中的作用。这相当于给运动康复专业提供了政策定位：运动康复不只是运动损伤后的恢复，而是连接“预防-治疗-康复-健康管理”的关键专业。

可用于答题的三层展开：

1. 预防端：体质测试、运动风险评估、姿势和功能筛查、肥胖与慢病风险干预。
2. 治疗后端：骨科术后、运动损伤、神经康复、老年功能衰退、慢病患者功能恢复。
3. 健康管理端：运动处方、长期随访、体重管理、老年防跌倒、青少年体态与骨骼健康、职业人群肌骨疼痛干预。

### 2030健康中国背景下运动康复行业应该做什么

- 建立标准化运动处方体系：形成“评估-分层-处方-执行-复评”的闭环，覆盖肥胖、高血压、糖尿病、骨关节疾病、术后恢复、老年衰弱和青少年体态等场景。
- 主动进入基层和社区：服务社区卫生中心、养老机构、学校、企业健康管理和家庭康复，承接康复护理网络下沉趋势。
- 强化医学基础和循证能力：减少泛健身化，补强解剖、生理、病理、运动生物力学、康复评定、慢病运动干预、疼痛科学和临床转诊边界。
- 服务老龄化和慢病年轻化：重点关注老年功能维护、跌倒预防、肌少症、骨质疏松、慢病运动干预、术后康复和长期护理前移。
- 融入多学科团队：与医生、康复治疗师、营养师、心理人员协作，负责功能、运动能力和身体活动行为改变。
- 发展可量化、可随访的数字康复：用体成分、肌力、关节活动度、步态、平衡、心肺、疼痛和生活质量等指标证明效果，结合可穿戴设备与线上随访做长期健康管理。

### 背诵版结论

十四五的重点是“补短板、强基层、筑牢公共卫生和慢病防控体系”；十五五的重点是“提质量、促整合、推主动健康和康复护理扩容”。在健康中国2030框架下，运动康复专业的核心价值，是用科学运动和功能评估把“预防-治疗-康复-健康管理”连接起来，成为慢病防控、老龄健康、体医融合和健康产业升级的重要支撑。
