# 每日晨测

本目录保存上海体育大学运动康复考研每日晨测。

## 目录规则

- `题目/`：只放当天题目、分值、分类、考纲模块、知识点关键词和作答要求。
- `答案/`：只放当天答案关键词、评分点、易丢分点和 20 分钟复习任务。

## 命名规则

- 题目：`YYYY-MM-DD-题目.md`
- 答案：`YYYY-MM-DD-答案.md`

## 出题规则

- 默认 300 分：解剖、生理、康复每天都出，每科 100 分。
- 每科题型：2 道 25 分简答 + 1 道 50 分论述/动作分析/案例题。
- 每天轮换的是各科内部的考纲模块和知识点，不再轮换单一学科。
- 依据上海体育大学运动康复考纲、2023-2025 上体真题结构和已整理的 1706 条真题关键词表。

## 打印格式

- 题目文件使用一张紧凑表格：题号、科目、分值、模块/关键词、依据、题目。
- 答案文件使用一张速查表：题号、关键词、评分分配、易丢分点。
- 避免长段解析，优先控制在 1-2 页内，便于直接打印。
