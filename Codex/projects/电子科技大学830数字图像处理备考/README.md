更新：2026-09-18。目标专业：生物医学工程；目标专业课成绩：110/150；基础：本科阶段学过图像处理，目前遗忘较多。

## 复习策略

恢复知识框架与手算能力同步进行。主线是“图像获取与表示 → 增强和复原 → 分割 → 特征 → 分类”，每个主题学完立即闭卷做题，不等读完教材才开始真题。

- 先练熟：直方图均衡与规定化、空间滤波、几何变换与插值、形态学、灰度共生矩阵。这些题型在提供的多份试题中重复出现。
- 持续训练：频域滤波与复原、阈值分割、边缘检测、彩色处理。既考原理，也支撑综合设计。
- 完整覆盖：各种图像变换、投影重建、SIFT、PCA、贝叶斯、神经网络与CNN。不能因旧卷少见就删除现考纲内容。
- 从第2周起每周至少写2道设计题的完整流程。2022年细胞分类、2023年手写数字识别题都限制使用深度学习，必须能用传统处理与特征方法解决问题。
- 主要投入闭卷手算、简答和设计；可视化或小实验仅在理解卡住时使用，不把编程项目作为考试准备的完成标准。

110分是结果目标。训练时以新题或未熟记题取得115–120/150为留出余量的目标，不把反复刷过的旧卷高分当作真实水平；没有完整分值和可靠评分依据的回忆卷，只记录完成率、错误与用时。

## 每天怎么学

正常学习日180分钟：20分钟闭卷回忆旧知识，55分钟教材与例题，85分钟独立做题，20分钟订正和记录。专题阶段把阅读减到30分钟，将独立做题增到110分钟。先计时尝试，再查书；订正后遮住答案重写关键步骤。

复盘日180分钟：75分钟小测，60分钟修正主要问题，45分钟整理公式与安排下周。模考日连续180分钟，次日用90–120分钟复盘；模考当天不额外堆阅读任务。

每个核心知识点用三次输出确认掌握：①不看书说清概念与适用条件；②独立解一道题；③隔7天能完成一个变式。错题在次日、3天后、7天后抽取重做，不抄整段解析。

错因只用六类：概念混淆／公式条件／运算错误／坐标和边界／流程缺环节／时间不足。每题记录年份题号、首次用时、错因、下次复测日即可。

## 真题使用方式

- 2003–2012：从旧题中挑出与当前考纲匹配、题干完整的基础手算和推导，按主题练，不逐年全刷。
- 2013–2016：第一轮与第二轮的主要练习来源，题型较便于与当前教材对应。
- 2018–2020：用于专题提升与设计训练；回忆版中只有“同某年原题”的条目，要回到所指原题核对条件。
- 2021–2023：用户尽量保留到后期首次限时作答。本规划只列题型，不提供解答；其中重题在前期见过也正常，因此不能把整卷当完全陌生卷预测分数。
- 2017：本文件缺失。2024：只有标题及尚未提供正文的说明；2025、2026：本文件未收录。缺资料不影响先按现有考纲与真题开始学习。

设计题的书写顺序：任务与限制 → 图像/噪声特性 → 具体处理步骤 → 参数选择依据 → 输出与验证。需要时补充失败情形。算法名称后必须说明为何适用；不把所有操作机械堆在一起。题目若禁用CNN或直方图均衡化，流程必须遵守这一限制。

## 阶段验收与调整

- 9/24：基础概念能讲清；几何变换至少能列式，错误能归类。
- 10/1：直方图、空间滤波和简单频域小题，5道新变式至少4道方法正确。
- 10/29：考纲11模块全部接触过；每模块有一页以内的框架，并能闭卷回答至少2个核心问题。
- 11/19：常规计算正确率力争85%以上；20个随机简答至少16个覆盖核心要点；设计题能在15–20分钟内写出可执行流程。
- 12/10：完整且有评分依据的150分新模拟卷力争115–120；若低于100，立即压缩低收益拓展，重点修补基础计算、简答与设计的具体失分，保留所有模块的基本概念。

这些是内部训练阈值，不是历年官方评分规则或录取保证。

时间调整：3小时为每天的计划基线，不要求把“3小时及以上”全部用满。临时忙碌日保留20分钟回忆、30分钟代表题、10分钟订正；缺失的新内容移到本周补缺时段。连续两周实际投入不足15小时，再压缩同类题量并重排进度，不靠熬夜补齐。
