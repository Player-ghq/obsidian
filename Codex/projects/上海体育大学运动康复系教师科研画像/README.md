# 上海体育大学运动康复系教师科研画像

## 项目目标

整理上海体育大学运动健康学院“运动康复学系”专任教师的科研方向、文献/论文/著作、科研项目、成就/获奖/专利，形成可筛选表格，服务后续导师研究方向分析、文献追踪与考研/科研选题判断。

## 数据说明

- 教师基础信息来自“专任教师”列表页。
- 文献、项目、获奖与成就来自各教师详情页。
- 官网详情页栏目格式不统一；部分教师未列出逐条论文或项目，只在简介中概述“发表论文若干篇、主持项目若干项”等，因此总表保留“简介/总体成果”列。

## Codex skill 配置

- 2026-07-12 已安装文献检索/审稿相关 skills：`literature-search-openalex`、`literature-search-europepmc`、`academic-paper-reviewer`。
- 2026-07-12 已创建自定义 skill：`kaoyan-literature-digest`。
- 当前使用原则：文献检索与摘要优先服务 2026 上海体育大学运动康复考研，所有文献默认映射到运动生理学或人体解剖学考纲；仅当能帮助理解知识点、生成答题素材或判断导师方向时提高优先级。
- 2026-07-12 已创建 Codex 每日自动化任务：`digest`（每日 08:00）。任务内容：随机抽取考纲知识点，生成考研导向文献 digest，将 A 级文献转成考研答题素材，并延伸 2-3 个科研方向问题；输出保存到 `daily-digest/YYYY-MM-DD.md`，A 级文献同步进入 `reading-queue.md`。
- 每日 A 级精读整理：对当天每篇 A 级文献产出考研精读卡（研究问题、考纲对应、核心机制链、证据边界、3 条以内可背句、建议阅读段落/图表）及 3–5 道闭卷自测题；B/C 级不制作精读卡。卡片与当日 digest 同页保存，精读队列保留勾选状态。
