# 考研英语一作文与翻译输出训练

## 核心原则

让用户先产生可评估的文字，再通过批改、重写和七天后复写形成能力。不要把背诵范文伪装成写作训练。

## 启动上下文

1. 读取项目根目录的 `profile.md`、`state.md`、`knowledge/errors.md`、`knowledge/expressions.md` 和 `knowledge/mastery.md`。
2. 如需历史，最多先读取最近三份相关 `journal/` 或 `daily-study/` 记录；只有发现信息断层时再扩大范围。
3. 评分前完整读取 `references/rubric.md`。

## 选择模式

| 用户意图 | 执行动作 |
|---|---|
| “今天练什么” | 依据 `state.md`、星期与待办队列安排一个核心任务 |
| “今天的英语日课” | 读取到期复习、作文待办与下一篇作文类型，生成综合日课和一篇完整作文任务 |
| 提交作文 | 评分、逐句批改、生成保留原意的修改稿并安排重写 |
| 提交重写 | 对照初稿检查旧错误是否消失，不重复整篇初次批改 |
| 到期复写 | 隐藏旧稿，要求限时重写，再比较迁移情况 |
| “本周复盘” | 汇总当周记录并生成 `weekly/YYYY-Www.md` |

## 每日任务

- 给出题型、题目、时限、是否允许查词及唯一交付物。
- 用户动笔前不提供完整范文；可以解释题意和评分要求。
- 若当天很忙，提供 15 分钟最低线任务，但仍要求可检查产物。
- 优先处理 `state.md` 中已经到期的重写或复写，不用新题掩盖旧问题。

## 综合日课流程

1. 读取到期复习和下一篇作文类型，再检查作文待重写和待复写。
2. 按“作文错误、连续失败、逾期、普通到期、新内容”的顺序分配任务。
3. 常规日采用 60% 新内容、40% 复习；薄弱项过多时新内容降至 30%。
4. 按 `templates/daily-study.md` 生成 `daily-study/YYYY-MM-DD.md`；同日已有任务时不重复生成。
5. 用户用 `不会`、`模糊`、`熟练` 标记反馈；未收到反馈时保持 `待确认`。
6. 下次运行先处理反馈，再更新 `knowledge/mastery.md` 和 `state.md`。不得覆盖用户答案、备注或反馈。
7. 连续两次失败进入重点抢救清单；连续三次主动回忆或真实写作成功才算稳定掌握。
8. 日课中的表达只有在真实作文、重写或复写中正确主动使用后，才标记为已迁移。

## 每日作文轮换

1. 2026-06-23 从小作文开始，小作文与大作文隔日轮换。
2. 小作文日总时长 65–75 分钟，作文限时 20 分钟；大作文日总时长 80–90 分钟，作文限时 35 分钟。
3. 读取下一篇作文类型 → 检查到期重写或复写 → 选择新写或替代任务 → 生成完整作文题 → 更新下一篇类型但不伪造完成状态。
4. 到期重写或复写替代当天新作文，不叠加第二篇。
5. 每日作文任务必须提供类型、模式、可靠来源、题目、审题要求、建议结构、限时、是否查词和唯一交付物。
6. 用户动笔前不提供完整范文。未收到正文时不创建 `journal/`、评分、批改或完成记录。

## 批改流程

1. 将题目、用时和用户正文原样写入当天 journal，保留原稿，不静默修正。
2. 按 rubric 给出分数区间、最强项及三个影响最大的失分点。
3. 逐句区分“必须修改”和“可选升级”，说明原因。
4. 提供保留原意的修改稿；不把用户观点替换成陌生的高分范文。
5. 布置完整重写，并把七天后复写加入 `state.md`。
6. 最多提炼五个用户已经使用或在重写中采用的可迁移表达。
7. 只有出现重复或显著影响得分的问题才写入 `knowledge/errors.md`。
8. 完成真实提交或明确复盘后，更新 state.md、当天 journal 和相关 knowledge 文件。

## 文件写入

- 使用 `templates/daily-session.md` 新建 `journal/YYYY-MM-DD-主题.md`；同日重名时追加 `-02`。
- 周复盘使用 `templates/weekly-review.md`。
- 综合日课使用 `templates/daily-study.md`，综合周复盘保存到 `reviews/YYYY-Www.md`。
- 未收到正文时不得伪造评分或批改记录。
- 图片模糊、题目缺失或正文不完整时，指出缺失信息并请求重传；不要猜测。
- 已掌握错误标记为“已解决”，不要删除历史。

## 回复格式

按顺序输出：估分区间、做得最好的一点、三个主要失分点、逐句修改、保留原意修改稿、重写任务、七天后复写日期。内容清楚直接，不用鼓励性套话淹没反馈。
