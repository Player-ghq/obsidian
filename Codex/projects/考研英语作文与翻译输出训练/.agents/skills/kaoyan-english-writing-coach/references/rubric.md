# 英语一作文评分与批改口径

## 使用原则

- 给出训练估分区间，不宣称等同阅卷现场的官方分数。
- 题目、图片或正文不完整时降低判断置信度，并明确缺失信息。
- 首先判断是否完成任务和切题，再评价语言华丽程度。
- 修改必须服务于用户原意，不能用一篇全新范文替换诊断。

## 小作文：10 分

| 维度 | 检查重点 |
|---|---|
| 任务完成 | 是否实现书信、通知或告示要求的交际目的 |
| 内容覆盖 | 题目要求的信息点是否齐全、具体且无矛盾 |
| 组织 | 开头、主体、结尾是否清楚，信息顺序是否自然 |
| 语域 | 称呼、礼貌程度、格式和措辞是否符合对象与场景 |
| 语言控制 | 语法、拼写、搭配和句式是否准确清晰 |

训练目标：稳定 7–8 分。明显遗漏任务点、语域错误或大量基础错误时不得仅靠“高级句型”抬分。

## 大作文：20 分

| 维度 | 检查重点 |
|---|---|
| 审题 | 图画、图表或文字材料的事实与寓意是否理解准确 |
| 内容 | 描述、解释、论证和结论是否完整，观点是否有支撑 |
| 结构 | 段落功能明确，重点分配合理，无机械模板拼接 |
| 连贯 | 句间、段间逻辑清楚，指代和连接自然 |
| 语言范围 | 在准确基础上有适当句式和词汇变化 |
| 准确性 | 主谓、时态、冠词、单复数、拼写及搭配错误可控 |

训练目标：稳定 15–17 分。跑题、核心寓意误判或论证空洞属于高优先级问题。

## 固定反馈顺序

1. 估分区间与判断置信度。
2. 做得最好的一点。
3. 三个最影响得分的问题。
4. 逐句修改表：原句、问题、必须修改、理由。
5. 保留原意的修改稿。
6. 完整重写任务与七天后复写日期。

可选升级必须与必须修改分开；一次最多给五个可迁移表达。
