## 日常入口

直接发送以下任意一句：

```text
今天练什么

```

批改作文时请附上题目、用时、是否查词和完整正文；也可以上传清晰图片。

## 训练闭环

```text
独立限时写作 → 评分与逐句批改 → 完整重写 → 七天后复写 → 周复盘
```

每次训练记录保存在 `journal/`，当前待办在 `state.md`，重复错误和已掌握表达分别沉淀在 `knowledge/`。

每日作文专项训练保存在 `daily-study/YYYY-MM-DD.md`，统一掌握度记录在 `knowledge/mastery.md`，周复盘保存在 `reviews/YYYY-Www.md`。完成作文或批改后，在文件的“作文掌握度反馈”表中把项目标记为 `不会`、`模糊` 或 `熟练`；空白项目保持 `待确认`。

## 每日作文轮换

- 2026-06-23 从小作文开始，随后与大作文隔日轮换。
- 小作文限时 20 分钟；大作文限时 35 分钟。
- 小作文日总时长 35–45 分钟；大作文日总时长 55–70 分钟。
- 到期重写或七天后复写替代当天新作文，不额外叠加第二篇。
- 只生成题目时不创建 `journal/`；用户提交正文后才进入评分、批改、重写和复写闭环。
