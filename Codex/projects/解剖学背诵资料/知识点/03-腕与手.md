# 腕与手

来源范围：Neumann 第 2 版第 7-8 章；附录 B 上肢肌肉附着点与神经支配。

## 一句话框架

腕是前臂和手之间的“可调稳定平台”，手是精细操作器官。腕的位置决定外在屈伸肌的长度张力，直接影响抓握效率。

## 快速背诵顺序

1. 腕骨：近排舟月三豌，远排大小头钩。
2. 腕动作：屈伸、桡偏、尺偏。
3. 手关节：CMC、MCP、PIP、DIP，拇指只有 IP。
4. 肌肉分组：腕肌、手外在肌、手内在肌。
5. 神经分区：桡伸、正中偏鱼际和桡侧屈、尺神经管大多数手内在肌。

## 骨与骨性标志

| 区域 | 结构 | 考点 |
|---|---|---|
| 前臂远端 | 桡骨茎突、尺骨茎突、桡骨远端关节面、Lister 结节 | 桡骨远端是桡腕关节主组成；Lister 结节引导拇长伸肌腱。 |
| 近排腕骨 | 舟骨、月骨、三角骨、豌豆骨 | 舟骨易骨折，月骨易不稳；近排较灵活。 |
| 远排腕骨 | 大多角骨、小多角骨、头状骨、钩骨 | 远排更稳，为掌骨提供基础；钩骨钩和腕管相关。 |
| 掌骨 | 第 1-5 掌骨，含基部、干、颈、头 | 第 1 掌骨旋转约 90 度，利于拇指对掌。 |
| 指骨 | 拇指 2 节，其余 4 指各 3 节 | MCP、PIP、DIP；拇指为 MCP + IP。 |

## 腕管与手弓

| 结构 | 背诵点 |
|---|---|
| 腕管边界 | 腕骨沟为底和壁，腕横韧带为顶。 |
| 腕管内容 | 正中神经和指屈肌腱为核心记忆。 |
| 近端横弓 | 由远排腕骨形成，较稳定。 |
| 远端横弓 | 通过 MCP 区形成，较灵活。 |
| 纵弓 | 沿第 2、3 掌骨和指骨方向，利于抓握。 |

## 抓握机制

| 抓握 | 关键结构 |
|---|---|
| 强力握 | 指深/浅屈肌提供屈指力，腕伸肌等长稳定腕，鱼际/小鱼际和骨间肌调整掌弓。 |
| 精细捏 | 拇指 CMC 对掌，鱼际肌控制拇指，蚓状肌和骨间肌稳定手指。 |
| 钩状抓握 | 指屈肌为主，可不需要强拇指参与。 |
| 放手展开 | 指伸肌伸 MCP，蚓状肌和骨间肌帮助伸 IP。 |

## 易混点

| 易混 | 区分 |
|---|---|
| 桡偏 vs 尺偏 | 桡偏靠桡侧腕伸肌 + 桡侧腕屈肌；尺偏靠尺侧腕伸肌 + 尺侧腕屈肌。 |
| 指浅屈肌 vs 指深屈肌 | 浅屈 PIP，深屈 DIP。 |
| 拇长屈肌 vs 拇短屈肌 | 长屈肌屈 IP，短屈肌屈 MCP。 |
| 拇长伸肌 vs 拇短伸肌 | 长伸肌伸 IP，短伸肌伸 MCP。 |
| 蚓状肌 vs 骨间肌 | 蚓状肌 MCP 屈/IP 伸；骨间肌负责外展内收，也协助伸 IP。 |
| 正中神经 vs 尺神经手内在肌 | 正中管鱼际多数和外侧 2 蚓状；尺神经管大多数手内在肌。 |

## 易考点

- 腕的位置影响抓握：轻度腕伸有利于指屈肌发力。
- 舟骨骨折常见，且血供问题可影响愈合。
- 第 1 CMC 是拇指对掌核心。
- 蚓状肌动作：MCP 屈曲 + IP 伸展。
- DAB/PAD：背侧骨间肌外展，掌侧骨间肌内收。
- 尺神经支配大多数手内在肌，尤其骨间肌和拇收肌。

## 考研问答模板

### 为什么腕的位置会影响手的抓握？

许多控制手指的外在肌起于前臂并跨过腕关节到达手指。腕的位置会改变这些肌肉的长度和被动张力。轻度腕伸时，指屈肌处于较有利长度，能产生更有效的抓握力；若腕过度屈曲，指屈肌缩短，主动张力下降，抓握力量减弱。因此腕是手功能的稳定平台。

### 手内在肌的主要功能是什么？

手内在肌包括鱼际肌、小鱼际肌、蚓状肌和骨间肌等。鱼际肌负责拇指外展、屈曲和对掌，小鱼际肌调整小指位置，蚓状肌使掌指关节屈曲并帮助指间关节伸展，骨间背侧肌使手指外展，骨间掌侧肌使手指内收。它们共同完成精细操作、掌弓调整和手指协调。

## 背诵卡片

- 问：近排腕骨从桡侧到尺侧？  
  答：舟骨、月骨、三角骨、豌豆骨。
- 问：远排腕骨从桡侧到尺侧？  
  答：大多角骨、小多角骨、头状骨、钩骨。
- 问：腕管顶部是什么？  
  答：腕横韧带。
- 问：屈 PIP 和屈 DIP 分别是哪块肌？  
  答：指浅屈肌屈 PIP，指深屈肌屈 DIP。
- 问：蚓状肌功能？  
  答：MCP 屈曲，IP 伸展。
- 问：DAB/PAD 是什么？  
  答：背侧骨间肌外展，掌侧骨间肌内收。
