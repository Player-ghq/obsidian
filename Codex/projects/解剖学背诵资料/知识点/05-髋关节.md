# 髋关节

来源范围：PDF 第 12 章；附录 D 下肢肌肉附着点与神经支配。

## 背诵总框架

髋关节是“稳定优先的承重球窝关节”：髋臼深、盂唇加深、关节囊和韧带强，肌群大而多方向，功能是连接躯干与下肢，完成承重、步态、蹲起、跳跃和骨盆控制。

记忆顺序：骨盆和股骨近端 -> 髋臼和盂唇 -> 三条韧带 -> 六组运动肌 -> 单腿支撑骨盆稳定。

## 骨与骨性标志

| 结构 | 必背点 | 定位价值 |
|---|---|---|
| 髋骨 | 髂骨、坐骨、耻骨共同形成髋臼 | 髋关节近端承重基础 |
| 髂骨 | 髂嵴、髂前上棘、髂后上棘、髂窝、臀面 | 肌肉附着和体表定位 |
| 坐骨 | 坐骨结节、坐骨支、坐骨棘 | 腘绳肌、深外旋肌起点 |
| 耻骨 | 耻骨体、耻骨支、耻骨梳 | 内收肌群、耻骨肌起点 |
| 髋臼 | 股骨头关节窝，外周有盂唇 | 增加包容和稳定 |
| 股骨头 | 与髋臼构成球窝关节 | 承重和多轴运动 |
| 股骨颈 | 连接股骨头和股骨干 | 力线传递和损伤高发区 |
| 大转子 | 臀中肌、臀小肌、梨状肌等附着 | 外展肌和外旋肌杠杆 |
| 小转子 | 髂腰肌止点 | 髋屈主力记忆点 |
| 臀肌粗隆 | 臀大肌止点之一 | 强力髋伸 |
| 粗线 | 内收肌、股四头肌、腘绳肌相关 | 大腿肌群附着中轴 |

## 关节与稳定结构

| 结构 | 背诵点 | 功能 |
|---|---|---|
| 关节类型 | 典型球窝关节 | 屈伸、外展内收、内外旋、环转 |
| 髋臼盂唇 | 加深髋臼 | 增加股骨头包容、分散压力 |
| 关节囊 | 前方较强，包绕股骨颈 | 限制过度运动，提供被动稳定 |
| 髂股韧带 | 前方强韧 | 限制髋过伸，是站立省力结构 |
| 耻股韧带 | 前下方 | 限制外展和伸展 |
| 坐股韧带 | 后方 | 限制内旋和伸展 |
| 股骨头韧带 | 含血管成分，机械稳定较小 | 辅助营养和连接 |

## 髋关节运动

| 运动 | 主要平面 | 正常理解 |
|---|---|---|
| 屈曲 | 矢状面 | 大腿靠近躯干；蹲起、上楼、摆腿 |
| 伸展 | 矢状面 | 大腿向后；跑步后蹬、起立 |
| 外展 | 冠状面 | 大腿离开身体中线；单腿支撑稳定 |
| 内收 | 冠状面 | 大腿靠近身体中线；夹腿、变向控制 |
| 外旋 | 水平面 | 股骨向外旋；盘腿、转向 |
| 内旋 | 水平面 | 股骨向内旋；步态和深蹲控制 |

## 位置与功能理解

| 场景 | 解剖学解释 |
|---|---|
| 单腿站立 | 支撑侧臀中肌、臀小肌收缩，防止对侧骨盆下沉 |
| 起立、上楼、冲刺后蹬 | 臀大肌和腘绳肌强力髋伸 |
| 深蹲下蹲 | 髋屈增加，臀大肌离心控制，屈髋肌群参与位置控制 |
| 跑步摆腿 | 髂腰肌快速屈髋，股直肌同时影响膝伸 |
| 变向剪切 | 内收肌群和外展肌群共同控制骨盆与股骨 |
| 髋稳定强于肩 | 髋臼深、盂唇、韧带强、肌肉厚，牺牲部分灵活性换稳定 |

## 易混点

| 易混点 | 正确记法 |
|---|---|
| 髂腰肌 vs 股直肌 | 髂腰肌是髋屈主力；股直肌跨髋膝，兼髋屈和膝伸 |
| 臀中肌 vs 臀大肌 | 臀中肌管外展和骨盆稳定；臀大肌管伸髋和强力外旋 |
| 臀小肌 vs 深外旋肌 | 臀小肌偏内旋；梨状肌、闭孔肌、孖肌、股方肌偏外旋 |
| 大收肌前部 vs 后部 | 前部闭孔神经，主内收；后部坐骨神经胫骨部，助伸髋 |
| 股薄肌 vs 其他内收肌 | 股薄肌跨膝，既内收髋又屈膝 |
| 阔筋膜张肌 vs 臀中肌 | 二者都外展髋，但阔筋膜张肌还屈髋、内旋并张紧髂胫束 |

## 高分答题点

- 髋关节属于球窝关节，运动多轴，但以承重稳定为核心。
- 被动稳定来自深髋臼、盂唇、关节囊和髂股/耻股/坐股韧带。
- 动态稳定来自臀肌群、髂腰肌、内收肌群、深外旋肌群和腘绳肌。
- 臀中肌是单腿支撑时防止骨盆下沉的关键肌。
- 大收肌兼具内收部和伸肌部，神经支配不同，是常考细节。

## 简答题模板

题目：试述髋关节的结构与功能。

答题顺序：

1. 髋关节由股骨头和髋臼构成，属于球窝关节。
2. 髋臼较深，并有髋臼盂唇加深关节窝，增强稳定。
3. 关节囊及髂股、耻股、坐股韧带限制过度伸展、外展、旋转。
4. 髋关节可完成屈伸、外展内收、内旋外旋和环转。
5. 肌肉按功能分为屈肌、伸肌、外展肌、内收肌、内旋肌、外旋肌。
6. 运动中髋关节承担承重、传力、骨盆稳定和下肢动力输出。

## 背诵卡片

- 问：髋关节类型？  
  答：股骨头和髋臼构成的球窝关节。
- 问：髋关节最强的前方韧带？  
  答：髂股韧带。
- 问：髋屈主力？  
  答：髂腰肌。
- 问：髋伸主力？  
  答：臀大肌和腘绳肌。
- 问：单腿支撑骨盆稳定关键肌？  
  答：臀中肌，臀小肌协同。
- 问：臀中肌神经支配？  
  答：臀上神经。
- 问：臀大肌神经支配？  
  答：臀下神经。
- 问：大收肌最容易考的特点？  
  答：前部闭孔神经主内收，后部坐骨神经胫骨部助伸髋。
- 问：髋外旋深层肌包括哪些？  
  答：梨状肌、闭孔内外肌、上孖肌、下孖肌、股方肌。
- 问：为什么髋比肩稳定？  
  答：髋臼深、盂唇加深、韧带强、肌群厚，且承担承重功能。
