# 步态与动作分析

来源范围：PDF 第 1-4 章运动功能学基础；第 15 章行走运动功能学。

## 背诵总框架

动作分析的核心是：先描述运动学，再解释动力学，最后落到肌肉如何产生、控制或吸收力。步态分析则是把“一个步态周期”拆成阶段，逐段说明关节运动、外力矩、肌肉收缩和功能任务。

记忆顺序：任务 -> 时相 -> 关节运动 -> 外力矩 -> 肌肉收缩 -> 稳定/推进 -> 代偿风险。

## 动作分析通用流程

| 步骤 | 问自己什么 | 卷面写法 |
|---|---|---|
| 1. 任务 | 这个动作目的是什么 | 支撑、推进、缓冲、抓握、上举等 |
| 2. 链型 | 开链还是闭链 | 远端自由为开链，远端固定为闭链 |
| 3. 关节 | 哪些关节参与 | 按近端到远端或主关节到辅关节 |
| 4. 平面轴 | 发生在哪个平面和轴 | 矢状面屈伸、额状面外展内收、水平面旋转 |
| 5. 运动学 | 骨怎么动 | 屈、伸、旋转、滚动、滑动 |
| 6. 动力学 | 外力矩方向是什么 | 重力、地面反作用力、阻力造成的转动趋势 |
| 7. 肌肉 | 肌肉如何工作 | 向心发力、离心制动、等长稳定 |
| 8. 风险 | 哪些结构负荷高 | 韧带、半月板、椎间盘、肌腱、足弓等 |

## 基础概念

| 概念 | 背诵点 |
|---|---|
| 运动学 | 描述运动本身，不解释原因 |
| 动力学 | 解释产生、控制或停止运动的力 |
| 力矩 | 力使身体绕关节轴旋转的趋势 |
| 力臂 | 关节轴到力线的垂直距离 |
| 内力矩 | 肌肉或被动组织产生的力矩 |
| 外力矩 | 重力、地面反作用力、外部负荷产生的力矩 |
| 关节反应力 | 关节面间的合力，常随负重和肌力增加 |
| 开链 | 远端自由，常描述远端骨相对近端骨运动 |
| 闭链 | 远端固定，常描述近端骨相对远端骨运动 |
| 向心收缩 | 肌肉缩短，产生动作 |
| 离心收缩 | 肌肉被拉长，控制动作或吸收能量 |
| 等长收缩 | 长度基本不变，维持姿势和稳定 |

## 步态周期

| 项目 | 必背点 |
|---|---|
| 步态周期 | 同一足从一次初始接触到下一次初始接触 |
| 支撑相 | 约 0%-60%，足与地面接触并承重 |
| 摆动相 | 约 60%-100%，足离地并向前摆动 |
| 双支撑 | 正常行走有两段双支撑；速度越快，双支撑比例越小 |
| 单支撑 | 一侧下肢支撑身体，另一侧摆动 |
| 跑步区别 | 跑步无双支撑，出现双足腾空期 |

## Perry 七阶段

| 阶段 | 周期 | 功能任务 | 关键词 |
|---|---|---|---|
| 初始接触 | 0% | 足放到地面，准备承重 | 足跟着地、踝接近中立 |
| 承重反应 | 0%-10% | 接受体重、吸收冲击 | 胫骨前肌、股四头肌、臀大肌离心/稳定 |
| 支撑中期 | 10%-30% | 单腿支撑，身体越过足 | 臀中肌稳骨盆，小腿三头肌离心控胫骨前移 |
| 支撑末期 | 30%-50% | 足跟离地，身体前移 | 小腿三头肌储能，足逐渐变刚性 |
| 预摆动 | 50%-60% | 推进并准备摆动 | 跖屈推进，髋屈开始 |
| 摆动初期 | 60%-73% | 足离地并加速前摆 | 髋屈、膝屈、踝背屈保证清地 |
| 摆动中期 | 73%-87% | 小腿通过身体下方 | 踝背屈维持足清地 |
| 摆动末期 | 87%-100% | 减速下肢，准备接触 | 腘绳肌离心减速，股四头肌伸膝准备落地 |

## 传统事件记忆

| 事件 | 大约周期 | 记忆 |
|---|---|---|
| 足跟着地 | 0% | 周期开始 |
| 足平 | 约 8% | 足底接触地面 |
| 对侧足尖离地 | 约 10% | 进入单支撑 |
| 支撑中期 | 约 30% | 身体质心最高，单支撑关键 |
| 足跟离地 | 30%-40% | 推进开始增强 |
| 对侧足跟着地 | 约 50% | 第二段双支撑开始 |
| 足尖离地 | 约 60% | 支撑相结束，摆动相开始 |
| 足相邻 | 约 73% | 摆动足经过支撑足 |
| 胫骨垂直 | 约 87% | 摆动末期准备落地 |

## 步态中的质心

| 现象 | 背诵点 |
|---|---|
| 行走本质 | 连续的失衡与恢复平衡 |
| 垂直位移 | 双支撑中点最低，单支撑中点最高 |
| 内外侧位移 | 质心向支撑侧移动，单支撑时不完全落在足支撑面正上方 |
| 能量策略 | 动能和势能交替转换，降低能量消耗 |
| 稳定策略 | 低速行走常见步长短、步频低、双支撑时间长 |

## 下肢关节运动学

| 阶段 | 髋 | 膝 | 踝足 |
|---|---|---|---|
| 初始接触 | 屈曲位 | 近伸直 | 踝接近中立或轻背屈 |
| 承重反应 | 髋伸肌控制屈曲趋势 | 膝轻度屈曲吸震 | 胫骨前肌离心控制足放平 |
| 支撑中期 | 髋逐渐伸展 | 膝由屈转伸 | 小腿三头肌离心控制胫骨前移 |
| 支撑末期 | 髋伸展接近最大 | 膝较伸展 | 踝背屈增加，足跟离地 |
| 预摆动 | 髋屈开始 | 膝快速屈曲 | 踝跖屈推进 |
| 摆动初期 | 髋屈加速 | 膝屈增加 | 踝背屈清地 |
| 摆动中期 | 髋继续屈 | 膝开始伸 | 踝保持背屈 |
| 摆动末期 | 髋屈减速 | 膝伸准备落地 | 踝保持中立 |

## 步态肌肉活动

| 肌肉/肌群 | 活动时机 | 主要作用 |
|---|---|---|
| 胫骨前肌 | 初始接触后、摆动期 | 承重反应离心控制足拍地；摆动期背屈清地 |
| 趾长伸肌/拇长伸肌 | 摆动期和承重早期 | 协助背屈、伸趾、清地 |
| 小腿三头肌 | 支撑中期到预摆动 | 离心控制胫骨前移，后期跖屈推进 |
| 胫骨后肌 | 支撑早中期到后期 | 控制旋前，后期旋后并支持内侧纵弓 |
| 腓骨肌群 | 支撑期 | 控制外侧稳定，支持前足和横弓 |
| 足内在肌 | 支撑中后期 | 稳定前足，提高足弓，辅助刚性杠杆 |
| 股四头肌 | 承重反应、支撑早期 | 离心控制膝屈，随后伸膝支撑体重 |
| 腘绳肌 | 摆动末期、初始接触前后 | 离心减速髋屈和膝伸，准备落地 |
| 臀大肌 | 初始接触和承重反应 | 控制髋屈趋势，稳定髋 |
| 臀中肌/臀小肌 | 单支撑期 | 防止对侧骨盆下沉 |
| 髂腰肌等髋屈肌 | 预摆动和摆动初期 | 启动下肢前摆 |
| 竖脊肌/腹肌 | 全周期调节 | 控制躯干姿势和骨盆运动 |

## 地面反作用力

| 方向 | 步态表现 | 记忆点 |
|---|---|---|
| 垂直方向 | 承重反应和支撑末期较大，支撑中期较小 | 双峰曲线 |
| 前后方向 | 初始接触后为制动力，支撑末期为推进力 | 前期刹车，后期推动 |
| 内外方向 | 帮助控制身体侧向移动 | 单支撑侧向稳定相关 |
| 压力中心 | 从足跟外侧逐渐向前足和第 1-2 跖骨区移动 | 足底受力轨迹 |

## 常见步态偏差

| 表现 | 常见原因 | 解剖学解释 |
|---|---|---|
| 足拍击 | 踝背屈肌轻中度无力 | 胫骨前肌离心控制不足 |
| 足下垂 | 踝背屈肌明显无力 | 摆动期足尖清地困难 |
| 高抬腿步态 | 足下垂代偿 | 增加髋膝屈曲来清地 |
| 髋回旋步态 | 摆动腿功能性变长或屈髋/屈膝/背屈不足 | 用外绕增加足尖间隙 |
| 骨盆上提 | 摆动腿清地困难 | 腰方肌等抬高骨盆代偿 |
| Trendelenburg 征 | 支撑侧臀中肌无力 | 对侧骨盆下沉 |
| 躯干向支撑侧倾 | 髋外展肌无力或髋痛 | 缩短外力臂，减轻髋外展肌需求 |
| 膝反屈 | 股四头肌无力、踝跖屈挛缩等 | 用膝过伸获得被动稳定 |
| 支撑期膝屈曲位 | 膝屈曲挛缩或伸膝控制差 | 支撑腿功能性变短，耗能增加 |
| 足过度旋前 | 胫骨后肌控制不足、结构因素 | 内侧纵弓下降，胫骨/股骨内旋链增加 |
| 足跟过早离地 | 踝背屈受限或小腿三头肌紧张 | 支撑末期胫骨前移不足 |

## 常见动作分析模板

### 深蹲下降

| 项目 | 分析 |
|---|---|
| 链型 | 闭链 |
| 关节运动 | 髋屈、膝屈、踝背屈，躯干保持稳定 |
| 外力矩 | 重力造成髋屈、膝屈和躯干前屈趋势 |
| 肌肉 | 股四头肌离心控膝屈；臀大肌/腘绳肌离心控髋屈；小腿三头肌控制踝背屈 |
| 稳定 | 腹壁、竖脊肌、多裂肌维持脊柱；臀中肌控制膝内扣 |

### 深蹲上升

| 项目 | 分析 |
|---|---|
| 链型 | 闭链 |
| 关节运动 | 髋伸、膝伸、踝跖屈趋势 |
| 肌肉 | 臀大肌和大收肌后部伸髋；股四头肌伸膝；小腿三头肌辅助踝控制 |
| 易错 | 躯干过度前倾、膝内扣、足弓塌陷 |

### 弓步

| 项目 | 分析 |
|---|---|
| 任务 | 单侧承重和下肢力线控制 |
| 前腿 | 髋膝踝闭链屈曲下降，伸展回起 |
| 肌肉 | 股四头肌、臀大肌、臀中肌、小腿三头肌协同 |
| 易错 | 骨盆侧倾、膝内扣、足过度旋前 |

### 上台阶

| 项目 | 分析 |
|---|---|
| 任务 | 把身体质心抬高并前移 |
| 主关节 | 支撑腿髋伸、膝伸、踝跖屈 |
| 主动肌 | 臀大肌、股四头肌、小腿三头肌 |
| 稳定 | 臀中肌控制骨盆，核心控制躯干 |

### 上举

| 项目 | 分析 |
|---|---|
| 主关节 | 盂肱屈曲/外展，肩胛上回旋、后倾、外旋 |
| 肌肉 | 三角肌、冈上肌；前锯肌和斜方肌上/下束形成上回旋力偶 |
| 稳定 | 肩袖压迫并居中肱骨头 |
| 代偿 | 腰椎过伸、肋骨外翻、肩胛控制不足 |

## 高分答题点

- 动作分析必须分阶段，不要只列肌肉。
- 肌肉功能不等于“产生动作”，还包括离心制动和等长稳定。
- 步态的支撑相约 60%，摆动相约 40%。
- 承重反应的任务是接受体重和缓冲冲击。
- 单支撑期考臀中肌，承重反应考股四头肌和胫骨前肌，推进期考小腿三头肌。
- 足在支撑早期偏柔软以缓冲，在支撑后期偏刚性以推进。
- 异常步态要按“表现 -> 原因 -> 代偿 -> 相关肌肉/关节”回答。

## 简答题模板

题目：试述正常步态周期及主要肌肉活动。

答题顺序：

1. 步态周期是同一足从一次初始接触到下一次初始接触的过程。
2. 正常行走中支撑相约占 60%，摆动相约占 40%。
3. 支撑相可分为初始接触、承重反应、支撑中期、支撑末期和预摆动。
4. 摆动相可分为摆动初期、摆动中期和摆动末期。
5. 胫骨前肌在初始接触后离心控制足下落，并在摆动期维持背屈清地。
6. 股四头肌在承重反应期离心控制膝屈，臀中肌在单支撑期稳定骨盆。
7. 小腿三头肌在支撑中后期控制胫骨前移并参与跖屈推进。
8. 正常步态依赖下肢关节运动、地面反作用力和肌肉协调共同完成支撑、缓冲、推进和清地。

## 背诵卡片

- 问：步态周期如何定义？  
  答：同一足从一次初始接触到下一次初始接触。
- 问：正常行走支撑相和摆动相比例？  
  答：支撑相约 60%，摆动相约 40%。
- 问：承重反应的功能任务？  
  答：接受体重、吸收冲击、维持稳定。
- 问：支撑中期最重要的骨盆稳定肌？  
  答：臀中肌和臀小肌。
- 问：足跟着地后控制足拍地的肌肉？  
  答：胫骨前肌离心收缩。
- 问：推进期最关键的肌群？  
  答：腓肠肌和比目鱼肌为主的小腿三头肌。
- 问：摆动末期腘绳肌做什么？  
  答：离心减速髋屈和膝伸，为初始接触做准备。
- 问：足下垂常见原因？  
  答：踝背屈肌无力，常见腓神经相关问题。
- 问：Trendelenburg 征说明什么？  
  答：支撑侧髋外展肌，尤其臀中肌无力。
- 问：动作分析三步主线？  
  答：运动学 -> 动力学 -> 肌肉活动。
