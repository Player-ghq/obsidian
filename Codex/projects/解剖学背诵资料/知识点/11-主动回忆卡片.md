# 主动回忆卡片

用途：每天快速抽背。建议先看问题口答，再打开答案；答不出就回到对应部位文档。

## 使用方法

1. 每次抽 20-30 张，不追求一次全背完。
2. 答案只要关键词准确即可，不追求原句。
3. 连续 3 次答对的卡片可以降低频率。
4. 答错的卡片当天晚上再复述一遍。

## 总论

| 问题 | 答案 |
|---|---|
| 解剖学姿势的核心是什么？ | 身体直立、面向前、上肢下垂、掌心向前、足尖向前。 |
| 矢状面主要发生什么运动？ | 屈曲和伸展。 |
| 额状面主要发生什么运动？ | 外展和内收，或侧屈。 |
| 水平面主要发生什么运动？ | 内旋、外旋、水平屈伸。 |
| 运动学和动力学区别？ | 运动学描述运动；动力学解释产生或控制运动的力。 |
| 开链和闭链区别？ | 开链远端自由；闭链远端固定。 |

## 肩复合体

| 问题 | 答案 |
|---|---|
| 肩复合体包括哪些关节？ | 胸锁、肩锁、盂肱、肩胛胸壁功能关节。 |
| 盂肱关节为什么灵活但不够稳定？ | 肱骨头大、关节盂浅，骨性稳定少。 |
| 肩袖包括哪些肌肉？ | 冈上肌、冈下肌、小圆肌、肩胛下肌。 |
| 肩袖核心作用？ | 压迫并居中肱骨头，稳定盂肱关节。 |
| 肩外展主力？ | 三角肌中束，冈上肌启动和辅助。 |
| 肩胛上回旋力偶？ | 前锯肌、斜方肌上束和下束。 |
| 前锯肌无力常见表现？ | 肩胛翼状、上举受限。 |
| 冈上肌神经支配？ | 肩胛上神经。 |

| 髋伸主力？ | 臀大肌和腘绳肌。 |

## 步态与动作分析

| 问题 | 答案 |
|---|---|
| 步态周期定义？ | 同一足从一次初始接触到下一次初始接触。 |
| 正常行走支撑相比例？ | 约 60%。 |
| 正常行走摆动相比例？ | 约 40%。 |
| 承重反应任务？ | 接受体重、吸收冲击、维持稳定。 |
| 支撑中期关键肌？ | 臀中肌/臀小肌稳定骨盆，小腿三头肌控制胫骨前移。 |
| 初始接触后控制足拍地？ | 胫骨前肌离心收缩。 |
| 推进期关键肌群？ | 小腿三头肌。 |
| 摆动期足清地靠什么？ | 髋膝屈曲和踝背屈。 |
| Trendelenburg 征说明什么？ | 支撑侧髋外展肌无力。 |
| 足下垂说明什么？ | 踝背屈肌无力或腓神经相关问题。 |
| 动作分析主线？ | 运动学 -> 动力学 -> 肌肉活动。 |

## 易混对比速背

| 对比 | 答案 |
|---|---|
| 髂腰肌 vs 股直肌 | 髂腰肌是髋屈主力；股直肌跨髋膝，屈髋并伸膝。 |
| 臀中肌 vs 阔筋膜张肌 | 都受臀上神经支配；臀中肌重骨盆稳定，阔筋膜张肌重屈髋/内旋/张紧髂胫束。 |
| 胫骨前肌 vs 胫骨后肌 | 胫骨前肌背屈内翻；胫骨后肌辅助跖屈内翻并支撑内侧纵弓。 |
| 腓肠肌 vs 比目鱼肌 | 腓肠肌跨膝踝；比目鱼肌只跨踝，站立控制重要。 |
| ACL vs PCL | ACL 限制胫骨前移；PCL 限制胫骨后移。 |
| MCL vs LCL | MCL 抗外翻；LCL 抗内翻。 |
| 腹外斜 vs 腹内斜 | 外斜肌对侧旋转；内斜肌同侧旋转。 |
| 寰枕 vs 寰枢 | 寰枕点头；寰枢摇头。 |
