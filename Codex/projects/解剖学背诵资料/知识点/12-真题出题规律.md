# 真题出题规律

来源：`运康 医技真题.docx`、`运动解剖学全国康复考研真题题库.pdf`。  
用途：反推背诵优先级和以后模拟出题方向。

## 总判断

上海体育大学运动康复近年更偏“大题作答能力”，不是单纯记名词。高频问法是：给一个结构或动作，让你从解剖结构、功能、运动意义、训练/康复应用几个层面展开。

2021 年以后参考价值更高。2024 年运康与医技分开后，运康 615 仍保留“人体解剖 + 生理 + 康复”的大综合风格；人体解剖部分常见 25 分简答和 50 分论述/动作分析。

## 上体近年命题特征

| 特征          | 具体表现                  | 复习含义                 |
| ----------- | --------------------- | -------------------- |
| 大题为主        | 常见 9 题，每题 25-50 分     | 不能只背零散名词，要能组织段落      |
| 解剖题常占 2-3 题 | 关节、肌肉、动作分析反复出现        | 解剖必须能写完整答案           |
| 运动系统优先      | 骨、关节、骨骼肌、动作分析高频       | 运动系统是第一优先级           |
| 结构功能结合      | 例如肩髋对比、膝关节结构运动肌肉      | 任何结构都要答“为什么这样就有这种功能” |
| 运动实践结合      | 俯卧撑、立定跳远、步行、核心、股四头肌训练 | 会用动作分析模板比死背更重要       |
| 康复桥接明显      | ACL、髌骨、踝韧带、跟腱、肩痛、腰背保护 | 解剖知识要能解释损伤机制和训练原则    |

## 高频题型

| 题型     | 高频问法                            | 训练方向                    |
| ------ | ------------------------------- | ----------------------- |
| 名词解释   | 解剖学姿势、矢状面、关节、半月板、肩袖、椎间盘、骨盆、肌节等  | 30-80 字，关键词准确           |
| 简答题    | 骨的结构、关节结构、膝关节构造、肌组织特点、脊柱结构、足弓作用 | 按“组成-结构-功能-运动意义”写       |
| 论述题    | 肩髋异同、关节运动幅度影响因素、运动对骨/肌影响、脊柱稳定   | 有层次，有比较，有总结             |
| 动作分析题  | 俯卧撑、立定跳远、步行、跑、深蹲、体育动作解剖学分析      | 必须按阶段分析关节、力矩、肌肉         |
| 应用/康复题 | ACL、踝外侧韧带、股四头肌挫伤、髌骨骨折、跟腱断裂      | 结构基础 -> 损伤机制 -> 评定/训练思路 |

## 高频知识模块

### 第一优先级

| 模块 | 高频原因 | 必会题 |
|---|---|---|
| 骨 | 上体和全国题库都反复考 | 骨的构造、分类、功能、骨生长、体育锻炼对骨的影响 |
| 关节总论 | 2024 医技考关节运动幅度，题库也高频 | 关节主要结构和辅助结构、关节分类、运动幅度影响因素 |
| 骨骼肌总论 | 2024 运康考肌组织，2021/2022 多次考肌肉工作 | 骨骼肌结构、肌肉工作性质、单/双/多关节肌、影响肌力因素 |
| 动作分析 | 2024 俯卧撑、2022 立定跳远，历年环节受力分析 | 原动肌判断、运动学/动力学/肌肉分析 |
| 膝关节 | 2024 运康直接考膝关节，康复题常连 ACL/髌骨 | 膝结构、运动、主要肌肉、半月板、交叉韧带、Q 角 |

### 第二优先级

| 模块 | 常见问法 |
|---|---|
| 肩关节/肩复合体 | 肩髋对比、肩关节结构运动、肩袖、肩带运动、俯卧撑和上举 |
| 髋关节/骨盆 | 肩髋异同、骨盆结构和运动、核心稳定 |
| 踝足 | 足弓结构作用、踝外侧韧带损伤、踝背屈限制、跟腱/小腿三头肌 |
| 脊柱 | 颈胸腰椎异同、椎间盘结构功能、脊柱稳定、腰背保护 |
| 步态 | 步行周期、步行分期、正常步行条件、步态分析参数 |

### 第三优先级

| 模块    | 说明                            |
| ----- | ----------------------------- |
| 神经系统  | 上体考过内囊、自主神经、躯体/内脏运动神经，医技尤其要注意 |
| 内脏/循环 | 医技 2024 考肝肺肾血液循环；运康也可能通过综合题出现 |
| 呼吸肌   | 呼吸训练、T4 脊髓损伤、膈肌、胸廓相关          |
| 体表标志  | 全国题库常见，但上体近年不是最核心             |

## 高频问法公式

### 结构类

题干常写：简述某结构的组成、构造、运动和功能。

答题公式：

1. 组成：由哪些骨、组织或关节构成。
2. 结构：主要结构和辅助结构。
3. 运动：运动方向、平面、轴。
4. 肌肉：主动肌、协同肌、稳定肌。
5. 功能意义：承重、稳定、灵活、传力、缓冲、推进。

### 比较类

题干常写：比较肩关节和髋关节、上肢骨和下肢骨、颈胸腰椎异同。

答题公式：

1. 先写共同点。
2. 再按结构差异分条比较。
3. 最后落到功能差异。
4. 一定写一句总结：结构决定功能。

### 影响因素类

题干常写：影响关节运动幅度、肌力、骨生长、骨骼肌收缩效能的因素。

答题公式：

1. 结构因素。
2. 神经肌肉因素。
3. 年龄/性别/训练因素。
4. 疾病损伤因素。
5. 运动训练或康复意义。

### 动作分析类

题干常写：以某动作为例进行体育运动解剖学分析。

答题公式：

1. 分阶段：准备、下降/缓冲、发力、结束。
2. 分关节：躯干、肩/髋、肘/膝、腕/踝。
3. 分平面：屈伸、外展内收、旋转。
4. 分力矩：外力矩和内力矩方向。
5. 分肌肉：向心、离心、等长。
6. 分意义：稳定、发力、缓冲、损伤风险。

## 上体优先押题方向

| 优先级 | 题目方向               | 理由                   |
| --- | ------------------ | -------------------- |
| S   | 关节运动幅度影响因素         | 2024 医技出现，且是关节总论大题核心 |
| S   | 膝关节构造、运动和主要肌肉      | 2024 运康直接出现，康复桥接强    |
| S   | 俯卧撑/立定跳远/深蹲动作分析    | 近年明确考体育动作分析          |
| S   | 肌组织或骨骼肌结构功能        | 2024 运康、2019 上体均出现   |
| S   | 骨结构及体育锻炼影响         | 2023/2019/2016 等反复出现 |
| A   | 肩关节和髋关节异同          | 2023 和 2019 均有类似方向   |
| A   | 单、双、多关节肌与主动不足/被动不足 | 2021、2016 出现，适合论述    |
| A   | 脊柱/椎间盘/颈胸腰椎异同      | 2020、2019 出现，稳定高频    |
| A   | 足弓结构和作用            | 2016 上体出现，全国题库高频     |
| A   | 步行周期、步态分析参数、正常步行条件 | 2019/2016 等出现，康复相关强  |
| B   | 内囊和神经传导通路          | 2023 出现，但不如运动系统稳定    |
| B   | 肝肺肾血液循环、胆汁排出途径     | 医技方向更强，运康作为补充        |

## 以后给你出题的规则

### 题型比例

| 类型 | 比例 | 目的 |
|---|---|---|
| 25 分简答 | 50% | 训练完整结构化输出 |
| 50 分论述/动作分析 | 30% | 训练高分展开能力 |
| 名词解释/快问快答 | 20% | 训练关键词提取 |

### 内容比例

| 内容 | 比例 |
|---|---|
| 运动系统总论：骨、关节、肌肉 | 30% |
| 部位解剖：肩、髋、膝、踝足、脊柱 | 35% |
| 动作分析：俯卧撑、深蹲、跳、步态、跑 | 20% |
| 神经/内脏/循环补充 | 15% |

### 难度设计

| 难度  | 标准               |
| --- | ---------------- |
| 基础  | 能背出组成、结构、功能      |
| 中等  | 能比较异同，能解释结构与功能关系 |
| 高分  | 能结合动作、训练、损伤或康复应用 |

## 不该怎么出题

- 不以偏门小结构为主。
- 不大量出选择题。
- 不只问起止点而不问功能。
- 不只问定义，要逼迫你写“结构-功能-运动意义”。
- 不把全国题库的低频内脏细节放在运康解剖主线前面。

## 一句话复习策略

先把“骨-关节-骨骼肌-动作分析”练成能写大题的系统，再用部位文档补肩、髋、膝、踝足、脊柱，最后用主动回忆卡片扫名词和易混点。
