# 膝关节

来源范围：PDF 第 13 章；附录 D 下肢肌肉附着点与神经支配。

## 背诵总框架

膝关节是“以屈伸为主、兼具旋转的承重铰链复合体”：骨性匹配不如髋稳定，所以依赖半月板、交叉韧带、侧副韧带、髌股关节和肌肉控制。

记忆顺序：股骨远端和胫骨平台 -> 半月板 -> ACL/PCL/MCL/LCL -> 髌骨伸膝装置 -> 股四头肌和腘绳肌 -> 锁定与解锁。

## 骨与骨性标志

| 结构 | 必背点 | 定位价值 |
|---|---|---|
| 股骨内外侧髁 | 与胫骨平台构成胫股关节 | 屈伸和滚滑运动基础 |
| 股骨髁间窝 | 交叉韧带相关 | ACL/PCL 位置记忆 |
| 髌面/滑车 | 髌骨滑行轨道 | 髌股关节力线 |
| 胫骨平台 | 承接股骨髁 | 半月板附着、承重 |
| 髁间隆起 | 半月板和交叉韧带邻近 | 膝内稳定结构定位 |
| 胫骨粗隆 | 髌韧带止点 | 伸膝装置终点 |
| 腓骨头 | 股二头肌、外侧副韧带相关 | 外侧结构定位 |
| 髌骨 | 股四头肌腱内籽骨 | 增加伸膝力臂 |

## 关节组成

| 关节 | 结构 | 功能重点 |
|---|---|---|
| 胫股关节 | 股骨内外侧髁与胫骨平台 | 屈伸为主，屈曲位可旋转 |
| 髌股关节 | 髌骨后面与股骨滑车 | 改变股四头肌力线，提高伸膝效率 |
| 上胫腓关节 | 胫骨外侧髁与腓骨头 | 配合踝足受力和小腿骨间运动 |

## 半月板与韧带

| 结构 | 背诵点 | 功能 |
|---|---|---|
| 内侧半月板 | C 形，较固定，与 MCL 关系密切 | 增加接触面积、减震、稳定，损伤较常见 |
| 外侧半月板 | 近 O 形，活动度较大 | 适应外侧髁运动，减震稳定 |
| 前交叉韧带 ACL | 从胫骨前方向股骨外侧髁内侧走行 | 限制胫骨前移，控制旋转 |
| 后交叉韧带 PCL | 从胫骨后方向股骨内侧髁外侧走行 | 限制胫骨后移 |
| 内侧副韧带 MCL | 股骨内上髁至胫骨内侧 | 抵抗膝外翻 |
| 外侧副韧带 LCL | 股骨外上髁至腓骨头 | 抵抗膝内翻 |
| 斜腘韧带 | 后方关节囊加强 | 抵抗过伸，后方稳定 |
| 髂胫束 | 止于胫骨外侧近端 | 外侧动态稳定 |

## 锁定与解锁

| 概念 | 背诵点 |
|---|---|
| 膝关节锁定 | 伸膝末期胫骨相对股骨外旋，或闭链中股骨相对胫骨内旋，使关节更稳定 |
| 膝关节解锁 | 屈膝开始时腘肌启动，开链使胫骨内旋，闭链使股骨外旋 |
| 记忆句 | 伸直要锁，屈曲先解；解锁找腘肌 |

## 肌肉总表

| 肌肉 | 起点 | 止点 | 神经 | 主功能 |
|---|---|---|---|---|
| 股直肌 | 髂前下棘、髋臼上缘 | 髌骨、髌韧带至胫骨粗隆 | 股神经 | 膝伸、髋屈 |
| 股外侧肌 | 大转子附近、粗线外侧唇 | 髌骨外侧、胫骨粗隆 | 股神经 | 膝伸，影响髌骨外侧力线 |
| 股内侧肌 | 粗线内侧唇、内侧髁上线 | 髌骨内侧、胫骨粗隆 | 股神经 | 膝伸，稳定髌骨内侧 |
| 股中间肌 | 股骨前外侧面 | 髌骨、胫骨粗隆 | 股神经 | 膝伸 |
| 股二头肌长头 | 坐骨结节 | 腓骨头 | 坐骨神经胫骨部 | 膝屈、胫骨外旋、髋伸 |
| 股二头肌短头 | 股骨粗线外侧唇 | 腓骨头 | 坐骨神经腓总部 | 膝屈、胫骨外旋 |
| 半腱肌 | 坐骨结节 | 胫骨近端内侧 | 坐骨神经胫骨部 | 膝屈、胫骨内旋、髋伸 |
| 半膜肌 | 坐骨结节 | 胫骨内侧髁后部、斜腘韧带等 | 坐骨神经胫骨部 | 膝屈、胫骨内旋、髋伸 |
| 缝匠肌 | 髂前上棘 | 胫骨近端内侧 | 股神经 | 膝屈，辅助胫骨内旋 |
| 股薄肌 | 耻骨体、耻骨下支 | 胫骨近端内侧 | 闭孔神经 | 膝屈，辅助胫骨内旋 |
| 腓肠肌 | 股骨内外侧髁后面 | 跟骨结节 | 胫神经 | 踝跖屈、膝屈 |
| 腘肌 | 股骨外侧髁、外侧半月板 | 胫骨后面 | 胫神经 | 解锁膝关节，膝屈初期控制 |
| 阔筋膜张肌 | 髂前上棘附近 | 髂胫束至胫骨外侧 | 臀上神经 | 经髂胫束影响膝外侧稳定 |

## 动作反查

| 动作 | 主动肌 | 协同肌 | 拮抗肌 |
|---|---|---|---|
| 膝伸 | 股四头肌 | 髌骨提高力臂 | 腘绳肌、腓肠肌 |
| 膝屈 | 腘绳肌 | 腓肠肌、腘肌、缝匠肌、股薄肌 | 股四头肌 |
| 胫骨内旋 | 半腱肌、半膜肌、腘肌 | 缝匠肌、股薄肌 | 股二头肌 |
| 胫骨外旋 | 股二头肌 | 髂胫束可影响外侧控制 | 半腱肌、半膜肌、腘肌 |
| 抗外翻 | MCL、内侧肌群、髋外展外旋控制 | 足踝力线配合 | 外翻应力 |
| 抗内翻 | LCL、外侧结构、腓骨肌群协同 | 髂胫束 | 内翻应力 |

## 髌股关节与伸膝装置

| 结构 | 背诵点 |
|---|---|
| 股四头肌腱 | 股四头肌汇合至髌骨 |
| 髌骨 | 增加股四头肌对膝的力臂，提高伸膝效率 |
| 髌韧带 | 髌骨至胫骨粗隆 |
| 髌骨轨迹 | 受股骨滑车、股内侧肌、股外侧肌、髂胫束、下肢力线影响 |
| 闭链膝伸 | 股四头肌控制身体重心，髋踝共同参与 |

## 易混点

| 易混点 | 正确记法 |
|---|---|
| ACL vs PCL | ACL 限制胫骨前移；PCL 限制胫骨后移 |
| MCL vs LCL | MCL 抗外翻；LCL 抗内翻 |
| 内侧半月板 vs 外侧半月板 | 内侧更固定，和 MCL 关系近；外侧活动度较大 |
| 股二头肌 vs 半腱半膜肌 | 股二头肌使胫骨外旋；半腱半膜肌使胫骨内旋 |
| 股直肌 vs 其他股四头肌 | 股直肌跨髋膝，既屈髋又伸膝；其他三块主要伸膝 |
| 腓肠肌 vs 比目鱼肌 | 腓肠肌跨膝踝，可屈膝和跖屈；比目鱼肌只跨踝 |

## 高分答题点

- 膝关节稳定不是只靠骨性结构，而是半月板、韧带、关节囊、髌股机制和肌肉共同完成。
- 半月板增加接触面积、分散压力、吸收震荡、改善稳定。
- ACL/PCL 主要控制胫骨前后移位，MCL/LCL 主要控制侧方应力。
- 髌骨的核心功能是增加股四头肌力臂，提高伸膝效率。
- 腘肌是膝关节“解锁”关键词。

## 简答题模板

题目：试述膝关节的结构与功能。

答题顺序：

1. 膝关节包括胫股关节和髌股关节，主要运动为屈伸，屈曲位可有旋转。
2. 骨性结构包括股骨髁、胫骨平台、髌骨，骨性匹配有限。
3. 半月板增加接触面积、分散压力、缓冲震荡并增强稳定。
4. ACL 限制胫骨前移，PCL 限制胫骨后移，MCL 抗外翻，LCL 抗内翻。
5. 股四头肌完成伸膝，髌骨提高伸膝力臂；腘绳肌完成屈膝并参与旋转控制。
6. 运动中膝关节承担承重、缓冲、推进和下肢力线控制。

## 背诵卡片

- 问：膝关节主要由哪两个关节组成？  
  答：胫股关节和髌股关节。
- 问：膝伸主力？  
  答：股四头肌。
- 问：膝屈主力？  
  答：腘绳肌，腓肠肌和腘肌辅助。
- 问：ACL 限制什么？  
  答：限制胫骨前移，并参与旋转稳定。
- 问：PCL 限制什么？  
  答：限制胫骨后移。
- 问：MCL 和 LCL 分别抵抗什么？  
  答：MCL 抵抗外翻，LCL 抵抗内翻。
- 问：髌骨的功能？  
  答：增加股四头肌力臂，提高伸膝效率。
- 问：解锁膝关节的肌肉？  
  答：腘肌。
- 问：股二头肌对胫骨旋转方向？  
  答：外旋。
- 问：半腱肌、半膜肌对胫骨旋转方向？  
  答：内旋。
