# 中轴骨骼：躯干、头颈、胸廓

来源范围：PDF 第 9-11 章；附录 C 中轴骨骼肌肉附着点与神经支配。

## 背诵总框架

中轴骨骼负责“支撑、保护、传力、运动和呼吸咀嚼”：颅骨保护脑和感觉器，脊柱保护脊髓并传递负荷，胸廓保护心肺并参与通气，头颈肌控制感觉器官定位，躯干肌控制姿势和核心稳定。

记忆顺序：中轴骨组成 -> 脊柱分区 -> 椎间盘/小关节/韧带 -> 躯干后侧肌 -> 腹壁肌 -> 头颈肌 -> 颞下颌关节 -> 呼吸肌。

## 中轴骨组成

| 组成 | 必背点 | 功能 |
|---|---|---|
| 颅骨 | 枕骨、颞骨等与头颈和 TMJ 关系密切 | 保护脑和感觉器官，提供肌肉附着 |
| 脊柱 | 颈椎、胸椎、腰椎、骶骨、尾骨 | 支撑、保护脊髓、传递负荷、提供运动 |
| 肋骨 | 12 对，后方连胸椎，前方经肋软骨连胸骨 | 保护胸腔脏器，参与呼吸 |
| 胸骨 | 胸骨柄、胸骨体、剑突 | 肋软骨附着，胸廓前壁 |
| 舌骨 | 位于喉部上方，悬吊于颅底 | 舌骨上/下肌附着，参与吞咽、发声、下颌运动 |

## 脊柱分区

| 区域 | 骨学特点 | 运动特点 | 记忆关键词 |
|---|---|---|---|
| 颈椎 | 椎体小，有横突孔；寰椎、枢椎特殊 | 活动度大，旋转和屈伸明显 | 灵活、感觉定位 |
| 胸椎 | 有肋凹，与肋骨连接 | 受胸廓限制，旋转相对重要 | 稳定、胸廓 |
| 腰椎 | 椎体大，承重强 | 屈伸明显，旋转受限 | 承重、屈伸 |
| 骶骨 | 由骶椎融合，形成骶髂关节一侧 | 活动小，传递躯干到骨盆负荷 | 稳定、传力 |
| 尾骨 | 脊柱末端 | 活动小 | 盆底相关附着 |

## 典型椎骨与骨性标志

| 结构 | 背诵点 |
|---|---|
| 椎体 | 前方主要承重结构，承受压缩负荷 |
| 椎弓 | 包括椎弓根、椎板，围成椎孔 |
| 棘突 | 后方突起，肌肉和韧带附着 |
| 横突 | 两侧突起，肌肉和韧带附着；胸椎与肋骨相关 |
| 上下关节突 | 构成椎间小关节，决定运动方向 |
| 椎孔 | 连成椎管，容纳脊髓 |
| 椎间孔 | 脊神经根穿出位置 |

| 结构 | 作用 |

## 易混点

| 易混点 | 正确记法 |
|---|---|
| 寰枕 vs 寰枢 | 寰枕偏点头屈伸；寰枢偏摇头旋转 |
| 竖脊肌 vs 多裂肌 | 竖脊肌偏大范围伸展；多裂肌偏分节稳定 |
| 腹外斜 vs 腹内斜 | 外斜肌对侧旋转；内斜肌同侧旋转 |
| 腹直肌 vs 腹横肌 | 腹直肌屈 trunk；腹横肌增加腹压和稳定 |
| 胸锁乳突肌旋转方向 | 单侧收缩使头转向对侧 |
| 斜角肌功能 | 既能颈侧屈，也能辅助吸气抬第 1、2 肋 |
| 咬肌 vs 翼外肌 | 咬肌闭口；翼外肌前伸和张口相关 |
| 膈肌神经 | 膈神经 C3-C5，必须直接背 |
| 平静呼气 vs 用力呼气 | 平静呼气多被动；用力呼气靠腹肌和内肋间肌 |

## 高分答题点

- 中轴骨骼不仅支撑身体，还保护神经系统和内脏，并参与呼吸、咀嚼、姿势控制。
- 脊柱稳定来自椎间盘、小关节、韧带、深层肌和腹压系统共同作用。
- 核心稳定不是腹直肌单独完成，而是腹横肌、多裂肌、膈肌、盆底和胸腰筋膜协同。
- 头颈部运动服务于视觉、听觉、嗅觉定位，所以既需要大范围运动，也需要精细稳定。
- TMJ 有关节盘，动作包括上提/下压、前伸/后缩和侧移。
- 通气依赖胸廓关节活动和呼吸肌收缩，膈肌是平静吸气主肌。

## 简答题模板

题目：试述中轴骨骼的结构与功能。

答题顺序：

1. 中轴骨骼由颅骨、脊柱、肋骨和胸骨组成。
2. 颅骨保护脑和感觉器官，脊柱支撑躯干并保护脊髓，胸廓保护心肺并参与呼吸。
3. 脊柱由椎体、椎弓、椎间盘、小关节和韧带构成，兼具稳定和活动。
4. 躯干肌包括竖脊肌、横突棘肌、腹壁肌和腰方肌，完成运动与稳定。
5. 头颈肌控制头颈屈伸、侧屈和旋转，帮助感觉器官定位。
6. 中轴骨骼还通过 TMJ 参与咀嚼，通过胸廓和呼吸肌参与通气。
