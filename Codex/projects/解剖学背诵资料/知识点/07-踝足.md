# 踝足

来源范围：PDF 第 14 章；附录 D 下肢肌肉附着点与神经支配。

## 背诵总框架

踝足是“缓冲器加推进杠杆”：落地时需要柔韧、吸收冲击；蹬地时需要变硬、传递力量。踝关节主控背屈/跖屈，足部关节主控内翻/外翻、旋前/旋后和足弓稳定。

记忆顺序：胫腓骨远端 -> 距骨跟骨和足弓 -> 距小腿/距下/横跗/跖趾关节 -> 小腿四群肌 -> 足内在肌 -> 步态缓冲和推进。

## 骨与骨性标志

| 区域 | 结构 | 必背点 |
|---|---|---|
| 小腿远端 | 胫骨远端、内踝 | 内侧承重柱，构成踝穴内侧 |
| 小腿远端 | 腓骨远端、外踝 | 外踝较低，外侧稳定重要 |
| 跗骨后部 | 距骨 | 无肌肉直接附着，传递小腿到足的力 |
| 跗骨后部 | 跟骨 | 足跟承重，跟腱止点 |
| 跗骨中前部 | 舟骨、骰骨、三块楔骨 | 足弓和跗跖稳定关键 |
| 跖骨 | 第 1-5 跖骨 | 前足承重和推进 |
| 趾骨 | 拇趾两节，其余三节 | 抓地、推进和精细平衡 |
| 籽骨 | 第 1 跖趾关节下方常见 | 增加拇趾屈肌力臂 |

## 足弓

| 足弓 | 组成理解 | 功能 |
|---|---|---|
| 内侧纵弓 | 跟骨、距骨、舟骨、楔骨、第 1-3 跖骨 | 高而弹性大，缓冲和推进关键 |
| 外侧纵弓 | 跟骨、骰骨、第 4-5 跖骨 | 低而稳定，承重支撑 |
| 横弓 | 楔骨、骰骨、跖骨底 | 维持前足形态，分散压力 |
| 动态支持 | 胫骨后肌、腓骨长肌、足内在肌、足底腱膜 | 运动中维持弓形 |

| 距小腿关节 | 胫骨、腓骨、距骨滑车 | 背屈和跖屈主关节 |
| 距下关节 | 距骨与跟骨 | 内翻/外翻核心关节 |

| 趾间关节 | 趾骨之间 | 脚趾抓地和精细控制 |

## 步态理解

| 阶段 | 踝足任务 | 关键结构 |
|---|---|---|
| 足跟着地 | 接触地面，开始缓冲 | 胫骨前肌离心控制跖屈 |
| 承重反应 | 足部变柔软，吸收冲击 | 距下关节旋前、足弓弹性下降 |
| 中期支撑 | 胫骨向前越过足 | 踝背屈活动度、比目鱼肌离心控制 |
| 末期支撑 | 足部变硬，准备推进 | 足旋后、足底腱膜张紧 |
| 蹬离 | 第 1 跖趾关节伸展，拇趾参与推进 | 拇长屈肌、腓骨长肌、足内在肌 |

## 易混点

| 易混点 | 正确记法 |
|---|---|
| 距小腿关节 vs 距下关节 | 距小腿主背屈/跖屈；距下主内翻/外翻 |
| 胫骨前肌 vs 胫骨后肌 | 胫骨前肌背屈+内翻；胫骨后肌跖屈辅助+内翻，是内侧纵弓关键 |
| 腓骨长肌 vs 腓骨短肌 | 长肌到内侧楔骨和第 1 跖骨，支持横弓；短肌到第 5 跖骨 |
| 腓肠肌 vs 比目鱼肌 | 腓肠肌跨膝踝，能屈膝；比目鱼肌只跨踝，站立控制重要 |
| 拇长屈肌 vs 趾长屈肌 | 拇长屈肌管拇趾推进；趾长屈肌管第 2-5 趾 |
| 内翻扭伤 vs 外翻扭伤 | 外侧韧带较易受内翻损伤；内侧三角韧带较强 |

## 高分答题点

- 踝足功能不是单纯活动，而是在柔韧缓冲和刚性推进之间切换。
- 距小腿关节主要完成背屈/跖屈；距下关节主要参与内翻/外翻。
- 足弓由骨性排列、韧带、足底腱膜、外在肌和内在肌共同维持。
- 胫骨后肌是内侧纵弓动态支持的关键词。
- 腓骨长肌支持横弓和第 1 跖骨，推进期很重要。
- 第 1 跖趾关节和拇长屈肌对步态蹬离意义大。

## 简答题模板

题目：试述踝足的结构与功能。

答题顺序：

1. 踝足由胫腓骨远端、跗骨、跖骨和趾骨构成，包括距小腿、距下、横跗、跗跖、跖趾等关节。
2. 距小腿关节主要完成背屈和跖屈，距下关节参与内翻和外翻。
3. 足弓包括内侧纵弓、外侧纵弓和横弓，由骨、韧带、足底腱膜和肌肉共同维持。
4. 小腿前群主背屈，外侧群主外翻，后群浅层主跖屈，后群深层主内翻和足弓支持。
5. 足内在肌维持足弓、稳定跖趾关节并完成脚趾精细控制。
6. 运动中踝足既吸收冲击，又在推进期形成刚性杠杆。

## 背诵卡片

- 问：踝关节背屈主力？  
  答：胫骨前肌，趾长伸肌、拇长伸肌、第三腓骨肌辅助。
- 问：踝跖屈主力？  
  答：腓肠肌和比目鱼肌。
- 问：足内翻主力？  
  答：胫骨后肌和胫骨前肌。
- 问：足外翻主力？  
  答：腓骨长肌和腓骨短肌。
- 问：支持内侧纵弓的关键动态肌？  
  答：胫骨后肌。
- 问：腓骨长肌止点和意义？  
  答：止于内侧楔骨和第 1 跖骨底，支持横弓和第 1 跖骨。
- 问：距小腿关节主要运动？  
  答：背屈和跖屈。
- 问：距下关节主要相关运动？  
  答：内翻和外翻。
- 问：推进期最关键的趾关节？  
  答：第 1 跖趾关节。
- 问：外侧踝扭伤常伤哪组韧带？  
  答：外侧副韧带复合体，尤其距腓前韧带常见。
