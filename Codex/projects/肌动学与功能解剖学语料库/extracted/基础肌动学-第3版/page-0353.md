比目鱼肌闭链激活
心 严？鱼肌是第 2 膝伸肌 使膝关节伸展
比目鱼肌作为踝拓屈肌起着重要的作用，但也是
重要的膝伸肌和稳定肌 。 在足底与地面紧密接触的情
况下，比目鱼肌收缩产生闭链拓屈运动 。 该运动向后
躯动胫骨的上侧（和膝关节），有效地伸展膝关节（图
11.30 ) 。 股四头肌无力者可以使用比目鱼肌的这一功
能产生膝关节伸展力矩 。
然而在下肢承重时，比目鱼肌过度活动（痉挛）
可能会引起膝关节过伸 。 这种情况通常发生在中风导
致比目鱼肌痉挛的人群中 。 随着时间的推移，当下肢
负重时，该肌肉活动的增加最终可导致膝过伸 。
