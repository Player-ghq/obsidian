思考
步行周期中的起伏
在正常步态中，身体上下左右摆动 。 这些自然发生的运动是有目的的 。 图 12.9A 说明了行走时人体质心的
自然垂直位移 。 步行周期中身体质心的最低时期在足跟触地之后，因为重量巳转移到支撑腿上 。 屈榄屈膝作为
降低质心运动的特征，形成一种减震机制 。 如果没有这种机制，随着时间的流逝，初始承重时的冲击可能会对
下肢和脊椎造成伤害 。
步行周期质心的最高时期发生在支撑相中期 。 这时支撑腿完全直立，可以使摆动腿得到最大的廓清空间 。
除了上下起伏，正常的步态还包括质心自然地产生双侧横向位移 。 横向位移虽然相对幅度较小，但可以有
效地将身体的重心转移到支撑腿上 。 如图 12.9B 所示，最大的横向位移发生在支撑相中期，即对侧腿充分处于
摆动相 。
