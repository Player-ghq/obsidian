跳跃步态
损伤： 任何下肢的损伤都可能会导致前进时
下肢长度的功能性缩短（如无法屈骸
或屈膝） 。
异常描述： 支撑腿需要提踵（图中的左腿），才
能使对侧前移腿完成廓清 。
异常原因： 支撑腿提踵会为对侧（长）腿摆动时
增加额外的空间，以完成廓清 。
股四头肌步态
损伤： 股四头肌肌力较弱或避免用力 。
异常描述： 整个支撑相，膝关节保持充分伸展且
躯千过度前倾 。
重力线移至内外 异常原因： 躯于前倾使重力线移向膝关节内外
轴前方
轴的前方 。 这个运动将膝关节机械
锁定在伸展状态，从而减少股四头肌
股四头肌 \ ~ 收缩 。
