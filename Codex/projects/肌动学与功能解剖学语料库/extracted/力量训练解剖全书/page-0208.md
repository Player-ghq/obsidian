# 力量训练解剖全书 page-0208

## 识别标题

眩三头肌

## 页文本

眩三头肌
固定器械练习
所涉肌肉
主要肌肉 ：脓三头肌、胸大肌（下部）、三角肌（前部）。
次要肌肉 ：胸小肌、前锯肌、喙脓肌、肩脾下肌、肘肌 。
括抗肌 ：背阔肌、脓二头肌，三角肌（后部）。
动作要领
动作与双杠臂屈伸基本相同，但此时膝盖或者双脚（依器械设计而定）要支撑在器械
的座椅上做练习 。 以较小的握距握住握杆并挺直躯于 。 先深吸一 口气并屈肘，使身体垂直
下降，在这个过程中不要使肘部远离躯干，以免胸大肌发力过多 。 到达最低点后再将身体
垂直撑起，同时呼气 。
提示
在练习过程中你应该感受到是在伸直你的手臂而不是在“推＂ 。 在身体下降过程中，
肘部应始终贴近躯千（朝向身体后方而不是两侧）。 除此之外，在双杠臂屈伸中提到的注
意事项皆适用于此练习 。 此练习适合新手，也适合希望提高动作技巧（在做更多次数的同
时避免身体摇晃）的训练者 。
小
常见错误： 动作幅度过小；肘部远离躯干而使胸大肌发力过多；躯干姿势不正确；在
动作最高点时手臂超伸 。
