# 力量训练解剖全书 page-0177

## 识别标题

眩二头肌 圈硐固咋华阳却若一

## 页文本

雇
眩二头肌 圈硐固咋华阳却若一
自由重量练习
所涉肌肉
主要肌肉 ：脓二头肌、脓肌、脓挠肌 。
次要肌肉： 旋前圆肌、挠侧腕长伸肌、指浅屈肌、挠侧腕屈肌 。
括抗肌 ：脓三头肌、肘肌 。
动作要领
俯卧在一端向上倾斜45° 的健身凳上（胸部和腹部紧贴健身凳）， 一 只手正握或反握
哑铃做弯举练习，另 一只手抱住健身凳 。 在练习过程中，胸部不要离开健身凳 。 开始向上
举哑铃时吸气，在放下哑铃的过程中呼气 。
— 提示
此练习较少用到，主要适合背部有问题的而练者，以使部分重址由健身凳分担 。 除
此之外，它与常规的哑铃弯举或杠铃弯举相比没有任何优势 。 此练习也被健美运动员称为
＂蜘蛛弯举” 。
如果你斜向外移动手臂，那么可使动作幅度更大，但这完全没有必要，效果与常规
练习几乎没有区别 。
\
. 常见错误： 晃动手臂以借助惯性，动作不完整 。
