# 力量训练解剖全书 page-0279

## 识别标题

下肢固定

## 页文本

下肢固定
器械练习
所涉肌肉
主要肌肉： 臀中肌、阔筋膜张肌、臀大肌 。
次要肌肉： 臀小肌、梨状肌、闭孔内肌、上开肌、下抒肌、排肠
肌、缝匠肌 。
括抗肌 ：股内收肌、耻骨肌 。
动作要领
动作与仰卧滑轮腿内收基本相同，但此时要将滑轮的绳索绑在远离滑轮的脚上做外
展动作 。 练习时自然呼吸即可，若使用的重址较大（最好避免），则开始外展时吸气，回
到起始位置后呼气 。
— 提示
乙
在负重的情况下做腿内收和外展动作不太舒适 。 此练习的唯一优势是，它可以使受
训腿始终受到压力 。 最好选择可以以坐姿做练习的器械，因为以卧姿做练习不太舒适也
不太方便 。

常见错误： 借助惯性，转动身体 。
