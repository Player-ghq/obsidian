# 力量训练解剖全书 page-0061

## 识别标题

胸部自由

## 页文本

胸部自由
重量练习
所涉肌肉
主要肌肉 ：胸大肌、背阔肌、腹部肌肉 。
次要肌肉 ：大圆肌、小圆肌、前锯肌、喙脓肌、眩三头肌、
萎形肌 。
括抗肌： 三角肌、胸大肌（上部）。
动作要领
起始姿势与哑铃滑动俯卧撑相似 。 先伸展双臂使哑铃向身体前方滑动，直到身体贴近
地面，再滑动哑铃靠近身体，回到起始位置 。 双臂向前伸展时吸气并憋住，回到起始位置
后呼气 。
—
提于
/J\
做此练习时腹部肌肉会强烈收缩，因此它适合有经验的训练者 。 体重过大者做此练习
难度较高，但是可以用膝盖代替双脚来支撑地面 。 此练习与其他练习相比没有太大优势 。
用一根杠铃杆穿过哑铃片或者用特制的滚轮做此练习更有效 。 尽管我将此练习放在胸部肌
群这一章来介绍，但它对腹部肌肉的锻炼效果也十分显著 。
丿. ＼ 常见错误： 动作不规范；身体弯曲；双臂伸展不充分 。
