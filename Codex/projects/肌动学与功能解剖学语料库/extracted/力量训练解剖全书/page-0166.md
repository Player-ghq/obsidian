# 力量训练解剖全书 page-0166

## 识别标题

解析：胧二头肌或许是人们最熟悉的肌肉，同时发达的胧二头肌也最能展现一个人的强壮

## 页文本

解析：胧二头肌或许是人们最熟悉的肌肉，同时发达的胧二头肌也最能展现一个人的强壮
体魄。 矛盾的是，虽然肮二头肌属于骨骼肌三大肌群中的四肢肌，但它并不会过多发力，
仅仅是进行快速的、大幅度的运动而已 。 很多人夸大了胧二头肌练习的种类，人们总是力
求将胧二头肌分成许多部分进行锻炼，千是，出现了所谓针对胧二头肌上部、下部以及肌
峰的各种练习 。 但他们忽略了胧二头肌其实是一个整体这一事实 。 实际上，胧二头肌上工
作的肌束几乎是不变的，因此针对胧二头肌的练习的种类比针对胸大肌等大体积肌肉的练
习的种类少得多 。 为了有效锻炼胧二头肌，你应当以掌心朝上的姿势做练习，或至少在胧
二头肌收缩时掌心朝上 。 因为当掌心相对和掌心朝下时，胧二头肌的工作量减少，胧肌以
及前臂其他肌肉的工作扯增加 。
肮二头肌长头的近端嵌入点十分脆弱，因此在做肩部和胸部的夹胸练习以及肩部和
手臂姿势不太自然的练习时应加以注意 。 另外，有极少数人的胧二头肌可能出现第 3个头 。
你可以在日常饮食时观察到手臂的运动方式：当你拿取面前的食物时，需要使前臂
向内旋转以使掌心朝下；当你将食物送旌嘴里时，需要使前臂向外旋转以使掌心朝上，
并使手臂屈曲 。 当你做使前臂旋内的动作时，还通常伴以肩部的外展，比如将水壶里的
水倒进杯子里时 。
有些人胧二头肌较短，但力址训练无法改变这一情况 。 没有肌肉的部位无法生长出肌
肉，因此胧二头肌也不可能延长至肘部，只能通过锻炼胧肌使手臂变得美观。
最后还要注意，胧二头肌的体积比胧三头肌的小，因此，如果你想拥有美观健壮的
手臂，也不要忽略对胧三头肌的锻炼 。
