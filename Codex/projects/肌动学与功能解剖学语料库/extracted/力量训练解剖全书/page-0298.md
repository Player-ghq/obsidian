动作要领
站在镜子前，目视前方，双腿分开以保持平衡 。 双手掌
心朝前将一根木质长杆稳定在体后颈部下方，使长杆紧贴肩
部 。 交替向左和向右屈曲躯干（屈曲角度不超过40° ) ，使腹
部肌肉强烈收缩，并利用腹部肌肉的力址开始和结束侧屈动
作 。 直起身子时吸气，侧屈时呼气 。
提示
与长杆转体一样，由千此练习无须过多发力，动作次数往往比其他练习多 。 请注意在
练习过程中不但要收紧腹部肌肉，还要使腰部肌肉也保持一定程度的紧张 。 在这里我必须
提醒一旬，所用重批或屈曲角度过大容易导致脊柱受伤 。 此练习可锻炼腹内斜肌和腹外斜
肌，尽管很大一部分的工作由腰方肌承担 。

腰椎的活动和稳定性有相当重要的作用 。
