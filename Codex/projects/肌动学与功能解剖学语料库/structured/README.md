# 结构化章节

本目录用于存放经过二次整理的章节级语料。优先级高于 `cleaned/` 和原始 `chunks/`。

推荐读取顺序：

1. 先读本目录对应章节。
2. 需要更细主题时读 `concepts/`。
3. 需要核对原文时读 `cleaned/`。
4. 只有 OCR 疑似错误时回到 `chunks/` 或 `extracted/`。

## 囚徒健身全集

`structured/囚徒健身全集-共4册/` 保存的是阅读整理层，不是 EPUB 原文层。回答自重训练和 HYROX 辅助训练问题时，先读该目录，再按 `index/prisoner-fitness-routing-map.md` 回查 EPUB 抽取文本；涉及肌肉、关节和伤病风险时，还要回查解剖学/肌动学教材语料。
