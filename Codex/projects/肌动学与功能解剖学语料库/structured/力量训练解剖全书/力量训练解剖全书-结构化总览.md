# 力量训练解剖全书-结构化总览

## 项目定位

这本书在本语料库中定位为“力量训练动作库 + 应用解剖参考”。它补充现有解剖学和肌动学教材在具体训练动作、器械选择、常见错误和训练计划上的不足。

使用时分三层：

1. 来源原意：PDF 抽取文本，见 `extracted/力量训练解剖全书/` 与 `cleaned/by-book/力量训练解剖全书/`。
2. 内容提炼：本文件和 `index/strength-training-anatomy-routing-map.md`。
3. 关联推断：结合《基础肌动学》《骨骼肌肉功能解剖学》《运动解剖学》《囚徒健身》后给出的训练建议。

## 与已有项目的关系

- 与《基础肌动学》《骨骼肌肉功能解剖学》：本书给动作和训练提示；两本肌动学教材负责解释关节运动、力矩、肌肉功能和稳定机制。
- 与北体《运动解剖学》：本书可作为运动系统考研答题中的训练例子，但不替代教材定义。
- 与《囚徒健身》：本书偏器械和动作解剖，《囚徒健身》偏自重动作进阶。回答训练计划时可以互相映射，例如卧推/俯卧撑、引体/下拉、深蹲/腿举、卷腹/举腿。
- 与 HYROX：优先检索腿臀、背部、前臂、腰腹章节，用于雪橇、农夫走、沙袋弓步、墙球和疲劳状态下核心稳定的辅助训练设计。

## 回答模板

### 动作分析

1. 动作名称和来源页。
2. 主要肌肉与次要肌肉。
3. 主要关节运动。
4. 动作要领：起始姿势、动作过程、呼吸。
5. 常见错误和风险点。
6. 可替代动作：自由重量、固定器械、徒手版本。
7. 对考研/HYROX/当前训练的适用性。

### 肌群训练

1. 肌肉位置和主要功能。
2. 代表动作分类：自由重量、固定器械、徒手、滑轮。
3. 初学/维护/增肌/力量不同目标的选择。
4. 与解剖学教材的交叉依据。
5. 不推荐或需谨慎的动作。

## OCR 处理

PDF 是扫描/OCR 版本，文字抽取有明显识别错误。回答时应使用规范术语，例如：

- `肱二头肌`，不要沿用 OCR 的 `眩二头肌` 或 `胧二头肌`。
- `肱三头肌`，不要沿用 OCR 的 `胧三头肌`。
- `杠铃`，不要沿用 OCR 的 `杠钤`。
- `肩胛`，不要沿用 OCR 的 `肩肿`、`肩眒`。

需要精确核对动作图、二维码、肌肉标注和变式图时，回到 PDF 图像页。
