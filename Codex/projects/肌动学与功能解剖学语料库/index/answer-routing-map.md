# answer-routing-map

用途：下次回答《基础肌动学 第3版》《骨骼肌肉功能解剖学 第2版》相关问题时，先按问题类型定位资料层，减少反复读取长文本。

## 默认检索顺序

1. `structured/`：手工结构化章节，优先级最高。
2. `concepts/`：概念卡，适合快速回答定义、机制、临床意义。
3. `structured/compiled-chapters/`：按章清洗汇编，适合顺读整章和补证据。
4. `cleaned/by-book/`：按 chunk 清洗语料，适合查细节、页码、局部表述。
5. `chunks/by-book/` 与 `extracted/`：仅在 OCR 疑似错误或需要核对页级来源时使用。

## 问题类型路由

| 用户问题类型 | 优先读取 | 回答结构 |
|---|---|---|
| “某关节结构与功能” | `index/body-region-quick-map.md` -> 对应 compiled chapter -> concepts | 骨性结构 -> 关节面/运动轴 -> 韧带/稳定性 -> 肌肉作用 -> 临床/训练意义 |
| “某动作怎么分析” | `index/exam-answer-templates.md` -> 对应关节章节 -> 肌肉概念卡 | 关节运动 -> 肌肉收缩类型 -> 力矩/力臂 -> 稳定机制 -> 代偿/损伤风险 |
| “比较两个姿势/角度” | 对应 compiled chapter + concepts | 先列变量，再比较骨运动学、关节运动学、肌肉长度-张力、稳定性 |
| “为什么会疼/撞击/不稳” | concepts 中临床卡 -> 对应章节临床段 | 病理力学 -> 受压/受牵组织 -> 诱因 -> 表现 -> 康复方向 |
| “考研简答/论述” | `index/exam-answer-templates.md` -> structured/concepts | 先给可背答案，再给展开逻辑和关键词 |
| “截图学习问题” | `qa/` 现有答案 -> 对应章节补证据 | 逐题回答；每题尽量标注来源章节和页码范围 |
| “术语解释” | `concepts/` -> `index/keyword-index.md` -> cleaned | 定义 -> 构成/机制 -> 例子 -> 易混点 |
| “肌肉神经支配/损伤表现” | 对应章节末附录/肌肉段 -> concepts | 神经根/外周神经 -> 主要肌肉 -> 功能缺失 -> 代偿表现 |

## 回答约束

- 回答时优先使用整理稿中的概念化表达，不直接堆原文。
- 涉及书中细节时标明“依据：书名 + 页码范围”。
- OCR 疑似错误的词，回答中采用规范解剖名，并在必要时说明原语料可能有 OCR 误字。
- 用户要“背诵版”时，输出 150-300 字；用户要“讲师版”时，输出机制链条。
