## 问题类型路由

| 用户问题类型 | 优先读取 | 回答结构 |
|---|---|---|
| “这个动作练哪里” | 对应页级语料 -> 解剖学/肌动学教材交叉核对 | 主要肌肉 -> 次要肌肉 -> 关节运动 -> 稳定需求 -> 常见错误 |
| “某肌群怎么练” | 本书对应肌群章节 -> `index/body-region-quick-map.md` | 肌肉功能 -> 动作分类 -> 自由重量/固定器械/徒手选择 -> 风险边界 |
| “动作怎么做” | 本书动作页 -> 必要时查看 PDF 图像页 | 起始姿势 -> 动作过程 -> 呼吸 -> 常见错误 -> 替代动作 |
| “和囚徒健身怎么结合” | 本路由 -> `index/prisoner-fitness-routing-map.md` | 器械动作与自重动作对应 -> 选择标准 -> 考研阶段最低有效量 |
| “HYROX 辅助训练” | 腿臀、背部、前臂、腰腹章节 -> 囚徒健身整理层 | 跑/雪橇/农夫走/弓步/墙球对应肌群 -> 动作选择 -> 疲劳控制 |
| “考研答题素材” | 本书肌肉功能段 -> `index/exam-answer-templates.md` | 只作训练例子和应用延伸；概念定义仍以教材语料为主 |

## 使用边界

- 本书偏训练动作库和应用解剖，适合回答训练方案、动作要领、所涉肌群和错误动作。
- 解剖定义、关节结构、神经支配、运动系统考研答题，仍优先用《基础肌动学》《骨骼肌肉功能解剖学》《运动解剖学》。
- 疼痛、损伤和康复建议必须保守，并标明哪些是书中内容，哪些是结合项目语料的推断。
