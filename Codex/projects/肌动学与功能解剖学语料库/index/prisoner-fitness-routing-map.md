4. `index/prisoner-fitness-retrieval-map.jsonl`：程序化检索映射。
5. `cleaned/by-book/囚徒健身全集-共4册/`：核对 EPUB 抽取文本。
6. `chunks/by-book/囚徒健身全集-共4册/` 与 `extracted/囚徒健身全集-共4册/`：原始抽取层，必要时核对。

## 使用边界

- 《囚徒健身》是训练哲学和动作进阶库，不是运动康复、疼痛诊断或医学指南。
- 涉及伤病、疼痛、关节不适时，必须回到《基础肌动学》《骨骼肌肉功能解剖学》《运动解剖学》语料核对结构和功能，再给保守建议。
- 高风险动作包括颈桥、极限桥、单臂/单腿最终式、自由倒立、高难人旗、打挺、前翻、后翻；默认不作为考研阶段训练主线。
- 回答时区分三层：EPUB 原文抽取、已有阅读整理、训练应用推断。
