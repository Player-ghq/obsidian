# QA 使用说明

回答本知识库内教材相关问题时：

1. 优先使用本知识库，不重新读取 PDF。
2. 先查 `index/answer-routing-map.md` 判断问题类型和读取顺序。
3. 再查 `index/body-region-quick-map.md` 定位身体部位、章节和页码范围。
4. 考研简答/论述先套 `index/exam-answer-templates.md`。
5. 北体《运动解剖学》运动系统问题先查 `index/beiti-motion-system-structured-index.md`，再按需查 `index/beiti-motion-system-index.md`。
6. 囚徒健身、自重训练、徒手力量、抓握、桥、倒立撑、爆发力、自重增肌、HYROX 辅助训练问题先查 `index/prisoner-fitness-routing-map.md`。
7. 器械力量训练、动作要领、所涉肌肉、常见错误、训练计划问题先查 `index/strength-training-anatomy-routing-map.md`。
8. 再查 `structured/`、`concepts/` 获取高效率整理稿和概念级答题素材。
9. 需要顺读整章时查 `index/compiled-chapter-index.md` 与 `structured/compiled-chapters/`。
10. 需要核对原文时查 `index/cleaned-retrieval-map.jsonl`、`index/beiti-motion-retrieval-map.jsonl`、`index/prisoner-fitness-retrieval-map.jsonl`、`index/strength-training-anatomy-retrieval-map.jsonl` 或 `cleaned/by-book/`。
11. 回答应尽量带上书名与页码范围，例如“依据《骨骼肌肉功能解剖学 第2版》p.120-126”或“依据北体《运动解剖学》p.30-66”；囚徒健身以卷册、章节和 EPUB 条目标注。
12. 若清洗层文字明显错漏，再回到原始 `chunks/by-book/` 或 `extracted/` 查页级/条目级文本；只有页级文本也不足时，才提示需要重新查看 PDF 或 EPUB 原件。
13. 面向考研答题时，优先把知识转写为“概念-结构-功能-运动/康复意义-易混点”的格式。
14. 囚徒健身和力量训练解剖全书内容用于训练进阶、动作库和训练组织；涉及肌肉、关节、疼痛、损伤风险时，必须回查解剖学/肌动学语料后再做推断。
