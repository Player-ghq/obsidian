# QA 使用说明

回答这两本书相关问题时：

1. 优先使用本知识库，不重新读取 PDF。
2. 先查 `index/chapter-index.md`、`index/concept-index.md` 与 `structured/` 定位高效率整理稿。
3. 再查 `concepts/` 获取概念级答题素材。
4. 需要顺读整章时查 `index/compiled-chapter-index.md` 与 `structured/compiled-chapters/`。
5. 需要核对原文时查 `index/cleaned-retrieval-map.jsonl` 或 `cleaned/by-book/`。
6. 回答应尽量带上书名与页码范围，例如“依据《骨骼肌肉功能解剖学 第2版》p.120-126”。
7. 若清洗层文字明显错漏，再回到原始 `chunks/by-book/` 或 `extracted/` 查页级文本；只有页级文本也不足时，才提示需要重新查看 PDF 图像页。
8. 面向考研答题时，优先把知识转写为“概念-结构-功能-运动/康复意义-易混点”的格式。
