# 运动康复真题与出题系统

本目录保存上海体育大学运动康复考研出题系统，已从旧项目迁入当前“肌动学与功能解剖学语料库”项目。

## 目录

- `每日晨测/`：每日 300 分整卷晨测，题目与答案分开保存。
- `outputs/`：2023-2025 真题 OCR 整理、分类表、关键词表、Excel/CSV/Markdown 交付物。
- `真题原图/上海体育大学/`：已人工核对并集中归档的上体运动康复回忆版原图。
- `scripts/`：OCR、真题整理、关键词标注、表格测试和历史 PDF 生成脚本。

## 当前规则

- 每日晨测只默认生成 Markdown，不再生成 PDF。
- 题目：`每日晨测/题目/YYYY-MM-DD-题目.md`
- 答案：`每日晨测/答案/YYYY-MM-DD-答案.md`
- 每次自动化运行前先检查缺失日期，缺题目或答案则按日期顺序补齐。
- 出题结构固定为 300 分：解剖 100 分、生理 100 分、康复 100 分；每科 2 道 25 分简答 + 1 道 50 分论述/动作分析/案例题。
- 题目文件必须明确写出 `考纲模块` 和 `知识点明细`，但仍保持一张紧凑表格，方便打印。
- 答案文件每题必须包含 `考纲定位`、`知识点明细`、`完整参考答案`、`背诵稿够用性`、`需要补充`、`可直接加入背诵稿`。若背诵稿不够，不能只指出缺口，必须直接写出可并入背诵稿的补充段落。
- 这里的“背诵稿”指用户此前其他对话已生成并保存在知识库里的背诵稿，不是临时泛称。每日晨测判定够用性前，应优先检索：
  - 解剖：`qa/背诵稿/`。
  - 生理：`运动生理学-王瑞元苏全生/背诵稿-*.md` 及同项目后续生理背诵稿。
  - 康复：若尚无主稿，先写入 `qa/背诵稿/晨测补充/`，后续可再并入康复专题主稿。
- 若判定需要补充，除在答案文件中写 `可直接加入背诵稿` 外，还必须同步生成或更新 `qa/背诵稿/晨测补充/YYYY-MM-DD-晨测补充.md`，确保补充内容沉淀到背诵稿体系中。
