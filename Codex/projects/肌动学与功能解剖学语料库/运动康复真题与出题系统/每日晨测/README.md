# 每日晨测

本目录保存上海体育大学运动康复考研每日晨测。

## 目录规则

- `题目/`：保存当天题目 Markdown；不再默认生成 PDF。
- `答案/`：保存当天详细答案解析 Markdown，用于线上查看，不要求压缩。

## 命名规则

- 题目：`YYYY-MM-DD-题目.md`
- 答案：`YYYY-MM-DD-答案.md`

## 出题规则

- 默认 300 分：解剖、生理、康复每天都出，每科 100 分。
- 每科题型：2 道 25 分简答 + 1 道 50 分论述/动作分析/案例题。
- 每天轮换的是各科内部的考纲模块和知识点，不再轮换单一学科。
- 依据上海体育大学运动康复考纲、2023-2025 上体真题结构和已整理的 1706 条真题关键词表。

## 输出格式

- 题目 Markdown 使用一张紧凑表格：题号、科目、分值、模块/关键词、依据、题目。
- 答案 Markdown 保留详细解析、评分点、标准框架和易丢分点，适合线上查看。
- 每次自动化运行前，先检查从最近一次已生成日期到今天之间是否缺少题目或答案；若缺失，按日期顺序补齐。
