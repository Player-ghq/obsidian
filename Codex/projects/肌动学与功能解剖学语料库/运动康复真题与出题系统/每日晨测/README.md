# 每日晨测

本目录保存上海体育大学运动康复考研每日晨测。

## 目录规则

- `题目/`：保存当天题目 Markdown；不再默认生成 PDF。
- `答案/`：保存当天详细答案解析 Markdown，用于线上查看，不要求压缩。
- `每日题目汇总.md`：汇总所有每日晨测题目，按解剖、生理、康复三科分段分类。
- `../../qa/背诵稿/晨测补充/`：保存每日晨测发现的背诵稿补充内容，属于用户已有背诵稿体系的一部分。

## 命名规则

- 题目：`YYYY-MM-DD-题目.md`
- 答案：`YYYY-MM-DD-答案.md`

## 出题规则

- 默认 300 分：解剖、生理、康复每天都出，每科 100 分。
- 每科题型：2 道 25 分简答 + 1 道 50 分论述/动作分析/案例题。
- 每天轮换的是各科内部的考纲模块和知识点，不再轮换单一学科。
- 依据上海体育大学运动康复考纲、2023-2025 上体真题结构和已整理的 1706 条真题关键词表。

## 输出格式

- 题目 Markdown 使用一张紧凑表格：题号、科目、分值、考纲模块、知识点明细、依据、题目。题目仍以打印紧凑为优先，不写答案和长段说明。
- 答案 Markdown 保留详细解析、评分点、完整参考答案和易丢分点，适合线上查看；不能只给提纲或答题框架。
- 答案中每题必须额外写明：
  - `考纲定位`：对应上海体育大学运动生理学/人体解剖学考纲模块；康复题写明对应真题高频方向或康复能力模块。
  - `知识点明细`：把题目拆成可背诵的 3-6 个小知识点，不能只写宽泛关键词。
  - `背诵稿够用性`：必须先检索用户已有背诵稿，再判断是否足以覆盖本题，使用 `够用`、`基本够用但需补充`、`不够用` 三档。
  - `需要补充`：若不是“够用”，明确列出应补的概念、机制链、动作分析要点、评定指标或分期方案。
  - `可直接加入背诵稿`：若背诵稿需要补充，必须直接写出一段可复制进背诵稿的补充内容；不能只提示“建议补充”。
- “用户已有背诵稿”优先指：
  - 解剖：`../../qa/背诵稿/` 下的系统背诵稿与高颗粒度专题。
  - 生理：`../../运动生理学-王瑞元苏全生/背诵稿-*.md` 及同项目下后续新增背诵稿。
  - 康复：若尚无对应主稿，则把补充写入 `../../qa/背诵稿/晨测补充/`，并在答案中注明“暂无康复主稿，已沉淀为晨测补充稿”。
- 每次生成答案后，若任一题判定为 `基本够用但需补充` 或 `不够用`，必须同步写入 `../../qa/背诵稿/晨测补充/YYYY-MM-DD-晨测补充.md`；补充稿按 解剖/生理/康复 分段，保留题号、考纲定位、目标背诵稿或待归档主稿、补充正文。
- 每次自动化运行前，先检查从最近一次已生成日期到今天之间是否缺少题目或答案；若缺失，按日期顺序补齐。
- 每次生成或补齐晨测后，运行 `../scripts/update_daily_question_summary.py` 刷新 `每日题目汇总.md`。

## 汇总表规则

- 汇总表来源只读取 `题目/YYYY-MM-DD-题目.md`，不读取答案文件。
- 汇总表按 `解剖`、`生理`、`康复` 三个章节分类。
- 每行字段：日期、原题号、分值、考纲模块、知识点明细、依据、题目、来源。
- 汇总脚本兼容旧版 `模块关键词` 单列题目表；旧题会把原 `模块关键词` 同时写入 `考纲模块` 和 `知识点明细`。
- 汇总表用于查重、轮换知识点、回看每日出题覆盖面。
