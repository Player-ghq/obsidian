## 一、解剖｜100 分

### 第 1 题｜25 分

答案关键词：骨膜、骨质、骨髓；骨密质、骨松质；骨的血管神经；骨密度；骨小梁排列；力学适应；抗压抗弯能力。

标准答题框架：先写骨的构造，再写各结构功能，最后写体育锻炼对骨形态和功能的长期影响。

评分点：

- 骨的基本构造：骨膜、骨质、骨髓，6 分
- 骨密质与骨松质特点，5 分
- 骨的血供、神经和代谢更新，4 分
- 体育锻炼对骨密度、骨小梁、骨粗隆/附着点的影响，6 分
- 训练适应与损伤预防意义，4 分

易丢分点：只写“骨变粗、骨密度增加”，没有解释力学负荷如何影响骨结构和功能。

### 第 2 题｜25 分

答案关键词：股胫关节、髌股关节；关节囊；半月板；前后交叉韧带；内外侧副韧带；屈伸；股四头肌；腘绳肌；腓肠肌。

标准答题框架：组成结构 -> 辅助结构 -> 运动形式 -> 屈伸肌群 -> 稳定性和损伤联系。

评分点：

- 膝关节组成与关节面，5 分
- 半月板、韧带、关节囊等辅助结构，7 分
- 主要运动形式：屈、伸及轻度旋转，4 分
- 伸膝主要肌群：股四头肌，3 分
- 屈膝主要肌群：股二头肌、半腱肌、半膜肌、腓肠肌等，4 分
- 结构与稳定性/运动损伤联系，2 分

易丢分点：漏写半月板和交叉韧带，或者只背肌肉名，不说明结构对稳定性的意义。

### 第 3 题｜50 分

答案关键词：下蹲期、起立期；髋屈伸、膝屈伸、踝背屈跖屈；臀大肌、股四头肌、腘绳肌、竖脊肌、小腿三头肌；离心、向心、等长；核心稳定；膝内扣风险；髋膝踝协同。

标准答题框架：动作阶段 -> 关节运动 -> 肌肉工作形式 -> 力学风险 -> 训练/康复意义。

评分点：

- 动作阶段划分：准备、下蹲、底部控制、起立，6 分
- 关节运动分析：髋、膝、踝、脊柱，10 分
- 下蹲期肌肉离心控制，8 分
- 起立期肌肉向心收缩，8 分
- 躯干和核心稳定作用，6 分
- 力学风险：膝内扣、腰椎代偿、足弓塌陷等，6 分
- 训练与康复意义：下肢力量、动作控制、膝/髋/腰损伤预防，6 分

易丢分点：只写“股四头肌发力”，没有分阶段说明离心/向心/等长工作，也没有分析髋膝踝协同。

## 二、生理｜100 分

### 第 4 题｜25 分

答案关键词：运输氧气和二氧化碳；运输营养物质和代谢产物；缓冲酸碱；维持体温；免疫防御；凝血；内环境稳态；血容量与心血管功能。

标准答题框架：血液功能分类 -> 运动中功能意义 -> 训练或康复监控价值。

评分点：

- 运输功能：气体、营养物质、代谢产物、激素，7 分
- 调节功能：酸碱平衡、体温、水盐平衡，6 分
- 防御和保护功能：免疫、凝血，5 分
- 运动训练中的意义：氧运输能力、代谢清除、耐力表现，5 分
- 与运动康复安全性的联系，2 分

易丢分点：只罗列血液功能，没有联系运动能力、耐力训练或康复训练监控。

### 第 5 题｜25 分

答案关键词：磷酸原系统；糖酵解系统；有氧氧化系统；供能速度；供能容量；乳酸；运动强度和持续时间；专项适应。

标准答题框架：分别说明三大系统特点 -> 对应项目举例 -> 强调三系统按比例共同参与 -> 训练意义。

评分点：

- 磷酸原系统特点及 100 米应用，6 分
- 糖酵解系统特点及 400 米应用，6 分
- 有氧氧化系统特点及马拉松应用，6 分
- 三大供能系统不是孤立工作，需按强度和时间比例变化，4 分
- 对训练安排或康复运动强度控制的意义，3 分

易丢分点：把三大供能系统机械对应三个项目，忽视不同系统在同一运动中同时参与但比例不同。

### 第 6 题｜50 分

答案关键词：胰岛素；胰高血糖素；肾上腺素；糖皮质激素；生长激素；肝糖原分解；糖异生；肌糖原利用；运动强度；低血糖风险；运动处方安全。

标准答题框架：血糖来源去路 -> 降糖激素 -> 升糖激素 -> 不同运动强度下调节 -> 运动表现和康复安全。

评分点：

- 血糖来源和去路：肝糖原、肌糖原、糖异生、组织摄取，8 分
- 胰岛素降低血糖的机制，7 分
- 胰高血糖素、肾上腺素、糖皮质激素等升糖作用，10 分
- 不同强度运动中血糖调节特点，8 分
- 血糖稳定对运动表现、疲劳和中枢功能的意义，7 分
- 运动康复训练中的安全控制：糖尿病、低血糖、监测和补给，7 分
- 答题结构清晰，能把机制和应用连接，3 分

易丢分点：只写激素名称，不写作用机制；只谈内分泌，不联系运动强度和康复安全。

## 三、康复｜100 分

### 第 7 题｜25 分

答案关键词：肱骨外上髁；腕伸肌总腱；过度使用；疼痛诱发试验；握力；活动度；离心训练；负荷管理；物理因子；回归运动。

标准答题框架：机制 -> 评定 -> 疼痛期处理 -> 恢复期训练 -> 预防复发。

评分点：

- 发病机制：腕伸肌总腱反复牵拉、退变、局部疼痛，6 分
- 康复评定：疼痛、压痛点、抗阻伸腕试验、握力、功能量表，7 分
- 急性/疼痛期处理：减负、疼痛控制、物理治疗，4 分
- 恢复期训练：牵伸、离心抗阻、肩肘腕链条控制，5 分
- 回归运动和复发预防，3 分

易丢分点：把网球肘简单写成“炎症”，没有指出过度使用和肌腱病特点；训练方案没有分期。

### 第 8 题｜25 分

答案关键词：神经病理性疼痛；伤害感受性疼痛；肌骨疼痛；疼痛部位和性质；VAS/NRS；感觉评定；痉挛；体位管理；药物配合；运动治疗；心理教育。

标准答题框架：疼痛类型 -> 评定维度 -> 相关功能问题 -> 康复处理原则 -> 风险控制。

评分点：

- 疼痛类型：神经病理性、肌骨疼痛、内脏/继发疼痛等，6 分
- 评定要点：疼痛强度、性质、诱因、感觉障碍、功能影响，7 分
- 与脊髓损伤相关问题联系：痉挛、压疮、关节僵硬、姿势异常，4 分
- 康复处理原则：体位、关节活动、肌力和平衡训练、物理因子、教育，5 分
- 风险控制和多学科处理，3 分

易丢分点：只写“止痛”，没有区分疼痛类型，也没有把疼痛和功能训练、体位管理联系起来。

### 第 9 题｜50 分

答案关键词：全膝关节置换；疼痛肿胀控制；关节活动度；股四头肌激活；步态训练；肌力训练；平衡训练；功能训练；禁忌动作；分期目标。

标准答题框架：总原则 -> 早期目标/评定/训练 -> 中期目标/评定/训练 -> 后期目标/评定/训练 -> 禁忌和进阶标准。

评分点：

- 总原则：保护假体、控制疼痛肿胀、恢复 ROM、重建肌力和步态，8 分
- 术后早期目标：消肿止痛、预防血栓、股四头肌激活、床上和转移训练，8 分
- 早期评定：疼痛、肿胀、切口、ROM、肌力、步行能力，6 分
- 中期目标和训练：ROM 提升、闭链力量、步态纠正、平衡训练，8 分
- 后期目标和训练：耐力、上下楼、日常功能、低冲击运动回归，8 分
- 禁忌和风险控制：感染、血栓、过大冲击、疼痛肿胀反复，6 分
- 答题结构：按分期写目标、评定、训练、进阶标准，6 分

易丢分点：只列训练动作，没有写分期目标、评定指标和进阶标准；忽视术后风险控制。
