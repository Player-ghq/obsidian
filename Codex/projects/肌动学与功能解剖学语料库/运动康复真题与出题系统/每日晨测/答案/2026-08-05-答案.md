# 2026-08-05 上体运动康复晨测｜答案与评分

总分 300 分。答题时优先使用“结构/机制 -> 功能表现 -> 评定或训练意义 -> 风险控制”的框架。

## 1. 肩关节和髋关节比较（25分）

**分类与模块**：解剖；上肢/下肢关节；肩髋比较；真题同源变式。

**答案关键词**：球窝关节、盂浅囊松、髋臼深、盂唇/髋臼唇、肩袖、关节囊韧带、灵活性、稳定性、脱位、撞击、动力链。

**评分点**：
- 结构共同点：均为多轴球窝关节，可做屈伸、收展、旋转和环转，均有盂/臼、关节囊、韧带和周围肌肉稳定。（5分）
- 肩关节特点：肱骨头大、关节盂浅、囊薄松，运动范围大，静态稳定弱，依赖肩袖、肩胛控制和盂唇。（6分）
- 髋关节特点：髋臼深、关节囊韧带强，负重和稳定性强，运动范围相对小，依赖骨性包容和髋周肌群。（6分）
- 功能差异：肩偏向灵活操作和投掷，髋偏向承重、推进和下肢力线控制。（4分）
- 损伤与训练意义：肩易不稳、撞击、肩袖问题；髋易撞击、软组织紧张或力量失衡，训练需兼顾活动度、稳定性和动力链。（4分）

**标准答题框架**：先写共同分类，再按“骨性结构-囊韧带-肌肉稳定-功能-损伤风险”比较，最后回到运动训练和康复意义。

**易丢分点**：只说“肩灵活、髋稳定”而不解释结构原因；忽略肩胛胸廓和骨盆对两个关节功能的影响；不写损伤意义。

## 2. 膈肌的结构与运动意义（25分）

**分类与模块**：解剖；躯干/胸腔结构；膈肌；考纲高频原创。

**答案关键词**：胸腹腔分隔、中心腱、腰肋胸骨部、膈顶下降、吸气肌、腹压、核心稳定、腰椎控制、呼吸训练。

**评分点**：
- 位置形态：膈肌位于胸腹腔之间，呈穹隆状，由胸骨部、肋部、腰部和中心腱构成。（5分）
- 呼吸功能：收缩时膈顶下降、胸腔容积增大、胸内压降低，引起吸气；放松时参与呼气回位。（6分）
- 与腹压和核心稳定：膈肌与腹横肌、盆底肌、多裂肌协同调节腹内压，参与腰椎稳定。（5分）
- 运动意义：高强度运动中影响通气效率、躯干抗伸展/抗旋转能力和动作稳定。（5分）
- 康复意义：呼吸模式训练可用于颈肩腰痛、核心控制不足和运动耐力训练。（4分）

**标准答题框架**：位置组成 -> 吸气机制 -> 腹压与核心 -> 运动表现 -> 康复应用。

**易丢分点**：把膈肌只当作呼吸肌；漏写中心腱和三部分起点；不说明躯干稳定意义。

## 3. 深蹲动作解剖学分析（50分）

**分类与模块**：解剖；运动动作解剖学分析；深蹲；考纲高频原创。

**答案关键词**：下蹲/上升阶段、髋膝踝屈伸、矢状面、臀大肌、股四头肌、腘绳肌、竖脊肌、离心/向心、膝内扣、腰椎屈曲、足弓控制。

**评分点**：
- 阶段划分：准备位、下降期、底部控制、上升期，并说明主要动作目标。（6分）
- 关节运动：下降期髋屈、膝屈、踝背屈；上升期髋伸、膝伸、踝跖屈趋势；躯干需维持中立。（10分）
- 肌肉工作：下降期股四头肌、臀大肌、腘绳肌、竖脊肌多为离心/等长控制；上升期臀大肌、股四头肌向心发力，核心等长稳定。（12分）
- 力线与稳定：髋-膝-足对线，膝盖与足尖方向一致，足弓稳定，骨盆和躯干控制影响负荷分配。（8分）
- 风险控制：膝内扣、足过度旋前、腰椎屈曲、骨盆眨眼、踝背屈不足和负荷过快增加会提高膝腰髋风险。（8分）
- 训练/康复意义：可用于下肢力量、髋膝控制和功能动作训练；康复中需按疼痛、活动度、力量和动作质量进阶。（6分）

**标准答题框架**：阶段 -> 平面轴与关节运动 -> 肌肉工作 -> 力线和稳定 -> 常见错误 -> 训练/康复应用。

**易丢分点**：只写肌肉名称不写工作形式；忽略踝背屈和足弓；没有把动作错误和损伤风险联系起来。

## 4. 内环境稳态与运动安全（25分）

**分类与模块**：生理；细胞/内环境；稳态调节；真题同源变式。

**答案关键词**：细胞外液、理化性质、神经调节、体液调节、自身调节、负反馈、酸碱、温度、血糖、康复监控。

**评分点**：
- 概念：内环境主要指细胞外液，稳态指其理化性质保持相对稳定。（5分）
- 调节方式：神经调节反应快，体液调节作用广，自身调节局部精细，负反馈是主要方式。（7分）
- 运动变化：运动会改变体温、血糖、酸碱、水盐、血压和氧供需，需要动态调节。（5分）
- 训练意义：稳态维持是运动能力和恢复的基础，决定运动强度耐受和疲劳出现。（4分）
- 康复安全：慢病、术后和高风险人群需监测心率、血压、症状、血糖或疼痛反应。（4分）

**标准答题框架**：定义 -> 调节机制 -> 运动扰动 -> 训练意义 -> 康复安全。

**易丢分点**：把稳态写成“完全不变”；只写神经调节而漏体液/自身调节；不联系运动和康复。

## 5. 运动性疲劳与恢复（25分）

**分类与模块**：生理；运动性疲劳与恢复；考纲高频原创。

**答案关键词**：中枢疲劳、外周疲劳、能量耗竭、代谢产物、神经肌肉兴奋性、心率恢复、RPE、睡眠、营养、主动恢复。

**评分点**：
- 概念：运动性疲劳是运动能力暂时下降，经休息和恢复可改善。（4分）
- 中枢机制：中枢驱动下降、神经递质变化、动机和感觉负荷变化。（4分）
- 外周机制：ATP/糖原减少、无机磷和氢离子增加、钙离子处理受影响、肌纤维损伤。（7分）
- 判断指标：运动表现下降、RPE升高、动作质量下降、心率恢复变慢、乳酸或肌酸激酶等指标变化。（5分）
- 恢复方法：睡眠、补糖补液、蛋白摄入、主动恢复、拉伸放松、负荷管理和心理恢复。（5分）

**标准答题框架**：概念 -> 中枢/外周机制 -> 指标 -> 恢复方法 -> 训练安排意义。

**易丢分点**：只写乳酸堆积；忽略中枢疲劳和神经肌肉兴奋性；恢复方法没有和疲劳机制对应。

## 6. 三大供能系统与跑类项目特点（50分）

**分类与模块**：生理；物质与能量代谢/主要运动项目生理特点；真题同源变式。

**答案关键词**：磷酸原系统、糖酵解、有氧氧化、供能速率、供能容量、乳酸、短跑、中跑、长跑、专项训练。

**评分点**：
- 磷酸原系统：供能最快、容量小、不需氧，主要支持极短时间最大强度运动，如起跑和冲刺。（8分）
- 糖酵解系统：供能速度较快、容量中等，可产生乳酸，适合高强度持续几十秒至数分钟运动。（8分）
- 有氧氧化系统：供能速度较慢、容量大，依赖氧供应，适合长时间耐力运动。（8分）
- 项目比较：短跑以磷酸原为主并有糖酵解参与；中跑糖酵解和有氧共同重要；长跑以有氧供能为主并受糖脂代谢能力影响。（10分）
- 训练启示：短跑重爆发力、神经动员和充分间歇；中跑重乳酸耐受、速度耐力和有氧基础；长跑重有氧能力、跑步经济性和补给策略。（10分）
- 康复/安全意义：处方中应根据患者能力选择强度、间歇和总量，避免代谢负荷过高。（6分）

**标准答题框架**：逐一写系统特点 -> 按项目比较主导供能 -> 转化为训练和康复处方启示。

**易丢分点**：把三大系统割裂为单一供能；不写供能速率和容量；只背短跑/长跑结论，不解释原因。

## 7. 肱骨外上髁炎康复（25分）

**分类与模块**：康复；运动损伤康复/康复评定；真题同源变式。

**答案关键词**：伸腕肌总腱、过度使用、疼痛诱发、握力、Cozen试验、离心训练、负荷管理、手法/物理因子、回归标准。

**评分点**：
- 机制：多与伸腕肌群尤其桡侧腕短伸肌反复牵拉和退变有关，表现为外上髁区域疼痛。（5分）
- 评定：疼痛部位和诱发动作、握力、腕伸抗阻、Cozen/Mill试验、肘腕肩功能和工作运动负荷。（7分）
- 治疗原则：相对休息和负荷调整，控制疼痛，改善腕伸肌腱耐受和上肢链控制。（5分）
- 训练内容：腕伸肌等长、离心/重慢抗阻、前臂旋前旋后、握力、肩胛肩袖力量训练。（6分）
- 进阶标准：疼痛可控、握力恢复、专项动作无明显症状后逐步回归。（2分）

**标准答题框架**：病因机制 -> 评定 -> 急性/慢性处理 -> 渐进负荷 -> 回归标准。

**易丢分点**：把它当作单纯炎症长期制动；只写理疗不写运动治疗；漏掉腕伸肌腱负荷进阶。

## 8. 腰椎间盘相关下腰痛康复（25分）

**分类与模块**：康复；脊柱康复/核心控制；考纲高频原创。

**答案关键词**：椎间盘、纤维环、髓核、神经根刺激、方向偏好、疼痛筛查、核心稳定、髋铰链、负荷管理。

**评分点**：
- 机制：椎间盘结构改变、反复屈曲负荷或压缩剪切力可诱发下腰痛，严重时刺激神经根。（5分）
- 筛查：疼痛部位、放射痛、感觉肌力反射、直腿抬高、红旗征、日常和训练负荷。（6分）
- 康复原则：疼痛教育、避免诱发负荷、寻找方向偏好、逐步恢复活动和功能。（5分）
- 训练内容：腹压控制、深层核心激活、髋铰链、臀肌训练、步行/低冲击有氧和渐进抗阻。（6分）
- 风险控制：症状加重、进行性神经体征、夜间痛或大小便异常需转诊。（3分）

**标准答题框架**：结构机制 -> 临床表现与筛查 -> 运动治疗原则 -> 进阶训练 -> 转诊风险。

**易丢分点**：笼统写“加强腰背肌”；忽略神经症状筛查；过早安排高负荷屈曲或扭转。

## 9. ACL重建术后康复方案（50分）

**分类与模块**：康复；术后分期方案/回归运动；跨学科综合原创。

**答案关键词**：前交叉韧带、胫骨前移、移植物保护、肿胀疼痛、ROM、股四头肌、闭链训练、本体感觉、跳跃测试、对称指数、心理准备。

**评分点**：
- 总原则：保护移植物，控制疼痛肿胀，恢复伸膝和屈膝活动度，重建力量、神经肌肉控制和专项能力。（6分）
- 早期阶段：消肿止痛、获得完全伸膝、恢复股四头肌激活、髌骨活动、直腿抬高、步态训练，避免过早剪切力。（8分）
- 中期阶段：逐步恢复ROM，闭链力量训练，臀肌和腘绳肌训练，平衡和本体感觉，规范下肢力线。（9分）
- 后期阶段：力量强化、单腿控制、跑跳落地、变向减速和专项动作，由低强度到高强度进阶。（9分）
- 评定指标：疼痛肿胀、ROM、股四头肌力量、单腿下蹲质量、跳跃测试、Y平衡、患者报告量表和心理准备。（8分）
- 回归标准：无肿胀疼痛，活动度接近健侧，力量和跳跃对称性通常达到约90%以上，动作质量合格，专项训练耐受。（7分）
- 禁忌与风险：避免带痛硬推、膝内扣、过早对抗变向、忽视疲劳状态下动作控制。（3分）

**标准答题框架**：损伤结构 -> 术后目标 -> 分期康复 -> 评定指标 -> 回归运动标准 -> 风险控制。

**易丢分点**：只按时间写阶段而不写进入下一阶段标准；漏掉完全伸膝和股四头肌激活；回归运动只看时间不看测试。
