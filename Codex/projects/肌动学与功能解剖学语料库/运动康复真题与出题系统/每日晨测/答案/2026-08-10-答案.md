# 2026-08-10 上体运动康复晨测｜答案与评分

总分 300 分。答题时注意把“基础机制”写到“训练或康复应用”，每题都要有结构化层次。

## 1. 肘关节与前臂旋转（25分）

**分类与模块**：解剖；上肢关节；肘关节/前臂旋转；考纲高频原创。

**答案关键词**：肱尺关节、肱桡关节、桡尺近侧关节、桡尺远侧关节、屈伸、旋前旋后、肱二头肌、肱肌、肱三头肌、旋前圆肌、旋后肌。

**评分点**：
- 组成：肘关节复合体包括肱尺、肱桡、桡尺近侧关节，前臂旋转还依赖桡尺远侧关节和骨间膜。（6分）
- 运动形式：肘主要屈伸，前臂可做旋前和旋后，旋转轴大致经过桡骨头和尺骨头。（5分）
- 屈伸肌群：肱肌、肱二头肌、肱桡肌参与屈肘，肱三头肌和肘肌参与伸肘。（5分）
- 旋转肌群：旋前圆肌、旋前方肌参与旋前，旋后肌和肱二头肌参与旋后。（5分）
- 运动/康复意义：投掷、支撑、抓握和上肢闭链训练都需肘腕肩协同，旋转受限会影响功能动作。（4分）

**标准答题框架**：关节组成 -> 运动形式 -> 屈伸肌群 -> 旋转肌群 -> 运动康复意义。

**易丢分点**：只写肱尺关节；漏掉桡尺远侧关节；把肱二头肌只写成屈肘肌，忽略旋后作用。

## 2. 肝脏功能解剖与运动代谢（25分）

**分类与模块**：解剖；内脏学/运动与系统关系；肝脏；考纲高频原创。

**答案关键词**：右季肋区、肝小叶、门静脉、肝动脉、胆汁、糖原、糖异生、脂代谢、解毒、运动供能。

**评分点**：
- 位置形态：肝主要位于右季肋区和上腹部，是人体重要实质性消化腺和代谢器官。（4分）
- 血供特点：有肝动脉和门静脉双重血供，门静脉带来消化道吸收物质。（5分）
- 基本结构功能：肝小叶是基本结构单位，肝细胞参与代谢、胆汁生成和解毒。（5分）
- 运动代谢：肝糖原分解和糖异生维持血糖，参与脂肪、蛋白质代谢和乳酸转化。（7分）
- 训练/康复意义：长时间运动、低血糖风险、代谢异常和营养恢复都与肝功能相关。（4分）

**标准答题框架**：位置 -> 血供 -> 基本结构 -> 主要功能 -> 运动代谢意义。

**易丢分点**：只写肝脏“解毒”；不写门静脉和肝动脉；不联系血糖维持。

## 3. 墙球动作解剖学分析（50分）

**分类与模块**：解剖；运动动作解剖学分析；墙球；跨学科综合原创。

**答案关键词**：深蹲、髋膝踝伸展、肩屈、肘伸、腕指控制、臀大肌、股四头肌、三角肌、肱三头肌、核心稳定、接球缓冲。

**评分点**：
- 阶段划分：接球准备、下蹲缓冲、上升发力、上肢投掷、接球再缓冲。（6分）
- 下肢运动：下蹲期髋膝屈、踝背屈；上升期髋膝伸、踝跖屈趋势，以下肢伸展传递力量。（8分）
- 上肢运动：投掷期肩屈/上举、肘伸、腕指控制；接球期肩肘腕离心缓冲。（8分）
- 肌肉工作：臀大肌、股四头肌、小腿三头肌向心发力；三角肌、前锯肌、斜方肌、肱三头肌参与上举投掷；核心维持躯干稳定。（12分）
- 动力链：力量由下肢经骨盆躯干传至上肢，动作效率取决于节奏和协同。（5分）
- 风险控制：避免膝内扣、腰椎过伸、肩胛控制差、接球僵硬和疲劳下动作崩坏。（7分）
- 训练/康复意义：可训练下肢力量、上肢推举和全身协调；康复后期才适合加入。（4分）

**标准答题框架**：阶段 -> 下肢 -> 上肢 -> 肌肉工作 -> 动力链 -> 风险和应用。

**易丢分点**：只写深蹲或只写投掷；不写接球离心缓冲；忽略肩胛上旋和核心稳定。

## 4. 动作电位与骨骼肌收缩（25分）

**分类与模块**：生理；细胞基本功能；动作电位；考纲高频原创。

**答案关键词**：静息电位、阈电位、去极化、复极化、钠通道、钾通道、全或无、传导、神经肌肉接头、兴奋收缩耦联。

**评分点**：
- 静息基础：细胞膜内外离子分布和膜通透性形成静息电位。（4分）
- 产生过程：刺激达阈值后钠通道开放，钠内流去极化；随后钾外流复极化。（7分）
- 特点：动作电位具有全或无、可传播、不衰减等特点，并有不应期。（5分）
- 传导意义：兴奋沿神经纤维传导至神经肌肉接头，引发递质释放和肌膜兴奋。（5分）
- 收缩意义：肌膜兴奋经T管和肌浆网钙释放引起兴奋-收缩耦联，是骨骼肌收缩前提。（4分）

**标准答题框架**：静息电位 -> 去极化/复极化 -> 特点 -> 神经传导 -> 兴奋收缩耦联。

**易丢分点**：只写“钠进钾出”；不写阈值和全或无；不联系肌浆网钙释放。

## 5. 运动技能形成的神经机制（25分）

**分类与模块**：生理；运动技能形成；条件反射/动力定型；考纲高频原创。

**答案关键词**：条件反射、动力定型、反馈、感觉信息、大脑皮层、小脑、基底节、泛化、分化、自动化。

**评分点**：
- 条件反射：运动技能是在练习中建立暂时神经联系和条件反射的过程。（5分）
- 动力定型：反复练习使动作程序稳定化，形成较固定的神经活动模式。（5分）
- 阶段变化：通常经历泛化、分化、巩固自动化阶段，动作从粗糙到精确省力。（5分）
- 反馈调节：视觉、本体感觉、前庭觉等反馈帮助纠错，小脑和基底节参与协调和程序优化。（6分）
- 训练/康复意义：技能学习需重复、反馈、任务特异和逐步增加复杂度，康复训练也应任务导向。（4分）

**标准答题框架**：条件反射 -> 动力定型 -> 阶段 -> 反馈和中枢 -> 训练康复应用。

**易丢分点**：只背阶段名称；不写反馈；不联系康复任务训练。

## 6. 应急反应与运动负荷调控（50分）

**分类与模块**：生理；内分泌/机能状态；应急反应；真题同源变式。

**答案关键词**：交感-肾上腺髓质、下丘脑-垂体-肾上腺轴、儿茶酚胺、皮质醇、心率血压、血糖、脂肪动员、警觉性、负荷监控。

**评分点**：
- 神经内分泌通路：应急反应主要涉及交感-肾上腺髓质系统和下丘脑-垂体-肾上腺轴。（8分）
- 心血管表现：心率、心肌收缩力和血压上升，血流向骨骼肌等重要组织重新分配。（8分）
- 代谢表现：儿茶酚胺和皮质醇促进糖原分解、糖异生和脂肪动员，提高可利用能量。（8分）
- 呼吸和神经表现：呼吸加快，警觉性和兴奋性提高，但过度应激会影响动作控制和恢复。（6分）
- 训练比赛意义：适度应急有助于比赛动员，过强可导致紧张、动作变形、疲劳积累和恢复不足。（7分）
- 康复监控意义：高风险人群需监控心率、血压、RPE、症状和疼痛，避免超过耐受范围。（8分）
- 调控策略：热身、呼吸放松、负荷递增、睡眠恢复和心理调节可帮助控制应激水平。（5分）

**标准答题框架**：通路 -> 心血管 -> 代谢 -> 神经呼吸 -> 训练意义 -> 康复监控 -> 调控。

**易丢分点**：只写肾上腺素；不写HPA轴；不区分适度动员和过度应激。

## 7. 颈源性头痛康复（25分）

**分类与模块**：康复；疼痛康复/姿势控制；颈源性头痛；考纲高频原创。

**答案关键词**：上颈椎、枕下肌、头前伸、关节活动受限、深颈屈肌、胸椎活动、肩胛控制、疼痛教育。

**评分点**：
- 机制：上颈椎关节、枕下肌紧张、头前伸姿势和颈肩肌控制失衡可诱发或维持头痛。（6分）
- 评定：头痛部位和诱因、颈椎ROM、上颈段活动、压痛、深颈屈肌耐力、姿势和神经红旗。（7分）
- 治疗原则：疼痛教育，减少诱发姿势，恢复颈胸活动度，重建深颈屈肌和肩胛控制。（5分）
- 训练内容：下巴内收、深颈屈肌耐力、胸椎伸展旋转、肩胛稳定和呼吸放松训练。（5分）
- 风险控制：突发剧烈头痛、神经症状、外伤后头痛或进行性加重需转诊。（2分）

**标准答题框架**：机制 -> 评定 -> 原则 -> 训练 -> 红旗风险。

**易丢分点**：把所有头痛都当肌肉紧张；不写红旗筛查；只按摩不训练控制。

## 8. 髌腱病负荷管理（25分）

**分类与模块**：康复；运动损伤康复/膝前痛；髌腱病；考纲高频原创。

**答案关键词**：跳跃负荷、髌腱、膝伸机制、下蹲痛、单腿下蹲、等长、重慢抗阻、离心、跑跳进阶。

**评分点**：
- 机制：髌腱病多与跳跃、变向、深蹲等膝伸负荷过高和恢复不足相关。（5分）
- 评定：疼痛部位、压痛、下蹲/跳跃诱发、膝伸力量、髋膝足力线、训练负荷和24小时反应。（7分）
- 早期原则：降低高冲击负荷，保留可耐受活动，用等长训练镇痛和维持能力。（4分）
- 进阶训练：重慢抗阻、离心训练、髋膝力量和落地控制，逐步加入弹跳和专项动作。（6分）
- 回归标准：疼痛可控、力量和跳跃能力恢复、训练后反应不加重，动作质量达标。（3分）

**标准答题框架**：机制 -> 评定 -> 早期负荷 -> 力量进阶 -> 跑跳回归。

**易丢分点**：只休息不负荷训练；只拉伸股四头肌；不看24小时疼痛反应。

## 9. 脑卒中后上肢功能康复（50分）

**分类与模块**：康复；神经康复/上肢功能；跨学科综合原创。

**答案关键词**：偏瘫、肌张力、协同运动、肩痛、感觉障碍、Fugl-Meyer、任务导向、双侧训练、约束诱导、镜像疗法、日常活动。

**评分点**：
- 问题分析：脑卒中后上肢可出现肌力下降、肌张力异常、协同运动、感觉障碍、肩痛和精细动作受限。（7分）
- 评定内容：ROM、肌力、肌张力、感觉、协调、肩关节稳定、疼痛、Fugl-Meyer、ARAT和ADL能力。（9分）
- 早期原则：保护肩关节，预防挛缩和疼痛，促进主动参与，避免粗暴牵拉患肢。（7分）
- 运动控制训练：肩胛控制、近端稳定、伸肘伸腕、抓握释放、分离运动和感觉输入训练。（9分）
- 任务导向训练：围绕取物、拿杯、穿衣、支撑转移等功能任务，可用双侧训练、镜像疗法或约束诱导训练。（8分）
- 进阶与家庭训练：从辅助到主动，从单关节到复合任务，从低负荷到日常场景，安排家庭重复练习。（5分）
- 风险控制：肩手综合征、肩半脱位、疼痛加重、痉挛加重和疲劳需及时调整。（5分）

**标准答题框架**：障碍分析 -> 评定 -> 早期保护 -> 运动控制 -> 任务训练 -> 进阶家庭 -> 风险。

**易丢分点**：只练肌力不练任务；忽略肩关节保护；不写感觉和精细动作。
