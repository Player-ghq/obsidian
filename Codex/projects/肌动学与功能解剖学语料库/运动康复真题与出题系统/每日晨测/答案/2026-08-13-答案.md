# 2026-08-13 上体运动康复晨测｜答案与评分

总分 300 分。答题时先写结构或机制，再落到运动表现、评定和训练控制。

## 1. 颈椎形态、运动与功能（25分）

**分类与模块**：解剖；躯干/颈椎；头颈功能；考纲高频原创。

**答案关键词**：寰椎、枢椎、横突孔、椎间孔、生理前凸、屈伸、侧屈、旋转、椎动脉、脊髓神经根。

**评分点**：
- 形态特点：颈椎椎体较小，椎孔较大，多数有横突孔，寰枢椎结构特殊。（6分）
- 运动形式：颈椎可屈伸、侧屈和旋转，上颈椎对头部旋转和精细控制重要。（5分）
- 支撑功能：维持头部位置和视线稳定，生理前凸有助于分散负荷。（4分）
- 神经血管保护：椎管保护脊髓，椎间孔与神经根相关，横突孔与椎动脉通行相关。（5分）
- 运动康复意义：头前伸、活动受限或稳定不足可增加颈肩痛和神经症状风险，训练需兼顾活动度与深颈稳定。（5分）

**标准答题框架**：形态特点 -> 运动形式 -> 支撑姿势 -> 神经血管保护 -> 康复意义。

**易丢分点**：不写寰枢椎；只说“颈椎灵活”；忽略神经根和椎动脉相关风险。

## 2. 影响肌力的解剖学因素（25分）

**分类与模块**：解剖；骨骼肌；肌力因素；考纲高频原创。

**答案关键词**：生理横断面积、肌纤维类型、肌肉长度、关节角度、力臂、羽状角、神经支配、协同肌、固定肌。

**评分点**：
- 肌肉结构：生理横断面积越大，潜在最大肌力越大；肌纤维类型和羽状角也影响输出。（6分）
- 长度-张力：肌肉长度和关节角度影响肌丝重叠和力量发挥。（5分）
- 杠杆力臂：肌肉止点、关节轴和力臂决定力矩大小，不同角度力矩不同。（5分）
- 神经与协同：运动单位募集、拮抗肌放松、协同肌和固定肌配合影响实际表现。（5分）
- 应用：力量训练和康复需选择合适关节角度、动作链、负荷和稳定条件。（4分）

**标准答题框架**：肌肉结构 -> 长度角度 -> 杠杆力臂 -> 神经协同 -> 训练康复应用。

**易丢分点**：只写肌肉越大力量越大；不写力臂和关节角度；忽略固定肌稳定。

## 3. 跳箱落地动作解剖学分析（50分）

**分类与模块**：解剖；运动动作解剖学分析；跳箱落地；跨学科综合原创。

**答案关键词**：腾空、足接触、髋膝踝屈曲、离心缓冲、臀大肌、臀中肌、股四头肌、小腿三头肌、膝内扣、前交叉韧带。

**评分点**：
- 阶段划分：起跳或离箱、腾空准备、双足着地、缓冲吸收、稳定站立。（6分）
- 关节运动：着地后髋膝屈、踝背屈吸收冲击，躯干适度前倾，随后控制回到稳定位。（9分）
- 肌肉工作：股四头肌、臀大肌、腘绳肌、小腿三头肌离心缓冲，臀中肌控制骨盆和膝力线，核心稳定躯干。（12分）
- 力线控制：髋膝足对齐，避免膝内扣、足过度旋前、骨盆侧倾和躯干过度前倾或后仰。（8分）
- 损伤风险：缓冲不足、膝外翻内旋、踝背屈受限和疲劳可增加ACL、髌股、踝扭伤风险。（8分）
- 训练/康复意义：适合回归跳跃后期评估与训练，需从低高度、双脚到单脚、可控到反应任务进阶。（7分）

**标准答题框架**：阶段 -> 关节运动 -> 肌肉离心缓冲 -> 力线 -> 风险 -> 进阶应用。

**易丢分点**：只写股四头肌；不写离心收缩；不联系膝内扣和ACL风险。

## 4. 氧运输链与运动意义（25分）

**分类与模块**：生理；呼吸；氧运输链；考纲高频原创。

**答案关键词**：肺通气、肺换气、血红蛋白、心输出量、组织换气、线粒体、有氧代谢、摄氧量。

**评分点**：
- 外呼吸：肺通气完成空气进出，肺换气完成肺泡与血液间氧和二氧化碳交换。（6分）
- 气体运输：氧主要与血红蛋白结合运输，二氧化碳以多种形式运输。（5分）
- 内呼吸：组织毛细血管与细胞间进行气体交换，氧进入细胞参与有氧代谢。（5分）
- 运动变化：运动时通气、心输出量和组织摄氧增加，以满足骨骼肌代谢需要。（5分）
- 训练康复意义：氧运输链任一环节受限都会影响耐力和运动处方安全。（4分）

**标准答题框架**：肺通气/换气 -> 血液运输 -> 组织换气 -> 运动调节 -> 应用。

**易丢分点**：只写肺通气；不写血红蛋白和心输出量；不联系线粒体利用。

## 5. 皮质醇与训练压力（25分）

**分类与模块**：生理；内分泌；皮质醇；考纲高频原创。

**答案关键词**：糖皮质激素、糖异生、蛋白分解、脂代谢、抗炎、应激、免疫、过度训练、恢复。

**评分点**：
- 来源与性质：皮质醇由肾上腺皮质分泌，是重要糖皮质激素。（4分）
- 代谢作用：促进糖异生，影响蛋白质分解和脂代谢，帮助维持应激状态下能量供应。（7分）
- 抗炎免疫：具有抗炎和免疫调节作用，但长期过高可能抑制免疫和组织修复。（5分）
- 训练意义：急性升高有助于应激动员，长期高水平提示负荷、睡眠、营养或恢复问题。（5分）
- 康复意义：术后、损伤或慢病训练中需关注疲劳、疼痛、睡眠和恢复，避免长期应激过高。（4分）

**标准答题框架**：来源 -> 代谢作用 -> 抗炎免疫 -> 训练压力 -> 康复监控。

**易丢分点**：只写“应激激素”；不写蛋白分解和免疫影响；不区分急性与长期变化。

## 6. 神经肌肉疲劳机制与应用（50分）

**分类与模块**：生理；运动性疲劳与恢复；神经肌肉疲劳；跨学科综合原创。

**答案关键词**：中枢疲劳、运动单位、神经递质、外周疲劳、兴奋收缩耦联、钙离子、代谢产物、糖原、动作质量、恢复。

**评分点**：
- 中枢机制：中枢驱动下降、运动单位募集频率变化、神经递质和主观努力感改变可降低输出。（9分）
- 外周机制：肌糖原下降、H+和无机磷累积、钙释放/回收受影响、肌膜兴奋性下降、肌纤维微损伤等。（12分）
- 神经肌肉接头和兴奋收缩耦联：传递效率和钙调控变化会影响肌肉收缩力量和速度。（7分）
- 动作影响：疲劳会降低力量、速度、协调和本体控制，增加技术变形和损伤风险。（7分）
- 训练安排：高技术、高速度和大重量训练应避免在严重疲劳下堆量，需安排间歇和恢复。（6分）
- 康复进阶：康复训练要观察疼痛、动作质量、RPE和次日反应，疲劳下控制差时降低难度。（6分）
- 恢复措施：睡眠、营养补给、主动恢复、负荷周期化和心理恢复共同促进恢复。（3分）

**标准答题框架**：中枢疲劳 -> 外周疲劳 -> 耦联传递 -> 动作风险 -> 训练/康复安排 -> 恢复。

**易丢分点**：只写乳酸；不写中枢机制；不把疲劳与动作质量和康复进阶联系。

## 7. 肩胛运动障碍康复（25分）

**分类与模块**：康复；肩关节与肩复合体；肩胛运动障碍；考纲高频原创。

**答案关键词**：肩胛翼状、上旋不足、前倾、内旋、前锯肌、斜方肌、肩胛节律、过顶痛、闭链训练。

**评分点**：
- 表现：可见肩胛翼状、上旋不足、过度前倾内旋、耸肩代偿或左右不对称。（5分）
- 机制：前锯肌、斜方肌功能不足，胸小肌紧张，胸椎活动受限或肩袖疼痛均可相关。（6分）
- 评定：观察静态姿势和动态上举，检查胸椎活动、肩胛控制、肩袖力量和疼痛诱发动作。（6分）
- 训练原则：先改善疼痛和活动度，再训练肩胛后倾、上旋、外旋和贴胸稳定。（4分）
- 训练内容：前锯肌、下斜方肌、闭链支撑、墙滑、俯卧Y/T和过顶动作渐进。（4分）

**标准答题框架**：表现 -> 机制 -> 评定 -> 原则 -> 训练。

**易丢分点**：只练肩袖；不观察动态上举；忽略胸椎和胸小肌。

## 8. 腘绳肌拉伤与回归跑步（25分）

**分类与模块**：康复；运动损伤康复；腘绳肌拉伤；考纲高频原创。

**答案关键词**：高速跑、离心负荷、髋屈膝伸、压痛、柔韧性、等长、离心、Nordic、加速跑、回归标准。

**评分点**：
- 机制：常发生于高速跑摆动末期，腘绳肌在髋屈膝伸位承受高离心负荷。（6分）
- 评定：疼痛压痛、瘀斑、ROM、抗阻屈膝/伸髋力量、神经张力、跑步动作和既往伤史。（7分）
- 早期原则：保护和控制疼痛，维持可耐受活动，避免过早冲刺和强拉伸。（4分）
- 训练进阶：等长、向心、离心、髋主导力量、Nordic、跑步技术和速度渐进。（5分）
- 回归标准：无痛全范围力量接近健侧，高速跑和加减速无症状，训练后24小时反应可控。（3分）

**标准答题框架**：机制 -> 评定 -> 早期 -> 离心和跑步进阶 -> 回归标准。

**易丢分点**：只拉伸；不写高速跑摆动末期；没有速度进阶标准。

## 9. 踝慢性不稳康复方案（50分）

**分类与模块**：康复；踝足损伤康复/方案设计；跨学科综合原创。

**答案关键词**：反复扭伤、机械不稳、功能不稳、距腓前韧带、腓骨肌、本体感觉、单腿平衡、跳跃落地、变向、回归运动。

**评分点**：
- 机制分析：反复踝扭伤后可出现韧带松弛、关节位置觉下降、腓骨肌反应不足和运动控制缺陷。（8分）
- 评定内容：扭伤史、疼痛肿胀、ROM、前抽屉/距骨倾斜、腓骨肌力量、单腿平衡、跳跃和变向能力。（10分）
- 早期目标：控制症状，恢复踝背屈和基础负重，建立足踝中立控制。（6分）
- 力量训练：腓骨肌、胫后肌、小腿三头肌、足内在肌和髋膝控制共同训练。（8分）
- 本体感觉训练：单腿站、平衡垫、扰动训练、闭眼任务、动态伸手和多方向控制。（7分）
- 跑跳变向进阶：从直线慢跑到加速、跳跃落地、侧向移动、变向和专项反应任务。（7分）
- 回归标准：无明显疼痛肿胀，ROM和力量接近健侧，平衡跳跃测试合格，专项动作稳定。（4分）

**标准答题框架**：机制 -> 评定 -> 症状和ROM -> 力量 -> 本体感觉 -> 跑跳变向 -> 回归。

**易丢分点**：只练平衡板；不恢复踝背屈；忽略髋膝控制和专项变向。
