# 2026-08-09 上体运动康复晨测｜答案与评分

总分 300 分。答题时先写基础概念，再写运动或康复应用，避免只有名词堆砌。

## 1. 骨结构与运动适应（25分）

**分类与模块**：解剖；骨结构与骨适应；真题同源变式。

**答案关键词**：骨膜、骨质、骨髓、骨密质、骨松质、有机质、无机盐、弹性、硬度、骨重建、机械负荷。

**评分点**：
- 骨的构造：骨由骨膜、骨质和骨髓构成，骨质分骨密质和骨松质。（6分）
- 化学成分：有机质主要赋予弹性和韧性，无机盐主要赋予硬度和支持性。（6分）
- 物理特性：骨兼具坚硬、弹性和一定抗压抗弯能力，随年龄和负荷改变。（4分）
- 运动影响：适宜负荷可促进骨重建、提高骨密度和骨小梁适应，不足或过量负荷均有风险。（6分）
- 康复意义：骨折、骨质疏松和青少年训练需按负荷、营养和恢复情况循序渐进。（3分）

**标准答题框架**：构造 -> 成分 -> 物理特性 -> 体育锻炼影响 -> 康复/训练意义。

**易丢分点**：只写骨密质骨松质；不区分有机质和无机盐作用；把运动影响写成越多越好。

## 2. 躯体运动神经通路与损伤表现（25分）

**分类与模块**：解剖；神经系统/运动传导；考纲高频原创。

**答案关键词**：上运动神经元、下运动神经元、皮质脊髓束、锥体系、脊髓前角、周围神经、肌张力、腱反射、瘫痪。

**评分点**：
- 基本组成：随意运动主要经大脑皮质运动区、下行传导束、脊髓前角运动神经元、周围神经到骨骼肌。（7分）
- 上运动神经元：皮质脊髓束等损伤可出现肌张力增高、腱反射亢进、病理反射和痉挛性瘫痪。（6分）
- 下运动神经元：前角细胞或周围神经损伤可出现肌张力降低、反射减弱、肌萎缩和弛缓性瘫痪。（6分）
- 运动功能影响：表现为力量、协调、精细控制、步态和平衡障碍。（3分）
- 康复意义：评定需结合肌力、肌张力、反射、感觉和功能任务，训练应按损伤类型选择。（3分）

**标准答题框架**：通路组成 -> 上运动神经元损伤 -> 下运动神经元损伤 -> 功能影响 -> 康复评定。

**易丢分点**：混淆上、下运动神经元体征；不写脊髓前角和周围神经；不联系功能表现。

## 3. 波比跳远动作分析（50分）

**分类与模块**：解剖；运动动作解剖学分析；波比跳远；跨学科综合原创。

**答案关键词**：下蹲、手撑、俯撑、收腿、髋膝踝伸展、落地缓冲、肩胛稳定、核心抗伸展、股四头肌、臀大肌、腓肠肌。

**评分点**：
- 阶段划分：下蹲手撑、向后跳成俯撑、收腿回蹲、水平跳远、落地缓冲和连续转入下一次。（7分）
- 上肢肩带：俯撑阶段腕肘肩承重，肩胛稳定肌、肩袖、胸大肌和肱三头肌维持支撑和控制。（8分）
- 躯干核心：俯撑和收腿阶段需腹肌、竖脊肌、髋屈肌协同，防止腰椎塌陷或过度屈伸。（8分）
- 下肢发力：跳远阶段髋膝踝快速伸展，臀大肌、股四头肌、小腿三头肌向心发力；落地时离心缓冲。（10分）
- 平面与力线：以矢状面为主，需控制膝内扣、足旋前、骨盆前倾和躯干晃动。（6分）
- 风险控制：腕肩过载、腰椎塌陷、落地膝内扣、踝膝冲击和疲劳下动作变形需控制。（7分）
- 训练/康复意义：适合综合体能和回归跑跳后期训练，康复中需先具备支撑、下肢力量和落地控制。（4分）

**标准答题框架**：阶段 -> 上肢支撑 -> 核心控制 -> 下肢跳落 -> 风险 -> 训练应用。

**易丢分点**：只写跳远不写俯撑；不写肌肉工作形式；忽略疲劳状态下动作风险。

## 4. 运动体温升高与散热（25分）

**分类与模块**：生理；体温调节；真题同源变式。

**答案关键词**：代谢产热、肌肉收缩、核心温度、皮肤血流、出汗、蒸发、辐射、传导、对流、热应激。

**评分点**：
- 升温原因：运动时骨骼肌代谢增强，化学能大量转化为热，产热增加导致体温上升。（6分）
- 调节中枢：下丘脑体温调节中枢整合温度信息，调节产热和散热。（4分）
- 皮肤血流：皮肤血管扩张增加体表散热，但会与工作肌供血存在分配竞争。（5分）
- 出汗蒸发：出汗和汗液蒸发是热环境运动中重要散热方式，受湿度影响大。（5分）
- 其他散热：辐射、传导、对流参与散热，环境温度、风速、衣着和补液影响散热效率。（3分）
- 运动意义：散热不足可导致脱水、热痉挛、热衰竭或中暑风险。（2分）

**标准答题框架**：产热 -> 中枢调节 -> 皮肤血流 -> 出汗蒸发 -> 环境影响 -> 风险。

**易丢分点**：只写出汗；不写皮肤血流；忽略湿度和热风险。

## 5. 肾脏水盐调节与运动脱水（25分）

**分类与模块**：生理；肾脏生理；运动脱水；考纲高频原创。

**答案关键词**：肾小球滤过、肾小管重吸收、抗利尿激素、醛固酮、尿量减少、钠水潴留、血容量、渗透压。

**评分点**：
- 基本过程：肾脏通过滤过、重吸收和分泌调节水、电解质和代谢产物排出。（6分）
- ADH作用：血浆渗透压升高或血容量下降时ADH增加，促进水重吸收，尿量减少。（6分）
- 醛固酮作用：促进钠重吸收和钾排出，有助于维持血容量和血压。（5分）
- 脱水反应：出汗导致水盐丢失，血容量下降、渗透压升高、心率上升、体温调节压力增加。（5分）
- 运动意义：补液补钠、监控尿色体重和症状可降低热伤害和运动能力下降风险。（3分）

**标准答题框架**：肾单位功能 -> ADH -> 醛固酮 -> 脱水反应 -> 补液监控。

**易丢分点**：只写排尿；不写激素调节；不联系血容量和体温。

## 6. 肥胖运动干预机制与处方（50分）

**分类与模块**：生理；运动与体重控制/运动处方；跨学科综合原创。

**答案关键词**：能量平衡、脂肪氧化、胰岛素敏感性、基础代谢、肌肉量、有氧运动、抗阻训练、NEAT、饮食配合、监控。

**评分点**：
- 能量机制：运动增加能量消耗，形成能量负平衡，是体脂下降的基础。（7分）
- 代谢机制：提高脂肪氧化能力、胰岛素敏感性和血脂代谢，改善代谢综合征风险。（8分）
- 肌肉与基础代谢：抗阻训练增加或维持瘦体重，提高力量和长期体重管理能力。（7分）
- 有氧处方：中低到中等强度起步，选择步行、骑车、游泳等低冲击项目，逐渐增加频率和总量。（8分）
- 抗阻处方：全身大肌群训练，先动作质量和关节耐受，再增加负荷，避免疼痛和屏气。（7分）
- 监控要点：体重、腰围、心率、RPE、疼痛、血压血糖、睡眠和饮食执行，关注过度训练和伤病。（8分）
- 行为与安全：结合饮食、日常活动、长期依从性和个体化目标，肥胖伴慢病者需风险筛查。（5分）

**标准答题框架**：减脂机制 -> 代谢改善 -> 有氧 -> 抗阻 -> 监控 -> 长期依从。

**易丢分点**：只写跑步减肥；忽略抗阻训练；不给监控和风险筛查。

## 7. 缺血缺氧性脑病康复（25分）

**分类与模块**：康复；神经康复/康复评定；真题同源变式。

**答案关键词**：意识认知、运动障碍、肌张力、吞咽言语、平衡步行、ADL、神经发育治疗、任务导向、并发症预防。

**评分点**：
- 功能障碍：可出现意识认知障碍、运动控制障碍、肌张力异常、吞咽言语问题、平衡步行和ADL下降。（6分）
- 康复评定：意识认知、肌力肌张力、ROM、感觉、平衡、步态、吞咽言语、ADL和并发症风险。（7分）
- 治疗原则：早期介入、综合康复、个体化目标、任务导向训练和家庭参与。（5分）
- 训练内容：体位管理、关节活动、肌力与运动控制、坐站转移、平衡步行和日常活动训练。（5分）
- 风险控制：癫痫、误吸、压疮、跌倒、疲劳和生命体征异常需监控。（2分）

**标准答题框架**：障碍 -> 评定 -> 原则 -> 训练 -> 风险。

**易丢分点**：只写运动障碍；漏掉吞咽认知和并发症；没有任务导向训练。

## 8. 肩袖损伤康复（25分）

**分类与模块**：康复；运动损伤康复/肩关节；考纲高频原创。

**答案关键词**：冈上肌、肩峰下撞击、肩胛节律、疼痛弧、外旋力量、肩袖控制、肩胛稳定、渐进负荷。

**评分点**：
- 机制：肩袖退变、过顶负荷、肩峰下空间减少、肩胛控制不足和外旋力量不足均可相关。（6分）
- 评定：疼痛部位、疼痛弧、ROM、外旋/外展力量、肩胛运动、姿势、专项动作和功能量表。（7分）
- 治疗原则：控制疼痛，恢复活动度，重建肩袖和肩胛稳定，逐步回归过顶负荷。（5分）
- 训练内容：肩袖等长到弹力抗阻、肩胛后缩下压/上旋控制、胸椎活动度和闭链稳定训练。（5分）
- 风险控制：避免带痛大负荷过顶、忽视肩胛代偿或过早高速投掷。（2分）

**标准答题框架**：机制 -> 评定 -> 原则 -> 训练 -> 回归风险。

**易丢分点**：只练三角肌；不写肩胛节律；忽略疼痛弧和外旋力量评定。

## 9. 跟腱病康复方案（50分）

**分类与模块**：康复；运动损伤康复/回归跑跳；跨学科综合原创。

**答案关键词**：跟腱负荷、腓肠肌、比目鱼肌、晨僵、压痛、跟腱增厚、等长、离心、重慢抗阻、弹跳进阶、回归跑步。

**评分点**：
- 机制分析：跟腱病多与跑跳负荷过快增加、小腿三头肌力量不足、踝背屈受限和恢复不足有关。（7分）
- 评定内容：疼痛部位、晨僵、压痛/增厚、踝ROM、小腿力量、单腿提踵能力、跑跳负荷和鞋场地因素。（9分）
- 早期处理：负荷调整，疼痛监控，等长提踵镇痛，保持可耐受有氧，避免完全停练或硬顶疼痛。（7分）
- 力量进阶：从等长到离心提踵、重慢抗阻，分别训练屈膝和伸膝位小腿力量。（9分）
- 跑跳进阶：先走跑交替，再连续慢跑、加速跑、跳跃、变向和专项动作，按24小时疼痛反应调整。（8分）
- 回归标准：疼痛轻微且不持续加重，单腿提踵和跳跃能力接近健侧，跑跳训练后反应可控。（6分）
- 风险控制：急性撕裂征象、明显肿胀瘀斑、突然爆裂感或跖屈无力需立即转诊。（4分）

**标准答题框架**：机制 -> 评定 -> 早期负荷 -> 力量进阶 -> 跑跳进阶 -> 回归标准 -> 风险。

**易丢分点**：只做拉伸；忽略比目鱼肌训练；没有用训练后24小时反应调整负荷。
