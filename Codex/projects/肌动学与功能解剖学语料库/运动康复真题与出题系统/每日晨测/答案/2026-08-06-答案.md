# 2026-08-06 上体运动康复晨测｜答案与评分

总分 300 分。答题优先采用“结构/机制 -> 功能障碍或运动表现 -> 评定 -> 训练或康复意义”的表达。

## 1. 头颈肌与颈椎稳定（25分）

**分类与模块**：解剖；头颈肌结构与功能；头颈肌；考纲高频原创。

**答案关键词**：胸锁乳突肌、斜角肌、头夹肌、颈夹肌、枕下肌、深颈屈肌、颈椎稳定、姿势控制、呼吸辅助、颈肩痛。

**评分点**：
- 主要肌群：胸锁乳突肌、斜角肌、头夹肌/颈夹肌、枕下肌、深颈屈肌等参与头颈运动和稳定。（6分）
- 运动功能：可完成颈部屈伸、侧屈、旋转和头部精细控制，部分肌肉参与吸气辅助。（5分）
- 稳定功能：深层肌群参与节段稳定，浅层肌群参与方向控制和抗重力姿势维持。（5分）
- 姿势意义：长期头前伸可造成深颈屈肌抑制、胸锁乳突肌和斜角肌代偿，增加颈肩负荷。（5分）
- 康复意义：训练应包括深颈屈肌激活、胸椎活动度、肩胛控制和呼吸模式调整。（4分）

**标准答题框架**：列肌群 -> 写运动功能 -> 写稳定机制 -> 联系姿势异常 -> 写训练/康复应用。

**易丢分点**：只写胸锁乳突肌；不区分浅层运动肌和深层稳定肌；不联系头前伸和颈肩痛。

## 2. 下肢体表标志与康复评定（25分）

**分类与模块**：解剖；体表标志与定位；下肢定位评估；考纲高频原创。

**答案关键词**：髂嵴、髂前上棘、髂后上棘、大转子、髌骨、胫骨粗隆、腓骨头、内外踝、跟骨、足舟骨。

**评分点**：
- 骨盆髋部标志：髂嵴、髂前上棘、髂后上棘、坐骨结节、大转子可用于骨盆位置和髋部定位。（6分）
- 膝小腿标志：髌骨、股骨内外上髁、胫骨粗隆、腓骨头、胫骨前缘可用于膝关节和下肢力线观察。（6分）
- 踝足标志：内外踝、跟骨、舟骨粗隆、第五跖骨粗隆可用于踝足定位和足弓评估。（5分）
- 应用：用于关节轴定位、测量ROM、观察膝内扣/足旋前、判断骨盆倾斜和动作代偿。（5分）
- 注意事项：体表标志需结合双侧比较、动态观察和疼痛/功能评定，不应单独下诊断。（3分）

**标准答题框架**：按髋骨盆、膝小腿、踝足三段列标志，再说明定位和康复评定用途。

**易丢分点**：只罗列名称不说明用途；漏掉踝足标志；把静态触诊当成完整评定。

## 3. 自由泳动作解剖学分析（50分）

**分类与模块**：解剖；运动动作解剖学分析；自由泳；跨学科综合原创。

**答案关键词**：入水、抱水、划水、推水、移臂、打腿、肩屈外展内旋、肩胛上旋、躯干旋转、髋伸、肩峰下撞击、腰椎伸展。

**评分点**：
- 阶段划分：上肢可分入水、抱水、划水、推水、出水移臂；下肢为连续交替打腿。（7分）
- 上肢关节运动：肩屈曲、外展、内旋和伸展交替，肘屈伸配合，肩胛上旋、后倾和前伸运动参与。（9分）
- 躯干和下肢：躯干围绕纵轴旋转，核心控制身体流线；髋参与伸展/屈曲小幅快速打腿，膝踝协同传递推进。（8分）
- 主要肌群：背阔肌、胸大肌、三角肌、肩袖、前锯肌、斜方肌、腹斜肌、臀肌、髂腰肌、股四头肌和腘绳肌参与。（10分）
- 肌肉工作形式：水下划推阶段以上肢内收伸展向心发力为主，移臂阶段肩胛和肩袖控制，躯干核心多为等长/旋转控制。（6分）
- 风险控制：肩胛控制不足、肩内旋过度、胸椎活动不足可致肩峰下撞击；腰椎过伸和核心不足可致腰痛。（6分）
- 训练/康复意义：需强化肩袖肩胛、胸椎旋转、核心抗伸展和髋驱动，逐步增加划水量。（4分）

**标准答题框架**：阶段 -> 上肢 -> 躯干下肢 -> 肌群和工作形式 -> 动力链 -> 损伤风险和训练意义。

**易丢分点**：只写上肢不写躯干旋转和打腿；不写肩胛运动；风险控制只写“注意肩伤”没有机制。

## 4. 肌纤维类型与运动适应（25分）

**分类与模块**：生理；骨骼与骨骼肌；肌纤维类型；考纲高频原创。

**答案关键词**：I型纤维、IIa型纤维、IIx型纤维、收缩速度、抗疲劳、线粒体、毛细血管、糖酵解、力量、耐力。

**评分点**：
- I型纤维：收缩较慢、抗疲劳强、有氧代谢能力强、线粒体和毛细血管丰富，适合耐力活动。（6分）
- II型纤维：收缩快、力量和功率高，IIa兼具一定耐力，IIx速度快但抗疲劳弱。（7分）
- 代谢特点：慢肌偏有氧氧化，快肌偏糖酵解和高功率输出，不同运动强度募集比例不同。（5分）
- 训练关系：耐力训练提高有氧酶、线粒体和毛细血管；力量速度训练提高神经动员和快肌力量输出。（5分）
- 康复意义：早期低负荷耐力和控制训练，后期根据专项逐步加入力量、速度和爆发训练。（2分）

**标准答题框架**：分类 -> 生理特点 -> 代谢特点 -> 训练适应 -> 康复应用。

**易丢分点**：把快肌慢肌绝对化；不写代谢和疲劳差异；不联系训练方式。

## 5. 牵张反射、腱反射与运动控制（25分）

**分类与模块**：生理；神经系统功能；神经反射；考纲高频原创。

**答案关键词**：肌梭、Ia传入、α运动神经元、牵张反射、腱器官、Ib传入、保护性抑制、肌张力、姿势控制。

**评分点**：
- 牵张反射过程：肌肉被牵拉后肌梭兴奋，经Ia传入兴奋同名肌α运动神经元，使肌肉收缩。（7分）
- 腱反射/腱器官：张力过大时高尔基腱器官兴奋，经Ib传入产生保护性抑制，调节肌张力。（6分）
- 功能意义：维持肌张力、姿势稳定、快速纠正扰动，参与平衡和动作协调。（5分）
- 训练意义：动态稳定、落地控制、平衡训练和本体感觉训练均依赖反射调节。（4分）
- 康复意义：神经损伤后需评估反射亢进或减弱，合理选择牵伸、负重、节律性训练和任务练习。（3分）

**标准答题框架**：分别写反射弧 -> 比较功能 -> 联系姿势和运动控制 -> 写康复应用。

**易丢分点**：混淆肌梭和腱器官；不写传入纤维和运动神经元；忽略保护性调节。

## 6. 高血压运动处方与机制（50分）

**分类与模块**：生理；运动处方/代谢异常与慢病；高血压；跨学科综合原创。

**答案关键词**：血管内皮、一氧化氮、外周阻力、交感活性、体重控制、胰岛素敏感性、有氧训练、抗阻训练、血压监测、禁忌。

**评分点**：
- 改善机制：规律运动可改善血管内皮功能、增加NO释放、降低外周阻力、改善动脉弹性。（8分）
- 神经体液调节：降低交感兴奋，改善自主神经平衡，影响肾素-血管紧张素-醛固酮系统和水钠调节。（8分）
- 代谢与体成分：控制体重、改善胰岛素敏感性和血脂，间接降低心血管风险。（6分）
- 有氧处方：以中等强度有氧为主，如步行、骑车、游泳，每周多数天，循序渐进控制总量。（8分）
- 抗阻和柔韧：中低到中等强度抗阻，避免屏气和长时间等长用力，配合热身、整理和柔韧训练。（7分）
- 监控指标：训练前后血压、心率、RPE、头晕胸闷气短等症状，关注药物影响和个体耐受。（7分）
- 禁忌与停止：血压明显过高、胸痛、明显气短、头晕、心律异常或症状加重时停止并转诊。（6分）

**标准答题框架**：机制 -> 处方要素 -> 监控 -> 禁忌 -> 康复训练安全。

**易丢分点**：只说“运动降压”不写机制；抗阻训练没有提醒避免憋气；缺少停止运动指征。

## 7. 脊髓损伤疼痛管理（25分）

**分类与模块**：康复；神经康复/疼痛管理；脊髓损伤；真题同源变式。

**答案关键词**：神经病理性疼痛、肌骨疼痛、内脏痛、疼痛部位、性质、诱因、ASIA、体位管理、运动治疗、药物协作。

**评分点**：
- 疼痛类型：可包括神经病理性疼痛、肌肉骨骼疼痛、内脏相关疼痛和痉挛相关疼痛。（6分）
- 评定内容：疼痛部位、性质、强度、诱因、持续时间、感觉运动平面、痉挛、睡眠和功能影响。（7分）
- 处理原则：明确疼痛来源，药物、物理因子、运动治疗、体位和心理干预综合管理。（5分）
- 康复训练：关节活动、肌力训练、转移训练、姿势和轮椅适配，避免压疮和过度使用损伤。（5分）
- 风险控制：新发剧烈疼痛、自主神经反射异常、感染或骨折风险需及时医学处理。（2分）

**标准答题框架**：分类 -> 评定 -> 综合处理 -> 功能训练 -> 风险提醒。

**易丢分点**：只写神经痛；忽略肩痛等过度使用问题；不写感觉平面和功能影响。

## 8. 运动员腹股沟疼痛与内收肌损伤（25分）

**分类与模块**：康复；运动损伤康复；腹股沟疼痛；考纲高频原创。

**答案关键词**：髋内收肌、内收肌长肌、变向冲刺、疼痛诱发、挤压试验、髋活动度、核心骨盆控制、离心训练。

**评分点**：
- 机制：多与髋内收肌群反复牵拉、急性拉伤、变向冲刺和骨盆控制不足有关。（5分）
- 评定：疼痛部位、压痛、抗阻内收、内收挤压试验、髋ROM、核心稳定、跑跳变向动作观察。（7分）
- 鉴别思路：注意髋关节、腹壁、耻骨联合和神经相关问题，必要时转诊。（4分）
- 治疗原则：控制疼痛和负荷，恢复髋活动度，重建内收肌、臀肌和核心力量。（4分）
- 训练进阶：等长内收、离心内收、侧向移动、变向加速和专项回归，按症状反应进阶。（5分）

**标准答题框架**：机制 -> 评定 -> 鉴别 -> 运动治疗 -> 回归运动。

**易丢分点**：只练内收肌不练骨盆和臀肌；不写变向冲刺负荷；忽略鉴别诊断。

## 9. 脑外伤后运动功能障碍康复方案（50分）

**分类与模块**：康复；神经康复/方案设计；脑外伤；跨学科综合原创。

**答案关键词**：意识认知、肌张力、平衡、协调、步行、日常活动、任务导向训练、渐进负荷、疲劳监控、安全防护。

**评分点**：
- 问题分析：脑外伤后可出现肌力下降、肌张力异常、协调障碍、平衡步行障碍、认知注意和疲劳问题。（7分）
- 初始评定：意识和认知、肌力肌张力、ROM、感觉、平衡、协调、步态、ADL、跌倒风险和生命体征。（9分）
- 早期目标：预防并发症，体位管理，维持关节活动，促醒和基础移动，建立安全坐站能力。（7分）
- 运动控制训练：采用任务导向训练、重心转移、坐站转换、上肢支撑与抓握、核心控制和双侧协调训练。（9分）
- 平衡步行训练：从静态到动态平衡，从辅助站立到步行，加入步态节律、转向、跨越障碍和耐力训练。（8分）
- 风险控制：监测头痛、眩晕、疲劳、血压心率、癫痫风险、跌倒风险和认知负荷，避免过度刺激。（6分）
- 回归标准：功能目标达成、步行和转移安全、疲劳可控、认知配合良好，并能完成家庭/运动相关任务。（4分）

**标准答题框架**：障碍分析 -> 全面评定 -> 分期目标 -> 运动控制 -> 平衡步行 -> 风险控制 -> 回归标准。

**易丢分点**：只写肢体训练不写认知和疲劳；缺少安全监控；没有把训练进阶和功能目标绑定。
