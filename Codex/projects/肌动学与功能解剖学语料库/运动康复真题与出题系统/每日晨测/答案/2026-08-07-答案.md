# 2026-08-07 上体运动康复晨测｜答案与评分

总分 300 分。答题时注意把“结构/机制”转化为“运动表现、评定指标和康复训练意义”。

## 1. 上肢带稳定与过顶动作（25分）

**分类与模块**：解剖；上肢带/关节结构；肩锁胸锁；考纲高频原创。

**答案关键词**：胸锁关节、肩锁关节、肩胛胸廓关节、锁骨旋转、肩胛上旋、后倾、外旋、前锯肌、斜方肌、过顶动作。

**评分点**：
- 组成：上肢带运动涉及胸锁关节、肩锁关节和肩胛胸廓运动，三者共同决定肩胛骨位置。（5分）
- 胸锁关节：是上肢与躯干骨性连接的主要关节，参与锁骨上提、下降、前伸、后缩和旋转。（5分）
- 肩锁关节：允许肩胛骨相对锁骨微调，配合肩胛上旋、后倾和外旋。（5分）
- 肩胛胸廓运动：前锯肌、斜方肌等控制肩胛上旋和贴胸稳定，为盂肱关节提供稳定平台。（6分）
- 运动/康复意义：过顶动作需要肩胛-肱骨节律，失衡可增加肩峰下撞击、肩袖负荷和颈肩代偿。（4分）

**标准答题框架**：关节组成 -> 各关节运动 -> 肌肉控制 -> 过顶动作意义 -> 损伤/康复意义。

**易丢分点**：只写肩关节不写胸锁、肩锁；忽略锁骨旋转；不把肩胛稳定和过顶损伤联系起来。

## 2. 血管结构功能与运动供血（25分）

**分类与模块**：解剖；脉管系统；运动循环；考纲高频原创。

**答案关键词**：动脉、静脉、毛细血管、管壁弹性、静脉瓣、物质交换、血管舒缩、骨骼肌泵、局部代谢调节。

**评分点**：
- 动脉特点：管壁厚、弹性和收缩性强，负责将血液由心脏输送至组织，调节外周阻力和血流分配。（6分）
- 静脉特点：管壁较薄、容量大，静脉瓣和骨骼肌泵帮助血液回流。（5分）
- 毛细血管：壁薄、分布广，是气体、营养物质和代谢产物交换的主要部位。（5分）
- 运动供血变化：运动肌局部代谢产物使血管扩张，非活动区域相对收缩，血流向工作肌和皮肤重新分配。（6分）
- 康复意义：循环结构功能影响有氧训练耐受、肿胀管理、恢复速度和慢病运动风险控制。（3分）

**标准答题框架**：动脉 -> 静脉 -> 毛细血管 -> 运动时血流重分配 -> 训练/康复意义。

**易丢分点**：把脉管系统写成纯生理调节；漏写静脉瓣和骨骼肌泵；不写毛细血管交换。

## 3. 农夫行走动作解剖学分析（50分）

**分类与模块**：解剖；运动动作解剖学分析；农夫行走；跨学科综合原创。

**答案关键词**：握力、肩胛下沉、躯干抗侧屈、核心稳定、髋膝踝步行、斜方肌、背阔肌、腹斜肌、臀中肌、前臂屈肌。

**评分点**：
- 动作阶段：可按起始提起、负重站立、连续步行、放下负重分析。（6分）
- 上肢和肩带：手指屈肌和前臂肌维持握持，斜方肌、背阔肌、肩袖和肩胛稳定肌控制肩带下沉与稳定。（8分）
- 躯干控制：竖脊肌、腹横肌、腹斜肌、腰方肌等维持躯干中立，重点抵抗侧屈、旋转和过伸。（9分）
- 下肢运动：髋膝踝完成步行周期，臀大肌、臀中肌、股四头肌、小腿三头肌参与支撑和推进。（8分）
- 肌肉工作形式：握持和核心多为等长收缩，下肢在步行中交替向心、离心和等长控制。（7分）
- 风险控制：避免耸肩、圆肩、腰椎侧屈、步幅不稳和负荷过快增加；注意握力疲劳导致姿势崩坏。（7分）
- 训练/康复意义：可训练握力、负重步行、核心抗侧屈和负重转移，康复中需按疼痛和动作质量进阶。（5分）

**标准答题框架**：阶段 -> 上肢握持 -> 肩带稳定 -> 躯干抗变形 -> 下肢步行 -> 风险控制。

**易丢分点**：只写“练核心和握力”；没有分析抗侧屈/抗旋转；漏写下肢步行周期。

## 4. 血液功能与运动意义（25分）

**分类与模块**：生理；血液/循环；氧运输；真题同源变式。

**答案关键词**：运输、调节、防御、凝血、血红蛋白、氧解离、缓冲、体温、免疫、酸碱平衡。

**评分点**：
- 运输功能：血液运输氧、二氧化碳、营养物质、代谢产物和激素，运动中氧运输尤为关键。（6分）
- 调节功能：参与酸碱平衡、体液平衡和体温调节，维持内环境稳定。（6分）
- 防御和保护：白细胞、抗体等参与免疫，血小板和凝血因子参与止血。（4分）
- 运动意义：血红蛋白携氧能力、血容量和血流分配影响有氧能力和恢复。（5分）
- 康复意义：贫血、脱水、炎症或凝血风险会影响运动处方安全和强度控制。（4分）

**标准答题框架**：运输 -> 调节 -> 防御保护 -> 运动表现 -> 康复安全。

**易丢分点**：只写运输氧气；漏写酸碱缓冲和体温调节；不联系运动能力。

## 5. 激素作用与运动血糖调节（25分）

**分类与模块**：生理；内分泌/血糖调节；真题同源变式。

**答案关键词**：靶细胞、受体、第二信使、基因表达、胰岛素、胰高血糖素、儿茶酚胺、肝糖原分解、糖异生、葡萄糖摄取。

**评分点**：
- 激素作用机制：激素经血液到达靶细胞，与特异受体结合，可通过膜受体第二信使或胞内受体调节功能。（7分）
- 胰岛素：促进组织摄取葡萄糖、糖原合成和血糖降低，运动后恢复中有重要作用。（5分）
- 胰高血糖素：促进肝糖原分解和糖异生，使血糖升高，维持运动供能。（5分）
- 儿茶酚胺：运动应激时增加，促进糖原分解、脂肪动员和心血管反应。（5分）
- 运动意义：运动中血糖由摄取增加和肝糖输出共同平衡，处方需关注低血糖和糖尿病风险。（3分）

**标准答题框架**：激素一般机制 -> 三类激素对血糖作用 -> 运动时动态平衡 -> 康复处方意义。

**易丢分点**：只写胰岛素；不写受体和靶细胞；忽略运动中肝糖输出。

## 6. 乳酸阈与耐力/康复强度控制（50分）

**分类与模块**：生理；能量代谢/运动机能评定；乳酸阈；跨学科综合原创。

**答案关键词**：糖酵解、乳酸生成、乳酸清除、氧化利用、乳酸阈、通气阈、耐力表现、训练区间、强度监控。

**评分点**：
- 乳酸生成：高强度运动时糖酵解加速，丙酮酸转化为乳酸，乳酸生成不等于单纯缺氧。（8分）
- 乳酸清除：乳酸可被心肌、慢肌等氧化利用，也可经肝脏糖异生转化，生成和清除共同决定血乳酸水平。（8分）
- 乳酸阈概念：随强度增加，血乳酸开始持续明显升高的强度点，反映有氧代谢能力和耐力水平。（8分）
- 训练应用：阈下训练发展有氧基础，阈值附近训练提高耐力和乳酸清除，高于阈值训练提高高强度耐受但疲劳大。（10分）
- 评定应用：可结合血乳酸、心率、配速/功率、RPE和通气阈确定个体训练区间。（8分）
- 康复意义：慢病或术后人群应多在阈下或低中强度训练，逐步进阶并监控症状、心率和RPE。（6分）
- 表达质量：能把机制、指标和处方联系起来，避免把乳酸简单等同为废物。（2分）

**标准答题框架**：生成 -> 清除 -> 阈值定义 -> 训练分区 -> 康复强度控制。

**易丢分点**：写成“乳酸越少越好”；不写清除途径；处方只给强度不写监控指标。

## 7. 股四头肌挫伤康复（25分）

**分类与模块**：康复；运动损伤康复/康复评定；真题同源变式。

**答案关键词**：直接撞击、肌内血肿、疼痛肿胀、膝屈ROM、等长收缩、早期保护、渐进拉伸、力量训练、骨化性肌炎。

**评分点**：
- 机制：多由直接撞击导致股四头肌出血、肿胀和疼痛，影响膝关节屈曲和伸膝发力。（5分）
- 评定：疼痛、肿胀、压痛、瘀斑、膝屈ROM、伸膝力量、步态和运动功能。（6分）
- 早期处理：保护、冷敷、加压、抬高，避免暴力按摩和过早大幅牵伸。（5分）
- 中后期训练：疼痛可控后逐步恢复ROM、等长到抗阻力量、柔韧性、跑跳和专项动作。（6分）
- 风险控制：警惕骨化性肌炎，若疼痛肿胀持续加重或ROM明显受限需复查。（3分）

**标准答题框架**：机制 -> 评定 -> 早期处理 -> 分期进阶 -> 风险。

**易丢分点**：急性期马上热敷/按摩；只写消炎止痛不写膝屈ROM；漏写骨化性肌炎风险。

## 8. 前庭功能障碍与平衡训练（25分）

**分类与模块**：康复；神经康复/平衡评定；考纲高频原创。

**答案关键词**：眩晕、眼震、姿势不稳、前庭眼反射、Dix-Hallpike、动态视力、Berg、感觉整合、凝视稳定、习服训练。

**评分点**：
- 常见表现：眩晕、头动不适、眼震、平衡下降、步态不稳和视觉依赖增加。（5分）
- 评定内容：病史诱因、眼震观察、位置试验、动态视力、平衡量表、步态和跌倒风险。（7分）
- 训练原则：根据病因选择复位、凝视稳定、习服训练、姿势控制和感觉整合训练。（6分）
- 进阶方式：从静态到动态、睁眼到闭眼、稳定支撑面到不稳定支撑面，逐步加入头动和步行任务。（5分）
- 风险控制：剧烈新发眩晕、神经系统体征或跌倒高风险需转诊/保护。（2分）

**标准答题框架**：表现 -> 评定 -> 训练类型 -> 进阶 -> 风险。

**易丢分点**：把所有眩晕都当耳石症；只写平衡垫训练；不写眼震和动态视力。

## 9. 肩关节前脱位后康复方案（50分）

**分类与模块**：康复；运动损伤康复/方案设计；跨学科综合原创。

**答案关键词**：外展外旋、盂唇、关节囊、肩袖、肩胛控制、恐惧试验、ROM、等长训练、闭链稳定、回归过顶/对抗。

**评分点**：
- 机制分析：肩前脱位常发生在外展外旋位，可能损伤盂唇、关节囊韧带和肩袖，导致前方不稳。（7分）
- 评定内容：疼痛、肿胀、ROM、肌力、肩胛控制、神经血管状态、恐惧试验、功能量表和运动需求。（9分）
- 早期目标：保护愈合、控制疼痛、维持邻近关节活动，避免过早外展外旋终末位应力。（7分）
- 中期训练：逐步恢复ROM，肩袖等长到弹力抗阻，肩胛稳定，闭链支撑和本体感觉训练。（9分）
- 后期专项：加入快速反应、过顶控制、投掷或对抗专项动作，训练疲劳下稳定性。（7分）
- 回归标准：无痛、ROM接近健侧、力量和稳定性达标、恐惧感低、专项动作质量合格。（7分）
- 风险控制：反复脱位、麻木无力、明显不稳或疼痛加重需医学评估，不可只追求活动度。（4分）

**标准答题框架**：损伤机制 -> 评定 -> 早中后期训练 -> 回归标准 -> 风险控制。

**易丢分点**：早期强行外旋拉伸；只练三角肌不练肩袖肩胛；回归运动没有稳定性测试。
