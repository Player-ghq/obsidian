## 单个知识点的背诵流程

1. 将标题改写为问题。
2. 看懂答案，划出 3～7 个一级关键词。
3. 合上材料，按关键词口述完整答案。
4. 闭卷写出答案骨架；S 级题再写一遍完整答案。
5. 对照材料，用另一种颜色补漏，只记录漏词，不抄整段原文。
6. 标记掌握度，并进入 D1、D3、D7、D14 复习队列。

掌握度统一记为：

- `0`：完全想不起来。
- `1`：只能回忆少数关键词，完整度低于 60%。
- `2`：完整度 60%～80%，结构基本正确。
- `3`：完整度超过 80%，能够按题型组织答案。

当天达到 `2` 即可继续推进；`0～1` 进入次日补测，不因追求一次背熟而停滞。

## 两科答题骨架

运动生理学：`概念/条件 → 变化过程 → 调节机制 → 最终结果 → 运动意义`。

人体解剖学：`位置 → 组成/连接 → 结构特点 → 运动 → 主要肌肉 → 训练或动作意义`。

动作分析：`动作阶段 → 环节运动 → 关节运动 → 原动肌 → 固定条件 → 工作性质 → 功能意义`。

## 周测规则

1. 周测前不得临时翻书突击。
2. 25 分题限时 20～25 分钟，50 分题限时 45～50 分钟。
3. 先按关键词覆盖率评分，再检查层级、逻辑和教材术语。
4. 错题不抄标准答案；看完答案后合上材料，立即重新作答。
5. 周测结束只保留一张错漏清单：题目、漏掉的一级关键词、下次复测日期。
