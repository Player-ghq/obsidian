# 背诵对话规则

本对话用于上海体育大学运动康复考研人体解剖学背诵。

## 主线

采用方案 C：总论打底，再按部位循环整合。

1. 总论：解剖学术语、面和轴、骨、骨连结、骨骼肌、动作分析基础。
2. 部位循环：骨 -> 关节 -> 肌肉 -> 动作分析。
3. 考研整合：简答题、论述题、动作分析题表达。

## 每篇输出格式

1. 录音逐字稿：可直接朗读，句子完整。
2. 知识点骨架：提取必须背的层级。
3. 例子库：优先用语料库、健身动作、生活动作和 HYROX 训练场景。
4. 易混点：指出容易背串、漏答或误用的术语。
5. 考研答题版：可改写为简答或论述答案。
6. 自测题：用于闭卷复述。
7. 上体大题转化：给出 25 分/50 分可能问法、答题抓手和失分点。

## 部位肌肉专题硬性要求

凡涉及头颈、躯干、上肢、下肢等具体部位，必须额外生成“主要肌肉专题”，不能只在逐字稿中概括肌群。

每块重点肌肉至少包含：

1. 起点。
2. 止点。
3. 位置与形态。
4. 主要功能。
5. 功能分析：在关节运动、稳定、力偶、动作链或损伤机制中的作用。
6. 练习方法：力量训练、激活训练、拉伸或康复训练举例。
7. 记忆抓手：用形态、位置、动作或健身生活场景帮助背诵。

输出形式优先采用“逐字稿 + 表格 + 动作分析 + 考研答题模板”，确保既能朗读录音，也能查表复习。

## 高颗粒度重整标准

已经生成的背诵稿保留为“通读录音版”，同时补充 `A` 类“高颗粒度专题”文件。

总论类专题必须拆到：

1. 定义。
2. 分类。
3. 结构组成。
4. 关键术语。
5. 功能或运动机制。
6. 体育训练/康复例子。
7. 上体大题答题抓手。

部位类专题必须拆到：

1. 骨性标志。
2. 关节或连结。
3. 主要肌肉起止点。
4. 位置与形态。
5. 单块肌肉功能。
6. 肌群协同和动作链。
7. 练习、激活、拉伸或康复应用。
8. 易混点和闭卷自测。

## 晨测反向补充规则

每日晨测答案里提到的“背诵稿够用性”，必须以本目录已生成的实际背诵稿为判断对象，不得泛泛判断。

- 解剖优先对照 `qa/背诵稿/` 下的系统背诵稿与 `A` 类高颗粒度专题。

- 康复如暂时没有完整主稿，先把补充内容沉淀到 `qa/背诵稿/晨测补充/`。
- 若晨测答案判定 `基本够用但需补充` 或 `不够用`，必须同时写出可直接背诵的补充段，并写入 `qa/背诵稿/晨测补充/YYYY-MM-DD-晨测补充.md`，等待后续归并到对应专题主稿。
