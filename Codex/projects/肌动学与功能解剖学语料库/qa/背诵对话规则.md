# 背诵对话规则

本对话用于上海体育大学运动康复考研人体解剖学背诵。

## 主线

采用方案 C：总论打底，再按部位循环整合。

1. 总论：解剖学术语、面和轴、骨、骨连结、骨骼肌、动作分析基础。
2. 部位循环：骨 -> 关节 -> 肌肉 -> 动作分析。
3. 考研整合：简答题、论述题、动作分析题表达。

## 每篇输出格式

1. 录音逐字稿：可直接朗读，句子完整。
2. 知识点骨架：提取必须背的层级。
3. 例子库：优先用语料库、健身动作、生活动作和 HYROX 训练场景。
4. 易混点：指出容易背串、漏答或误用的术语。
5. 考研答题版：可改写为简答或论述答案。
6. 自测题：用于闭卷复述。

## 资料优先级

优先使用本项目语料库：`structured/`、`concepts/`、`structured/compiled-chapters/`、`index/`。若当前专题语料不足，应先询问是否继续添加资料。
