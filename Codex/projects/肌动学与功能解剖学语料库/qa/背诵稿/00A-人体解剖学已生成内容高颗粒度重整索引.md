## 后续生成标准

从第 8 批开始，每个部位默认同时生成：

- `完整版`：可直接朗读录音，串联骨、关节、肌肉、动作和上体大题。
- `A 高颗粒度专题`：按重点肌肉/结构拆表，必须包含起点、止点、位置形态、功能分析、练习方法、记忆抓手和自测题。

## 背诵检查法

每个专题按四轮背：

1. 名词轮：能说出结构名称和分类。
2. 位置轮：能在身体上定位或想象其形态。
3. 功能轮：能说出关节运动和稳定作用。
4. 应用轮：能举出健身、HYROX、生活或康复训练例子。

## 上体答题转换

总论题按“定义 -> 分类 -> 结构 -> 功能 -> 运动/康复意义”写。

部位题按“骨性结构 -> 关节连结 -> 主要肌肉 -> 运动功能 -> 训练/康复意义”写。

动作分析题按“动作阶段 -> 关节运动 -> 主要肌肉 -> 工作性质 -> 稳定控制 -> 易错代偿”写。
