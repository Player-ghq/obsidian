# 12A 动作分析高颗粒度模板与体表定位专题

适用目标：2026 上海体育大学运动康复考研人体解剖学。

## 1. 动作分析万能表

| 步骤 | 要回答的问题 | 写法 |
|---|---|---|
| 动作范围 | 从哪里到哪里 | 例如深蹲从站立下降至最低点再起立 |
| 阶段划分 | 分几个阶段 | 下降、转换、起立 |
| 关节运动 | 哪些关节动 | 髋屈伸、膝屈伸、踝背屈跖屈 |
| 平面轴 | 在什么平面绕什么轴 | 矢状面绕额状轴 |
| 外力矩 | 重力/地面反作用力造成什么趋势 | 下蹲时重力促使屈曲 |
| 肌肉 | 哪些肌群控制 | 股四头肌、臀大肌、腘绳肌、小腿三头肌 |
| 工作性质 | 向心/离心/等长 | 下降离心，起立向心，躯干等长 |
| 评价 | 效果、风险、建议 | 膝内扣、塌腰、足弓塌陷需调整 |

## 2. 常考动作模板

### 俯卧撑

- 下降：肩水平外展、肘屈曲，胸大肌/三角肌前束/肱三头肌离心，肩袖和前锯肌稳定。
- 撑起：肩水平内收、肘伸展，胸大肌/三角肌前束/肱三头肌向心，前锯肌末端伸出。
- 风险：翼状肩胛、塌腰、肘外展过大、肩前痛。

### 仰卧起坐

- 起身：脊柱屈曲，腹直肌和腹斜肌向心；髋屈肌可能参与。
- 下降：腹肌离心控制。
- 风险：髋屈肌代偿、腰椎反复屈曲负荷过大。

### 深蹲

- 下降：髋膝屈曲、踝背屈，臀大肌和股四头肌离心。
- 起立：髋膝伸展、踝跖屈，臀大肌、股四头肌、小腿三头肌向心。
- 稳定：核心抗屈伸，臀中肌控制膝内扣，足内在肌维持足弓。

### 跑步

- 着地缓冲：髋膝踝屈曲吸收冲击。
- 支撑中期：骨盆和躯干稳定。
- 蹬离：髋伸、膝伸、踝跖屈推进。
- 摆动：髋屈、膝屈伸配合，足背屈准备触地。

## 3. 体表标志速记

| 部位 | 标志 | 用途 |
|---|---|---|
| 肩 | 锁骨、肩峰、肩胛冈、喙突 | 肩复合体定位 |
| 肘 | 肱骨内外上髁、鹰嘴 | 肘关节线、网球肘/高尔夫肘 |
| 腕手 | 桡骨茎突、尺骨茎突、腕横纹 | 腕关节定位 |
| 骨盆髋 | 髂嵴、髂前上棘、坐骨结节、大转子 | 骨盆倾斜、髋肌定位 |
| 膝 | 髌骨、胫骨粗隆、股骨髁、腓骨头 | 髌股、韧带、肌腱定位 |
| 踝足 | 内踝、外踝、跟骨、舟骨粗隆、第5跖骨粗隆 | 踝扭伤、足弓定位 |

## 4. 其他系统整合表

| 系统 | 基本作用 | 运动联系 |
|---|---|---|
| 神经系统 | 支配肌肉、调节反射和协调 | 动作学习、平衡、本体感觉、损伤后控制 |
| 脉管系统 | 血液供应和回流 | 供氧、代谢物清除、恢复 |

| 内分泌系统 | 激素调节 | 能量代谢、训练适应、恢复 |
