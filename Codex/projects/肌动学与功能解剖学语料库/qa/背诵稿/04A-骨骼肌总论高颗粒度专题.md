# 04A 骨骼肌总论高颗粒度专题

适用目标：2026 上海体育大学运动康复考研人体解剖学。

## 1. 逐字稿

骨骼肌总论要从“肌肉是器官”开始背。每块骨骼肌都有肌腹、肌腱、血管、神经和筋膜等结构。肌腹负责主动收缩，肌腱负责把肌力传到骨，神经决定肌肉能否被动员，血供影响代谢和恢复，筋膜影响滑动、包裹和力传递。考试如果只写“肌肉能收缩”，答案会很薄；要写成“结构、功能、工作方式和训练应用”的链条。

肌肉的起点和止点是动作分析的核心。一般把相对固定、靠近身体中心或近端的附着点叫起点，把活动较多、远端的附着点叫止点。但在运动中固定条件会改变，肌肉的作用也会改变。例如腹直肌在仰卧起坐时常以下端相对固定，使躯干屈曲；在仰卧举腿时可以上端相对固定，控制骨盆后倾和下肢位置。所以起止点帮助判断拉力方向，但不能机械背死。

肌肉工作性质主要包括向心、离心和等长。向心是肌肉缩短并产生运动，比如引体向上上拉时背阔肌向心收缩；离心是肌肉在拉长中控制运动，比如深蹲下蹲时股四头肌离心控制膝屈；等长是肌肉长度基本不变但产生张力，比如农夫行走中躯干抗侧屈、肩胛带抗下垂。动作分析题必须写工作性质，否则就只是列肌肉。

影响肌力发挥的解剖学因素包括生理横断面、肌纤维排列、肌肉初长度、肌拉力角、力臂、关节角度、固定条件和神经支配。羽状肌生理横断面大，适合产生较大力量；长梭形肌收缩幅度大，适合速度和活动范围。肌肉过短或过长都会影响力量，初长度合适时力量更好。多关节肌还会出现主动不足和被动不足，是柔韧性和力量训练的高频点。

## 2. 肌肉结构细表

| 结构 | 定义 | 功能 | 训练/康复意义 |
|---|---|---|---|
| 肌腹 | 肌纤维为主的收缩部分 | 主动产生张力 | 肌肥大、耐力和神经动员训练作用于此 |
| 肌腱 | 致密结缔组织连接肌腹与骨 | 传递力量、储存弹性能 | 跟腱、髌腱训练需渐进负荷 |
| 腱膜 | 扁宽肌腱 | 扩大附着、传力 | 腹肌腱膜参与腹直肌鞘和腹白线 |
| 筋膜 | 包裹肌肉和肌群 | 分隔、滑动、传力 | 胸腰筋膜参与核心和背阔肌传力 |
| 血管 | 供血回流 | 提供氧和营养、清除代谢物 | 影响恢复和耐力 |
| 神经 | 运动和感觉支配 | 启动收缩、本体感觉 | 神经损伤会肌力下降或控制差 |

## 3. 命名颗粒表

| 命名依据 | 例子 | 名称提示 |
|---|---|---|
| 形态 | 三角肌、斜方肌、菱形肌 | 形状 |
| 位置 | 冈上肌、冈下肌、胫骨前肌 | 所在部位 |
| 大小 | 胸大肌、胸小肌、大圆肌、小圆肌 | 相对大小 |
| 起止点 | 胸锁乳突肌、肱桡肌 | 附着点 |
| 肌束方向 | 腹外斜肌、腹横肌 | 纤维走向 |
| 功能 | 肩胛提肌、旋后肌 | 主要作用 |
| 头数/腹数 | 肱二头肌、肱三头肌、二腹肌 | 肌头或肌腹数量 |

## 4. 工作性质表

| 工作性质 | 肌肉长度变化 | 功能 | 例子 | 答题关键词 |
|---|---|---|---|---|
| 向心 | 缩短 | 产生或加速运动 | 引体上拉背阔肌 | 主动缩短、克服阻力 |
| 离心 | 拉长 | 控制或减速运动 | 深蹲下降股四头肌 | 控制下放、制动 |
| 等长 | 基本不变 | 稳定和抗运动 | 平板支撑腹肌 | 固定、稳定、抗屈伸 |
| 上固定 | 上端相对固定 | 下端向上端靠近 | 仰卧举腿腹直肌控制骨盆 | 固定条件改变功能 |
| 下固定 | 下端相对固定 | 上端向下端靠近 | 仰卧起坐腹直肌屈躯干 | 同一肌肉功能可变 |
| 无固定 | 两端均活动 | 两端相互靠近 | 两头起 | 动作更复杂 |

## 5. 肌力影响因素

| 因素 | 对肌力的影响 | 例子 |
|---|---|---|
| 生理横断面 | 越大，理论最大力量越大 | 股四头肌、大腿肌群力量大 |
| 肌纤维排列 | 羽状肌更利于力量，梭形肌更利于幅度 | 腓肠肌、肱二头肌 |
| 初长度 | 过短过长都不利，适中最佳 | 深蹲深度影响臀大肌和股四头肌发力 |
| 肌拉力角 | 改变转动分力和加固分力 | 肱二头肌屈肘不同角度力量不同 |
| 力臂 | 力臂越长，转动力矩越大 | 侧平举手臂伸直更难 |
| 关节角度 | 改变肌肉长度和力臂 | 膝关节角度影响股四头肌力矩 |
| 固定条件 | 近端稳定影响远端发力 | 肩胛稳定后手臂推拉更有效 |
| 神经动员 | 影响运动单位募集和协调 | 新手早期力量提升多来自神经适应 |

## 6. 多关节肌专题

| 概念 | 定义 | 例子 | 训练意义 |
|---|---|---|---|
| 单关节肌 | 只跨一个关节 | 肱肌 | 功能相对单纯 |
| 双关节肌 | 跨两个关节 | 股直肌、腘绳肌、腓肠肌、肱二头肌长头 | 功能受两个关节姿势影响 |
| 多关节肌 | 跨多个关节 | 指长屈肌等 | 容易出现复杂代偿 |
| 主动不足 | 多关节肌在所有跨越关节同时缩短，主动张力不足 | 屈腕时握拳力量下降 | 力量训练要考虑关节位置 |
| 被动不足 | 多关节肌在所有跨越关节同时被拉长，限制动作范围 | 直膝屈髋受腘绳肌限制 | 柔韧性训练要分清限制来源 |

## 7. 训练方法框架

| 目标 | 方法 | 例子 | 解剖学依据 |
|---|---|---|---|
| 最大力量 | 大阻力、低到中次数、充分休息 | 深蹲、硬拉、推举 | 神经动员和横断面 |
| 肌肥大 | 中高训练量、接近力竭 | 卧推、划船、分化训练 | 肌纤维机械张力和代谢压力 |
| 肌耐力 | 低中阻力、高次数或长时间 | 平板、墙蹲、循环训练 | 抗疲劳能力 |
| 激活控制 | 低负荷、精准感觉 | 肩袖外旋、腹横肌呼吸 | 神经控制和本体感觉 |
| 柔韧性 | 静态、动态、PNF | 腘绳肌拉伸、胸小肌拉伸 | 肌腱和结缔组织伸展性 |
| 康复进阶 | 等长 -> 向心 -> 离心 -> 弹性/专项 | 跟腱、肩袖、ACL 后训练 | 组织耐受和动作链重建 |
