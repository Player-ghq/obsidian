# 00B 人体解剖学自测题汇总与理解型扩展

适用目标：2026 上海体育大学运动康复考研人体解剖学。

来源范围：`01-12 完整版` 与 `01A-12A 高颗粒度专题`。本文件不是简单摘录原题，而是把每篇末尾自测题统一汇总，并按“知识掌握、理解解释、动作应用、上体大题表达”继续细化。

## 使用规则

1. 闭卷回答，不只说关键词，要说完整因果链。
2. 每题至少按“结构 -> 功能 -> 运动表现 -> 训练/康复意义”组织。
3. 遇到比较题，必须同时写出“相同点、不同点、为什么不同”。
4. 遇到动作分析题，必须写出“动作阶段、关节运动、主要肌肉、工作性质、稳定控制、常见代偿”。
5. 一轮自测只看题目，不看背诵稿；二轮自测看题目后录音复述；三轮把核心题改写成 25 分或 50 分答题稿。

## 答题深度标准

- L1 识记：能说出定义、分类、组成、位置和名称。
- L2 理解：能解释结构为什么产生这种功能，为什么稳定或灵活，为什么容易损伤。
- L3 应用：能把知识迁移到深蹲、俯卧撑、仰卧起坐、跑步、HYROX、日常姿势和康复训练。
- L4 大题：能按上体答题风格，把局部知识写成系统论述题或动作分析题。
