# 01 解剖学总论

## 1. 录音逐字稿

学习人体解剖学，第一步不是直接背某一块肌肉，也不是一上来就背肩关节、膝关节，而是先建立一套描述人体的共同语言。人体解剖学研究的是正常人体的形态结构，以及这些结构之间的相互关系。对上海体育大学运动康复考研来说，解剖学不是单纯记名称，而是要把结构、运动、肌肉、训练和康复意义连成一条线。一个结构为什么长成这样，它能完成什么功能，在运动中承担什么力学角色，受伤后会出现什么问题，这些才是上体大题真正考察的能力。

人体由细胞、组织、器官和系统逐级构成。细胞是人体结构和功能的基本单位；形态相似、功能相关的细胞和细胞间质构成组织；几种组织按照一定方式组合，形成器官；多个器官共同完成某一类功能，就构成系统。比如骨、骨连结和骨骼肌共同构成运动系统；脑、脊髓和周围神经共同参与神经调控；心脏、血管和血液共同参与循环功能。人体不是零散零件，而是多个系统共同维持姿势、完成运动、适应训练和参与康复恢复。

总论中最重要的基础，是解剖学姿势。解剖学姿势是人体直立，面向前方，两眼平视，双上肢自然下垂于身体两侧，掌心向前，双下肢自然靠近，足尖向前。以后说前方、后方、内侧、外侧、近侧、远侧，都是从这个标准姿势出发。哪怕一个人正在跑步、深蹲、卧推、俯卧撑或者倒立，我们描述结构位置和基本方向时，也要先回到解剖学姿势这个共同参考。

常用方位术语要成组记忆。靠近头的一侧叫上方，靠近足的一侧叫下方；靠近身体腹侧或面向的一侧叫前方，靠近背侧叫后方；靠近身体正中线叫内侧，远离正中线叫外侧；靠近躯干或肢体根部叫近侧，远离躯干或肢体根部叫远侧；靠近体表叫浅，远离体表叫深。比如肘关节相对腕关节是近侧，腕关节相对肘关节是远侧；胸骨相对肩关节更内侧，肩关节相对胸骨更外侧；皮肤比骨骼肌浅，骨骼肌比皮肤深。

理解人体运动，要掌握三个基本平面。矢状面把身体分成左右两部分，典型运动是屈曲和伸展。深蹲、硬拉、仰卧起坐、跑步摆腿，主要都离不开矢状面屈伸。冠状面把身体分成前后两部分，典型运动是外展和内收。侧平举是肩外展，开合跳有髋外展和内收，单腿支撑时骨盆抗侧倾也和冠状面控制相关。水平面把身体分成上下两部分，典型运动是内旋、外旋和躯干旋转。投掷、转体、变向、肩关节内外旋训练，都离不开水平面。

和三个面相对应的是三个轴。内外轴从身体一侧指向另一侧，常与矢状面运动配对；前后轴从身体前方向后方通过，常与冠状面运动配对；垂直轴或纵轴沿上下方向通过，常与水平面旋转配对。这里必须背熟一句话：运动平面与运动轴互相垂直。矢状面运动围绕内外轴完成，冠状面运动围绕前后轴完成，水平面运动围绕垂直轴或纵轴完成。

把这句话放进动作里，就能变成答题工具。肘关节屈伸，是前臂在矢状面围绕内外轴运动。肩关节外展，是上臂在冠状面围绕前后轴运动。肩关节内旋和外旋，是肱骨围绕纵轴在水平面运动。躯干向左向右转，是躯干围绕垂直轴的水平面旋转。以后遇到动作分析题，不能只说“手臂抬起来”“身体弯下去”，而要说“哪个关节、在哪个平面、围绕哪个轴、做什么方向的运动”。

基本运动术语要和训练动作绑定。屈曲通常表示相邻骨之间角度减小，伸展通常表示角度增大。屈肘时前臂靠近上臂，伸肘时前臂远离上臂；深蹲下蹲时髋膝屈曲，站起时髋膝伸展。外展是身体部位远离正中线，内收是靠近正中线。侧平举是肩外展，手臂放回体侧是肩内收。旋转是骨段围绕自身纵轴或身体垂直轴转动，比如肩内旋、肩外旋、髋内旋、髋外旋和躯干旋转。

有些部位有特殊术语。前臂旋前，是从解剖学姿势出发，前臂旋转使掌心向后或向下；前臂旋后，是前臂旋转使掌心向前或向上。踝背屈是足背向小腿前方靠近，踝跖屈是脚尖下压或足跟抬起。腕关节向桡骨侧偏斜叫桡偏，向尺骨侧偏斜叫尺偏。足底朝内常称内翻，足底朝外常称外翻。这些术语后面会直接用于踝扭伤、跑步落地、握力训练和农夫行走等分析。

从上体考研角度看，总论的价值不是考一个孤立定义，而是为 25 分和 50 分大题提供表达框架。分析俯卧撑时，要能说出肩关节水平内收或屈曲、肘关节伸展、肩胛骨前伸，以及胸大肌、肱三头肌、前锯肌等肌肉参与。分析深蹲时，要说髋膝踝主要在矢状面屈伸，髋膝伸肌完成站起，核心和髋外展肌帮助维持躯干、骨盆和下肢力线。分析 HYROX 弓步走时，要说下肢以矢状面屈伸为主，同时骨盆和躯干需要抵抗侧倾和旋转。

所以，解剖学总论可以压缩成一条主线：人体由细胞、组织、器官和系统构成；解剖学姿势是描述结构和运动的标准；方位术语确定结构位置；平面和轴确定运动方向；动作分析要按关节、平面、轴、运动方向、肌肉作用和训练康复意义来组织。掌握这条主线，后面背骨、关节、肌肉和动作分析，就不会变成散乱名词，而会变成能直接写进上体大题的答案。

## 2. 知识点骨架

- 解剖学研究对象：正常人体形态结构及其相互关系。
- 上体运康要求：结构 -> 功能 -> 运动 -> 训练/康复意义。
- 人体构成层级：细胞 -> 组织 -> 器官 -> 系统。
- 解剖学姿势：直立、面向前、两眼平视、上肢下垂、掌心向前、下肢靠近、足尖向前。
- 方位术语：上/下、前/后、内侧/外侧、近侧/远侧、浅/深。
- 三个基本面：矢状面、冠状面、水平面。
- 三个基本轴：内外轴、前后轴、垂直轴或纵轴。
- 面轴关系：运动平面与运动轴互相垂直。
- 基本运动：屈曲、伸展、外展、内收、内旋、外旋、环转。
- 特殊运动：旋前、旋后、背屈、跖屈、桡偏、尺偏、内翻、外翻。
- 大题句式：关节 + 平面 + 轴 + 方向 + 肌肉活动 + 力学/训练/康复意义。

## 3. 例子库

- 深蹲：髋膝屈伸和踝背屈/跖屈趋势，主要为矢状面运动。
- 侧平举：肩关节外展，冠状面，前后轴。
- 俯卧撑：推起阶段肩水平内收或屈曲、肘伸展、肩胛骨前伸。
- 引体向上：肩关节内收或伸展，肘关节屈曲，肩胛骨下压和后缩参与。
- 仰卧起坐：躯干屈曲，主要在矢状面完成，可连接上体 2025 动作分析信号。
- 前臂拧毛巾：旋前与旋后交替。
- 提脚尖：踝背屈；提踵和跑步蹬伸：踝跖屈。
- HYROX 弓步走：下肢矢状面屈伸为主，躯干和骨盆抗侧倾、抗旋转。
- 农夫行走：躯干没有明显大幅运动，但深层和浅层核心肌需要等长抗侧屈。

## 4. 易混点

- 解剖学姿势中掌心向前，所以前臂和手部方向判断要回到掌心向前。
- 内侧/外侧看身体正中线，不看观察者左右。
- 近侧/远侧多用于四肢，看离躯干根部近还是远。
- 矢状面把身体分左右，冠状面把身体分前后，水平面把身体分上下。
- 运动平面和运动轴不是同一个概念，二者互相垂直。
- 外展通常是远离正中线，但手指和足趾有特殊参考线。
- 屈伸、收展、旋转必须结合具体关节判断，不能只按肉眼方向判断。
- 肌肉功能不能只背一个固定动作名，要结合关节位置、运动轴和拉力线。

## 5. 考研答题版

人体解剖学是研究正常人体形态结构及其相互关系的科学。人体结构由细胞、组织、器官和系统逐级构成。运动康复专业学习解剖学，不仅要掌握结构名称，还要理解结构与运动、训练和康复功能之间的关系。

解剖学姿势是描述人体结构和运动的标准参考姿势，即人体直立，面向前方，两眼平视，双上肢下垂于身体两侧，掌心向前，双下肢自然靠近，足尖向前。常用方位术语包括上方与下方、前方与后方、内侧与外侧、近侧与远侧、浅与深等。

人体运动常按三个基本平面和三个基本轴描述。矢状面将身体分为左右两部分，屈曲和伸展多发生于矢状面，并围绕内外轴进行；冠状面将身体分为前后两部分，外展和内收多发生于冠状面，并围绕前后轴进行；水平面将身体分为上下两部分，内旋、外旋和躯干旋转多发生于水平面，并围绕垂直轴或纵轴进行。运动平面与运动轴互相垂直。

掌握解剖学姿势、方位术语、运动平面、运动轴和基本运动形式，是进行关节结构功能分析、肌肉功能分析和运动技术动作解剖学分析的基础。答题时可按“关节、平面、轴、运动方向、肌肉活动和功能意义”的顺序组织。

## 7. 上体大题转化

### 25 分可能问法

简述人体解剖学常用方位术语、运动平面和运动轴，并说明其在运动动作分析中的意义。

答题抓手：

- 先写解剖学姿势。
- 再写方位术语。
- 再写三面三轴和面轴垂直。
- 最后用俯卧撑、深蹲或仰卧起坐说明动作分析意义。

### 50 分可能问法

结合具体运动动作，论述常用解剖学术语、运动平面和运动轴在运动技术动作解剖学分析中的应用。

答题抓手：

- 总论：解剖学姿势是共同参考。
- 动作拆分：按阶段写主要关节。
- 关节运动：写平面、轴、方向。
- 肌肉活动：写主动肌、协同肌、稳定肌和收缩类型。
- 应用意义：训练技术、代偿风险和康复评估。

### 失分点

- 只背术语，不会联系动作。
- 把矢状面、冠状面、水平面的分割方向背反。
- 把运动平面和运动轴混为一谈。
- 动作分析只写“弯曲、伸直”，没有关节、平面、轴和肌肉。
