# 提高记忆与减少遗忘的方法

## 核心判断

提高记忆能力的关键不是反复重读，而是让信息经历“主动提取、间隔复现、结构连接、实际使用”。

## 可执行原则

1. 主动回忆优先于重读。
   - 学完后合上资料，用空白纸写出要点。
   - 能从空白处提取出来，才算真正进入可用记忆。

2. 用间隔重复对抗遗忘。
   - 初次学习后，按第 1、3、7、14、30 天复习。
   - 如果闭卷输出失败，提前复习；如果连续稳定正确，可以拉长间隔。

3. 把笔记改写成问题。
   - 不只记录“关节的基本结构”，而要写成“关节的基本结构包括哪些？各自功能是什么？”
   - 复习时优先答题，再看答案订正。

4. 先搭框架，再补细节。
   - 孤立知识容易忘；有上位结构的知识更容易提取。
   - 考研专业课可按“系统功能 → 运动时变化 → 训练适应 → 评定指标 → 常见考点”整理。

5. 用睡眠、运动和专注保护记忆编码。
   - 熬夜会削弱记忆巩固。
   - 学习时减少切换 App 和短视频刺激，避免注意力碎片化。

## 前额叶稳定

前额叶可理解为学习和执行的“总控台”，负责计划、注意力控制、冲动抑制、工作记忆、情绪调节和自我监控。它不直接等于知识储存，但决定知识能否被稳定调用。

保持前额叶稳定的关键是减少过载和即时刺激：

1. 睡眠优先，尽量保证 7-9 小时，并固定起床时间。
2. 学习时减少短视频、消息通知和频繁切换 App，用 25-50 分钟单任务块。
3. 稳定进食和能量，不靠空腹、暴食甜食或过量咖啡因硬撑。
4. 保持中等强度运动和适量力量训练，但避免训练过量影响备考恢复。
5. 把每日学习任务提前写清楚，减少临场决策消耗。
6. 焦虑、烦躁或想逃避时，先用慢呼吸、散步或冷水洗脸降低生理唤醒，再继续处理任务。

判断信号：如果开始频繁刷手机、拖延、暴躁、逃避或学不进去，优先视为前额叶疲劳或状态过载，先恢复状态，再谈自律。

## 25 分钟学习闭环

1. 学 25 分钟。
2. 合上资料，闭卷回忆 5 分钟。
3. 写 3 个自测问题。
4. 第二天再答一遍。
5. 一周后再次闭卷输出。

## 考研使用方式

- 判断掌握度时，不看“熟不熟”，只看“能不能写出来、讲出来、做题用出来”。
- 每个知识点至少保留一个可自测问题。
- 每次复习后记录结果：不会、模糊、熟练。
- “不会”和“模糊”必须进入下一轮复习，不能只靠感觉跳过。
